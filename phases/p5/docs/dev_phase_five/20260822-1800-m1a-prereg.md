## 1. 为什么先做仪器（立项 §5 原文）

第十八轮实测：`D` 中位 **0.01203**，而一个单元 `h/c ≈ 0.041` ⇒ **`D ≈ 0.29 个单元**；
而 `foot_from_field` 取的是**超声速壁面相邻单元的最大质心 `x`**（`run_gs40i:114`，本轮已读）
⇒ **分辨率就是单元尺度**，却被要求分辨 `h/4`。

★★★ **在仪器变得可分辨之前，任何修法起没起作用我们量不出来。**

## 2. 亚单元提取：怎么做

**现行**：`x_foot = max{ 质心 x : 单元超声速且壁面相邻且在站带内 }`。
**改为**：把站带内壁面相邻单元**按质心 `x` 排序**，找**最后一次** `M` 跨过 1 的相邻对，
**线性插值**求 `M = 1` 处的 `x`：

> `x* = x_i + (1 − M_i)·(x_{i+1} − x_i)/(M_{i+1} − M_i)`

★ 落点在**两个质心之间** ⇒ **亚单元**。★★ **只改提取，不碰任何求解**。
