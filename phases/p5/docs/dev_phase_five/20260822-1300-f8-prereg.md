# 20260822-1300 — **第五阶段第六轮**预注册（F8）：库里的 `D-*` 决策 ID **能不能解析**

**性质**：预注册。**在任何普查代码之前提交**。
**执行前置**：[第五轮判定](20260822-1200-f2-verdict.md) §6（F8）。

## 0. 起因与赌注

第五轮发现 `C_L_DEFAULT` 的注释引用 **`(D-CT-2)`**，而**那个 ID 全仓库没有任何定义** ——
它只在**那个值旁边**出现。★ 同时看到 **`D-CT-1` 也只在 `closures.py` 里出现**。

★★★ **留着它的代价是具体的**：下一个人看到 `(D-XX)` 会**以为那是可查的记录**，
而第五轮刚证明那种信任是错的 ⇒ **一个解析不了的 ID 比没有 ID 更糟，因为它假装有出处。**

## 1. ★★ 判据的核心区分（**这是第五轮学到的东西**）

> **"在某文档里出现" ≠ "在那里被定义"。**

GV1.1 的 VERDICT **提到**了 `c_l = 0.09 (D-CT-2)` —— 那是**引用**，不是**定义**：
它没说 D-CT-2 **是什么决定**。⇒ 分类必须把两者分开：

| 类 | 判据 |
|---|---|
| ★ **DEFINED** | 存在一处**说明该决定内容**的记录（表格行 / 小节 / 明确的 "D-XX = …"） |
| ★★ **CITED-ONLY** | 只在**值旁边**或散文里出现，**没有一处说它是什么决定** |
| **ABSENT** | 在 `pyfp3d/` **之外**没有任何出现 |

## 2. 判据

| 判定码 | 条件 | ★ 反向结果落在哪 |
|---|---|---|
| ★★★ **D-RESOLVE** | 枚举 `pyfp3d/` 里**每一个** `D-*` ID，逐个分类 | **全部 DEFINED** ⇒ F2 的 `D-CT-2` 是孤例，F8 干净关闭；**有 CITED-ONLY/ABSENT** ⇒ 逐个列出 |
| ★ **D-COUNT** | RECORDED：ID 总数、三类各几个 | —— |
| ★★ **D-FIX** | ★ **只改注释**：把 CITED-ONLY / ABSENT 的 ID **就地标注为"项目的选择，无记录"**，或**删掉那个假装有出处的 ID** —— 二选一，**逐个说明选了哪个和为什么** | **不改任何值**（F7/F2 先例） |

★★ **本轮不写任何新的设计记录** —— 补写一份 D-CT-2 的"设计记录"等于**事后编造出处**，
那正是第五轮判定所反对的。**能做的只有：如实标注它没有记录。**

## 3. 守卫

**G-FROZEN-VAL**（★ `pyfp3d/` 里**除注释外零改动**，用 `git diff` 逐行证明）、
**G-SENTINEL**（被注释所在行的常数**值逐位不变**）、
★ **G-DEFCITE**（新）：对每个判为 DEFINED 的 ID，**引出那处定义的原文与位置** ——
**不得只报"找到了"**（第五轮正是靠原文才定的性）。

## 4. Kill criterion

1. ★★★ 想为某个悬空 ID **补写一份设计记录** ⇒ 停（事后编造出处）。
2. 改任何值 ⇒ 停。
3. 把"出现过"当成"被定义" ⇒ 停（§1）。
4. > 30 min ⇒ 停。
