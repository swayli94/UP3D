## 2. ★★★ 勘误 3（对 R12 的 P-PRIOR）：`0.027 c` 是**收敛数减非收敛数**

我在 R12 里把它写成"`x_shock` 的线程间散布 0.027 c = 容差的 4.9×"，
**并在勘误 2 里又说了一次"线程 4.9× 引对了"。两次都错。** 逐字取被提交的两行：

| | `converged` | 钳制 | `x_shock` |
|---|---|---|---|
| medium / C=1.5 / seed 5 @**16t** | **True** | 0/0 | **0.6005923629** |
| 同一格 @**8t** | ★ **False** | 0/0 | 0.5737947433 |

⇒ **那 0.027 c 是"一个答案"与"一个非答案"之差**，不是两个答案之间的散布。
把它当散布引用，正是 **GS1.4 禁止的"拿非收敛态的数当结果"**。
★★ **正确的说法**：**两个线程数都收敛的 7 个格上，答案逐位相同**（0.000000）；
**线程数改变的是能不能收敛。**
⇒ **P-PRIOR 整条作废**（种子那半在勘误 2 已作废，线程这半在此作废）。
