## 1. ★★★ 要改什么 —— **一个表达式，Jacobian 一行都不动**

B31 的 Γ-pin 混合行**已经存在**（`newton.py:467-469`）：

```
F = σ·(t·F_raw) + (1 − t)·(s·Γ)          # t = tip_taper, s = kutta_weld_sign
```
`t_j = 0` 时它就是 **`F_j = s_j·Γ_j`，一个到 Γ = 0 的单位斜率 pin**。
对应的 Jacobian（`:599-602`）：`Kt_free = diag(t)·Kp_free`、`Db = t·D + diag((1−t)·s/σ)`。

**改动 = 把 pin 的目标从 0 推广到 Γ_target：**
```
F = σ·(t·F_raw) + (1 − t)·(s·(Γ − Γ_target))
```
| 为什么这是最小改动 | |
|---|---|
| ★★★ **Jacobian 完全不变** | `∂(Γ − Γ_target)/∂Γ = ∂Γ/∂Γ`，`∂Γ_target/∂φ = 0` ⇒ **既有的 FD 测试（`test_blend_jacobian_fd_phi/_gamma`）继续覆盖它，不需要新的 Jacobian 代码** |
| ★★ **默认 `None` 走的是同一段代码** | 用 `if gamma_target is not None` 包住那一项 ⇒ **不是"减 0"，而是字面上同一个表达式** ⇒ 逐位相同不需要论证 |
| ★ **全站 pin 用既有旋钮达成** | `tip_taper = zeros(n_stations)` ⇒ `_taper_active` 为真、混合分支被走、`Kt_free = 0`、`Db = diag(s/σ)` —— **已经正是纯 pin 的 Jacobian** |

★ **不做的事**（写下来免得漂移）：不改消元机制、不改 `kutta_sigma`/`kutta_weld_sign` 的冻结语义、
不动 Picard 路径、不改任何默认值。

## 2. ★★ 怎么对比 —— 二维因子设计（Γ 现在是输入，所以它可分离）

★ **注意**：prescribing Γ **不会消除** Γ 与 `upM` 的物理耦合 —— 它把耦合的方向**倒过来**
（Γ 变成输入、`upM` 变成输出）。**正是这样才能构造出 R18 找不到的那种腿。**

**网格（先在 coarse 上做，0.6–1.5 s/腿）**：`Γ_target ∈ {0, 0.1, 0.2, 0.3, 0.4}` × `M∞ ∈ {0.80, 0.84, 0.86}`
= **15 腿**，α ≡ 1.25 与 C ≡ 1.0 **逐字固定**（只两个轴动）。

| 判定码 | 条件 | 读法 |
|---|---|---|
| ★★★ **P-MATCH（binding）** | 找出 **`upM` 匹配（相对差 ≤ 5 %）而 Γ 不同**的腿对；在这些对里，TE sup 是否随 Γ 变 | **随 Γ 变 ⇒ Γ 是驱动量**；**不随 Γ 变 ⇒ `upM` 是驱动量** |
| ★★ **P-MATCHG（binding）** | 反向：**Γ 相同而 `upM` 不同**的腿对（同 Γ_target、不同 `M∞`） | 同上，从另一侧读 |
| **P-GRID（RECORDED）** | 整张 (Γ_target, M∞) → (upM, TE sup) 表 | —— |
| ★ **P-CONFIRM** | 网格上两个**决定性**格在 **medium** 上复算 | coarse 的结论在 medium 上还成不成立 |

★★ **若 P-MATCH 与 P-MATCHG 给出相反的答案 ⇒ 判 UNDEFINED**，不得挑一个报。

## 3. 怎么测（库改动的验收）

| 守卫 | 内容 |
|---|---|
★★★ **T-IDENT** | `gamma_target=None` ⇒ 重跑 **R14 的 medium/C1.0/s0** 腿，`phi` **逐位**等于缓存（`np.array_equal`），且 `n_limited/n_floored` 相同 |
★★ **T-CONSISTENT** | 取一条**收敛**腿的 Γ\*（R12 medium/C1.5，Γ = 0.17382），以 `gamma_target = Γ*` + `tip_taper = 0` 重解 ⇒ `phi` 与那条腿在**求解器容差内**一致（报 `max|Δφ|` 与 `cl_p` 相对差）。★ **这是最强的一条**：它说 prescribed-Γ 模式与 Kutta 模式在不动点上一致 |
★ **T-PIN** | `gamma_target = 0.25` ⇒ 解出的 Γ 必须 = 0.25（\|Δ\| ≤ 1e-10） |
★ **T-FD** | 既有 `test_blend_jacobian_fd_phi/_gamma` 必须仍绿；**新增**一条：`gamma_target ≠ 0` 时的 Jacobian 与 `gamma_target = 0` 时**逐位相同** |
★ **T-SUITE** | 全套件跑一遍，通过数**只允许增加等于新测试条数**；`pyfp3d/` 的 diff **只允许**是那一个表达式 + 一个可选参数 |
★ **T-BACKPORT**（纪律 #9） | 记录 Picard 侧：**已有 `gamma_fixed`，语义不同**（跳过 Kutta 循环 vs 替换 Kutta 行）⇒ **不需要 backport，但命名差异要记** |

## 4. Kill criterion
1. **T-IDENT 不逐位相同 ⇒ 停并回滚**（`git checkout HEAD -- pyfp3d/`，★ 不用裸 `git checkout --`）。
2. **T-CONSISTENT 的 `max|Δφ|` 大于该腿的求解器容差 ⇒ 停** —— prescribed-Γ 模式与 Kutta 模式不一致就没有实验价值。
3. 改动超出"一个表达式 + 一个可选参数" ⇒ 停。
4. 用到 `fine` ⇒ 停。5. 单腿 > 25 min / 总 > 90 min ⇒ 停（代码内）。
6. ★★ **P-MATCH 与 P-MATCHG 矛盾 ⇒ 判 UNDEFINED，不得挑一个**。
7. ★ **不得**据本轮重判 M1 的门。
8. ★★ **提交前必须做 sentinel 检查**（CLAUDE.md 的库文件交换教训）：从模块 import 新参数名确认它真的在生效，
   并跑一个快测试文件；**不得**在同一会话里做 `git add -A` 之前跳过这一步。

## 5. 事前预测
1. ★★ **T-IDENT / T-PIN / T-FD 全过，T-CONSISTENT 也过** —— 依据：Jacobian 不变、默认分支不变。
   ★ T-CONSISTENT 可以落空（pin 掉 Kutta 行会改变消元的条件数）。
2. ★★★ **P-MATCH：TE sup 在 `upM` 匹配的对里随 Γ 变化很小** ⇒ **`upM` 是驱动量** ——
   依据：R18 的表里 `upM` 从 1.39 跳到 1.98 时 TE 从 0 跳到 2146，**而 Γ 在干净腿里已经覆盖 0.0037–0.2637 的宽范围**
   （若 Γ 是驱动量，干净腿里 Γ = 0.26 那条应该更接近发散）。★ 可以落空。
3. ★ coarse 上 15 腿合计 < 5 min；medium 确认 2 腿 < 30 min。
4. ★★ **coarse 在 `Γ_target = 0.4` 附近才会出现 TE 超声速**（coarse 的 `upM` 基线只有 1.39）——
   ★ 若 coarse 在整个网格上都不出现 TE 超声速，**本轮的对比就要整体搬到 medium**，成本上升，如实记。
