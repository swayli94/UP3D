## 1. ★★★ 定律「err ≈ 0.35·C 个单元」**不符合它自己的数据**

`regular / exact / 收敛` 的两组（h=0.05 全部 `reason=cap` **不可引用**，GS1.4）：

| h | `err_cells`（C = 1.0 / 1.5 / 2.0 / 3.0） | 线性拟合 |
|---|---|---|
| 0.2 | 0.500 / 0.651 / 0.768 / 0.935 | **0.314 + 0.2131·C** |
| 0.1 | 0.551 / 0.684 / 0.804 / 1.038 | **0.315 + 0.2421·C** |

⇒ **有一个约 0.31 的常数项，斜率是 0.21–0.24 而不是 0.35。**

| 用法 | 定律 | 数据 | |
|---|---|---|---|
| 绝对值 @C=1.5 | 0.525 | 0.651 / 0.684 | 定律**低估 1.24–1.30×** |
| **差值 ΔC = 1.5→3.0** | 0.525 | **0.284 / 0.354** | ★★★ 定律**高估差值 1.48–1.85×** |

★★★ **而我在 R22 与综合记录里正是用它算差值** ⇒ **那些算术的定律侧输入是错的。**
★ "在 h 上按单元数近似常数"这**另一半成立**（收敛腿上 0.651 → 0.684，+5 %）；
★★ 而**看起来不成立的那部分（h=0.05 上 err_cells 涨到 0.768）全部来自非收敛腿。**

## 2. ★★★ 绕开公式的 like-for-like 比较（两边都是收敛腿、都以"单元"计）

| | `d(err_cells)/dC` |
|---|---|
| **喷管** regular/exact，h=0.2 / h=0.1（收敛） | **0.2131 / 0.2421** |
| **翼型** medium，ΔC=1.5，Δx=0.01297 c，用 `h_shock` 0.00996 | **0.8681** |
| 同上，用 `V^(1/3)` 0.00664 | 1.3022 |

⇒ ★★ **翼型/喷管 = 3.6× .. 6.1×**（"单元"定义带 1.5 倍不确定度，两个 h 带 1.14 倍）。
★ 更保守的读法：**喷管自己的斜率也随 h 增长**（0.213 → 0.242，h 减半 +14 %），
外推到翼型的 h 会把比值压到 **~2.3×** —— 但那是在**两点趋势上外推 4.3 次减半**，**很弱，如实标注**。

⇒ **无论哪种读法，翼型的 C 敏感度都是喷管的数倍**，而**这个结论不依赖 `0.35·C` 这个公式**。

## 3. ★★★ 侦察里最值钱的一条：**喷管上有"收敛但错 40 个单元"的解**

`start = perturbed`、h=0.1：

| leg | `err_cells` | `converged` | `reason` |
|---|---|---|---|
| regular / perturbed | **39.7 / 40.2 / 40.5 / 41.0** | ★ **True** | **tol** |
| irregular / perturbed | 35.9 / 36.2 / 36.5 / 37.1 | ★ **True** | tol |

⇒ ★★★ **在一个有解析解的案例上，`converged ∧ reason=tol` 的解可以错 40 个单元**
（`err_x ≈ −4 弦长）。**这就是 `C = 1.10` 那一类，而在这里它可以被证明是错的。**

★★★ **于是 R23 的可用性判据有了一个能对着真值验证的试验台** ——
翼型上锚点只能是"共识"，**喷管上锚点可以是解析解**。
⇒ **这是"走喷管"这条路真正的第一价值，而它不在我原来的计划里。**
