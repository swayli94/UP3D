## 1. 本轮做什么：**那些超声速单元贴着什么**

★★ **样本选得比以前好**：用 **`Γ=0.0 / M0.86 / coarse`** —— 它 **收敛、0/0 钳制、`Γ_out` 逐位 0.0、TE sup 325**。
**这是第一次用一个"合法解"而不是发散迭代来看这个结构**（R14 的那条是钳制且发散的）。
★ 第二条：**R17 的 `α=0 / M0.84 / medium`**（2146 单元，末步 0/0），用于跨级别一致性。

**分类**（对 TE 带 `x/c ∈ [0.80, 1.20]` 内的每个单元）：
| 类 | 定义 |
|---|---|
| **WAKE** | 与 `wake_plus` / `wake_minus` 面共享节点 |
| **TE-NODE** | 与后缘节点（`wc` 的 TE 站点）共享节点 |
| **WALL** | 与 `wall` 面共享节点（且非上二者） |
| **INTERIOR** | 以上皆非 |

★★ **G-EXHAUST**：四类必须**穷尽且互斥**，份额和 = 1（断言，R14 的教训）。

## 2. 判据 —— ★★ **每一条都带基率对照**

★★★ 没有基率，"80 % 贴着割缝"在"TE 带本来就有 80 % 贴着割缝"时**毫无意义**（R14 的对照臂教训）。

| 判定码 | 内容 |
|---|---|
| ★★★ **M-ENRICH（binding）** | 每一类的**富集比** = （超声速单元里该类的份额）/（**整个 TE 带**里该类的份额）。**基率来自同一条腿的同一个带** |
| | **判 (a) 割缝**：`WAKE` 富集比 ≥ 2 且其余 < 1.5；**判 (b) 后缘节点**：`TE-NODE` 同上；**判 (c) 无富集**：所有类的富集比 ∈ [0.7, 1.5] ⇒ **不是某个拓扑特征造成的**；其它 ⇒ **UNDEFINED** |
| ★★ **M-CONTROL（binding）** | 在**干净腿**（`Γ=0.0/M0.80`，TE 全亚声速）上算**同一组基率** ⇒ 两条腿的基率必须**基本一致**（相对差 ≤ 10 %），否则"富集"是**带内构成变了**而不是分布变了 |
| **M-LEVEL（RECORDED）** | medium 那条腿上重做，看结论是否跨级别一致 |
| ★ **M-GEOM（RECORDED）** | 超声速单元的**体积/长细比**分位数 vs 带内基率 —— 若它们是**畸形单元**，那是另一条线索（sliver） |
