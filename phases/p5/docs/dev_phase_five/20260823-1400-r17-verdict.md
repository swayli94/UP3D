## 2. ★★★ 脚本的 X-EXCLUDE **撤回**：`α = 0 ⇒ Γ ≡ 0` 是**输出，不是输入**

预注册 §0 写的是：**"对称翼型在 α = 0 上 Γ ≡ 0（对称性）⇒ 尾迹跳跃为零"** ——
**我把它当成了构造上的保证，而它只在解本身对称时成立。**

**实测**：**开火的那条腿（M0.84）Γ = +0.352 = 对照腿 0.798 的 44 %**，
且 `te_sym = 0.0` ⇒ **后缘超声速区 2146 个单元全在一侧** —— **解破坏了问题自身的对称性。**

⇒ **那两条腿不是"强激波 + 零尾迹跳跃"**，于是
**`X-EXCLUDE` 的推理链断在第一环** ⇒ **撤回。本轮既不排除也不支持尾迹耦合。**

★★★ **这正是 CLAUDE.md 四问里的第 4 问**：**"被匹配的量是输入还是输出？"**
`Γ = 0` 是**对称收敛解的输出**，不是我设定的输入 —— 与 σ 那一轮的 `sigma_min` 同族。
★ **而我的判据里没有任何一条守卫检查 Γ。** 前提被"断言"了，没有被"校验"。
⇒ **常设新增：预注册里每一个以"由构造保证"出现的前提，必须配一条守卫去测它** ——
凡"由对称性/由构造/按定义为零"的说法，都要有一行断言。

## 3. ★★ 而撤回之后剩下的东西比原结论更有价值

1. ★★★ **α = 0 这条路在结构上无法隔离尾迹跳跃**：
   要让后缘变超声速就得抬 `M∞`，而**在那些 `M∞` 上解不收敛，且一旦不收敛就破坏对称性、长出 Γ**。
   ⇒ **"强 TE 超声速 + Γ=0" 这个状态在本族上不可构造** —— 这比预注册预测 1
   （"包线内强度不够"）**更强，且理由完全不同**。
2. ★★ **α = 0 在 M ≥ 0.84 上出现寄生环量** —— 能力边界记的 "α=0 近乎唯一（0.0088 c）"
   是 **M0.80** 的读数；**M0.84 起 α=0 自己就有 Γ ≈ 0.35 的对称性破坏**。**这是新的。**
3. ★ **后缘超声速的起始在 M0.82 与 M0.84 之间**（TE max M 0.865 → 1.526）。
4. ★ **M0.84 的 2146 个后缘超声速单元 `0/0` 钳制**（末步）⇒ **那是一个远低于限幅阈值的真实超声速区**，
   不是限幅器的伪影 —— 而 α=1.25 的那团是 max M 29.5 的点发散。**两者峰值差 19×，不得当作同一个结构。**
