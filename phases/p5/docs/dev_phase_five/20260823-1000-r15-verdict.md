## 2. ★★★ L-MECH：**脚本报了"frozen-selection churn"，而数据反驳它** —— 我的判据缺陷

| 指标 | ② 目标（**失败**） | 对照（**收敛**） |
|---|---|---|
| `assignment_cycle` | **False** | ★ **True** |
| `n_freeze_refresh` | **0** | **1** |
| `n_assignment_stale` | **0** | **3** |
| `n_freeze_reverts` | **3** | 1 |
| `n_gmres_stalled` | 0 | 0 |

**四个指标里有三个是"收敛的那条腿更高"。** 而我的 `churn` 判定写成了 **OR** ——
只要 `n_freeze_reverts` 3 > 1 就宣布 churn ⇒ **单个指标越过就盖过了多数指标的反向证据**。

⇒ ★★★ **正确的读法：两种签名都不成立** —— `L-MECH` 应判 **UNDEFINED**。
**失败的那条腿的冻结选择活动比收敛的那条腿更少**，所以
**「limit_cycle ⇒ frozen-selection churn」这条 CLAUDE.md 的映射在这条腿上不被支持。**
★★ 这是本阶段登记的判据缺陷族的又一次：**多指标 OR 合并 = 单边**；
我预注册里**写了**第三支（"两者皆否 ⇒ UNDEFINED"），**而布尔逻辑把它绕过去了**。
★ 修法：**多指标判据必须报多数/逐项方向，OR 只能用于"命中任一即需进一步检查"，不能用于下结论。**

★ 顺带一条读法：`assignment_cycle` 在**收敛**的那条腿上为 True —— 与 CLAUDE.md 一致，
**它是一条 ACCEPT 路由，不是失效模式**（"read the code before naming a mode"）。

## 3. ★★★ 新发现：`n_limited` / `n_floored` 是**末步计数，不是累计**

②（C=3.0/seed 0）报 **0/0**，而它的 `clamp_history` 显示 **第 9–26 步共 3 步发生过限幅**。
⇒ **"0/0 钳制"不等于"从未钳制过"。**
★★ 这对失效分类有直接后果：CLAUDE.md 的表以 `n_limited/n_floored > 0` 作为 clamping 的签名，
而**一条中途钳制、末步恢复的腿会被归到别的模式上**。
⇒ **常设新增：读 `n_limited`/`n_floored` 时必须同时读 `clamp_history`；标量是末步的，历史才是过程。**

## 4. ① 的三问

- ★ **F-CAP-WHERE**：**LE 0.0 % · MID 0.0 % · SHOCK 5.8 % · TE 87.5 % · WAKE 6.7 %**
  —— 与 seed 0 同处（后缘），**而这次尾迹被显式计入**（G-BANDS 断言份额和 = 1，**修掉了 R14 的缺陷**）。
- **F-WHEN**：**capped 第 5–69 步（57 步）、floored 第 19–69 步（51 步）**
  ⇒ **两者共存并同时持续到最后，而 capping 早 14 步开始** ⇒ 落在"**同一次发散的两端**"那一支，
  **且有确定的次序：速度上限先，密度下限后。**
- **F-SEED**（同 C=1.0，只差种子）：seed 0 **1135/0、47 步、max M 29.49**；
  seed 5 **2587/391、70 步、max M 96.30** ⇒ **同一位置（后缘），严重程度 3.3×，并多出 floor 那一半。**
- **F-GAP**（**§0 事前已解决**）：**floored 单元在当前库上定位不了**（`ρ̃` 不返回、workspace 无相关属性）
  ⇒ **CLAUDE.md 的 clamping 签名「and where those cells are」对 `n_floored` 无法执行** —— 一处**被命名的库仪器缺口**，
  ★ 本轮**不**声称测过它。

## 6. 结论与禁止句

**(c) 的两端是两种不同的病，且都不在激波上：**
下端（C=1.0）是**后缘点发散**（两个种子同位置，严重度 3.3× 之差，速度上限先、密度下限后）；
上端（C=3.0/seed 0）是**无发散的振荡**（max M 1.39，后缘零超声速）。

① **不得**说 ② 是"发散" —— `q²/cap = 0.44`；
② **不得**引用 `L-MECH` 的"churn"判定 —— 已被自己的数据反驳；
③ **不得**把 `0/0 钳制`读成"从未钳制过"（§3）；
④ **不得**声称测过 floored 单元的位置（§4 F-GAP）；
⑤ **不得**据本轮重判 M1 的 (c)。
