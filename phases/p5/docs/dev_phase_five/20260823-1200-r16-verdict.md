## 2. ★★★ 判定：**无归因** —— `W-CONFOUND` 按事前预期开火

激波带 max M 跨三腿 **0.9824 → 1.1050 → 2.5483**，散布 **159.4 %**（分母 = min）≫ 注册的 20 %
⇒ **`W-DOSE` 判"不可隔离"**，按 **kill 条 5：不得给出归因。**

★ 决定性的那一支**没有开火**：α=0 是**干净的**（后缘 0.8302、零超声速）——
而那一支（"α=0 已经发散 ⇒ 排除尾迹耦合"）才是**免疫于混淆**的那个。
⇒ **读数与"升力/尾迹耦合"一致，但本轮不能据此归因。** 这正是预注册写死的处置。

## 3. ★★ 而数据指出了**去掉混淆的那个实验**

沿 α 轴出现的是**两种不同的失败**：

| | α = 0.5 | α = 1.25 |
|---|---|---|
| 模式 | **limit_cycle** | **clamping** |
| 后缘 | ★ **完全干净**（0.829，0 超声速） | **29.49，787 超声速** |
| 激波带 | **1.1050**（勉强超声速） | **2.5483** |

⇒ ★★★ **后缘那团东西跟的是"激波强度"，不是 α 本身** —— 而这正是混淆守卫在说的事。

★★ **能去掉混淆的单变量实验：固定 α = 0，抬高 `M∞`。**
对称翼型在 α = 0 上 **Γ ≡ 0**（对称性），**尾迹跳跃为零** ⇒
**"强激波 + 无尾迹跳跃"可以被单独构造出来**：
- 若 α=0 的强激波**也在后缘发散** ⇒ **尾迹耦合被排除**（决定性，免疫混淆）；
- 若不发散 ⇒ **尾迹跳跃是必要条件** ⇒ 升力/尾迹耦合成立。

★ 而它**便宜**：α=0 那条腿只花 **66.8 s**。**登记为 R17，本轮不执行**（kill 条纪律）。

## 4. ★ 两条顺带读数

1. ★★ **`G-CLAMPHIST` 当场付清**（R15 的教训）：α=0 与 α=0.5 的末步标量都是 **0/0**，
   而它们**分别在 1 步与 2 步上钳制过** ⇒ **若只看标量，我会写下"α=0 从不钳制"，那是错的。**
2. ★★ **α = 0.5 是一个不在门里的失败配置**：门只采 **α = 1.25**，而 C=1.0/medium 在 **α=0.5 上也失败**，
   且是**另一个模式**（limit_cycle，后缘毫无参与）⇒ **失败不是 α=1.25 独有的**。
3. **W-COST**：墙钟 66.8 / 324.8 / 1285 s ⇒ 从 α=0 到 α=1.25 是 **19×**。
