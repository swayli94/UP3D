## 2. `n*` 怎么定（★ **和 F1 一样明说是选择**）

第三轮实测（对 `n=96`）：`24` **1.7e-03 ~ 5.2e-03**、`40` 1.4e-05 ~ 2.0e-03、`64` **5.2e-08 ~ 5.5e-04**。
★ **`64` 在最难的状态上仍留 5.5e-04** ⇒ **没有"够用"的小数字**。

**声明的容差**（与 F1 同一条推理）：**低于任何现有锁加在湍流侧量上的最紧带**。
★ 本轮**先量出那个带是多少**（grep `tests/` 里湍流相关断言的容差），**再**据它选 `n*` ——
**不先挑数字**。

★★ **反向结果**：若**没有 `n ≤ 96` 能落到那个带以下** ⇒ **判 W-UNDEF**，
并**登记"高斯不是这里的正确工具"**（近壁层需要**分层/自适应**求积，而不是更多点）——
★ 那会是比"再加点数"重要得多的结论。
