## 1. 要做什么

`bench/usability.py::assess(result, *, consensus=None, ...)` 返回一个记录，字段：
| 字段 | 含义 |
|---|---|
| `converged` / `clamped` | 现有两条（GS1.4） |
| ★ `clamped_ever` | 从 `clamp_history` 读 —— **末步 0/0 ≠ 从未钳制**（R15） |
| ★★★ `anchor_ratio` | `max(cl, cons)/min(cl, cons)`，`cons` = 候选集合法腿的 `cl_p` **中位数** |
| ★★ `usable` | 三者皆过：收敛 ∧ 未钳制 ∧ `anchor_ratio ≤ R` |
| `reason` | 被拒的**具体**原因（不得只给 False） |

★★ **`assess_set(legs, axes)`**：对一组腿求共识并逐条判定，**并强制调用者声明门采样的轴**
（R22 勘误：断言必须跨每一个轴）——**若某个轴上只有一条可用腿，返回的散布判 `UNDEFINED` 而不是一个数**（R13）。
