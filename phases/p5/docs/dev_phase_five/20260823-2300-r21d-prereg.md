## 0. ★★ 可行性与量的定义（开工前核出来的，**精确、不是代理**）

`element_velocity_q2`：`grad(φ)_e = Σ_i φ_i B_e[i,:]`，`q² = |grad|²`（`kernels/gradient.py:41`）。
而 `Σ_i B_e[i,:] = 0`（常数的梯度为零）⇒ **梯度只依赖单元上 φ 的差**：

```
grad_e = Σ_i (φ_i − φ̄_e) B_e[i,:]        S_e = ‖φ_e − φ̄_e‖₂      G_eff,e = |grad_e| / S_e
⇒  log|grad_e| = log G_eff,e + log S_e            （精确恒等式，不是近似）
```

| 因子 | 是什么 |
|---|---|
| **`S_e`** | **解**在该单元上的节点变化（势的量纲） |
| **`G_eff,e`** | **几何/重构**放大（1/长度），上界是 `‖B_e‖_F` |

★★★ **于是"超额"可以加性分解**，**不需要任何阈值，也不需要把响应二值化** ——
这同时修掉 R20/R21-a 承认的设计错 ①（二值化）与 ②（拿输出当预测量）：
本轮**不做分离检验**，做的是**把一个连续量的超额拆成两项**。
