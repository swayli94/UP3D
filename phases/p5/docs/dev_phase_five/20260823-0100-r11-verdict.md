## 2. ★★★ R-J1 的带**有一支不可达** —— 判据缺陷，第一族

**纯噪声（对称分布）的同号率是 50 %。** 而我把"噪声"定成 **≤ 30 %** ——
**那需要反相关，噪声产生不出来。**
⇒ 这条判据**只可能返回"真实斜率"或 UNDECIDABLE**，"噪声"那一支**在构造上不可达**。
**这正是本阶段第一条就登记过的"单边带"缺陷**（"只设想了对照更差的那一侧"），
而我在**为修正另一条混淆判据而新写的判据里**又犯了它。

**用正确的零假设重读**（事后，如实标注）：

| | |
|---|---|
| 实测 | **51 / 91 = 56.0 %** |
| 正确零假设 | **50 %** |
| binomial `p` | **0.147** |

⇒ **与噪声无法区分：J1 的两侧一阶差基本就是噪声，检不出展向斜率信号。**

★★★ **于是第十轮的 "(a) CARRIES IT" 反而站住了** —— 第十轮**自己声明那条判据混淆、判定不得使用**，
