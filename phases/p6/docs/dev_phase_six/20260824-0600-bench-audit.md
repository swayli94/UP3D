## 7. ★★★ 追问：`artifacts/` 还有用吗 —— 它不是没用，**它是一条已经误导过文档的矛盾**

使用者追问：「artifacts 文件夹是不是也没有用了」。分三层回答，因为答案不是「有用/没用」。

### 7.1 事实：它**已经在 git 之外**

| | |
|---|---|
| `.gitignore:45` | `artifacts/` |
| **被 git 跟踪的文件** | ★ **0** |
| 本地实际内容 | **1.8 MB / 22 个目录**（`G1.3` 492K、`G3.2` 184K、`EXPORT_TE_DIAGNOSIS` 136K …） |

⇒ **没有东西可归档，也没有东西可从 git 里删**。本地那 1.8 MB 是**跑测试再生的**，删掉是免费的。

### 7.2 ★★★ 而它作为**规格**是自相矛盾的，而且矛盾已经写进了文档

**规则说它是证据**：

- `CLAUDE.md:569-570`（workflow 规则 1）：「Every visual gate needs a headless artifact
  (`artifacts/<gate_id>/*.png` + `summary.csv`; matplotlib `Agg`, PyVista off-screen —
  **never GUI-only checks**)」
- `README.md:109-110`：同一句，**紧接着下一句**是「A number that exists only in prose is not
  [evidence]」

**而 `.gitignore` 保证它永远不进 HEAD** ⇒ 按纪律 3「**证据需要一个被提交的产物**」，
**这些 PNG 不是证据**。

★★ **两条规则互相否证，而且已经有 11 处活文档把它当证据引用**：

| 位置 | 引用 |
|---|---|
| `docs/design.md:673` | `artifacts/G1.3/` |
| `PROJECT_STRUCTURE.md:1144` | `artifacts/G1.3/` |
| `PROJECT_STRUCTURE.md:1295` | `artifacts/G2.{1..5}/` + 具体读数 |
| `README.md` ×2 · `CLAUDE.md` ×1 · `PROJECT_STRUCTURE.md` 其余 3 处 | 规则本身 |

⇒ **那些路径在任何一个新 clone 里都不存在。** 这与我上一轮查出的 `docs/temp/` 引用
（指向从未提交的 scratch）**是同一族**，但这一族**更系统**，因为它**被写进了 workflow 规则**。

★★★ 而最能说明问题的是 `tests/test_conftest_artifacts.py` **自己的 docstring**：

> 「These tests lock in the fix: artifacts land in the persistent **(gitignored)**
> `<repo>/artifacts/` by default」

**那次修的是「teardown 不再删掉它们」，不是「它们成为证据」。** 修完之后它们仍然只存在于
**跑过测试的那台机器上**。

### 7.3 它的**功能**是真的，而**位置**必须换 —— 而这一条由使用者的新裁决逼出来

`artifacts/` 真正在做的一件事：**强制无头输出**（`Agg` / off-screen），
使一个视觉门**不可能**退化成 GUI 目视检查。**这个功能应当保留。**

★★★ 但**位置必须换**，理由直接来自裁决：C 类与 D 类**要求画图让使用者肉眼检查**
（「要支持画图展示压力分布/力系数对比，让我能够肉眼检查」）——
**如果图是 gitignored 的，那就只有跑过测试的人能看，使用者看不到。**

**而可行的模式已经在跑**：`cases/demo/*/results/` **55 个跟踪文件**、
`bench/studies/*/results/` **238 个**，全库 **292 个 PNG 已被跟踪**。
⇒ 图作为**被提交的证据**这件事，本项目一直在做，只是**没有做在 `artifacts/` 这条路上**。
