## 2. Q2:把改写后的 (a) 拆成两条**可分辨**的子假设

超声速泡前段在动,可以是两件事:

| 子假设 | 机制 | 预测的 Cp 变化量级 |
|---|---|---|
| **前脚在动** | 声速线的前端位置 `x_foot` 逐级移动 | ≈ `\|dCp/dx\|`(在前脚处)× `\|Δx_foot\|` |
| **峰值幅度在动** | 吸力峰的**深度** `Cp_min` 逐级变化 | ≈ `\|ΔCp_min\|` |

★★ **这是量纲一致的归因,不是 5 点相关性**:两条子假设各自**预测一个数**,
把它与**实测的逐站 d_self** 比 —— 谁对得上,谁就是机制。
★ 限定(事前):这是**一维估计**去解释一个三维效应 ⇒ **判据带故意放宽到"2 倍以内"**,
而**两条都对得上**或**都对不上**都是允许的结果。

## 4. 事前判据

**Q1(binding = η0.96 与 η0.99 两站)**

| | 条件 | 判定 |
|---|---|---|
| **O-CONF** | 两站 d_self **均 ≥ 0.373187**(η0.90 的值)**且**两站的 d² 在 **x<0.05** 的集中度 **≥ 1.0** 且质量占比 **> 50 %** | ⇒ ★★ **同一指纹在样本外复现** ⇒ "外侧前缘"那一格获得**独立确认** |
| **O-REFUTE** | 任一站 d_self **< 0.355800**(η0.80 的值)| ⇒ ★★ **向外递增的趋势不延续** ⇒ 上一轮的"外侧"读数很可能是**5 站集在 η0.90 截断**造成的边界效应 —— 这会**削弱**那一格 |
| **O-TIP** | 两站 d_self 更大,**但** x<0.05 的质量占比 **≤ 50 %** | ⇒ 那是**尖端伪影**(taper / P13),**不是**同一机制 ⇒ 不能算确认 |
| **O-MIX** | 其余 | ⇒ RECORDED,不宣称 |

**Q2(5 个未遮蔽站;尖端两站单独报,不进判据)**

| | 条件 | 判定 |
|---|---|---|
| **M-FOOT** | 前脚预测量 / 实测 d_self ∈ [0.5, 2.0] 在 **≥3/5** 站成立,而峰值预测不成立 | ⇒ 机制是**声速线前脚的位置**在动 ⇒ 修法指向 `m_crit` 切换与上风供体选择 |
