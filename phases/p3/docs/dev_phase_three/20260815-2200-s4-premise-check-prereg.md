**几何/工况**:M6 机翼、**S2 级**(h_wall 0.030,59 359 tets,已落盘 φ)、M0.8395 / α3.06 —— 与本阶段前几轮**同一条腿**。

**两个被核实的前提**

| | 前提(第一阶段的数) | 本轮怎么量 |
|---|---|---|
| **P1 成本比** | BL **9×** 无粘(1032 s vs 115 s) | **一次 IBL 求解**的墙钟 ÷ **同一条腿的无粘求解**墙钟(后者取**本阶段已提交 CSV** 的 `solve_s`,同溯源) |

## 3. 事前判据

| | 条件 | 判定与后续 |

| **Q-BOTH** | P1 比值 ∈ [4, 20] **且** P2 ≤ 0.15 | ⇒ ★★ **S4 的"做减法"在 HEAD 上有据**:BL 确实是成本大头,而横流确实没用上 ⇒ **GS4.1(弦向条带二维 IBL)是正确的第一门**,可据此立项 |
