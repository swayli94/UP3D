## 5. 读数汇总(四句话)

1. ★★ **A-SHAPE**:逐级变化的 RMS 由**曲线变形**主导(形状 3/5、水平 1/5),
   而**水平分量的大小正是峰值深度量到的那个**(3/5 站在 2 倍内)
   ⇒ **那 24–88 % 的缺口不是新机制,是"峰值深度按定义只量到一半"**;
2. ★ **bias 七站全正** ⇒ 加密**一致地加深 LE 吸力**;而**各站成分配比不同**(η0.44 纯形状、η0.80/0.99 水平主导);
3. ★★ **B-GEOM**:R_d 只动 **+0.1 %** 而 cl_p 动 **−3.1 %** ⇒ **旋钮活、剖面不动**
   ⇒ **η0.90 见顶是机翼自身的展向结构,不是 taper**;
4. ★★★ **三轮合成出一张自洽的图**:靶子是**前几个百分点弦长内、声速界面的亚单元表示** ——
   与能力边界 §3 首位的"亚单元激波定位"**同族**,位置在**泡的前脚**。
