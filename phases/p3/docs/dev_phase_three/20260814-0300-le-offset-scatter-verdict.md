## 3. 读数:M3 的误差是**两种病**,而它们在**不同的表面上**

- **上表面(LE 上 70.35 % + MID 上 21.05 % = 预算的 91 %)**:**散布**,检测不到偏置
  ⇒ 指向 **壁面恢复 / 刻面几何(G1.6 家族)** —— 与"只剩一条候选"一致,并**收紧**了它;
- **下表面(LE 下 5.02 % + MID 下 0.78 % + TE 下 0.37 % = 预算的 6.2 %)**:
  **真实的、系统性的小正偏置**(计算 Cp 偏高 = 压力偏高/吸力偏少)⇒ 那是**载荷/环量**的签名。

★★ **两条都要说,而不能只说一条**:预算的 **91 % 是散布**,所以**投入应当在 G1.6 那一侧**;
但**下表面确实有一个可测的载荷偏置**,它**小**(≤ 0.025 的 Cp)且**不在预算的大头上**。
⇒ 归因是"**散布主导,叠加一个不在大头上的小载荷偏置**",不是二者之一。
