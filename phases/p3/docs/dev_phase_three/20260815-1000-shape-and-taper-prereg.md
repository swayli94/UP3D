## 1. A —— 把 d_self **本身**做偏置/散布分解

上一轮:`|ΔCp_min| / d_self` = **0.24…0.88**(全 ≤ 1)⇒ 峰值深度是**下界**。
而 `RMS² = bias² + var` 是**恒等式**(本会话已用过一次,并且它自带 **1/n 空洞检查**):

    d_i = Cp_S2(x_i) − Cp_S4(x_i)     （LE 带内、三级公共点集)
    bias = mean(d)      var = mean((d−bias)²)      f_bias = bias²/RMS² ∈ [0,1]

**判读**:
- 若 **f_bias 高**且 **|bias| ≈ |ΔCp_min|** ⇒ 逐级变化是**整条带的水平位移**,而峰值恰好量到了这个位移
  ⇒ **那 24–88 % 的"缺口"不是新机制**,只是"RMS ≥ |mean|"这个恒等事实;
- 若 **f_bias 低** ⇒ 变化是**形状变形**(曲线换了形状,不是整体上下)⇒ **这是第三条子假设**,
  与"峰更深"和"前脚移动"都不同。

★★ **必须与 1/n 比,不与 0 比**(本会话记过的空洞:n=1 时 f_bias ≡ 1)。每站 n = 5–10 ⇒ 1/n ≈ 0.10–0.20。

**事前判据(binding = 5 个未遮蔽站;尖端两站单独报)**

| | 条件 | 判定 |
|---|---|---|
| **A-LEVEL** | f_bias ≥ **0.7** 在 ≥ **3/5** 站,**且** \|bias\|/\|ΔCp_min\| ∈ [0.5, 2] 在 ≥ 3/5 站 | ⇒ **缺口不是新机制**:逐级变化是带内水平位移,峰值量到的就是它 |
| **A-SHAPE** | f_bias ≤ **0.3** 在 ≥ **3/5** 站(★ 且这些 f_bias **高于各自的 1/n**,否则是纯噪声而非"形状") | ⇒ ★★ **第三条子假设成立:曲线在变形** ⇒ 修法既不是"分辨峰"也不是"钉住前脚" |
| **A-MIX** | 其余 | ⇒ RECORDED,不宣称 |

★ 附带必报:每站 `bias` 的**符号**(★ 符号一致 ⇒ 逐级变化有方向;翻转 ⇒ 不是单一位移)、
每站 `n` 与 `1/n`、以及 **f_bias ≤ 1/n 的站数**(那意味着"连位移都测不出来")。

## 2. B —— taper 半径的剂量响应,判据**沿用 W2 已验证的结构**

★ W2 那一轮(2026-08-13)用 `tip_taper` 半径 3 档扫 LE-RMS 的**展向剖面比**,
并测到 **cl_p 动 3.13 % 而剖面比只动 0.15 %** ⇒ 结构可用、且它已经证明这个旋钮**真的进到求解里**。
本轮**照搬那个结构**,只把被扫的量换成 **d_self 的展向剖面**。

**腿**:`taper_rc ∈ {0.025, 0.05(生产,已有), 0.10}` × **S2 与 S4**(d_self 需要一对)。
★ 不扫 r_c = 0(已实测该配置不收敛,不是读数)。

**主量**:`R_d = d_self(η0.90) / d_self(η0.20)`(生产腿已知 = 0.373187 / 0.129873 = **2.873**)。
★ 这个基线**我已经看过** ⇒ 它只作**参照**,判据建在**跨 r_c 的变化量**上(那是未看过的)。

| | 条件 | 判定 |
|---|---|---|
| **B-TAPER** | R_d 随 r_c **单调**,且 0.025→0.10 的**相对变化 ≥ 10 %** | ⇒ **"见顶"由 taper 造成** ⇒ 它是一个**已知模型偏差**的展向印记,而非流动结构 |
| **B-GEOM** | R_d 的相对变化 **≤ 3 %** | ⇒ **不是 taper** ⇒ 见顶是**机翼自身的展向结构**(锥度/后掠/载荷)⇒ 下一步查几何而非模型偏差 |
| **B-MIX** | 介于;或非单调;或收敛腿 < 2 对 | ⇒ RECORDED,不宣称(★ 非单调必须如实报)|

**必须一并报**:三档的**整条 7 站 d_self 剖面**与 **argmax 站**;各腿 `cl_p`
(★ taper 的模型偏差随 r_c 变,**必须与 d_self 一起报**,否则会把"偏差变了"读成"误差变了" —— W2 的原话)。
