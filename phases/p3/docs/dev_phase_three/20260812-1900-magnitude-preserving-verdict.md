## 2. ★★★ 判据的**第四个**缺陷 —— 而这次是**设计上不可能命中**

我用"σ_min 回到 legacy ±0.03"当作"幅度已还原"。**但 σ_min 是收敛态的输出。** 证据:

| eps / q | seed 0 / 5 / 12 的 m1_max |
|---|---|
| **0.00(legacy)** | **1.9522 / 1.8581 / 1.2473** ← 含瞬态尖峰,且**随种子大幅变化** |
| 0.05 / 1.00 | **1.3746 / 1.3208 / 1.3514** ← 尖峰消失,**三种子几乎一致** |
| 0.05 / 0.10 | 1.6694 / 1.3257 / 1.4919 ← 尖峰**部分回来** |

legacy 的 σ_min 0.743 来自 m1_max 1.95 那个尖峰。软化之后尖峰不再被捕获,
所以 **σ_min 变高既因为权重变小、也因为解变了** —— 两个原因叠在同一个数上。
⇒ **"把 σ_min 匹配回去"这个目标在设计上就不可能被稳定命中**,所以 binding 腿必然落 J3。

★★ **这是连续四轮的第四个判据缺陷**:单边带 → 未平衡面板 → 绝对阈值 → **把输出当输入**。
四次都是同一句话:**我写的判据没有覆盖被比较量的性质**。
⇒ 建议升为一条常设检查:**写下任何"把 X 匹配回基线"的判据之前,先问 X 是输入还是输出。**

## 3. ★★ 数据交出的更好归因变量(RECORDED,未注册)

它**不是事后捞出来的**:它就是两轮前机理分析命名的那个东西 ——
**冻结时刻捕获到的激波强度,在种子之间差多少**。

| 配置 | m1_max 的跨种子散布 | cl 散布 % |
|---|---|---|
| legacy(eps=0) | **0.705** | **32.11** |
| eps=0.05, q=1.00 | **0.054** | **4.28** |
| eps=0.05, q=0.25 | 0.077 | 3.99 |
| eps=0.05, q=0.10 | **0.344** | **24.19** |

**cl 散布与"捕获到的 m1_max 的散布"单调对应**(0.705→32 %、0.054→4.3 %、0.077→4.0 %、0.344→24 %)。
⇒ **软化之所以有效,是因为它让"被冻住的那个状态"不再依赖种子** ——
这正是 P-A(冻得太早)的机理,而不是"跳变"或"削弱"任何一个单独在起作用。

★ **但仍然不能宣布归因**:q 同时改变幅度与捕获均匀性(q 从 1 降到 0.1,修正**变强**、
散布**变差**),所以两者在我现有的每一个旋钮下都是**同向移动的**。
**要分开,必须改"捕获"而不改"幅度"。**
