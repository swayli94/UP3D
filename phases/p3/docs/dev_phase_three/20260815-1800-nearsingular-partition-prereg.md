## 0. 要检验的那个解释,以及它**唯一**的可证伪预测

分析给出的机制:**M3 的 LE 带 `x∈[0,0.15)` 把前缘近奇异区算进 RMS**,
而在最细一级、误差最大的 η0.90 站上,已提交的数字是:
**一个壁面单元 ≈ 0.0102 c**、**声速前脚 x_foot(S4) = 0.00405 c**(⇒ 在**第一个单元之内**)、
**最上游的被打分实验点 = 0.00057 c**(⇒ 距前缘 **1/18 个单元**)。
⇒ 在那里流动要在千分之几弦长内从 Cp≈+1 冲到 Cp≲−1.5,**P1 场在一个单元里表示不了**;
加密只把坏区**搬得更前**,不消除它。

★★★ **它的可证伪预测只有一条**:把 LE 带切成**内区(近奇异)**与**外区**,则

- **内区**:不收敛(`R = d_self/e ≥ 1`,与自收敛轮的 N-DISC 同一读法);
- **外区**:**正常收敛**(`R ≤ 1/3`,即 N-MODEL 那一档),像 MID 与 LE 下已测的那样。

★ **若外区也不收敛 ⇒ 我这套解释错了**,而那比"证实"更重要:说明问题**不**局限在近奇异区。

## 2. ★★★ 构造问题必须事前解决:分割点随网格移动 ⇒ 两级点集会不同

**分割点定义(binding)**:`x_split(η) = x_foot(S2, η)` —— **较粗那一级**的声速前脚。
理由:前脚随加密**前移**,所以**较粗级的前脚**囊括了"在**任一**级上属于近奇异区"的全部弦向范围。
⇒ **两级共用同一个分割点 ⇒ 同一个点集** —— 这与两轮前"公共点集"的修法**同一逻辑**(常设第 5 问)。

★ 已提交的 `x_foot(S2)` = **0.01326 / 0.01358 / 0.02514 / 0.02311 / 0.01978**(η 0.20→0.90)。

**并报(非判据)**:`x_split = 2·h_local`(h_local = 该站壁面切向间距/局部弦长)的**敏感性**版本。
★ **判定只看 binding 版本**;敏感性版本**只报**,且**不得**用来改判定 —— 报两个然后挑一个,正是判据缺陷。

**必须一并报**
- 两区的 **e(S2) / e(S4) / d_self / R / n**,以及**逐站**同样五个量(不判);
- ★ **两区的 e(S4)/e(S2) 比**(收敛率)—— 它与 R 是两个不同的读法,**都报**;
- **敏感性版本**(`x_split = 2·h_local`)的同一张表;
- ★ LE **下**表面与 **MID** 上表面的同一分区(**对照组**):它们已被测为"正常收敛",
  所以**它们的外区 R 也应当小** —— ★ 若对照组也给出奇怪的结果,那说明**分区这个工具本身有问题**,
  必须先查工具(这一条是事前写的**工具自检**)。

**守卫**
- **G-R**:全带池化 d_self 必须复现已提交值(**逐位**);
- ★★ **G-I(质量守恒)**:`Σd²(inner) + Σd²(outer) = Σd²(全带)` 到 **rtol 1e-12**
  ⇒ 分区互斥且穷尽,不过就停;
- **G-N**:两区逐站与池化点数全部打印;
- **G-Z**:零求解(沿用已修好的拼接断言)。
