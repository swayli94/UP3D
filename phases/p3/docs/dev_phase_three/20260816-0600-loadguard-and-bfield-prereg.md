## 2. 设计

**腿**:同一进程内 **S2 → S4 → S2r**(重复腿),各**一次 IBL**(`n_outer_max=1`,φ 落盘 ⇒ 无粘零求解)。
★★ **本轮把 U 落盘**(上一轮没存,所以②做不了)—— 纪律:cache before you report。

**② 的 binding 量(未看过):|B| 的空间持久性。**
把每级的节点按 **(x/c 局部, z/b)** 分到 **10×10** 格,取每级 **|B| 最大的 1 % 节点**,
记它们落在哪些格里,算 **重叠系数** `J = |bins(S2) ∩ bins(S4)| / |bins(S4)|`。

★★ **必须同时报零假设**:若两级的热点是**随机**的,`J` 的期望 ≈ `|bins(S2)| / 100`
—— **与 1/n 比较同一手法**(本会话已用过两次)。**判据是 J 相对它的零假设**,不是一个手拍的数。
