## 0. ★★ 入口检查(零求解,先读代码)

| 要读的东西 | 拿得到吗 | 后果 |
|---|---|---|
| 每单元因子 `s`(σ_RH(M₁)) | ✓ `ws.ent._s`(工作区缓冲,保存**最后一次 refresh** 的值) | 直接可读 |
| 累积 σ | ✓ `ws.sigma_frozen`(`refresh_sigma` 存了 `.copy()`) | 直接可读,且是**最终残差用的那一份** |
| **当次用的供体图 `upstream`** | ★ **拿不到** —— `refresh_sigma` 从 `frozen[0]` 或现场走步取,**不存** | 见下 |
| `m1_max` / `n_shock_cells` / `sigma_transport_converged` | ✓ 都在返回字典里 | 用作交叉核对 |
| `ws` 本身 | ✓ `result["workspace"]`(newton.py:1456) | 诊断可在解完之后做 |

★★ **供体图不能"重算"来代替**:`refresh_sigma` 的 docstring 明写,冻结阶段用的是
**freeze 的那份图**,否则用现场走步的图 —— 而"σ 与通量必须共用同一个上游概念"正是它的要点。
在**冻结步**上重算会给出**另一张图**,那样数出来的次数是**错图上的次数**。
⇒ 本轮需要一个**只记录、无数值影响**的存储(见 §1)。

★ **已排除的一个候选机制,证据是现成的**:带激波的供体环会被指针倍增**反复自乘**
(`entropy.py:288-291` 明写这是**故意**留着让状态被拒绝的)。但 σ 输运不收敛时
`accept_reason = "sigma_transport_not_converged"` 且**求解不会被报成收敛**
(`newton.py:1298-1304`),而本轮要测的腿全部 `converged=True` ⇒ **没有带激波的环**。
所以剩下的解释是"**多次彼此不同的跨声速排在同一条无环链上**",而那正是本轮要数的东西。

## 1. 本轮的库改动:**只记录,不改数值**

`NewtonWorkspace.refresh_sigma` 增加一行:把这次实际用的 `upstream` **拷贝存下**
(`self.upstream_sigma = np.asarray(upstream).copy()`)。

- **没有开关**,因此不是旋钮,也没有"用完要删"的问题;
- **没有数值影响**:只是一次 int64 数组拷贝(36k 单元 ≈ 290 KB);
- ★ 它属于项目已有的那条规矩的同族:**σ 的每一个消费者都必须明确并记录它的上游来源** ——
  这次是把"用了哪张图"变成**可查**,而本轮恰好证明了这件事是需要的。

**G2(惰性守卫)**:加了它之后,M1 门默认路径必须与已提交的 8 线程记录**逐位相同**
(12 行 × 14 字段)。不过就停。

## 2. 仪器:一个**与 `transport_sigma` 不共享代码**的暴力预言机

按项目已记的那条硬规矩(**"用独立的 ORACLE 证明内核性质,不要用自己想出来的算例"** ——
当年三个终止判据里**两个错的都通过了我能想到的全部算例**,杀死它们的是一个逐跳走链、
与实现零共享代码的测试):

本轮的走链器**自己**沿 `upstream` 逐跳前进,累乘 `s`,并**同时数** `s < 1` 的因子个数。

**G1(预言机 = 同时也是前提检查)**:走链器算出的乘积必须复现 `ws.sigma_frozen`。
★ **判据是 rtol 1e-12,不是逐位** —— 快算法把同样的因子按**不同顺序**相乘,而乘法不满足结合律
(这是项目记过的、我在写 oracle 时第一次就踩过的两个坑之一)。
★ G1 同时验证了"`_s` 与 `sigma_frozen` 来自同一次 refresh"这个前提;**G1 不过 ⇒ 下面的计数全部作废**。

★ 走链器必须**自带环保护**(跳数上限 = 单元数),并在发现环时**如实报出来** ——
即使 §0 的论证说不该有环,**论证不是测量**。

## 4. 事前判据

**主量** = 每条腿的 **N**:两个口径都报,**事前定死**
(a) `N_at_min` = σ 最小那个单元的链上 `s < 1` 因子个数;
(b) `N_max` = 全场最大的那个计数。判 **(a) 为 binding** —— 它对应的正是撑开散布的那个状态。

| | 条件 | 判定与后续 |
|---|---|---|
| **D1** | 离群腿(σ_min ≤ 0.85)的 `N_at_min` **≥ 5**,且对照腿(σ_min ≥ 0.95)的 **≤ 2** | ⇒ **多重收费被确认为判别量** ⇒ 靶子是**收费规则**(候选:①一道激波作为连通区只收一次;②给沿链累积一个物理上界),另行预注册 |
| **D2** | 各腿 `N_at_min` 相差 **≤ 1**,而 σ_min 相差却很大 | ⇒ **不是次数,是每次的幅度** ⇒ 转向"膝点走步取的 M₁ 偏大"这条线 |
| **D3** | 既不满足 D1 也不满足 D2 | ⇒ **RECORDED,不宣称方向** |

**N2(一致性断言,不是判据)**:实测 `N_at_min` 必须 **≥** `ln(σ_min)/ln(σ_RH(m1_max))`
—— 用返回的 **`m1_max`**(而不是流场 m_max,后者是更松的界)。
★ 若实测 N **小于**这个下界,那么**我的算式或我的走链器有错**,不是物理发现 ⇒ 停下查工具。

**附带 RECORDED(无判据)**:每条腿的 `n_shock_cells`、`m1_max`、`sigma_transport_converged`、
链长分布、以及"被收费的单元里有多少落在**同一条链**上"的直方图。
★ 已有的一条相关读数值得复核:混合 θ=1 上 seed 12 的 `n_shock_cells` = **159 > seed 0 的 153**,
而 σ_min 却温和得多 ⇒ **全局收费单元数不是判别量,排列方式才是**。本轮应当能直接解释它。
