## 0. 入口检查(零求解)

上一轮测到:软化 **同时**做了两件事 —— 去掉跳变 **且** 削弱修正
(σ_min 0.743/0.786 → 0.964–0.980;而 σ 全关时该族 x_shock 0.5605,软化后收拢到 0.52–0.54)。
所以"散布从 32.11 % 掉到 4.28 %"**不可归因**。

**能把两者分开的最小构造**:给权重加一个指数。

    s_i = 1 - (w_i)^q * (1 - sigma_RH(M1))          q in (0, 1]

- `q = 1` **就是上一轮的软化**(所以上一轮是本轮的一条腿,不是被丢掉的工作);
- `q < 1` 把带内的部分权重**推回 1** ⇒ **幅度恢复**,而**连续性不变**;
- ★ **两个端点仍然精确**:`w = 0 ⇒ 0`(不收费,与硬开关同)、`w = 1 ⇒ 1`(全额,与硬开关同)
  ⇒ **F3(默认惰性)与端点单元测试全部继续成立**,`soft_eps = 0` 仍走原分支;
- `0^q = 0` 对任意 `q > 0` 成立,无需特例。

★ **为什么不做"沿链归一化"**(那才是字面意义上的守恒):归一化需要知道整条链,
而 `shock_factor_sweep` 是**逐单元并行**的;把它改成非局部会改动内核结构,
风险与本轮要回答的问题不成比例。**指数形式是局部的、可逐位守卫的,而且足以回答归因问题。**

## 3. 事前判据(主问题:**跳变还是削弱?**)

**主量**:每个 q 上的 (σ_min 均值, cl_p 相对散布) 这一对。**混合族为 binding**(病最重的那一族)。

| | 条件 | 判定 |
|---|---|---|
| **J1 跳变是源头** | 存在一个 q,其 **σ_min 恢复到 legacy 的 ±0.03 之内**(即幅度基本还原),**而散布仍满足 F1′** | ⇒ **去掉跳变本身就够** ⇒ 软化是真正的治法,削弱只是上一版的副作用;进入采纳评估(含 F5) |
| **J2 削弱才是源头** | 随 q ↓(幅度恢复),散布**单调回升**,在 σ_min 还原处回到 **≥ 基线的 1/2** | ⇒ **上一轮 F1 的通过是"削弱"买来的** ⇒ 软化不是治法,这条路要重估 |
| **J3** | 既非 J1 也非 J2(非单调 / UNDEFINED ≥ 2 个 q) | ⇒ **RECORDED,不宣称方向** |

**同时必须报(判据不变,沿用上一轮)**

- **F2**:不得把 P-B 放回来(`selection_churn` 为 False,且收敛腿数不少于 legacy);
- **F3**:`soft_eps = 0` 逐位复现 5 个 legacy 答案;
- **F5**:x_shock 对 M1 的 **0.61 ± 0.02** —— ★ 上一轮它在混合族上 **0/3**,
  本轮若 J1 成立,**F5 必须一并改善才谈得上采纳**;只改善散布不算。
