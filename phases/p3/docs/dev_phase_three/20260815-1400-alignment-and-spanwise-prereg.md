## 1. F —— 对齐检验:变化住在**前脚扫过的区间**,还是**峰值附近**?

上一轮的合成说:**移动中的声速界面让曲线变形**。它有一个**可测的预测**:
逐级差在弦向上应当**与前脚扫过的区间对齐**,而**不是**与峰值位置对齐。

### 1a. ★★ 采样问题必须先解决,而它决定用哪个点集

**前脚扫过的区间** = `[min(x_foot(S2), x_foot(S4)), max(...)]`,上一轮实测宽度 **0.002–0.020 c**。
而 LE 带内的**实验点每站只有 5–10 个**,散布在 [0, 0.15) 上。
⇒ **该区间内很可能只有 0–2 个实验点** —— 与两轮前"声速邻域 n = 0"完全同一个陷阱。

**因此事前定下两种形式,并声明主次**:

| 形式 | 点集 | 用途 |
|---|---|---|
| ★ **主形式** | **计算曲线自身的密网格**(x ∈ [0, 0.15] 上 301 点,两级都插值到同一网格) | 机理问题问的是**解**,不是误差度量 ⇒ 不受实验采样限制 |
| 辅形式 | **实验横坐标**(三级公共点集) | **一致性检查**:密网格结论必须与它**不矛盾**(若矛盾,如实报) |

★★★ **必须声明**:密网格上的差 `D(x)` 与 `d_self` 是**两个不同点集上的量**(常设第 5 问)
⇒ **不得**把 D 的数值与 d_self 的数值混着比;只比**位置结论**。

### 1b. 事前判据(binding = 5 个未遮蔽站)

在密网格上取 `D(x) = Cp_S2(x) − Cp_S4(x)`,记 `x_argmax = argmax |D|`,
以及 `D²` 的**质量重心** `x_cen`。

★★ **两个候选窗口宽度相同**(这是公平性的关键,也是上一轮 CONC_max 缺陷的教训):
设 `w = ` 前脚扫过区间的宽度;窗口 A = 前脚区间**按原宽**;窗口 B = `[x_peak(S4) − w/2, x_peak(S4) + w/2]`。

| | 条件 | 判定 |
|---|---|---|
| **F-FOOT** | `x_argmax` 落在**窗口 A** 内在 **≥3/5** 站,且落在窗口 B 内的站数**更少** | ⇒ ★★ **合成图的预测被证实**:变化与**前脚位移**对齐 ⇒ 靶子确认为**声速界面的亚单元表示** |
| **F-PEAK** | 反之 | ⇒ ★★ **合成图被推翻**:变化与**峰值位置**对齐 ⇒ 回到"分辨吸力峰",而那与分配饱和的结果冲突,需要重新解释 |
| **F-BOTH** | 两窗口都 ≥3/5(它们可能重叠) | ⇒ RECORDED,并**报出两窗口的重叠比例** —— ★ 若重叠很大,这个检验**本身分辨不了**,必须这么说 |
| **F-NEITHER** | 都 <3/5 | ⇒ ★ RECORDED,而**有信息**:变化住在**第三个位置**,报出 `x_argmax` 与 `x_cen` 的实测分布 |

**必须一并报**:每站 `x_argmax / x_cen / 窗口 A / 窗口 B / 两窗口重叠比例 / w`;
辅形式(实验点)在窗口 A 内的点数(★ 若为 0,如实说"辅形式不可用",不当成支持)。

## 2. G —— η0.90 见顶的展向来源(**候选必须都能被否**)

B-GEOM 已把"见顶"指向**机翼自身的展向结构**;W2 已把**局部弦长**测负。
⇒ 本轮把**能零求解拿到的展向量**全部列出,问:**哪一个的展向剖面也在 η0.90 附近见顶并回落**?

★ `d_self` 的展向剖面是**先升后降、在 η0.90 见顶**(0.1299 / 0.2435 / 0.2795 / 0.3558 / **0.3732** /
0.3551 / 0.2682)—— **回落**是它的**特征**,而多数展向量是**单调到尖端**的。
⇒ **判别式 = 谁也回落。**

**候选(全部零求解;φ 与 γ 已落盘,`cut_wake` 不是求解)**:
`Γ(z)`、`dΓ/dz`、局部弦长 `c(z)`、`x_foot(z)`、`|ΔCp_min|(z)`、`Cp_min(z)`、
以及 `Γ(z)/c(z)`(截面升力系数的代理)。

| | 条件 | 判定 |
|---|---|---|
| **G-MATCH** | 至少一个候选的**归一化展向剖面**在 **η0.90 ± 一个站距**内取最大,**且向尖端回落** | ⇒ 命名它;见顶获得一个**几何/载荷**解释 |
| **G-NONE** | **所有**候选都**单调到尖端**(或极值不在 η0.90 附近)| ⇒ ★★ **回落无法由任何现成展向量解释** ⇒ 这是一个**新问题**,如实登记 |
| **G-MULTI** | 多个候选都匹配 | ⇒ RECORDED,并说明**它们彼此相关**(例如 Γ 与 Γ/c)⇒ 这个检验**分辨不出**是哪一个 |

★ 必报:每个候选的 argmax 位置、是否回落、以及**它与 d_self 剖面的形状差**(归一化后按站的最大偏差)。
★★ 而**不做**相关系数:7 个站上的相关系数**没有分辨力**(本会话已两次因小样本相关性被误导)。
