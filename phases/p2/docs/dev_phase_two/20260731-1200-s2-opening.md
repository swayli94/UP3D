## 3. 因此 S2 的实际内容(据测量重写,不是据愿望)

**已经不需要做的**:把二次恢复设为默认(已是现状);球面 max-norm 2% @h=0.08
(P11 证明超出任何 P1 场方法,且 G1.6 已按 Option C 重定并通过)。

**真正的杠杆,来自 P11 自己的对照数据**:P11 测出"**固定 h_min 只加密远场**"能让
壁面 φ 误差降 **3.17×**、阶数恢复到 **1.89**,而单变量 h_min 扫描测到的"阶数崩塌"
其实是**固定体网格的污染地板**。也就是说 —— **壁面精度的杠杆是壁面附近的分辨率,
而且必须与远场一起给**。这正是 **各向异性棱柱层**便宜地提供的东西
(法向拉伸:用很少的单元换很大的法向分辨率)。

⇒ **S2 = GS2.1(棱柱层)+ GS2.3(三维确认)**,而验收应当挂在**产品指标**上:

| 门 | 内容 | 验收 |
|---|---|---|
| **GS2.1** | 壁面各向异性棱柱层生成 + 求解器侧支持(AMG 参数/线平滑) | 球面 + M6 都能生成,质量指标提交;**AMG 迭代数不因各向异性爆掉(< 50)**;球面按**已采纳的 Option C 形式**读(阶数 ≥ 1.8、mean Cp < 1 %),**并额外记录 max-norm 与 P11 的 h_min 0.03 对照** |
| **GS2.3** | 三维确认 = **产品指标 M3** | M6 七站 Cp **RMS < 0.05**(无粘,对已提交实验) |
| ~~GS2.2~~ | **前提已是现状,门作废**(本轮) | — |

**kill criterion(沿用 D2 的裁决,措辞按本轮更新)**:若棱柱层 + 已采纳的 Option C 读数
仍拿不到 M3 的 RMS < 0.05,则**不转 P2**(D2:等参 P2 不采用),
并把"非结构 + P1 在壁面交付量上的能力上限"作为**测量结论**上报,触发半结构贴体网格的讨论。

## 4. ★ 与"激波定位"的关系:同族,但**不是同一段代码**

GS1b.10 §9 给出的战略连接是:激波定位的噪声与 G1.6 同根(不规则四面体上的**逐单元常梯度**)。
**但要说准**:

* `wall_tangential_gradient_quadratic` 是**壁面后处理**恢复 —— 它只修壁面 Cp;
* 激波定位需要的是**体单元梯度**的重构(激波在 x/c 0.6 的体内,不在壁面层里)。

⇒ **S2 现成的机器不会自动修好定位。** 共同的**修法族**是"用重构代替逐单元常梯度",
但落点不同,需要各自的实现。棱柱层能改善的是**壁面附近**的单元形状,
而实测的坏单元(max \|ΔM\| 0.219 的那些)分布在何处**尚未测量** ——
这是一条便宜且值得做的后续:**把离散噪声的空间分布画出来**,
看它是否与壁面层重合。若重合,棱柱层同时是两个问题的修法;若不重合,两者需分别处理。
