# 20260805-2330 — 重新定义门:M1a 从 (coarse, medium, fine) 移到 (xcoarse, coarse, medium)

依据:使用者裁决 2026-08-05(在 [20260805-1200](20260805-1200-m1-remeasure.md) §4b① 提出的三选项里选了
"重定 M1a 到 (xcoarse, coarse, medium)")+ 2026-08-04 的裁决"后续所有测试与 demo 不用 fine"。

**按 roadmap §5:门要改,必须在改之前单独写一轮"重新定义门"的记录并说明理由。本文件就是那一轮,
写在改测试之前。**

## 1. 为什么要改

M1a 的判据定义在 **medium→fine** 上,而 `fine` 已被裁定退出所有测试与 demo。
⇒ 判据依赖一个不再存在的层,必须重定。

## 2. ★★ 先说这个决策的**真实代价**:三条断言一条都搬不过去

NACA0012 2.5-D 的 h_wall 是干净的二倍阶梯 **0.040 / 0.020 / 0.010 / 0.005**
(`cases/meshes/naca0012_2.5d/generate_naca0012.py`),所以收敛比直接给观测阶。
四层 cl 实测(2026-08-05,M0.72/α1.25,全部 0 lim / 0 flr;三个粗层与 seed 无关):

| 窗口 | d1 | d2 | d2/cl_m | ratio | **观测阶 p** | Richardson |
|---|---|---|---|---|---|---|
| **coarse/medium/fine**(退役) | +0.010240 | +0.001593 | **+0.629%** | 0.1556 | **2.68** | **0.255123** |
| **xcoarse/coarse/medium**(新) | +0.020255 | +0.010240 | **+4.214%** | 0.5056 | **0.98** | 0.263707 |

已提交 `RICHARDSON_CL = 0.25511` —— **退役窗口的外推吻合到 5 位**;新窗口外推 **0.263707,偏 +3.4%**。

⇒ **新阶梯不在渐近区**(p ≈ 1,而退役窗口 p ≈ 2.68)。后果,如实列:

| 原断言 | 新阶梯上的实测 | 处置 |
|---|---|---|
| `medium→fine cl 差 < 1%` | **+4.214%** | **搬不过去**,必须换量 |
| `0 < ratio < 0.4` | **0.5056** | **搬不过去** |
| `Richardson 与 0.25511 吻合 1%` | **0.263707(+3.4%)** | **搬不过去,且该窗口的外推不可用** |

★ **这是决策的代价,不是可以调参绕过的事**:两个窗口处在不同的收敛区,粗窗口给不出细窗口那个
级别的陈述。**不允许把 <1% 放宽成 <5% 然后声称"同一条门"** —— 所以下面换的是**量**,并把
丢掉的东西**明写为丢掉**。

## 3. 新判据(在改测试之前固定)

工况不变:**M0.72 / α1.25**(M_max ≈ 1.15,包线内)。阶梯 = **(xcoarse, coarse, medium)**。
记 d1 = cl(coarse) − cl(xcoarse),d2 = cl(medium) − cl(coarse),ratio = d2/d1。

| | 判据 | 实测(包线内) |
|---|---|---|
| **(a)** | 三层**全部收敛**且 **0 limited / 0 floored** | ✓ |
| **(b)** | **单调**:d1 > 0 **且** d2 > 0 | ✓ (+0.0202 / +0.0103) |
| **(c)** | **收缩**:0 < ratio < 0.7 | ✓ **0.5065** |
| **(d)** | \|d2/cl(medium)\| **< 5%** | ✓ **4.22%** |
| **(e)** | 每层 cl 与已提交值一致(rtol 2e-3,原有的漂移锁) | ✓ |
| **(f)** | M_max < 1.25(仍在包线内,原有) | ✓ 1.1537 |

## 4. ★ 判据必须在包线外失败,否则是装饰 —— 已验证

同一三层序列,同一配方,只把 M∞ 换到 **0.80**(包线外,M_max ≈ 1.37):

| | M0.72(包线内) | **M0.80(包线外)** |
|---|---|---|
| 三层全收敛 / 0 clamp | ✓ | **✓ 也全收敛**(靠 2026-08-05 的冷启动回退) |
| cl | 0.222742 / 0.242984 / 0.253237 | 0.296972 / 0.407978 / **0.341340** |
| d1 / d2 | +0.0202 / **+0.0103** | +0.1110 / **−0.0666** |
| **(b) 单调** | ✓ | **✗** |
| **(c) ratio** | 0.5065 | **−0.6003** |
| **(d) \|d2/cl_m\|** | **4.22%** | **16.33%** |

⇒ 判据 (b)(c)(d) **三条都在包线外失败**,而 (a) **不失败** ——
**所以"收敛"这一条不是判别子,单调性才是**,这一点写进判据的注释里,免得后人以为 (a) 在做工作。

★ 顺带一致性:M0.80 的 d2/cl_m = **−16.33%** 与 M1 判据 (b) 的 **−16.2%**(coarse→medium)
是同一个数,两条独立路径量到一致。

## 5. 明确记为**丢失**的东西(不得在别处被静默恢复)

1. **1% 级别的层间一致性**:退役窗口 0.629%,新窗口 4.214%。M1a 从此**不再声称** 1% 级一致性。
2. **Richardson 外推**:新窗口给 0.263707 vs 已提交 0.25511 ⇒ **该窗口的外推不可用**,
   常量 `RICHARDSON_CL` 与它的断言**一并退役**。
3. **退役窗口的读数作为历史测量保留在本文件**(p = 2.68、Richardson 0.255123、d2/cl_m 0.629%,
   2026-08-05 实测,seed = 5),这样"这个求解器在 h 0.02→0.005 上到过 p ≈ 2.7"这件事不因
   退掉 fine 而丢失。★ 它**不是**一条活判据。

## 6. 与 `n_picard_seed` 回退的关系

§4 的 M0.80 medium 那一格能收敛,靠的是同日落地的**冷启动种子回退**
([20260805-2200](20260805-2200-seed-exposure.md))。⇒ **这条重定后的门在包线外的失败方式
是"非单调",不是"不收敛"** —— 比回退之前更干净,因为它测的是**解的性质**而不是求解器是否跑得动。

## 7. 我在本轮的判断

说明这个选择**确实要付代价**(丢掉 1% 级陈述与 Richardson)—— 这一点如实写在这里而不是
藏在实现里。若日后要把那两条捞回来,唯一的路是**在某处保留一个 h = 0.005 的层**
