## 1. 判定:**没有判定**(照预登记执行)

* **D-a**(逐带地板):LE 两带 A ≈ 0、地板集中在 MID(79 %)/TE(18 %) ⇒ **指向模型地板**;
* **D-b**(激波位移,三点已补齐):平均 \|Δ\| **0.0624 → 0.0408 → 0.0239**,
  纯幂律阶 **0.845**,带偏移拟合**退化**(A = −0.30、p = 0.10 = 数据拒绝偏移模型)
  ⇒ **位移奔向零** ⇒ 按预登记那一格:**"地板解释不成立"**。

**两条相反 ⇒ RECORDED,不下结论。**

## 2. ★ 不一致本身的信息(以及我措辞的第三次不准)

**它们量的不是同一件事**:D-a 量**中弦 Cp 的电平**(x/c 0.15–0.85 的 RMS),
D-b 量**激波的位置**。两者可以同时为真 —— 激波走到了对的 x,而该带的 Cp 电平仍有偏差。
**我的预登记把它们当作同一问题的两个读法,这是本会话第三次把措辞写得不够准**
(前两次:G1 用尖端带代理尖端后缘奇点;G1′a 用全局 M_max 代理污染)。
**我记录这个模式,而不是用它来挑一个我喜欢的判别器。**

## 3. 两条证据的强度**不对等**(这一点必须说)

* **D-b 强**:三点、纯幂律拟合良好(阶 0.845),且偏移模型**主动退化** —— 数据在拒绝"有地板";
* **D-a 弱**:三点拟三参数 = **恰定、残差恒为零**,A 的数值**没有任何自由度支撑**。

⇒ **决定性的缺口不是缺一条新判别器,是 D-a 缺点数。**

## 4. 补点(事前登记)

新增 **Tp5:h_wall = 0.020**(在 coarse 0.030 与 baseline 0.015 之间;
h_le = 0.010、h_te = 0.010,即与两端同比例),其余配方逐字不变
(taper vanish_smooth 0.05 b + pressure + 熵修正默认 ON + GV5.3 提取器 + 16 线程)。
规模估计 ≈ 155 k tets(coarse 的 3.4×),预计求解 **1–3 min**。

**四点 ⇒ 三参数拟合变超定(1 个自由度)**,于是可以事前登记:

| 判据 | 结论 |
|---|---|
| 四点下 MID 上的偏移拟合给出 **A > 0.03 且其残差 < 纯幂律残差的一半** | **地板有支撑** ⇒ D-a 站得住,与 D-b 的矛盾成为真问题(那时才需要外部 Euler 参照) |
| **A ≤ 0.03,或偏移模型的残差不优于纯幂律** | **地板无支撑** ⇒ **D-a 被四点推翻**,两条判别器归于一致:**这不是模型地板,是缓慢收敛** |
| 拟合数值不稳(A 随起点跳变) | RECORDED,不下结论 |

**0.03 这个阈值的来由**(事前说明,免得被当成拍脑袋):M3 目标 0.05、当前池化 0.1008;
若 MID 上的地板 ≤ 0.03,则按各带重建的全点地板落到 **0.05 以下** ⇒ 目标在原则上仍可达,
"模型地板挡住 M3" 这个命题就不成立。
