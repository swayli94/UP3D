## 1. 目的与判据(动手前写下)

S2 开篇文件(`20260731-1200`)提出的问题:GS1b.10 §9 把「激波定位」登记为独立问题,
并指出它与 G1.6 同根(**不规则四面体上的逐单元常梯度**);那么 S2 的各向异性棱柱层
是**一个修法解两个问题**,还是只解壁面?这取决于一件**没人测过**的事:**坏单元在哪。**

**判据(事前固定)**:在**光滑亚声速**态(M0.50,全场无一个超声速单元 —— 所以所有跨面
跳跃都是离散噪声而非物理)上取噪声最大的 1% 单元,读它们的**壁距**与**形状**:

* 若是**壁面层群体** ⇒ 棱柱层是共同修法;
* 若在**体内**且跟形状走 ⇒ 修法是重构 / 网格质量,棱柱层**到不了** x/c 0.6 的激波。

## 2. ★ 本轮抓到**我自己指标**的两处混淆(都是数字自己露出来的)

**混淆一(一阶差)。** 第一版用原始跨面 |ΔM| 当噪声,读到壁距比 0.022/0.019,判为
"壁面层群体"。**这个读数是混淆的**,而数字自己给了线索:全体面壁距中位数是 **1.84 弦长**
(计数被远场主导),而真正落在第一层壁面单元里的只有 **4.5%/2.6%**。一阶跨面差 = h·|∇M| + 噪声,
而光滑流场在物面附近 **|∇M| 本来就大** —— 干净的离散在那里也会给出大 |ΔM|。**该指标在任何地方
都分不开噪声与物理,判定作废。**

改用**扣掉光滑部分**的噪声:逐单元做**留一法节点邻域线性拟合**,取本单元与邻域线性趋势的偏差
`dev`,并配一个有界的 Jameson 型比值 `sensor = dev/(|g| + dev + eps)`。(它同时正是"用重构代替常梯度"
那个候选修法本身。)

**混淆二(eps 正则化)。** 新指标给出全局 `rho(sensor, |grad|) = +0.86/+0.88`、
`rho(sensor, 壁面接近度) = +0.80/+0.83` —— 看着像"噪声集中在物面附近的大梯度区"。
**这是我自己的 eps 造出来的**:远场 |g| ≪ eps 时 sensor 被压成 0,于是凭空造出一条单调关系。
**近场对照(d_wall < 1c,那里 |g| 是 eps 的 3–7 倍)把它打掉了**:aspect +0.05/+0.10、
|grad| +0.17/+0.15、**壁面接近度 −0.09/−0.02**。
而且 eps 的影响不止远场:近场离群点有 **38%/47% 落在前缘上游 x<0** 的**弱梯度来流区**。

**因此判定改为只读近场,并加一条"双指标一致性"**:同样两个决策读数在**无正则化**的
绝对偏差 `dev` 上重做一遍(它的偏差是另一种 —— `dev ~ h²|∇²M|` 偏向高曲率区)。
**两个指标一致的结论才算结论;不一致就什么都不结。**

## 3. 结果

| 读数 | coarse | medium |
|---|---|---|
| 超声速单元数(前提) | **0** | **0** |
| sensor 中位 / p99 / max | 0.045 / 0.461 / **0.692** | 0.026 / 0.405 / **0.850** |
| sensor > 0.5 的单元数 | **84** | **60** |
| 最噪 1% 在第一层壁面单元内 | **1.8 %** | **0.6 %** |
| 近场 rho(sensor, 壁面接近度) | **−0.091** | **−0.017** |
| **双指标** rho(dev, 壁面接近度) / 层内占比 | **+0.102 / 6.8 %** | **+0.098 / 6.8 %** |
| 壁面层问题:两指标 | **一致** | **一致** |
| 形状富集(sensor / dev) | 8.1× / **0.0×** | 5.4× / **0.0×** |

**(a) 稳健结论 —— 噪声**不是**壁面层群体。** 两个指标一致:近场内**没有**朝壁面增强的趋势
(ρ 分别 −0.09/−0.02 与 +0.10/+0.10,都远低于 0.3 判据),最噪单元只有 **0.6–6.8%** 落在第一层。
⇒ **棱柱层只买壁面精度,不解决激波定位。** S2 开篇文件那条"不会自动修好"的提醒,现在有了测量支撑。

**(b) 形状:两指标不一致 ⇒ 不作归因。** sensor 上近场富集 8.1×/5.4×,`dev` 上 **0.0×**。
所以"坏形状单元造成噪声"**没有稳健证据**。这**加强**了 GS1b.10 §9 那条 proof-shaped 障碍:
**你无法靠找坏四面体来找出虚假激波检测** —— 现在这句话有数字了(而且横跨两种噪声定义)。

**(c) 定位问题被直接测到了。** 在一个**完全光滑、零超声速单元**的流场上,一个阈值无关的
Jameson 型传感器在 0.5 阈值下会在 **84 / 60** 个单元上"发现激波"。
而且**加密不杀掉最坏的那些**:max 0.692 → **0.850**(变差),数量 84 → 60、占比 0.51% → 0.10%
(变好)。**重尾** —— 与 GS1b.10 测到的"下降慢于 O(h)"一致。

**(d) 它们在哪(记录,含 (b) 的保留)。** 近场离群点:38%/47% 在前缘上游 x<0(部分是 eps),
17%/18% 在 x∈[0.4,0.8) 但**全部在 |y| ≥ 0.2**;联合条件"x∈[0.4,0.8) 且 |y|<0.2"= **0.0%** 两级皆然。
即**最坏噪声与贴着物面的超声速泡不共位**。⚠ 这是 M0.50 光滑态的读数,
**不能**直接外推成"跨声速时虚假检测不落在激波上" —— 那需要在跨声速态上测。

## 4. 对 S2 与登记项的影响

1. **GS2.1(棱柱层)照做,但它的收益范围被定死了**:壁面精度(M3 的 Cp),**不含**定位。
2. **登记项 1「激波定位」的修法方向被本轮收窄**:它是**体内**的问题,修法是
   **体单元梯度重构**(与壁面后处理恢复不是同一段代码),且**不能**用"坏形状单元"当靶子选择器。
3. **对 GS2.3 的告警**:加密让**最坏**噪声变差(0.692 → 0.850)。M3 的 RMS 指标是池化量,
   可能通过;但任何 max-norm 型判据不要指望靠加密拿到。
