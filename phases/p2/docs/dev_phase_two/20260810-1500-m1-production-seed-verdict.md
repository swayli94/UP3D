## 3. ★ 顺带测到的一件关于回退覆盖面的事

medium 的 **C = 3.0 / seed = 0** 腿是 **`limit_cycle`、`0 limited / 0 floored`**,
而回退的触发条件是 **`clamped`** ⇒ **它按构造碰不到这条腿**。

**回退治钳制型失败,不治极限环型失败** —— 而 (c) medium 之所以"无法评估",正是因为这条腿。
