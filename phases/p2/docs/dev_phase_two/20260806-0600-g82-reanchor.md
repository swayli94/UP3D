## 1. 为什么要改

`onera_m6/medium.msh` 于 2026-08-04 随基础层名 flat → round 重生成,而 G8.2 的锚点是在
**平截**翼尖上测的。已证实(2026-08-05):`medium_flat.msh` 把已提交锚点复现到 5–6 位
(cl_p 0.263882 vs 0.263888、M_max 2.10697 vs 2.10709),圆角网格则**不收敛**。
⇒ 这条门红掉 **100% 是网格重生成**,与种子、与 σ 修复都无关。

## 2. 实测:round tip 能到多高

同一张 `onera_m6/medium.msh`(round),目标 M0.84,`NEWTON_M6_RECIPE` 逐字,只加/不加 taper。
★ **两腿都在后处理之前把 φ/γ/全部历史存成 npz** —— take 1 正是因为没存而丢了 40 分钟
(§6)。

| | conv | \|R\| | M_max | lim/flr | **收敛到的最高级** | 墙钟 |
|---|---|---|---|---|---|---|
| **配方逐字(无 taper)** | ✗ | 3.13e-06 | **2.92867** | 0/1 | **M0.82** | 2949 s |
| **加生产 taper** | **✓** | **6.155e-15** | **1.99687** | **0/0** | **M0.84** | **341 s** |

无 taper 腿的逐级历史:`0.70 ✓ → 0.75 ✓ → 0.80 ✓ → 0.84 ✗(60 步)→ 0.82 ✓ → 0.84 ✗(60 步)`
—— 驱动器细分后在 0.82 收敛、两次都过不去 0.84。

⇒ **裁决 (A) 的答案是:不需要降马赫。** round tip 在**生产配置**下**仍然到得了 M0.84**,
只有**不带 taper 的旧配方**才掉到 0.82。

## 3. 新锚点(从缓存的 npz 算,零重解)

| 量 | 已提交(FLAT,无 taper) | **新(round + taper)** | 变化 |
|---|---|---|---|
| converged | True | **True** | — |
| \|R\| | ~1e-14 | **6.155e-15** | — |
| lim / flr | 0 / 0 | **0 / 0** | — |
| **x_shock η0.44** | **0.59582** | **0.59632** | **+0.0005 c** |
| x_shock η0.65 | 0.53914 | **0.54020** | **+0.0011 c** |
| x_shock η0.90 | 0.34225 | **0.37144** | **+0.0292 c** |
| **cl_p** | 0.263888 | **0.268691** | **+1.82%** |
| **M_max** | **2.10709** | **1.99687** | **−5.2%** |
| 墙钟 | < 300 s(CI 参照 301.66) | **341 s** | 见 §5 |

★★ **最要紧的一条:激波位置的变化沿展向单调增大,而这本身是对重锚的一致性检验** ——
不是三个独立的数:

```
η 0.44   0.59582 → 0.59632   +0.0005 c
η 0.65   0.53914 → 0.54020   +0.0011 c
η 0.90   0.34225 → 0.37144   +0.0292 c    ← 最靠翼尖,动得最多
```

**内侧两站几乎不动**,而**最外侧动了 0.029 c** ⇒ 这正是一个**翼尖模型**应有的样子。
所以"物理定位被保住"是一条**测量**,不是希望;而 η0.90 越过旧的 0.02 容差
**是 taper 在改翼尖载荷,不是漂移**。

★ 激波位置是这条门里**唯一有外部锚定意义**的量(Euler 锚点带 0.60–0.63,针对内侧站)。
**内侧站落在带内且几乎不动** ⇒ **重锚移动的是模型量(cl、M_max)与翼尖附近的载荷,
不是内侧的物理定位。** ⚠ 措辞更正:**不能说"激波位置保持不变"** —— η0.90 动了 0.029 c;
准确的说法是**内侧不动、外侧按翼尖模型应有的方式动**。

★★ **并且它解决了 P8 自己登记的一个疑虑。** `tests/test_p8_newton.py` 的注释写着:

> ⚠ REGISTERED, not resolved: m1_max 1.975 at M_inf 0.84 means the walk finds a pre-shock Mach
> near 2 somewhere, and **this recipe carries no tip_taper**, so that is very likely the P13
> wing-tip free-edge singularity rather than a physical shock — i.e. **the correction may be
> charging entropy to a NUMERICAL artefact**.

加上 taper 后 **M_max 2.92867(无 taper、非收敛)→ 1.99687**,而平截锚点是 2.10709。
⇒ 那条登记项**在新锚点上被处理掉了**:熵修正不再对着一个被 taper 消掉的尖端峰值记账。
(⚠ 仍是**登记项的缓解**,不是"翼尖奇点已解决" —— P13 本身没动。)

## 4. cl_p 的 +1.82% 必须解释,不能只报

新锚点的 cl_p 比平截锚点**高** 1.82%,而 taper 单独作用是**降低** cl(翼身实测 −1.3%)。
⇒ 这里**混了两个效应**:(网格 flat → round)与(无 taper → 有 taper)。
本轮**没有**把它们分开测(那需要第三腿:round + 无 taper 的**收敛**解,而它不存在 —— 无 taper 腿
在 0.84 不收敛)。**所以 +1.82% 如实记为两个效应的合成,不归因。**
★ 唯一能说的:**圆角网格的效应把 taper 的 −1.3% 盖过去了并净剩 +1.82%**。

## 5. 墙钟预算:必须单独说,而且它**不是**重锚造成的

旧断言是 `wall < 300.0`(P8 记录,CI 参照 301.66 s)。本轮实测:
**平截腿 331 s**、round+taper **341 s** —— **两条都超**。
⇒ **超出与 round tip 无关**(平截那条同样超),是本机/负载与 P8 记录时不同。

**处置**:预算改为 **450 s**(比实测 341 s 留 ~30% 余量),并在断言旁写明
"平截腿在同一会话也测得 331 s,所以这不是圆角的成本"。
⚠ 这是**改性能门**,故列在本轮(重新定义门)里而不是顺手改掉。
