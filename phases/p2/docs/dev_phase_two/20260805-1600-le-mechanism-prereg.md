# 20260805-1600 预注册 — 任务 4:LE 那 70% 的亏空,是 **LE 局部**的,还是**周围网格的污染地板**?

**执行前提交。** 本文件在写任何测量代码之前写完并提交;下面的判据、阈值、守卫、
以及"什么结果算路走不通"都以本文件为准,**事后不得放宽**(roadmap §5)。

## 1. 为什么问这个问题

M3 的误差预算(20260731-1800 实测,medium):**LE 上表面占 69.6%**、MID 上表面 20.7%、
其余 9.7%。它是现在**最大的、且不属于粘性的、且没有已排除结论的**亏空 ——
Kutta 形式已否证(20260801-0030,用**看数字之前写下**的规则)、几何已排除
(L0p 与 L0 逐位相同)、地板判定说 MID/TE 的地板是**模型**的但 **LE 带收敛到零**(阶 0.709)。

而现有证据里有一个**尚未被利用的组合**:

| 加密方式 | LE 上 RMS 的响应 |
|---|---|
| **只加密 LE**(GS2.1 四腿) | **最好 −8.3%,而且非单调**(LE×4 的 0.2214 比 LE×2 的 0.2165 更差) |
| **全尺度加密**(h 0.030/0.020/0.015/0.010) | **单调 0.3899 → 0.2704 → 0.2358 → 0.1758**,阶 **0.725** |

**"对全尺度响应、对本地不响应"不是矛盾,而是一个签名。** 它正是 P11 在球面上**测出来**的
那个机制:单变量 h_min 扫掠会撞上**固定体网格的污染地板** —— P11 的原话是,在固定
h_min = 0.03 下**只加密远场**,壁面 φ 误差掉 **3.17×**,argmax 从 r = 1.53 移回壁面,
阶数恢复到 **1.89**。GS2.1 自己的脚本头也写了这个顾虑("a single-variable refinement can
hit the bulk pollution floor"),并为此加了 L3p 全尺度腿 —— 但 **L3p 不收敛**
(\|R\| 1.0e-05、M_max 3.1330),所以那一腿**不是读数**,这个顾虑至今**没有被测过**。

⇒ 缺的是**镜像那一臂:把 LE 之外的一切都加密,而 LE 分辨率按住不动。**

## 2. 设计:一个完整的 2×2 因子,而且放在便宜端

GS2.1 只做了"LE-only"一臂,所以它的负结果**无法归因**。本轮做**完整因子**:

| 腿 | h_wall | h_le | 含义 |
|---|---|---|---|
| **F00** | 0.030 | 0.015 | 控制(基线) |
| **F10 bulk-only** | **0.020** | **0.015**(按住) | 只加密 LE 之外 |
| **F01 le-only** | 0.030 | **0.010** | 只加密 LE |
| **F11 all-scales** | 0.020 | 0.010 | 两者都加密 |

`h_te`、`h_wake = 3·h_wall`、`h_far = 120·h_wall` 随 `h_wall`;`h_le` 与 `h_te`
**分开传**(GS2.1 addendum #1 的教训:`h_edge` 同时管 LE **和** TE,不分开就会读到
P13 尖端奇点而不是 LE)。

**为什么放在便宜端**:这一对(0.030 → 0.020)的全尺度效应**已经测过 = −30.6%**
(0.3899 → 0.2704),而两级的求解成本是 **7 s 与 61 s**(vs 全尺度 h 0.010 的 **4011 s**)。
所以整套 2×2 是分钟级,而不是小时级 —— 便宜判据先行(原则 3)。

**同问题重复(第二个因子)**:0.020 → 0.015(全尺度已测 −12.8%,0.2704 → 0.2358),
四腿约 9 分钟。它检验答案**不是便宜端特有的**。⚠ 若两个因子给出**不同**的答案,
本轮结论只能按**较细**那个写,并把便宜端标注为不可外推。

## 3. 事前判据(数字在此固定)

参照量:同一对 h 上的**全尺度**效应 **−30.6%**(因子 1)/ **−12.8%**(因子 2)。

| | 条件 | 结论 |
|---|---|---|
| **P(污染)** | **F10 的 \|ΔRMS\| ≥ 全尺度效应的 60%** | LE 亏空**主要不是 LE 局部的**,是周围网格的污染地板 ⇒ **S2 的靶子从"LE 处的棱柱层"改为体网格质量**,并与 P11 的球面机制合并为同一条 |
| **N(否证)** | **F10 的 \|ΔRMS\| < 10%**(与 LE-only 的 −8.3% 同量级) | **污染假设也被否证** ⇒ LE 亏空既非 LE 局部、亦非体网格污染;那么全尺度的 0.725 阶必来自**第三者**(候选:尖端/taper、远场半径、尾迹),需要新一轮 |
| **I** | 介于两者之间 | **RECORDED,不下结论**(按 20260801-2000 的先例,宁可不下) |

**加法性检查(附带读数,非判据)**:若 |ΔF10| + |ΔF01| ≈ |ΔF11|,两个方向近似独立;
若 F11 明显小于两者之和,存在饱和 —— 记录,不作判定。
