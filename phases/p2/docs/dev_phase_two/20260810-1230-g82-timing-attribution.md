## 4. 我这一轮的两个错

★ **第一处归因不完整,已当场更正**:我先把 588 s 归给"机器负载",但 bench 脚本在
**同样的负载**下只用 109 s ⇒ 负载解释不了 5 倍。**真正的变量是线程帽**

归因,就不该先说出口** —— 正确的顺序是先做那个对照。

★ **又踩了 `pgrep -f` 匹配自己的命令行**(设定里明写的操作风险):等待循环写成

就含那个串** ⇒ 永远匹配到自己,快层早就跑完了它还在转。按设定应当**按 PID 杀 / 轮询日志的
完成标记**,不要轮询进程表。
