## 2. 按预注册判:**RECORDED**

判据 P 要求 `Δ_LE(G10) ≥ 0.60 × Δ_LE(G11)`,而 **G11 按 G2 不可用**
(M_max **恰好 3.0** = `m_cap`,224 限幅 + 49 floor,\|R\| 5.3e-03)。
分母不存在 ⇒ **P 与 N 都无法评估 ⇒ RECORDED,不下结论。** 照办。

★ **这已经是第二次被同一件事挡住**:第一版在 M0.8395 上三腿撞帽,本轮把工况降到 M0.75、
把体网格臂换成 `h_far`,**单臂都能过,但两臂一起就撞帽**。M_max 的剂量-响应很干净:

```
基线 1.6783  →  只加密远场 1.9881  →  只加密 LE 2.0611  →  两者都加密 3.0000(撞帽)
```

⇒ **"加密把峰值马赫推向限幅器"不是 M0.8395 特有的现象**,它在 M0.75 上一样存在,
只是需要**两个方向一起**才越过帽子。这条本身是新的阻塞性读数。

## 3. 但三条可读腿说了什么(**未登记的读数**,标注为未登记)

预注册要求 P 必须同时满足三件事;其中**两件已经满足**,只缺归一化那一件:

### (a) 污染上界:远场那 0.37% 的 LE 污染**解释不了** ✓

| | 值 |
|---|---|
| G10 对 LE 带 h_t 的改动 | **0.37%**(0.006747 → 0.006722) |
| G01 对 LE 带 h_t 的改动 | **26.1%**(→ 0.004985) |
| 倍数 | **70.6×** |
| 线性外推的污染贡献 | 0.14332 × (0.37/26.1) = **0.00203** |
| addendum #2b 的上界(×5 余量) | **0.01015** |
| **实测 G10 的 LE 位移** | **0.10349 = 上界的 10.2 倍、裸估计的 51 倍** |

★ **仍然不能声称"G10 是干净的"** —— G1 已 FAIL,只能声称:**它的 LE 位移比它自己的
LE 污染按线性外推所能解释的量大一个数量级以上**。⚠ 线性性**是一个假设**(addendum #2b
明写),这里按约定标为假设,不当成测量。

### (b) 对照条款**未触发** ⇒ 是 **LE 特有的**,不是全局位移 ✓

| | Δ / Δ_LE |
|---|---|
| MID 上 | 0.01757 / 0.10349 = **0.170** |
| TE 上 | 0.00847 / 0.10349 = **0.082** |

判据的触发线是 ≥ 0.80。实测 0.17 / 0.08 ⇒ **远场加密对 LE 带的影响是对 MID 的 6 倍、
对 TE 的 12 倍**。**远场不是把整条曲线平移,它专门动前缘。**

### (c) 缺的那一件:归一化

只有 `Δ_LE(G11)` 不可得。**不替换判据**(那是事后改门),但如实记下**替代比较**:
`Δ_LE(G10)/Δ_LE(G01) = 0.10349/0.14332 = 0.722` —— 远场臂的效果是 LE 臂的 **72%**,
而它动的 LE 网格少 **71 倍**。这个比较**没有登记**,所以它**不是判定**;
它是下一轮该登记的量。
