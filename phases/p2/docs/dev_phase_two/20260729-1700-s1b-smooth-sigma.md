## 1. 目的：一个靶子，两个症状

GS1b.3 的判据 E 与 GS1b.3b §7.3 已经测出这是**同一个对象**：

| 症状 | 实测 |
|---|---|
| **E：σ 刷新不收敛** | 一个单元在"激波后"集合里反复进出（n_shock 73 ↔ 74），`max|Δσ|` 钉在 **2.9e-2** 不降，残差停 5e-6；靠把刷新封顶到 8 次才收得动 |
| **§7.3：M₁ 状态间不稳定** | fine 走 0.005 的马赫步，相邻状态 M₁ 跳 **1.26–1.49**、σ_min 跳 **0.932–0.986**（5.4 个百分点）；收敛目标态上却是干净的（1.271/1.347/1.352） |

共同根因：**σ 的构造里每一步都是硬判断**——

1. "激波后单元" = `供体超声速 AND 自己亚声速`（两个硬阈值，M = 1 处不连续）；
2. 向上游走的停止 = `上升 < knee_frac × 迄今最大上升` 就 `break`（硬比较）；
3. 走出气泡的停止 = `M² ≤ 1` 就 `break`（硬阈值）。

三处都是"状态动一点点、结果跳一跳"。所以修法不是加松弛，而是**把每一个硬判断换成
光滑过渡**，让 σ 成为马赫场的连续（且分段光滑）函数。

★ 这也直接服务于下一步：只有 σ 光滑，把 ∂σ/∂φ 纳入 Jacobian 才有意义（现在它几乎处处
为零而函数本身在跳，求导毫无用处）。

## 2. 做法（写在动代码之前）

单一光滑宽度 **`eps_m`（马赫单位）**驱动全部三处，用同一个 smoothstep：

```
ramp(t) = 0                t <= 0
        = t^2 (3 - 2t)     0 < t < 1      (C^1，两端导数为 0)
        = 1                t >= 1
```

1. **激波后的软指示**：`chi = ramp((M_u - 1)/eps_m) * ramp((1 - M_e)/eps_m)`，
   局部因子 `s_e = 1 - (1 - sigma(M1)) * chi`。硬版本是 chi ∈ {0,1}；软版本让 M = 1
   附近的单元携带部分熵，于是"73 ↔ 74 的翻转"变成一个连续变化的权重。
2. **膝点的软停止**：不再 `break`，而是给每一跳一个门
   `g_k = ramp((r_k/R - f_lo)/(f_hi - f_lo))`（`R` = 迄今最大上升），
   累计权重 `w_k = prod_{j<=k} g_j`，M₁ 取**加权平均** `sum w_k M_k / sum w_k`。
   走出结构后 g → 0，其后所有单元权重自然趋零。
3. **气泡边界的软停止**：把 `M² <= 1` 的 break 换成同一个 `ramp((M-1)/eps_m)` 乘进 `w_k`。

**旋钮**：`eps_m`（默认待定，见 §3 的敏感性要求）、`f_lo/f_hi`（膝点软带，替代
`knee_frac`）。三个都必须给出**实测敏感性**和**删除条件**，否则不算完成。

## 4. 改了什么

### 5.1 重新诊断：σ 继承了**供体图自己的 churn**

光滑我自己的判断不管用，说明不稳定不在那些判断里。直接量供体图：
相邻马赫步（同一延拓链）之间有多少单元换了供体？

| | 单元数 | 换供体的单元 | σ_min 的变化 |
|---|---|---|---|
| coarse | 16386 | 10 / 9 个（**0.06%**） | ±0.13 pp |
| medium | 61788 | 208 个（**0.34%**） | 0.99 pp |
| fine | 411k 级 | （未逐一计数） | **4.6 pp**（§5 的参照行） |

比例很小，但 **σ 是沿供体链求积**：激波附近一个供体翻转就把整条下游链的 M₁ 换掉。
而 churn 的比例**随加密增长**（0.06% → 0.34%），σ 的摆动也随之增长
（0.13 → 0.99 → 4.6 pp）。

⇒ **机制确定：σ 的状态间不稳定是它所依赖的供体图（离散选择）的 churn 传上来的。**
这与第一阶段早就记过的同一件事同源（B15 的选择churn极限循环、B19 关于选择不可导的讨论、
B21 的 freeze-capture）。我光滑的是自己那三个判断，churn 在**更下面一层**。

★ 同时一个重要的宽慰读数：**收敛的目标态上 σ 是干净的**
（GS1b.3b §7.2：1.2713 / 1.3470 / 1.3515，1 − σ 1.598 / 2.964 / 3.058% 且在收敛）。
不稳定只发生在**延拓途中**的状态上，代价是边际步的健壮性，不是最终答案的正确性。

**三条候选（需要裁决，我不自行展开）**：

| 候选 | 内容 | 代价 / 风险 |
|---|---|---|
| **(a) 不修，接受** | σ 在**收敛态**上干净且在收敛（1 − σ → ≈3.1%），不稳定只伤延拓的边际步。做法：在延拓里把 σ 的刷新与既有 freeze 机制绑定（冻结供体图时同时冻结 σ），并如实记录"边际步可能需要更小步长" | 最便宜。风险：第一阶段重算时个别重型算例可能需要更小的马赫步（更贵的重算） |

S1b 之后。★ 不建议现在做 (b)：熵修正的**物理效果已经被三个判据台确认**
（0 维恒等式、喷管命中预注册值、翼型 M0.80 落进 Euler 锚点 0.004c），
而 (b) 只改"怎么算 σ"，不改结论；先把重算做完、把默认值定下来，比再修一层机制更有价值。
