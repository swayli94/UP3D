## 1. 触发的发现

上一轮登记的第 (4) 项是"我这条 driver 路径的 medium 绝对 cl 比 P14 锚点低 4.8%",
当时我把它归给**种子路径**并登记不追。**那个归因是错的**,而 LE 逐点比较把它逼出来了:

* LE 上表面吸力偏弱(实验 −1.069/−1.127/−1.181 vs 我们 −0.864/−0.948/−0.942),
  LE 下表面偏正(+0.21/+0.16/+0.12),**且越往外翼越差**(驻点附近差 −0.17 → −0.32)
  ⇒ 这是**前缘载荷偏低**的签名,不是法向分辨率的签名;
* 顺着"载荷偏低"查:`NEWTON_M6_RECIPE` 继承库默认 **`kutta_estimator="probe"`**,
  而已提交的 P14 M0.84 锚点(cl_p 0.277628)是用 **`"pressure"`** 产出的;
* **P14 自己的头条结论就是**:medium M0.84 上 probe 路径比 pressure / level-set
  **低 4.5% / 4.3%** —— 与我测到的 −4.8% / −4.6% **对上**。

⇒ 登记项 (4) **不是种子问题,是 Kutta 估计子**。而这直接把上一轮的预算表推上审判台:
**那 70% 的 LE 项是在一条已知偏弱的 Kutta 路径上测的。**

## 3. 解读规则(**事前**固定)

以 LE 上表面 RMS(probe/OFF 基线 **0.2361**)为判据:

| 条件 | 结论 |
|---|---|
| 下降 **≥ 0.05**(≥ 21%) | **LE 项主要是 Kutta 形式误差** ⇒ S2 的前提**第三次**不成立;下一步是"把 `pressure` 翻成默认 + 重新基线",**不是**棱柱层 |
| 下降 **< 0.02** | 估计子不是 LE 的故事;cl 亏空与 LE 误差是两件事 ⇒ **S2 按计划推进** |
| 介于两者之间 | **RECORDED**,不改顺序,需补 coarse 腿再定 |

**附带必须记录的**:pressure 腿的 cl_p 是否回到 P14 锚点 0.277628 的 1% 内
——若是,则登记项 (4) 关闭;若不是,则 §1 的归因**只是部分正确**,必须如实说。

⚠ 无论结果如何,上一轮预算表的份额(LE 69.6% / MID 20.7%)**都必须在 pressure 腿上重算**
才能继续引用;probe 腿的份额将标注为"在一条已知偏弱的 Kutta 路径上测得"。
