## 1. 被撤回的结论

我在图之前报过:「**level-set 的尾迹机制带有一个随升力增长的收敛退化**
(m6wing LE 池化 R 0.825→0.988 = +18.0%,翼身 0.934→1.184 = +24.0%),而 conforming
在同一几何上没有」并称其为"已定位的发现"。**撤回。** 两条独立理由:

1. **落在抽样散布内。** per-station R 的站位间 SD = 0.234–0.362(m6wing)/
   0.32–0.53(翼身),给 5 站池化均值的标准误 **10.6–18.6%**。声称的 18% / 24% 分别是
   **~1.5σ / ~1.4σ**。
2. **配对检验(事后,未预注册)在两个几何上符号相反。** 同站位相减消掉站位散布后:
   m6wing α=3.06 的 R(LS)−R(conf) = **+0.105 ± 0.045**,而翼身 α=3.06 = **−0.108 ± 0.237**。
   一个说 LS 更差,另一个说 LS 更好 ⇒ 不可复现,不构成提示。

## 3. 仪器的两个失效源(本轮的主要技术收获)

`le_alpha_m6wing_curves.png` 与 `_spanwise.png` 直接显示:

1. **截面切割的锯齿。** 差值曲线 d2 = Cp(medium) − Cp(coarse) 在 x/c < 0.04 内高频振荡,
   幅度与其均值同量级 ⇒ **LE 带的 R 有相当份额在量"两组无关噪声之差"**。
   我此前的平滑敏感性检验(`smooth_passes` 0/1/2 变 9.2–9.7%)**低估了这一点**:
   它测的是池化带 R,而 1–2 遍平滑去不掉多少。
2. **站位抽样。** per-station R 在 5 个站位上摆动 **0.38–1.28(3.3 倍)**,且**两条路径在
   每个站位上基本重合**(配对差 |·| ≤ 0.25)⇒ 摆动是站位性质,不是路径性质。

**下一阶段 LE 研究的第一件事:换仪器。** 把 5 站截面采样换成**壁面三角形上的面积加权
积分范数**(按弦向位置分带):既无截面切割(去锯齿源 1),也无站位抽样(去源 2)。
在换掉之前,任何 <15% 的 LE 效应都不可读。

## 4. 本轮我犯的错(全部已提交记录)

1. **用 p 判收敛**,同时又说 p 不可信 —— 用户指出的自相矛盾。改用 R(不拟合幂律)。
2. **R 的否证阈用了通用 1.0**,而它是**阶梯相关**的(均匀 2× 是 1.000,翼身 1.47/2.00
   是 1.810)⇒ 错判翼身"被否证",撤回。
3. **拿有粘实验当全速势的精度参照** —— 用户指出:FP 无粘无涡,与有粘实验的距离主要是
   模型误差。相关读数限定撤回。
4. **提议以 cd 为主导指标** —— 用户指出:一有激波 cd 理论上就非零,零参照只在无激波
   亚声速成立,而那是求解器最容易的区域。cd 降为**异常判据**。
5. **第一版 R_field 仪器是伪影**(池化点采样,跨采样网格 0.52–1.19,极差 100%),
   预注册的对照组条款拦住了它。
6. **把坏仪器的输出读成物理**:声称"前缘支配范数且收敛慢,是 G1.6 的独立佐证" ——
   用正确求积后 LE 带是干净的 0.477,那个现象是**混叠集中在前缘**。
7. **从三点读趋势、漏掉判别点本身**:先报"LE 随 α 单调恶化"(只看 α≥1),而 α=0 的值
   与它们同值。
8. **锚点凭记忆写**(改 cell 表时断言失败,同一命令里启动的运行用了未打补丁的文件)。

**共同模式**:①②③④是**在不可比的基线上套判据**(第三/四/五次);⑤⑥⑦是**从不足以
支撑结论的数据读出结论**。两类都在本轮被独立检验抓住,没有一个是靠事后辩解修正的。
