## 1. 为什么在 GS2.1 之前插这一轮

S2 的验收挂在**产品指标 M3**:**M6 七站 Cp RMS < 0.05**。当前值(GV5.3,medium,
无粘 k=0)是 **0.1288** —— 差 2.6 倍。S2 打算用棱柱层去攻它,前提是**壁面精度是那个主导项**。
这个前提**没有被测量过**,而两件已知的事让它可疑:

1. **M3 是一个 M0.8395 的跨声速指标。** 那里的 Cp 误差里,**激波位置**通常是主导项 ——
   GV5.3 自己记录了"浅 LE 吸力 + 靠后的激波"。
2. **熵修正(2026-07-31 刚翻成默认 ON)在 2-D 上正是把激波位置从欧拉带外拉回带内的那件事**
   (coarse M0.80:0.6581 → 0.6073/0.6196),而**它在 3-D 上从未被测过**;
   更糟的是 G8.2 那条 strict xfail 记录着 3-D 的病征:**σ_min = 0.0**(donor-cycle)、
   57 个 floored 单元、|R| 2.49e-06 未收敛。

⇒ 若激波位置是主导项,则**修 3-D 的 donor-cycle** 的产品价值高于棱柱层;
若壁面精度才是主导项,S2 按原计划走。**这个判断值一次测量,而且比建 3-D 棱柱层便宜得多。**
这与刚才那次前提检验(省掉整个 GS2.2)是同一条纪律。

## 3. 事前登记的读数与**解读规则**

| 读数 | 内容 |
|---|---|
| **B1** | 池化 5 站 Cp RMS,ON vs OFF |
| **B2** | 逐站 RMS + 上表面激波位置(`shock_report`) |
| **B3** | **3-D 熵健康病征**:σ_min、n_shock、传输是否收敛、floored 单元数 |
| **B4** | cl_p / cl_KJ,ON vs OFF,对 P14 锚点 |

**解读规则(事前固定,防止事后挑故事):**

* **R1(载重条件)**:OFF 腿必须复现已提交的同提取器数字。medium 有 GV5.3 的 k=0
  **0.1288** 可比(容差 5%);coarse 无已提交 RMS ⇒ **RECORDED**。R1 不过 ⇒ 整张表不可信,
  先查漂移。
* **R2(ON 腿的有效性闸门)**:若 `σ_min == 0.0` 或熵传输不收敛或出现 floored 峰值,
  则 ON 腿的 RMS **不是**熵效应读数,而是 **G8.2 的 3-D 缺陷在复现**;
  必须如此记录,**不得**把它当作"熵修正在 3-D 无用"的证据。
* **R3(归因门槛)**:仅当 ON 腿通过 R2 时才谈预算份额。
  - ΔRMS(池化)**≥ 0.02**(即 ≥ 0.129 与 0.05 之间差距的 ~25%)⇒ **激波位置是主导项之一**
    ⇒ 3-D donor-cycle 修复排在棱柱层之前;
  - |ΔRMS| **< 0.01** ⇒ 激波位置**不是**主导项 ⇒ S2 按原计划(棱柱层)推进;
  - 之间 ⇒ RECORDED,不改顺序,由 medium 腿裁决。
* **R4**:激波位置读数只在 `shock_report` 判定存在激波的站上引用;缺失的站记为缺失,
  不用相邻站顶替。
