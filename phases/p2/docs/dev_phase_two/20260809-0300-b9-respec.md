## 2. 第一层:失效**分型**(不报黑箱)

| cap | kutta_converged | \|R\|(流场) | \|Δγ\| 尾部 | 判读 |
|---|---|---|---|---|
| 20 | False | **1.20e-08** | …2.596, 2.582, 0.473, 0.073, 0.139 | 截在**大偏移**之后 |
| 100 | False | **1.19e-08** | 0.007 / 0.042 / 0.042 / 0.006 / 0.014 / 0.013 | **极限环**,最小 1.32e-03(第 91 步),尾部**不单调** |

⇒ **流场解本身是收敛的**(1.19e-08);振荡在 **Kutta 外循环**。加预算不修好它
(100 步仍不到 `tol_gamma`,尾部不单调)⇒ **既非发散、也非预算不足,是极限环。**

**cap=20 为什么红**:第 ~14 步 \|Δγ\| 冲到 **2.596**,那一步的快照 **Γ_min = −0.117**,
于是这条测试的**主题**(Γ 在每个非翼尖站为正 = B8 掉升力探测器)**真的不成立**。
cap ≥ 60 后循环收拢到一个物理状态,主题成立。

★ **在极限环里断言前,先验它不 flaky**(否则就是对振荡序列的一个快照下断言):

```
cap      60      80      90      95     100     105     110     120
Γ_min  .00986  .01073  .01084  .01094  .01101  .01100  .01101  .01103   全正
结合处   .0810   .0852   .0863   .0866   .0870   .0865   .0872   .0877
```
散布 **1.2e-03**,**每一档主题都成立** ⇒ 可断言。

**处置**:`assert r["kutta_converged"]` → 换成 **`residual_norm < 1e-6`(那部分确实收敛)
+ Γ 正性**;`max_kutta_updates` 20 → **100**,理由写进 docstring。
★ 这**不是放宽**:主题断言原样保留且**仍有判别力**(cap 20 时它以 Γ_min −0.117 **失败**),
被去掉的是一条**实测不可达**的收敛声明。

## 3. ★★ 第二层:那条机身升力断言是**已退役前提**的残留

改完第一层后,失败**移到一条更后面的断言**:

```
assert abs(cl_f) < 0.15 * abs(cl_w)      →  机身 0.1257 vs 机翼 0.5953 = 21.1%
```

先查它与 cap 有没有关系 —— **没有**:

| cap | cl_wing | cl_fus | 比值 |
|---|---|---|---|
| 20 | 0.2792 | 0.0660 | **23.6%** |
| 60 | 0.5238 | 0.1122 | 21.4% |
| 100 | 0.5953 | 0.1257 | 21.1% |
| 140 | 0.6097 | 0.1280 | **21.0%** |

**21–24% 稳定,每一档都超 15%** ⇒ 独立的第二条失败。

然后查那个 15% 的**出处**,`cases/demo/b9_wingbody/results/checks.csv` 原文:

```
GB9.4, medium_fuselage_lift,
  out-band conf 0.0351 / LS 0.0376 (gap 7.0%); band 0.0005/0.0008; total 0.0356/0.0384,
  判据 = |conf_out − LS_out| <= 15% |conf_out|   (B28 re-spec),  PASS,
  备注 = "<=5%-of-wing premise RETIRED (physical carryover; B23)"
```

★★ **两件事同时成立**:
1. B28 的 **15% 是跨模型差**(conforming 与 level-set 的 out-band 机身升力之差),
   **不是"机身升力占机翼升力的百分比"**;
2. **"机身应当几乎不载升力"这个前提本身已被 B28 明确退役** —— 因为 B23 测出那份载荷携带是**物理的**。

⇒ 测试里那条断言**在种类上**就是被退役的前提,连 0.15 都像是从 B28 的跨模型差**借来的数**。
**重新定阈值等于把退役的前提换个数再进口一次。**

**处置**:**移除该断言并记录读数**(coarse 21.0–23.6%,与 cap 无关);
改断言为"两个升力有限 + 机翼升力为正"(那部分仍是物理陈述);
活着的门是 demo 那条**跨模型**检查,**medium 7.0% PASS**。
