## 2. 测的是什么

GV5.3 在同一算例(M6 / TEST 2308)上跑过松 VII 耦合,并**提交了逐站 Cp**。
那份证据当时只被读成"池化 RMS 0.1288 → 0.1299(变差)"。
**逐带**读法此前没人做过,而它恰好是 D-a 的同一把刀。

| 带 | 无粘 k0 | 粘性终态 | Δ | 方向 |
|---|---|---|---|---|
| LE 上 | 0.2355 | 0.2380 | **+0.0024** | 远离 |
| LE 下 | 0.0923 | 0.0964 | **+0.0041** | 远离 |
| **MID 上** | 0.0964 | 0.0961 | **−0.0003** | **靠近** |
| **MID 下** | 0.0266 | 0.0259 | **−0.0007** | **靠近** |
| **TE 上** | 0.0659 | 0.0646 | **−0.0013** | **靠近** |
| **TE 下** | 0.0484 | 0.0458 | **−0.0026** | **靠近** |

(medium = binding;coarse 只有 1/6 靠近,而 GV5.3 记录 coarse 未收敛,故不引为证据。)

★ 顺带的接线校验:GV5.3 medium 的 k0 LE 上 = **0.2355**,与我 T0 的 **0.2358** 几乎相同 ——
GV5.3 用 probe 无 taper、T0 用 pressure+taper,**LE 带几乎不动**,
与 `20260801-0030` 测到的"Kutta 形式不影响 LE"一致。

## 3. 怎么读

**符号模式正是模型地板假设所预言的**:粘性该修的是 **MID(激波)与 TE**,
**不该**修 LE(那是壁面/分辨率量)—— 实测四条 MID/TE 全部靠近、两条 LE 反而远离。

**但量级只有地板的 ~0.4 %**(MID 上 −0.0003 对 A = 0.0778)。
这与 **GV5.2 独立测到**的"松耦合在 M ≥ 0.725 下太弱"一致:**方向对,量级差两个数量级。**

⇒ 因此本旁证**支持**"MID/TE 地板是有粘性质"的读法,
但**不能**单独证成它 —— 一个太弱的模型给出正确符号,也可能只是巧合。

## 4. 它对"要不要外部 Euler 参照"的影响

若 D-b 的第三点落地后两条判别器一致指向模型地板,
则本旁证 + D-a 已足够支撑结论,**外部 Euler 参照不必要**。
只有在两条仍不一致时才需要它,而那时需要的是**逐站无粘 Cp 的数字**
(`eta, side, x/c, Cp`,至少 η 0.20–0.90 五站)。
公开来源的现状(2026-08-01 搜索):SU2 的 `Inviscid_ONERAM6` 条件完全一致但只发布
网格+配置+图;NASA TMR 的 M6 页以 RANS 为主;Boeing 的 Young & Kamenetskiy PDF 超出抓取上限。

(b) 自建 SU2 依赖(不成比例)、(c) 数字化已发表图(弱证据,须标注 digitized;
效应量 0.04–0.07 c 远大于数字化误差 ~0.005 c)。**使用者已裁决:先等 T1,不预先花这个钱。**
