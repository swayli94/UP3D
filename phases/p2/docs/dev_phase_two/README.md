使用者 2026-08-10 问的就是这件事。答案是**能,但每个文件有自己的条件,不是一次性、也不是按日期**。
下表就是那份检查单 —— 将来那次移动**对着条件勾**,不要临时判断:

| 文件 | 可以移的条件 |
|---|---|
| `progress.md` | phase 3 有了自己的台账之后(纯历史) |
| `roadmap.md` | phase 3 的计划文件**已把仍然有效的裁决承接过去**。⚠ 在那之前不能移 —— 移走等于让 D5/D2 无处可查 |
