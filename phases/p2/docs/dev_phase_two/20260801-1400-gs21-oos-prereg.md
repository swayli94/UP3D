## 3. ★ 样本外可证伪预测(本轮的正题)

若"**全尺度加密**是真杠杆"(P11 的读法),那么把序列**往粗的方向**延长必须继续成立。
新增一腿 **Tm1 = coarse + taper + pressure**(h_wall 0.030 / h_le 0.015 / h_te 0.015,
约 55 k tets,预计求解 ~20–40 s),并**事前**登记两条预测:

| 编号 | 预测 | 证伪条件 |
|---|---|---|
| **P1** | coarse 的 LE 上 RMS **≥ 0.26**(明显差于 T0 的 0.2358,留 10 % 余量) | 若 < 0.26 ⇒ 序列在粗端不成立 |
| **P2** | 三点序列 coarse → T0 → T1 的 LE 上 RMS **单调下降** | 任一处上升 ⇒ 不是收敛趋势 |

**P1 与 P2 必须同时成立**,"全尺度加密是杠杆"这个读法才被支持。
**任一条被证伪 ⇒ 该读法被推翻**,而且这次是**样本外**推翻,分量重于上一轮任何一条。
⚠ 注意 P1/P2 用的是**同一配方**(taper+pressure)的三点,不与无 taper 的 0.2361 混用。
