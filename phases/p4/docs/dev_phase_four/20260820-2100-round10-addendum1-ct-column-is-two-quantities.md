## 1. 干跑发现了什么

第十轮要扫 `x_tr`，先量 XFOIL 自己的转捩站间距，于是回读了 `xbl.f:821-822`：

```fortran
IF(IBL.LT.ITRAN(IS)) CTAU(IBL,IS) = AMI     ! 转捩前 = 放大因子 ñ
IF(IBL.GE.ITRAN(IS)) CTAU(IBL,IS) = CTI     ! 转捩后 = √Cτ
```

★★★ **`BLDUMP` 的 `CT` 列在转捩前写的是放大因子 `ñ`，转捩后才是 `√Cτ`。**
**同一列,两个量。** 而第九轮 B 腿把 `x_tr` 取成**「`CT` 首次 > 0 的站」** ⇒ 取到了**放大开始**，
不是**转捩**。

**实测证据（side_a，`x/c` 与 XFOIL 自己的列）：**

| `x/c` | `H` | `c_f`(换算后) | 层流相关式 | 湍流相关式 | `CT` 列 |
|---|---|---|---|---|---|
| 0.04109 | **2.5710** | 0.001609 | 0.001644 | 0.001602 | **0.00000** |
| ★ 0.04496 | **2.5780** | 0.001519 | 0.001561 | 0.001520 | **0.01062** ← 我取的 `x_tr` |
| ★ 0.04916 | **2.5680** | 0.001474 | 0.001519 | 0.001481 | 0.02238 |
| 0.05370 | **2.3030** | 0.002025 | 0.002030 | 0.002014 | 0.03720 |
| 0.05862 | **1.8230** | 0.003402 | 0.003828 | **0.003406** | 0.04890 |

⇒ `x/c` 0.04496 与 0.04916 两站的 **`H ≈ 2.57` 是层流值**，`c_f` 也还在层流侧，
**它们的 `CT` 是 `ñ = 0.011 / 0.022`（放大因子），不是 `√Cτ`**。
真正的转捩落在 **含强制转捩点 `XTR 0.05` 的那个间隔内**（0.04916 → 0.05370，`H` 从 2.568 掉到 2.303）。

## 2. 后果：**L-TURB 撤回**

第九轮 B 腿的湍流行进**从 `x/c 0.04496` 就切成湍流**，比 XFOIL 早**两站**，并且
**把我们的湍流态与 XFOIL 的层流态对比了两站**；`Cτ` 那条 **270 % @0.0492** 就是
**拿我们的 `√Cτ` 去比 XFOIL 的放大因子**。

⇒ 下列各项**撤回**，等重测：

| 撤回 | 第九轮原文位置 |
|---|---|
| **L-TURB 的四个逐站计数与最差值**（177/208/206/204 of 216） | §1 表、§3 表 |

| ★★ **`TRDIF` 候选（G10）** —— 它**建立在被撤回的读数上** | §3、§8、§10 |

★ **L-LAG 不自动撤回**（两条臂对**同一列**比较，误标站对两条臂**同样**污染），
**但必须重测** —— 不得假设它不变。

## 3. ★★ 归类：**第 5 问，而这次在一列之内**

本季已记五次「我比较的两个数是不是同一件东西」（跨管线 / 跨级别 / 跨线程 / 跨时间 / 跨网格族），
B 腿附录 #1 又加了一个**跨归一化**。**本条是第七个面孔：同一列，按行取不同的量。**

★ 而它**本可以被抓住**：B 腿附录 #1 我逐列核了归一化，**核的是列的单位，没核列的语义随行变化**。
⇒ **常设新增：核一列外部数据时，除了问"它的单位是什么"，还要问"它在所有行上是同一个量吗"。**

★★★ **更该记的是它为什么现在才被发现**：第九轮的 **G-SEED 打印了种子**、**G-UNITS 验了单位**、
**G-PROV 记了出处** —— 三条守卫都过了，因为**没有一条守卫问"转捩点取对了没有"**，

## 4. 修法与新守卫

**`x_tr` 改由我们自己设的强制转捩点给出**（`XTR 0.05` ⇒ `x/c = 0.05` 处的弧长）——
★ 那是**输入不是输出**（第 4 问），不是从被测数据里推的。

| 守卫 | |
|---|---|
| ★★ **G-XTR** | 三条一起断言：① `x_tr` 上游的站 `H` 保持层流平台（自由转捩**没有**抢在强制转捩之前）；② `x_tr` 下游 `H` **立刻**开始下降；③ `x_tr` 落在 `CT` 列语义翻转的那个间隔内。**任一条不成立即停。** |
| **G-COLSEM** | 打印 `CT` 列的**语义分段**（哪几行是 `ñ`、哪几行是 `√Cτ`），并断言比较**只用后者** |
