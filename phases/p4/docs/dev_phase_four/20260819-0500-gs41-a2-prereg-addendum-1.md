## 1. 起因：我写的一条测试断言**量纲上是错的**

第一次执行后写套件锁时，我把"Blasius 是不动点"断言成

```python
assert abs(dH_dxi) < 1e-3 * H
```

—— 左边是**速率**（量纲 1/长度），右边是个**无量纲数**。⇒ **换一套单位就能让它通过或失败**，
它量不了它声称要量的东西。实测 `|dH/dξ| = 5.6e-3` 越过了那条线，而**行进本身明明把 H 稳稳
held 在 Blasius 上（三个十倍程内 0.026 %）** —— 所以红的是断言，不是物理。

★ 归类：与本项目记过的**「阈值必须从数据推出来，不能挑一个整数」**同族（缺陷 #10），
这次的新面孔是**量纲**：一个**有量纲**的量对**无量纲**阈值。
