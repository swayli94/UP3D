## 2. 这是第 5 问：**我比较的两个数是不是同一件东西**

「禁用后 `c_D` 是否改变」与「该项是否接进模型」**不是同一个问题** ——
只有当该项**进入 `c_D`** 时两者才等价。五处里有一处不进,而那一处正好被判成"不可达"。

★ 与附录 #2 是**同一次判据的两处不同缺陷**：#2 修的是**类别不全**（单边）,
#3 修的是**度量的量选错**。★★ **一条判据在同一轮里两次不覆盖它所比较的量的定义域。**

## 3. 修法

A-USED 的度量改成 **`rhs_turb` 的两个分量 `(dθ/dξ, dH/dξ)`** ——
即**行进真正消费的量**,`c_f` 与 `c_D` 都流进它。
★ 这不是放宽:它**严格更强**（`c_D` 的任何变化都会经 `dH/dξ` 显现,反之不然）。

★ 反向结果落在哪：若某项连 `rhs_turb` 都不动,且函数层也证不出接线 ⇒ **NOT-WIRED ⇒ FAIL**（不变）。

## 4. 同时修：A-REBASE 的行应当是 **RECORDED**,不是 FAIL

第一次执行把 E-H / E-CF 打成 `E-FAIL`。**A-REBASE 注册的是"登记新数",且明写"不带方向判据"**,
而第八轮对同样的行用的是 **RECORDED**。⇒ 改回 RECORDED（**同一管线、同一处置**）,
并**另加一行 `A-STANDING`**,明说常设门此刻读数如何 —— 两件事分开陈述,不互相冒充。
