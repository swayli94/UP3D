## 0. 这一轮存在的理由，以及它**不是**什么

上一轮的失败模式变成这一轮的靶子：**SHOCK 分区为空**（逐单元常马赫的 M=1 集合散成
6 273 块碎片、中位数 2、最大 47、**0 个 ≥50**），所以 G-REAL 那一支**从未可测**。
⇒ **本轮的可交付成果是把那个测试重新变得可做**。

★★★ **本轮不重判上一轮。** G-SMEAR 与「共同修法」的退役**保持成立**。本轮问的是一个
**不同的量**（相干性，不是重尾），在一个**不同的轴**上（patch 尺度，不是恢复方法）。
若本轮为正，它不会把「共同修法」复活，只会**开一条新的、有具体形状的候选**。

### 0.1 ★★ 禁止句（三条，逐字沿用并扩一条）

1. **后处理探针是必要条件，不是充分条件** —— 任何结果不得写成"体内梯度重构可行"。
2. **零求解 ⇒ 本轮对"放进求解器会怎样"零发言权。**
3. ★ **新增**：**相干 ≠ 正确。** 一个更相干的声速面**不保证它在对的位置**。
   本轮没有声速面的外部真值（`cases/reference_data/` 里 M6 只有实验 Cp），
   所以"相干"只能作为**结构性必要条件**报，**不得**读成"激波被正确定位了"。

## 1. 轴与臂：**只动 patch 尺度，方法固定**

★ 上一轮测出**换 patch 比换方法多动 3.5 倍**，所以本轮把 patch 尺度做成**唯一自变量**，
方法固定为**线性重拟合**（B1 已过 G-CONS 1.58e-14；二次臂按附录 #2 仍不计分）。

| 臂 | patch = 以 e 为中心、**面邻接跳数 ≤ k** 的单元集合 |
|---|---|
| **P0** | k = 0 ⇒ 单元自身 = **今天的逐单元常梯度（控制）** |
| **P1** | k = 1 ⇒ 面邻居（= 上一轮的 **B0**，本轮的**假设来源**） |
| **P2** | k = 2 |
| **P3** | k = 3 |
| **N1** | 节点 1-ring（= 上一轮的 **B1**）—— 尺度上落在 P1 与 P2 之间，作**跨定义对照** |
| **S1** | 在 **P1 的 patch 上求平均**（不重拟合）—— ★ **纯平滑对照，逐尺度保留** |

★ **`k` 是一条干净的单参数阶梯**，这是本项目在网格侧一直造不出来、而在恢复算子上
**构造性**可得的东西。
★ **判据缺陷 #11 的新常设条已应用**：本轮的 patch 阶梯**只为主问题而选**，
**不依赖任何其他臂** —— 若某条臂死掉，阶梯**不回滚、不改动**。

## 2. 判据（**先过八问**）

### 2.1 被测的量

固定收敛 φ ⇒ 每臂一个 `M_e` ⇒ **跨声速面** = 面两侧 M 跨过 1 ⇒ 按"共享单元"求连通分量。

> **相干性 `C = (落在 ≥10 面分量里的跨声速面数) / (跨声速面总数)`**

★ **是份额不是计数** —— 归一化掉"某条臂产生更多跨声速面"这件事（上一轮 B0 的跨声速面
**比控制少**却更相干，正说明这两件事要分开）。
★ **10 这个数沿用上一轮已发表的表**（不是新挑的），且**不作为通过线**，只作为 C 的定义。

### 2.2 ★★ 主判据：**C 在 k 上的形状**，不是任何一个绝对值

| 判定码 | 条件（**binding = 两条样本外腿**，见 §3） | 含义 |
|---|---|---|
| **C-PEAK** | 存在**内点极大**：`max(C(P1), C(P2)) ≥ 1.3 · max(C(P0), C(P3))` | ★ **小 patch 是一个真实的最优，不是"离控制近"** |
| **C-MONO-DOWN** | C 随 k 单调不增 | 相干性只是"离 P0 近" ⇒ **上一轮的 B0 读数是伪影，本线关闭** |
| **C-MONO-UP** | C 随 k 单调不减 | 与上一轮相反 ⇒ 如实报，不宣称 |
| **C-FLAT** | `max(C) / min(C) < 1.15` | **UNDEFINED**（阶梯没分开东西） |

★★★ **为什么用形状而不用阈值**：本季已栽过**绝对阈值**（缺陷 #3）与**跨工况定带**
（缺陷 #7）。`C` 的**形状**是自归一的 —— **反向结果落在哪（第 1 问）说得很清楚**：
`C-MONO-DOWN` 就是"B0 那条读数是伪影"，而它**是本轮完全可能拿到的结果**。
★ 上一轮的三点（P0 0.191 / N1 0.110 / P1 0.428）**已经暗示 C-PEAK**，所以
**我不假装盲测**（§5）；本轮的价值在于 **P2/P3 是没看过的点**，且 binding 在**样本外的态**上。

### 2.3 次判据（**这才是可交付成果**）

> **D-USABLE**：最佳臂是否让**上一轮那个空掉的 SHOCK 分区非空** ——
> 即**至少 1 个 ≥ 50 面的分量**（★ **沿用上一轮注册的 50，不放宽、不降到 47**）。

达成 ⇒ 上一轮不可测的 G-REAL 分支**重新可做**，这是一个具体的、可被下一轮使用的东西。

### 2.4 结构检查（**RECORDED，不参与判定**）

最大分量的**面质心 PCA**：`λ2/λ1` 与 `λ3/λ1`。
一张**面**应当给出 λ2/λ1 不小、λ3/λ1 小；一条**丝**给 λ2/λ1 小；一个**团**给 λ3/λ1 大。
★ 这是本轮唯一**非循环**的形状检查（它不使用任何被测臂自己的判据），但**样本只有 1 个分量**
⇒ 按第八问**只作 RECORDED**。

### 2.5 守卫

| ID | 守卫 |
|---|---|
| **G-Z** | 零求解；查 `sys.modules` 不扫源码（自指）；每个态断言 `conv=True` **且** `nlim=nflr=0` |
| **G-MESH** | 网格按 GS4.0 manifest 的 **sha256** 断言（不靠文件名） |
| **G-A** | P0 必须**逐位**复现 `element_velocity_q2`（`np.array_equal`） |
| **G-P** | 面索引集合四臂逐位相同；C 的分母对每臂各自计算（份额定义） |
| ★ **G-CONS** | 线性再现，门槛**从条件数推出**：`tol = max(1e-12, 10·κ·eps)`，**κ 由脚本实测并打印** —— ★ **这是判据缺陷 #10 的修法**（上一轮我挑了个整数 1e-12，而它低于浮点地板） |
| ★ **G-REPRO** | P1 必须**复现上一轮 B0 在 rc0.05 上的数**（跨声速 13 295 / 最大 118 / C 0.428）—— 两者是**同一个算子的两次实现**，对不上就是仪器问题不是发现 |
| **G-SELF** | C 的定义与分量算法对每臂**完全相同**，且不读任何臂自己的判据 |

### 2.6 ★ 第八问：极端样本

| 情形 | 处置（**事前**） |
|---|---|
| 某态**没有超声速区** | 跨声速面 = 0 ⇒ **C 无定义** ⇒ 该腿 UNDEFINED，**不计入 binding**，并打印 |
| 某臂跨声速面 < 100 | C 的分母太小 ⇒ **只报不判** |
| **所有臂都 0 个 ≥50 分量** | D-USABLE **不达成**，如实报（这**不**影响主判据 C-PEAK） |
| **binding 腿只剩 1 条** | ★ **报 UNDEFINED，不报方向**（项目常设：收敛腿 < 2 不报方向） |
| C 的分母在不同臂间差很大 | 份额定义已归一化；★ 但**必须同时打印计数**，免得份额掩盖"几乎没有跨声速面" |

## 3. ★★ 样本：**独立性很弱，必须说清楚**

盘上共 **5 个**收敛缓存态，**全部在同一张网格**（`onera_m6_wingbody_conforming/medium.msh`，
135 051 节点切后）。其中：

| 态 | 可用性 |
|---|---|
| `le14_cache/rc0.05.npz` | ★ **假设来源（discovery sample）** ⇒ **单独报，不进 binding** |
| `le14_cache/rc0.025.npz` · `rc0.045.npz` | ★ **binding（样本外）**，`conv=True`、`0/0` clamps |
| `le10_cache/ref_entropyON_c1.5.npz` · `taperON_entropyOFF.npz` | ★ **不可用** —— npz 里**没有 `nlim`/`nflr`**，无法满足 G-Z 的钳制断言。**登记这个理由，而不是静默丢弃** |

★★★ **必须写下的限定，否则本轮会被读过头**：
**这三个态只差 `tip_taper` 半径**（0.025 / 0.045 / 0.05），**同一网格、同一工况 M0.88/α3.06**。
⇒ 「样本外」在这里的意思是「**另一个 taper 半径**」，**不是**「另一个流动工况」。
**独立性很弱**，而 **binding 腿恰好是 2 条 = 项目常设的最小值** ⇒
**任一条腿触发第八问的 UNDEFINED，整轮就是 UNDEFINED。**
★ 正因为样本弱，**主判据才定成"形状"** —— 形状比任一绝对值稳健，而且它在**每个态内部**
就是一条完整的 4 点曲线（k = 0..3），所以每条腿自己就能给出一个形状读数。

## 4. Kill criterion（**写在开工之前**）

1. ★ **判 C-MONO-DOWN ⇒ 上一轮那条 B0 读数是伪影，本线（小 patch 重拟合）关闭**，
   本轮结束，**不做任何后续设计**，并把这一条推到判定与审计 §6.3。
2. ★ **判 C-FLAT / UNDEFINED ⇒ 停**，不加态、不改 k 的范围（**加腿看到趋势之后 = 范围蔓延**）。
3. ★ **G-REPRO 对不上 ⇒ 停**（上一轮的 B0 数复现不了 ⇒ 仪器问题，读数不可读）。
4. ★ **G-CONS 任一计分臂失败 ⇒ 停**（门槛已按 #10 改成条件数推导，失败就是真失败）。
5. ★ **总机时 > 25 min ⇒ 停**（上一轮同类工作 60 s；本轮 3 态 × 6 臂 ≈ 15 分钟量级）。
6. ★ **任何一步需要改 `pyfp3d/` ⇒ 停并记 RECORDED**。本轮仍是探针。

## 5. 事前预测（**不假装盲测**，并写下可以怎样被推翻）

我**已经看过** rc0.05 上的三个点（P0 0.191 / N1 0.110 / P1 0.428），所以：

1. ★ **预测 C-PEAK**，峰在 **P1**。**推翻方式**：P2/P3（**没看过的点**）若也高，则是 C-MONO-UP；
   若 P1 在样本外两态上不高于 P0，则是 C-MONO-DOWN ⇒ 伪影。
2. ★ **预测 D-USABLE 达成**（P1 在 rc0.05 上已有 8 个 ≥50 分量），但**只在 P1 上**。
3. ★ **预测 S1 与 P1 明显分开** —— 这是与上一轮**相反**的预测：上一轮在**大** patch 上
   平滑与重拟合分不开，我预测在**小** patch 上它们分得开。★ **若 S1 ≈ P1，那么"重构"在
   任何尺度上都只是平滑**，本线的意义大幅削弱 —— 这是本轮**最有价值的可能坏消息**，
   与上一轮 S 臂的角色相同。
4. 总机时 < 15 min。

★ 预测落空**照实记、不改预测**（本季已落空两次：GS4.0 的 N≈10–14 实测 20；上一轮的 G-REAL 实测 G-SMEAR）。
