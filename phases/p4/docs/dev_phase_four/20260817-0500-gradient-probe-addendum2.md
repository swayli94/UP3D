## 1. 干跑校验抓到的三件事（**全部在合成线性场上，零测量**）

干跑用一个**解析线性场** `φ = a·x` 喂进五条臂，按 G-CONS 检查线性再现。

| 臂 | 第一版 | 修后 | 处置 |
|---|---|---|---|
| A | 2.7e-13 | 2.7e-13 | — |
| B1 | 7.5e-15 | 7.5e-15 | — |
| **B0** | ★ **4.0e-01** | **2.2e-13** | **实现 bug，已修**（§1.1） |
| **B2** | ★ **6.5e-02** | **3.8e-08 / 最坏 2.4e-07** | ★★ **不是 bug，是浮点地板**（§1.2） |
| S | 1.1e-14 | 1.1e-14 | — |

### 1.1 B0：两个不同的原点（**真 bug，已修**）

面邻居臂把 φ 在 `phi[idx].mean()` 上中心化，却把 `d` 在**单元质心**上中心化 ⇒
**两个不同的原点**，常数项没被消掉，线性场因此还回来一个 0.4 的梯度误差。
修法：**显式拟合截距**（加一列 1），原点从此无关。
★ 归类：与本项目记过的「两个要比的量是不是同一个东西」同族，只是这次两个"东西"是
**两个坐标原点**。

### 1.2 ★★★ B2：G-CONS 按字面**失败**，而它是浮点地板 —— 判据缺陷 #10

先修掉一个真问题：**点数不等于秩**。patch 可以有 ≥10 个点而二次系统仍**秩亏**
（薄片旁边的 1-ring 常常近共面），`lstsq` 于是返回**最小范数解**，把一个真实的线性梯度
**摊进 H 里**。附录 #1 已经登记了"欠定就退回线性"，而**秩亏就是欠定** ⇒ 改用**秩判据**
是把实现对齐到已登记的意图，**不是改规则**（且严格保守：只会让 B2 更像 B1）。
修完从 6.5e-02 降到 **3.8e-08**。

**但它仍然过不了母注册的 ≤ 1e-12。** 诊断（1 972 个满秩 patch，实测）：

| | |
|---|---|
| 二次设计矩阵 cond | median **9.96** / p99 6.53e+04 / **max 7.17e+08** |
| 梯度误差 | median **8.88e-16** / **max 2.43e-07** |
| ★ **max(cond)·eps** | **1.59e-07** ← 与实测最坏值差 **1.5 倍** |

⇒ **误差就是最坏条件数下的机器精度**，绝大多数 patch 上是 **8.9e-16 = 机器精度**。
**这不是算子错了，是我的门槛问的问题它答不了。**

★★★ **判据缺陷 #10（自查）**：我在一个**二次最小二乘**上写下 **1e-12** 的浮点门槛，
**没有先问这个拟合在真实四面体 patch 上能达到什么**。
**与 #9（臂在它的 patch 上不存在）、#5（`CONC_max` 按构造不可达）同族** ——
一句话：**我要求了一个在它自己的定义域里达不到的东西**，这次是**浮点意义上**的。
★ 而项目**已经学过一次**：GV5.1b 的 e2 门槛 1e-10 被裁决为
`tol = max(1e-10, 10·κ₁·eps)` 的 cond-aware 读法。**我没有把它带过来。**
⇒ **常设新增一条**：**一个计算量的容差必须从这个计算的条件数推出来，不能挑一个整数。**
