### 1.1 ★★★ 而结构比判定更要紧：**相干与位置反向**

**在相干性上赢的臂（P1）在位置上最差；在相干性上输的臂（P2/P3）在位置上最好，好 2.4×。**

| | C（相干，越大越好） | \|足迹−J1\|（位置，越小越好） |
|---|---|---|
| P1 | ★ **最高** | ★ **最差** |
| P2 / P3 | 较低 | ★ **最好（0.42×）** |

⇒ ★★★ **六轮优化的是一个代理量，而它在第一次被独立裁判检验时，
不但不跟踪目标，还可能反向。**

★ **三条必须一起说的限定**：
1. **n = 1** —— 一个工况、一张网格、一个态。**这是 RECORDED 观察，不是结论**，
   要动它需要一轮**事前登记**的确认（就像 B0 那次）；
2. **绝对值都很小** —— 全部 ≤ **0.017 弦长**。说"每条臂的位置都不算错"同样公道；
   反向关系是**相对**的，不是"P1 把激波放错了地方"；
3. **判定仍是 POS-SAME** —— 我**没有**因为看到这个结构就改判 POS-WORSE。

（供体是**离散选择**故比连续的耗散斜坡敏感；σ 集合是**硬开关**故最敏感）。

★★★ **在生产相关的马赫上判 BR-LARGE（>10 %）** ⇒ 按预注册的读法：
**把重构接进求解器不是一个局部修正，是一个不同的离散化。**
⇒ **成本要按"新离散化"估**，而不是按"改一个算子"估。

★ **B3 随马赫单调增大**（3.7 → 8.7 → 12.5 %）—— 激波越强，σ 集合被扰动得越多。
与已记录的"σ 成员判定是硬开关，一个单元进出就跳 `1−σ_RH`"一致。

★★ **禁止句照旧**：爆炸半径量的是**扰动的大小**，不是**解会怎么变**。
**BR-LARGE 不能读成"接进去会坏"**，正如小的不能读成"接进去安全"。

## 4. 结论：**这条线的代理量第一次被独立检验，结果是"它不跟踪目标"**

**本轮建立**：
1. ★ **位置没有变坏到判死**（POS-SAME），且**所有臂的绝对偏差 ≤ 0.017 c**；
2. ★★★ **但相干最优的臂在位置上最差，而相干较差的 P2/P3 好 2.4×**
   （**n=1，RECORDED，不是结论**）；
3. ★★ **接进求解器是一个不同的离散化**（生产马赫上 σ 集合翻转 **12.5 %**），
   **不是一个可以顺手加的修正**；
4. 我们的激波一律在实验**下游 0.04–0.14 c**（无粘 vs 有粘，RECORDED）。

**这对 A1–A7 意味着什么（如实）**：
A1–A7 **在它们各自的范围内仍然成立** —— 它们是关于**相干性**的陈述，而相干性照旧被测出来。
**变的是"相干性值不值得优化"这个前提**：本轮第一次拿独立裁判去问，
**答案是"它至少不跟踪位置，可能反向"**。
★ **A1–A7 不撤销，但从此引用它们必须带上这一条。**

**仍然不能声称**：
- **求解器内行为** —— 本轮只定价，**N2 仍然未答**（禁止句 §0）；
- **相干 ≠ 正确** —— 本轮把它从一句限定变成了**一个有数字的观察**；
- **n=1** —— 反向关系只在一个态上看到。

★ **仍不撤销**「共同修法 = 体内梯度重构」的退役；**前六轮判定一个都不重判**。

## 5. 下一步（**本轮不越界**，两条都要新的事前登记）

但代理量与目标反向这件事，比判定重要。**
