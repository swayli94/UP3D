## 2. 裁决的后果（**比清账重要,先写**）

★★★ 它把参照体系定成**两级**，而这比我在 note 里写的更清楚：

| 层 | 参照 | 回答什么 |
|---|---|---|
| **边界层量**（`θ / H / c_f / Cτ`） | **XFOIL**（同族） | **实现对不对** |
| ★★ **`Cp`**（目标量） | **实验**（`onera_m6` / `rae2822` / `naca0012` —— **它们本来就只有 `Cp`**） | **模型对不对** |

⇒ ★★★ **「仓库缺带 BL 剖面的实验参照」这条阻碍被裁决撤销** —— 不是"缺数据"，
而是**边界层量本来就不该拿实验当门**。而**该拿实验当门的 `Cp` 一直有数据**，
且 phase 1 的 **GV5.2 / GV5.3 已经那样做过**（两条都是对实验 `Cp` 的诚实 FAIL）。

★★★ **由此立下一条可执行的判据规矩（本轮新增，供后续所有边界层工作使用）**：

> **一条边界层量与 XFOIL 的差异，只有在被证明会移动 `Cp` 时才算债务。**
> 否则它是**记录**，不是待修项。

★ **这条规矩立刻改变四条开口的处置**（§3 的 G4 / G6 / G9 / G11）。
★ **它不是放宽**：它把"证明它移动 `Cp`"这个**更强**的举证责任加给了任何要重开的人。

★ **一条必须一起写下的限制**：以 XFOIL 为边界层参照 ⇒
**我们的边界层量在原理上不可能比 XFOIL 更"对"** —— 与 XFOIL 一致是**上限**，不是正确性。
★ 而这在**已测的层面上是矛盾的一处**：第四轮实测**我们的层流闭包族对 Falkner–Skan 比 XFOIL 的更准**
（这也正是第十七轮那 59 % 的来源）。⇒ **裁决在实践上是"以 XFOIL 为准以求可比"，
不是"XFOIL 是真值"**；本记录如实并列这两句。
