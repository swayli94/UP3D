## 2. 错在哪：**变量对不匹配**

**Kármán–Schoenherr** 的原式是

> `0.242/√C_F = log₁₀(Re_L · C_F)`

—— 它关联的是**沿长度平均**的 `C_F` 与**长度雷诺数** `Re_L`。
而我把它当成了**局部** `c_f` 与 **`Re_θ`** 的关系。**两者不是同一对量。**
括号 `[1e-4, 2e-2]` 因此不含根（实测 `f` 在两端同号），brentq 抛错。

★ 归类：这是本项目记过的第 5 问（**"我在比的两个数是同一个东西吗"**）
用在**参照**上的形态 —— 我检查了被测对象的量纲与口径，**却没检查参照自己的变量对**。
与第四轮那条同族（"审计仪器出错，不是被审计对象出错"）。

## 3. 替换：两条**只依赖 `Re_θ`** 的局部相关式

| | 形式 | 谱系 |
|---|---|---|
| **A** | **Coles–Fernholz（对数式）** `c_f = 2[(1/κ)ln Re_θ + C]⁻²`，`κ = 0.384`、`C = 4.127` | 对数律为基础（Nagib–Chauhan–Monkewitz 形式） |
| **B** | **1/4 次幂律** `c_f = 0.024 Re_θ^{−1/4}` | 经验幂律（Schlichting） |

两条都是**局部 `c_f` vs `Re_θ`** ✓，且**谱系独立**（对数律 vs 经验幂律）。

### 3.1 ★★ 被考虑并**否决**的第三个候选，理由值得记

**Ludwieg–Tillmann** `c_f = 0.246·10^{−0.678H}·Re_θ^{−0.268}` 是一条公认的相关式，
**但它依赖 `H`**，而 `H` 正是本轮要测的量之一（判据 T-H）。
⇒ 参照会**部分吸收 `H` 的误差**：若闭包的 `H` 偏了，LT 预测的 `c_f` 会跟着偏，
两边一起移动，检查就变松了。

★★★ **这正是入口文书 §5 第 7 问（"这条守卫会不会量到自己"）** ——
**参照不得依赖被测量。** 两条选中的相关式**只依赖 `Re_θ`**。
