# 20260818-1700 — 预注册：**亚单元足迹提取** —— 换尺子，不换被测对象

**性质**：预注册。**在任何代码之前提交**（roadmap 原则 8）。
**前一轮**：[POS-MIXED 判定](20260818-1500-position-primary-verdict.md) ——
13 个态上 `k_pos*` 无多数，而**最可能的原因是仪器**：
**D 中位数 0.0120 c ≈ 0.29 × 一个单元**，而足迹提取是**逐单元**的（分辨率 = h）。
**四个态出现并列**（多臂 D 逐位相同）是同一证据。

---

## 0. 本轮只动**一件事**

**同样的 13 个态、同样的 7 条臂、同样的 J1 裁判、同样的 D 定义** ——
**唯一变的是足迹提取器**：

| | 旧（per-cell） | ★ **新（sub-cell）** |
|---|---|---|
| 取法 | 壁面带里 `M ≥ 1` 的**单元质心**的最大 x/c | 在**跨声速面**上对 `M = 1` **线性插值**求交点：面 (e, e′) 上 `t = (1 − M_{e′}) / (M_e − M_{e′})`，交点 = 两质心的插值；取带内交点的最大 x/c |
| 分辨率 | **h** | **亚单元** |

⇒ **这是一次构造性干净的单变量实验**（这条线第三次拿到这种条件）。

★★ **而它有第二层意义**：**若亚单元插值让位置度量变得可分辨，那本身就是
"亚单元表示确实要紧"的一个直接演示** —— 而那正是**登记项 1** 要证明的东西。
★ 反过来若不可分辨，**我上一轮对 POS-MIXED 的解释就是错的**（见 §2 的 SUB-SAME）。

## 1. 判据

**不是新挑的整数**。

## 3. 第八问

| 情形 | 处置（事前） |
|---|---|
| ★ 某站带内**没有跨声速面对** | 该站无交点 ⇒ **NaN，不计入中位数**，并打印每臂每态的有效站数 |
| ★ `M_e = M_{e′}` （分母为零） | 该面**跳过**（不可能同时跨越） |
| 某臂有效站 < 3 | 该态该臂 **D = NaN** ⇒ 该态**整体 EXCLUDED**（沿用上一轮） |
| ★ 新提取器把**所有** D 推到 < 0.002 c | **打印"全部臂都在 0.2 % 弦长内"**，判定照报但结论必须带这句 |
| 并列判定 | **精确相等**才算并列（浮点上 `==`），**不设容差** —— 容差会让"并列"变成一个我挑的数 |
