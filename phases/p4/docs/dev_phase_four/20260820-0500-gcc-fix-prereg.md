## 1. 缺陷（第八轮开工前已定位，出处已引）

XFOIL `xblsys.f:856-877`（`BLVAR`，`ITYP=2`）：

```fortran
HKB = HK2 - 1.0
HKC = HK2 - 1.0 - GCC/RT2        ! GCC = GCCON = 18 ; 且 IF(HKC < 0.01) HKC = 0.01
CQ2 = SQRT( CTCON*HS2*HKB*HKC**2 / (USB*H2*HK2**2) )
```

`HKB` 与 `HKC` 是**两个不同的量**。而 `closures_2d.ctau_eq`（第五轮）写的是 `(hk-1)**3`
—— 把 `HKC` 当成了 `HKB`，**漏掉 `− 18/Re_θ` 与 `0.01` 下限**。

**成因**：那个减法在 `IF(ITYP.EQ.2)` 分支里，我把 `ITYP=2` 误读成尾迹，
并在常数表写下 `GCCON = 18.0  # (wake only; unused here)`。
源码自己写着 `ITYP = 1 : laminar / ITYP = 2 : turbulent`（`xblsys.f:794-795`），
且 `xbl.f:810` `IF(IBL.GE.ITRAN(IS)) CALL BLVAR(2)` ⇒ **`ITYP=2` 是湍流壁面，`3` 才是尾迹**。

★ **第五轮的 G-SOURCE 守卫打印了 `GCCON = 18.0` 却没发现它没被用**
⇒ **守卫覆盖的是"常数值对不对"，不是"常数用没用对地方"**（本轮新增 F-USED 补这一条）。

**量级**（`CτEQ` 偏高，随 `Re_θ` 下降急剧变大）：
`Re_θ` 578 → **+14.0 %**；1000 → +8.9 %；2000 → +4.7 %；5000 → +2.1 %；10⁴ → +1.1 %。

**那只是假设。** 因此本轮**事前**声明：
