## 2. 滞后方程（**逐条带出处**）

`xblsys.f:1769-1771` 的残差 `REZC = 0`，除以 `DXI` 并取连续极限（壁面 `ALD = 1`）：

> **`d(ln√Cτ)/dξ = SCC·(√CτEQ − √Cτ)/(2δ) + DUXCON·(UQ − (1/u_e)·du_e/dξ)`**

| 量 | 式子 | 出处 |
|---|---|---|
| `SCC` | `SCCON·1.333/(1 + U_s)`，`SCCON = 5.6` | `xblsys.f:1759` + `xbl.f:1558` |
| `DUXCON` | `1.0` | `xbl.f:1567` |
| `δ` | `(3.15 + 1.72/(H_k−1))·θ + δ*`，**上限 `HDMAX·θ`，`HDMAX = 12.0`** | `xblsys.f:1103` + `:1112` |
| `UQ` | `(0.5·c_f − HR²)/(GBCON·δ*)` | `xblsys.f:1730` |
| `HR` | `HKC/(GACON·ALD·H_k)`，`HKC = H_k−1−GCCON/Re_θ`（下限 0.01） | `xblsys.f:1726` + `:1712` |

★ 状态由 `(θ, H)` 变成 **`(θ, H, Cτ)`** ⇒ 第三条 ODE。

## 3. 两条臂（**本轮最有信息量的判别子**）

| 臂 | `Cτ` |
|---|---|
| **equilibrium**（第五~八轮的） | `Cτ = CτEQ`（瞬时） |
| ★ **lag**（本轮新增） | 由 §2 的 ODE 演化 |

XFOIL 自己的 `CT` 在转捩处 **0 → 8.9e-3 → 0.049** 是一条**可见的松弛曲线**。
⇒ **平衡臂应当瞬时跳上去，滞后臂应当跟出这条曲线。**

## 4. 判据

| 判定码 | 条件 | |
|---|---|---|
| ★★ **L-LAG** | 在转捩后的松弛段，**滞后臂对 XFOIL `Cτ` 的偏差 < 平衡臂的偏差** | ★ **相对比较**（我们两条臂对同一个外部参照）⇒ 无需挑绝对阈值。**反向结果**：若滞后臂**不优于**平衡臂，则滞后的实现或常数有问题 —— **完全可能** |
| **L-TURB** | 湍流段 `θ/H/c_f` 对 XFOIL **逐站**在**推导带**内 | ★ 带 = `max(` 两套相关式在**该站 `(H, Re_θ)`** 上**自身的差**, 本轮**数值地板**`)`；湍流段两套**同式** ⇒ 带落到地板 |
| **L-LAM** | 层流段同上 | ★ 层流两套**不同式**（我们 = 1987 published，XFOIL = 代码修订版；第四轮已测 `c_f` 差 2.9 %@Blasius、7.9 %@m=−0.05）⇒ 带**由该差给出**，不是我挑的 |
| **L-FLOOR** | RECORDED | 数值地板：自收敛（步数加倍）+ `u_e` 导数两种格式之差 |
| **L-TRANS** | RECORDED | 转捩后**首站**：第五轮已登记 GV3.1 的 `c_f` +44 % ⇒ **不得记为相关式的失败** |

★ **反向结果落在哪（第 1 问）**：`L-TURB` 失败⇒我们的湍流行进有问题（同式却对不上）；
`L-LAM` 失败⇒超出两套相关式自身差异，说明是**我们的**问题而非版本差异；`L-LAG` 见上。

## 8. 事前预测

1. **L-LAG 通过** —— 滞后臂优于平衡臂。★ **推翻方式**：我把 `δ`（`DE`）用错（它是 **BL 厚度**不是 `δ*`，两者差约 8 倍）⇒ 松弛率差一个量级。
2. ★★ **L-TURB 通过** —— 湍流段两套同式,应当只差数值地板。★ **这条最能证伪我的实现**。
3. ★ **L-LAM 通过但带很宽**（层流两套不同式,`c_f` 差 3–8 %）。
4. **L-TRANS**：首站出现 GV3.1 那类正偏差。
5. `Cτ` 的松弛长度量级 ~ 若干个 `δ`。
6. 总机时 < 5 min，零 FP 求解。
