## 1. 要转录什么（**逐条带出处，`M = 0` 且无吹吸**）

`BLDIF`（`xblsys.f:1554-1979`，**425 行 / 43 个普通赋值**，其余是解析导数 —— **我们不需要**，
用小型 Newton + 数值 Jacobian）。`M∞ = 0` ⇒ `M1 = M2 = MA = 0`；无壁面吹吸 ⇒ `DW = 0` ⇒ `HWA = 0`；
`HC = MSQ·(...)` ⇒ **`HCA = 0`**（`xblsys.f` HCT）。

**每个区间 `[X1, X2]` 三条残差**（`X` = 弧长，`T` = θ，`D` = δ*，`U` = u_e，`S` = √Cτ）：

| 残差 | 式子 | 行 |
|---|---|---|
| **上风权** | `HDCON = 5/H_k2²`；`HL = ln|(H_k2−1)/(H_k1−1)|`；`HLSQ = min(HL², 15)`；`UPW = 1 − 0.5·exp(−HLSQ·HDCON)` | 1590-1600 |
| **动量 `REZT`** | `CFX = 0.5·CFM·XA/TA + 0.25(CF1·X1/T1 + CF2·X2/T2)`；`BTMP = HA + 2 − MA + HWA`；`REZT = TLOG + BTMP·ULOG − XLOG·0.5·CFX` | 1876-1886 |
| **动能 `REZH`** | `DIX = (1−UPW)·DI1·X1/T1 + UPW·DI2·X2/T2`；`CFX` 同式换 `CF`；`BTMP = 2·HCA/HSA + 1 − HA − HWA`；`REZH = HLOG + BTMP·ULOG + XLOG·(0.5·CFX − DIX)` | 1930-1943 |
| **滞后 `REZC`** | `REZC = SCC(CQA − SA·ALD)·DXI − 2·DEA·SLOG + 2·DEA·(UQ·DXI − ULOG)·DUXCON` | 1769-1771 |

★ `CFM` 来自 `BLMID`：在**中点态** `(H_ka, Rt_a)` 上取 `max(CFT, CFL)`（第九轮已核）。
★ `DI = 2c_D/H*`（`dissipation_identity`，已有）。
★ 层流区间只解 `REZT/REZH`（2×2）；湍流区间三条（3×3）。**放大方程不需要** —— 转捩由我们指定。

## 2. ★★★ 判据里最重要的一条是**一致性**，它让本轮可解释

若我把 `BLDIF` 转录错了，`X-ANSWER` 的失败会在
**「我们的闭包与 XFOIL 不同」**与**「我的转录错了」**之间**无法区分**。
⇒ **先跑一致性，而且它是 kill 条**：

> ★★ **X-CONSIST**：在一个**合成的、可加密的**站点集上（平板，解析 `u_e`），
> 两点格式与我们的 RK4 行进**必须随加密相互收敛**。
> **两者共享闭包但不共享离散代码** ⇒ 这是一次**独立 oracle** 检验（本项目已立的纪律）。

★ **反向结果落在哪**：不收敛 ⇒ **转录错了，本轮到此为止，不去解释 XFOIL 的差别。**
