## 5. ★ 一处守卫改进（**不是放宽**）

继承的 **G-Z 断言"没有求解器模块被 import"**，而它**在本轮开火** ——
因为我 import `run_gs40g` / `run_gs40i` 是为了**复用它们的 helper 而不是重打一遍**，
那两个模块本身 import 了求解入口。

★★ **模块是否被 import 是"有没有求解"的代理，而且两个方向都不对**：
import 了不等于求解了，**没 import 也不能阻止**通过别的路径求解。
⇒ **修法是量那个性质本身，不是放宽代理**：
**把每个求解入口替换成会抛异常的桩** ⇒ **求解不是"会被发现"，而是"不可能发生"**（6 个入口）。
★ 这**严格更强**，与项目那条"守卫必须覆盖结论所声称的东西"同族。
