## 1. 四条**必须先钉死**的约定（否则比较的是两个不同的量）

`BLDUMP` 的 10 列是 `s x y Ue/Vinf Dstar Theta Cf H CD CT`，而其中**三列不是我们同名的量**：

| 列 | XFOIL 写的是 | 换算（`ρ = V∞ = 1`） | 出处 |
|---|---|---|---|
| `Cf` | `TAU/(0.5·V∞²)`，而 `TAU = 0.5·ρ·u_e²·c_f` | ★ **`c_f = Cf_dump / u_e²`** | `xoper.f:1845` + `xbl.f:276` |
| `CD` | `DIS/V∞³`，而 `DIS = ρ·u_e³·DI·H*/2 = ρ·u_e³·c_D` | ★ **`c_D = CD_dump / u_e³`** | `xoper.f:1863` + `xbl.f:277` |
| `H` | ★ **`HK`（运动学形状因子）**，不是 `δ*/θ` | `M = 0` 处两者相同 | `xoper.f:1859-1860` |
| `CT` | `CTAU(IBL,IS)`，而状态量 `S = √C_τ`（`xblsys.f:713`，耗散里用 `S²`） | ★ **`C_τ = CT_dump²`** | `xoper.f:1864` + `xblsys.f:713, 1014` |

★★ **算术自洽检查（已做）**：TE 站 `Ue = 0.89417`，`Cf = 0.001230`，`CD = 0.000958`，`CT = 0.041710`
⇒ `c_f = 1.538e-3`、`c_D = 1.340e-3`、`C_τ = 1.740e-3`，
而 `0.5·c_f·U_s + C_τ·(0.995−U_s)` 在 `U_s ≈ 0.55` 处给 ≈ 1.2e-3 —— **同一量级且结构自洽**。
⇒ 换算不是猜的，它**闭合**。

★★★ **不做这四条换算就直接比,正是本季记了五次的第 5 问**（"我比较的两个数是不是同一件东西"）,
而这次的面孔是**归一化速度不同**（`V∞` vs `u_e`）—— 在 `u_e ≈ 0.89` 处就是 **25 %** 的差。
