## 1. 什么坏了

R-STATIONS 修好后（**140 + 140 通过**），脚本崩在 polar 解析：

```
ValueError: could not convert string to float: 'Reynolds'
```

我的过滤器是 `len(f) >= 7 and f[0].replace(".", "").isdigit()`，
而 XFOIL polar 的表头里有一行

```
 1 1 Reynolds number fixed          Mach number fixed
```

`f[0] = "1"` 是数字、字段数 ≥7 ⇒ **被当成数据行**。

**修法**：数据行的判据改为**七个字段全部能转成 float**（`alpha CL CD CDp CM Top_Xtr Bot_Xtr`），
而不是"首字段像数字"。

## 2. ★ 这是本轮第三个同类 bug，值得记一句

三个都在**读外部格式**：表面/尾迹没分开、LE 行两侧重复、polar 表头被当数据。
**没有一个碰到判据**，而**三个都是被守卫或崩溃在产生任何读数之前挡住的**。

⇒ 常设一句（补第五轮"参照臂也要干跑"）：
**解析外部工具的输出，要先把"哪些行是数据"这件事本身当成一条断言来写**，
而不是用"看起来像数字"这类启发式 —— 启发式在表头上必然翻车。
