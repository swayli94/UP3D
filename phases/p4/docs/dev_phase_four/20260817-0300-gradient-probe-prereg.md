## 0. 这一轮问什么，以及为什么它可以这么便宜

**登记项 1「激波定位」的阻塞性结论**（`phases/p2/docs/dev_phase_two/20260731-0000-s1b-chainfree-sigma.md`
§9.4，五族判别子全部失败**并给出机制**）：

> ★★ **一个畸形四面体在马赫场里产生的局部 signature，与一个激波的 signature 是同一个东西**
> （单格大落差）。任何局部或半局部统计量都分不开它们 —— **因为没有东西可分**。

而它**不是分辨率问题**：单面马赫落差的 max 从 **0.219 只降到 0.111，远慢于 O(h)**；真实分布是
「**主体干净 + 约 1 % 重尾离群**」。同文 §9.5 的三条出路里 **(b) 修梯度**
（patch 最小二乘 / 二次重构代替**逐单元常梯度**）被记为修法，并与 **G1.6 同根**。
能力边界 §3.2 此后一直把它写成 **M1 (b)(c) 的「共同修法」**，
**而从 phase 2 登记至今（约三周）没有人量过它**。

**本轮要问的一句话**：

> **拿一个已经收敛的 φ，只把「逐单元常梯度」换成 patch 重构，那条重尾会不会塌 ——
> 而且塌的是畸形单元那一部分，不是把激波一起抹掉？**

★ **为什么零求解**：φ 固定 ⇒ **唯一的自变量是恢复算子**。这是本项目在网格侧一直
造不出来的那种**干净单变量实验**，而在这里它是**构造性**干净的。
★ **输入已在盘上**（本轮不产生任何新的求解）：
`bench/gate_results/le14_cache/rc0.05.npz` —— 生产 taper、翼身 medium、
**`conv=True`、`nlim/nflr = 0/0`**，配 `cases/meshes/onera_m6_wingbody_conforming/medium.msh`
（**GS4.0 已盖 manifest，溯源已钉住**：122 535 nodes / 679 391 tets / sha `aaed210e1e…`）。

### 0.1 ★★★ 这个探针**证明不了什么**（必须写在最前面）

它回答的是「**同一个 φ 下，patch 重构能不能给出更干净的马赫场**」。
它**不**回答「**把它放进求解器能不能给出更好的 φ**」。

⇒ **前者是后者的必要条件，不是充分条件。** 通过了**仍然**要付
CSR 图变宽 + 精确 Jacobian 重做的账（审计 §9.2b 修正 ②）。
**禁止句**：本轮任何结果都**不得**被写成「体内梯度重构可行 / 有效」。
可以写的只有：「**这条路的必要条件成立 / 不成立**」。

## 1. 三条臂（**第三条是故意放进来的对照**）

固定 φ、固定网格、固定线程。对每个四面体重新算 `grad(φ)_e` ⇒ `q²_e` ⇒ 当地马赫 `M_e`。

| 臂 | 恢复算子 | 角色 |
|---|---|---|
| **A** | **现状**：逐单元常梯度 `grad(φ)_e = Σᵢ φᵢ·B_e[i,:]`（`kernels/gradient.py:32`） | **控制** |
| **B1** | **线性 patch LSQ**：对单元 e 及其**面邻居**（`mesh/metrics.py::build_face_adjacency`）上的 φ 做最小二乘线性拟合，取其梯度 | §9.5 (b) 的字面 |
| **B2** | **二次 patch LSQ**：同 patch 上拟合二次模型，取质心处梯度 —— 与壁面侧**已默认在用**的 `wall_tangential_gradient_quadratic` 同形 | §9.5 (b) 的强形式 |
| ★★ **S** | **纯平滑对照**：节点平均梯度（体积加权）再回到单元 | ★ **故意的伪解** |

★★★ **S 臂是本轮设计的核心**。阻塞性结论说：**对一个局部统计量，薄片的 signature 与激波的
signature 是同一个东西**。所以**任何**把两者一起抹平的算子都会让重尾变小 —— 那不是修复，
是把信号和噪声一起删掉。**S 臂就是那个"只会抹平"的算子**，用来给"塌了"设一个下界：
**如果 B1/B2 的表现与 S 无法区分，那么"重构"什么也没买到，只是平滑。**

★ **不新增任何网格机制**：`node_to_element_csr`、`build_face_adjacency`、
`compute_aspect_ratios`、`precompute_element_geometry` **全部已在库里**（实测）。
本轮代码**全部**写在 `bench/run_gs40b_gradient_probe.py` 里，**`pyfp3d/` 零改动**。

## 2. 判据（**先过八问，再花机时**）

### 2.1 被测的量

**单面马赫落差** `J_f = |M_e − M_e'|`，f 遍历所有内部面（阻塞性结论量的就是它）。
★ **分区在控制臂 A 上定义一次，四条臂共用**（"公共点集"那一课；分区随臂移动的话
两个向量就不是同一个对象了）：

| 分区 | 定义（**全部在臂 A 上算**） | 它代表 |
|---|---|---|
| **SLIVER** | 两侧单元任一 `aspect_ratio` ≥ 该网格 AR 的 **99 分位** | 畸形单元 |
| **SHOCK** | 面两侧跨越声速（`M_e ≥ 1 > M_e'` 或反之）**且**该面属于**空间连通分量 ≥ 50 面**的集合 | 真激波（相干面） |
| **BULK** | 其余 | 光滑区 |

★ **SHOCK 用"相干分量"而不是"跨声速"**：单个跨声速面正是薄片能伪造的东西；
**一个激波是一张面，一个薄片是一个点** —— 这是本轮唯一可用的、不依赖局部统计量的判别。

### 2.2 主判据（binding）

对每条臂 X ∈ {B1, B2, S}，逐分区算 **`R_X(区) = p99(J | 区)_X / p99(J | 区)_A`**（相对本臂
自己的控制，**不用任何绝对阈值**，也**不用** 0.219 这个**跨算例**的老数 —— 见八问第 6）。

| 判定码 | 条件 | 含义 |
|---|---|---|
| **G-REAL** | `R(SLIVER) ≤ 0.5` **且** `R(SHOCK) ≥ 0.8` **且** `R(SLIVER) ≤ 0.6·R(SHOCK)` | ★ **重尾塌在薄片上、激波保住** ⇒ 必要条件**成立** |
| **G-SMEAR** | `R(SLIVER) ≤ 0.5` **但** `R(SHOCK) < 0.8`，**或** B 臂与 S 臂的 `R(SLIVER)` 相差 < 20 % | ★ **只是平滑** ⇒ 必要条件**不成立** |
| **G-NULL** | `R(SLIVER) > 0.8` | ★ **重尾根本没塌** ⇒ 必要条件**不成立** |
| **G-MIX** | 以上都不成立 | 不宣称方向 |

★★ **反向结果落在哪（第 1 问）**：**G-NULL 与 G-SMEAR 都是"路线死"**，而且是**本轮期望
能拿到的结果之一** —— 不是失败。若判 G-NULL/G-SMEAR，**能力边界 §3.2 那句「共同修法 =
体内梯度重构」必须退役**，这是一个被当作前提用了三周、从没被检验过的判断。

### 2.3 守卫

| ID | 守卫 |
|---|---|
| **G-Z** | ★ **零求解**：脚本不得 import 任何 `solve_*` 驱动器；断言 φ 来自 npz 且 `conv=True`、`nlim=nflr=0`。★ 禁止词清单**运行时拼接**（自指守卫第三次的教训） |
| **G-MESH** | ★ **网格身份用 GS4.0 的 manifest 断言**（sha256 + n_tets），不靠文件名 —— 第 5 问的"跨网格族"这一支现在**可以自动回答**了 |
| **G-A** | 臂 A **必须逐位复现** `kernels.gradient.element_velocity_q2` 的输出（rtol 0，`np.array_equal`）—— 控制臂算错的话整轮不可读 |
| **G-P** | **分区在 A 上算一次**，四条臂共用；断言四条臂的面索引集合**逐位相同** |
| **G-CONS** | 每条重构臂在**常数场与线性场**上必须精确复现梯度（线性再现 ≤ 1e-12）—— P11 的教训：mapped-P1 **丢线性再现**正是它失败的机制 |
| **G-SELF** | 分区来自 A、不来自被测臂；`p99` 的样本集固定 ⇒ **守卫不量自己** |

### 2.4 ★ 第八问：判据在四种极端样本上给什么

| 样本 | 后果 | 处置（**事前**） |
|---|---|---|
| **SLIVER 分区为空**（AR 分布太窄） | `R(SLIVER)` 无定义 | ★ **报 UNDEFINED，不报方向**；并记录 AR 分布本身 |
| **SHOCK 分区为空**（该状态无相干激波） | `R(SHOCK)` 无定义 ⇒ G-REAL 按构造不可达 | ★ **前提检查先跑**：若相干分量 < 50 面，**换状态**或报 UNDEFINED，**不放宽 50** |
| **n 面 = 1 的分区** | `p99` 退化成该值 | 每个分区**打印 n**，n < 100 的分区只作 RECORDED |
| **B 与 A 逐位相同** | `R ≡ 1` ⇒ 判 G-NULL | ★ 那是**接线错误**不是结果 ⇒ **G-CONS 会先红** |

★ 这张表在动代码之前抓到一处**构造性不可达**（SHOCK 空 ⇒ G-REAL 不可能成立），已写进处置。

## 3. Kill criterion（**写在开工之前**）

1. ★ **判 G-NULL 或 G-SMEAR ⇒ 路线 (b) 的必要条件不成立，登记项 1 的"共同修法"退役**，
   本轮到此结束，**不进成本估计**，并把退役推到能力边界 §3.2 / §3.1 / 审计 §6.3。
2. ★ **G-CONS 任一臂失败 ⇒ 停**（重构算子自己就是错的，读数不可读）。
3. ★ **G-A 不逐位 ⇒ 停**（控制臂错了，四条臂都不可读）。
4. ★ **总机时 > 20 min ⇒ 停**。本轮按设计是**零求解**；超了说明我把它做成了另一件事。
5. ★ **任何一步需要改 `pyfp3d/` ⇒ 停并记 RECORDED**。本轮是探针，不是实现。

## 4. 若通过，本轮**还要**交付的成本估计（**只估，不实现**）

判 G-REAL 时，同一轮补三个**可数的**数字（都不需要写实现）：

1. **触点计数**：`grep` 出多少处消费"每单元一个 `q²`/常梯度"的内核与调用点
   （审计 §9.2b 说它碰四条内核契约里的前三条 —— 把"三条"变成具体行数）；
2. **CSR 图变宽的倍数**：现在 Jacobian 的每行非零数 vs 用面邻居 patch 之后的

3. **单次装配的成本比**：patch LSQ 的 flop 计数 / 现状，以及一次实测的
   `element_velocity_q2` 墙钟对比（这一条是唯一要跑代码的，秒级）。

⇒ 产物 = **一个带数字的决策输入**，而不是又一句"共同修法"。

## 5. 事前预测（**不假装盲测**）

我事前写下预测与它可以怎样被推翻：

1. ★ **我预测判 G-REAL，但只是勉强** —— 重尾会明显塌（`R(SLIVER)` 落在 0.2–0.5），
   而 `R(SHOCK)` 会落在 **0.7–0.85 的边界附近**，即**激波也会被削一点**。
   若 `R(SHOCK)` < 0.8 就是 G-SMEAR，**我不挪那个 0.8**。
2. ★ **我预测 B2（二次）优于 B1（线性）**，因为壁面侧的同形算子是二次的且已被采纳。
   若 B1 ≈ B2，说明二次买不到东西，成本估计应只对 B1 做。
3. ★ **我预测 S 臂（纯平滑）的 `R(SLIVER)` 会与 B1 接近** —— 这是本轮最可能的**坏消息**，
   也正是 S 臂存在的理由。若如此，判 **G-SMEAR，路线死**。
4. **总机时 < 5 min**。

★ 预测落空**照实记，不改预测**（本季已有一次：GS4.0 的 N≈10–14 实测 20）。
