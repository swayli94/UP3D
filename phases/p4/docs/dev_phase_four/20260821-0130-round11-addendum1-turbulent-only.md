## 1. 只做湍流区间

预注册 §1 写「层流区间只解 `REZT/REZH`（2×2）」。写实现前发现**用不到**：
**X-ANSWER 的行进从 XFOIL 自己的转捩站种子起步**（第十轮已确立的干净读法），
比较集是那 **108 个湍流站** ⇒ **层流区间一次也不会被求解**。

★★ 而且做了反而**更糟**：XFOIL 的层流闭包是它自己的 `HSL`/`DIL`，
与我们 `closures_2d` 层流分支用的 **1987 published** 那一套**不是同一族**（第四轮已测差 3–8 %）
⇒ 层流段的比较会**同时**含闭包差与离散差，**正是本轮要拆开的东西**。
⇒ **层流区间不实现**，并在判定里写明**本轮对层流离散一无所述**。

## 2. 一致性检验（X-CONSIST）改用**真实 `u_e`**

预注册 §2 说「合成的、可加密的站点集（平板，解析 `u_e`）」。改为：
**XFOIL 自己的 `u_e` 插值 + 把它自己的站间隔逐级细分**（×1/×2/×4/×8）。

★ **理由不是省事，是覆盖**：ZPG 平板上 `ULOG = 0`，
**`REZT`/`REZH`/`REZC` 里所有带 `ULOG` 的项全部熄火** ⇒ 那个检验测不到它们。
用真实 `u_e` 才把**每一项都点着**。★ 站点可加密这一条不变（加密 = 在弧长上线性插值细分）。

## 3. ★ 一处**极易写错**、事前点名

`BLDIF` 里 **`HKA` 出现两次且定义不同**：
- 滞后块：`HKA = (1−UPW)·HK1 + UPW·HK2`（**上风加权**，`xblsys.f:1693`）；
- `BLMID` 的 `CFM`：`HKA = 0.5·(HK1 + HK2)`（**算术中点**，`xblsys.f:1155`）。

**两者必须分开**。★ 事前写下来，是因为这正是本季反复吃亏的形状
（同名不同物 —— `GCCON` 的 wake/turbulent、`CT` 列的两个量、`c_f` 的两种归一化）。
