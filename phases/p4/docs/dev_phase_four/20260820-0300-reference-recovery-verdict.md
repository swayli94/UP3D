## 1. ★★★ 结论：已提交的参照**无法从供给的源码复现**，而这加深了出处债

两条独立证据指向同一件事 —— **产生已提交参照的 XFOIL 不是 `reference/XFOIL6.99.zip` 里这份**：

1. **DUMP 字段布局**：6.99 的 `BLDUMP`（`src/xoper.f:1826`）写**恰好 10 个字段**
   （`s x y Ue/Vinf Dstar Theta Cf H CD CT`），而已提交的生成器过滤 `>= 12` 且
   docstring 写的是 `… H, H*, P, m, K` ⇒ **生成器解析这份 build 会得到零行**；
2. ★ **paneling**：同样的 `PPAR / N 280`，`x` 在 LE 附近**逐位相同**，向 TE **发散到 1.75e-3**
   （上表面倒数第三站 **0.99082** vs 已提交 **0.98962**）。

★ **而数值本身仍有旁证**：`cl`/`cd`/`cm` 在**两个**工况上都只差 **≤1 个末位存储单位**
（xtr005 `cd` 9.25e-3 vs 9.26e-3；xtr030 `cl` 0.2755 vs 0.2756），收敛也一致
（5 迭代、rms 1.14e-5，与 README 相符）。
⇒ **是同一份代码的不同 build，不是不同的物理。**

★★ **不去凑 paneling**。调 PPAR 直到 `x` 对上，就是**按目标输出搜自变量**。

## 2. ★★★ 本轮四个 bug 全是我的，而**第四个是新的失败模式**

| # | 在哪 | 类型 |

| ★★ **4** | **R-STATIONS 注册的是"站点 `x` 逐一对应"，我实现成了"行数相等"** | ★ **注册 ≠ 实现** |

前三个都被**守卫或崩溃**在产生任何读数之前挡住。**第四个不是** ——
**弱实现会通过**，于是 R-REPRO 拿着错的前提跑完，产出 `415/560 外、最差 388 ulp`
这样**看起来像结论**的数字。⇒ 那两行已按附录 #3 **撤回**。

★★★ **常设新增两条**：
- **解析外部工具的输出时，"哪些行是数据"本身要写成断言**，不能用"看起来像数字"的启发式
  —— 表头上必然翻车（bug 3）；
- ★★ **实现每一条判据时，逐字回读它注册时的措辞** ——
  "**逐一对应**"不是"**数量相等**"。这条的危险性在于**它会通过**。

## 5. 下一步（**需使用者裁决**）

出处债**记录了、没有清掉**（禁止句 ②：R-PROV 记录，不是修掉）。三条路：

| | 路 | |
|---|---|---|
| ★★ **(i)** | **第八轮把重建的 XFOIL 解当作它自己的参照**，**整体使用**（它自己的 `u_e` + `δ*/θ/cf/CT`），**不与已提交列混用** | 内部自洽、力系数对已提交值 ≤1 ulp ⇒ **可用**；但必须**在第八轮的预注册里显式登记**它是哪个 build、并带上本轮的出处债 |
| **(ii)** | 找出产生已提交参照的那个 XFOIL build | 需要外部信息（本轮拿不到）；能清掉出处债 |
| **(iii)** | 重新生成整份参照并**替换**已提交的 | ★ **不建议** —— 改写仓库唯一外部裁判的已提交证据，代价远大于收益，且会让此前所有引用它的结论悬空 |

★ **我建议 (i)**，理由:它**不改任何已提交证据**、**不需要外部信息**、
且第八轮真正需要的是**一组自洽的 `u_e + δ*/θ/cf/CT`**,而不是"与已提交 CSV 逐位相同"。
★★ **前提**:第八轮的预注册必须**明写**参照是"本地重建的 XFOIL 6.99,与已提交参照**不同 build**",
并把 §1 的两条证据带上 —— 否则就成了把一个未对齐的参照当成已验证的用。
