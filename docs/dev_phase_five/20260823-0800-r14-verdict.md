## A1. 最大的缺口：**我只看了失败的那条腿**

`V-WHERE` 判了"钳制单元在后缘"，**却没有问过收敛解在同一处长什么样**。
若 C=1.5 的收敛解在后缘也接近上限，那"后缘"就**不是 C=1.0 的病**，只是这股流的正常结构。
**补测（R12 已缓存，零机时）：**

★★★ **勘误（R18，2026-08-23）：这段的归因是错的，而错法正是我在 R16 里用来判 `W-CONFOUND` 的那一个。**

⇒ **正确措辞：`C = 1.0` 是达到那个条件的一条路径，不是成因**；而 `upM` 与 \|Γ\| 两个候选
**都分离且不独立 ⇒ 本轮不给出成因**。见 [R18 判定](20260823-1600-r18-verdict.md)。**原句原数保留不改写。**
