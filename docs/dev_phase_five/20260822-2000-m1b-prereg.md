```python

      if j1[e_] is not None and np.isfinite(feet[e_])]
```

| 判定码 | 条件 | ★ 反向结果 |

| ★★ **T-DEF** | 用**同一个场**、**同一个站**，把 `J1` 与 `足迹` 并排报；看 `D` 的量级是否由**系统性偏置**（两者定义不同）而非**散布**（分辨率噪声）主导 | **偏置 ≫ 散布** ⇒ `D` 的地板是**定义差**，那么 `D` 不是一把能评价"位置对不对"的尺子；**散布 ≫ 偏置** ⇒ 仍可能是分辨率/噪声 |
