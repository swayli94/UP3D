## 2. ★★★ **T-TIE 通过不是好消息** —— "可分辨" ≠ "有信息"

并列消失是**必然**的：亚单元把 `D` 变成连续量，**精确相等本来就是零测集**。
问题是**它把胜负定在了什么精度上**：

| 原本并列的态 | 亚单元胜者 | 与亚军的差 |
|---|---|---|
| `W M0.8395` | P2 | **0.000001** |
| `WB xcoarse` | P0 | **0.000025** |
| `W M0.86` | P1 | **0.000069** |
| `W M0.88` | P3 | **0.000148** |

**换提取器本身让 `D` 动了 0.00014（中位）。**
⇒ ★★★ **四个胜者的差全部 ≤ 制造它们的那个扰动。**
**并列被打破了，胜者并没有被确定。**

★ 而 POS-MIXED **原样存活**：`k_pos*` 直方图 **P0:2 / P1:4 / P2:4 / P3:3 → P0:2 / P1:5 / P2:3 / P3:3**
（13 个态里换了臂的有 **3** 个）—— **仍然没有多数**。

## 3. ★★ M1-c：`D` 的地板**不是**定义差 —— 假设被证伪

`D` 比较**体场的 `M=1` 壁面足迹**与**截面 `Cp` 的激波位置**，我据此预测**系统性偏置**。
实测：偏置 **+0.00257 = 0.06 个单元**，散布 **MAD 0.01459 = 0.36 个单元**，**比 0.18**；
符号 **0.565**（几乎五五开）。
⇒ **两个定义平均而言是一致的**（这对 `D` 是好消息 —— 它没有定义性偏差），
**而它们逐站相差 ~0.36 个单元。**
★★★ **勘误（第十轮，2026-08-22）：这句描述错了，数没错。** MAD **按设计忽略尾巴**，而这里
**21 % 的读数 \|d\| > 0.1**，且**整条尾巴是两个站**（`η=0.96` 中位 \|d\| **0.4515**、`η=0.99`
**0.5292**，内侧五站 0.004–0.012）⇒ **"逐站相差 0.36 个单元"是核心部分的统计量被当成了整体的描述**。
诚实的两个数：**内侧五站中位 \|d\| = 0.18 个单元**（更小），而**两个站根本没在量同一个激波**（更严重）。
见[第十轮判定](20260822-2300-m1e-verdict.md) §2。**原句原数保留不改写。**

## 4. ★★★ 事后量（**未注册，如实标注**）：POS-MIXED 是**统计**问题，不是分辨率问题

`D` 是 ~7 个站上的**中位数**。它自己的抽样不确定度（每态每臂用站间 MAD 估，
`1.253·σ/√n` —— **7 个点上的正态近似，是量级仪器不是严格置信区间**）：

| | |
|---|---|
| 胜者领先亚军的差 **超过** `D` 自身不确定度的态 | ★★★ **1 / 13**（中位 gap/SE **0.66**） |

⇒ **十二个态里，"哪条臂在位置上更好"这个判断，其差异小于 `D` 自己的噪声。**
**这才是 `k_pos*` 没有多数的原因** —— 不是提取器只有单元分辨率
（那一条本轮修掉了，结论没动），而是**度量的不确定度与它被要求分辨的差同量级**。

★ **不得**把这句读成"细化梯度重构没有用"：有几个态分得很开（`W M0.76` 差 0.0135）。
★★ 本节**未注册** ⇒ 只作 RECORDED，**并登记为 M1-d 的判据**（用 bootstrap/符号检验做严格版本）。

## 5. ★★ 勘误：第八轮 §2 有一句实测为假

第八轮写：

> 把分辨率做成亚单元，读数只动 0.004 个单元 —— **那不足以分开任何两条落在同一单元上的臂**。

**实测：它足以分开——四个并列态一个不剩。** 那句话是从 `S-SHIFT` 的**大小**推出来的，
而**打破精确相等需要的不是"大"，只需要"非零"**。
★★★ **而第八轮的结论（POS-MIXED 需要另一个解释）仍然成立，只是理由完全换了** ——
⇒ **不得**让活下来的结论盖住那句错话（纪律 #11 / F9）。
第八轮判定与 `progress.md` 第 8 行**就地加勘误指针，原句保留不改写**。

## 6. ★★★ 本轮的结构性教训

**第十八轮把一个症状（并列）诊断对了，又用它支持了一个错的推论。**
修掉症状的成因之后，那个推论要解释的东西（POS-MIXED、`D` 的地板）**一个都没有动**。

⇒ **常设新增：修好症状的成因，并不验证"症状解释了结论"这个推论。**
证明 X 造成了症状 S，与证明 S 造成了结论 C，是**两次**测量。
★ 本轮两边都做了，答案是**是**和**否**。
