## 1. ★★ 本阶段的中心风险：在多吸引子邻域把「单次跑出来的数」当结论

p6 最重的能力发现（能力边界 §5）是**敏感腿与多吸引子**。已钉死的事实：

| 事实 | 出处 |
|---|---|
| 「converged ∧ 零钳制」不是可用性充分条件 —— M0.86 α=0 有一个 \|R\|=2.6e-13、零钳制、cl=−0.52 的物理不可能解 | D14 / 能力边界 §5.1 |
| D08/D13 的 IBL 松耦合腿跨 BLAS 配置换吸引子（cl +9.7 %、`rel_to_band` 翻号）；固定 BLAS=1 下两次独立运行逐位复现 | 第 34 轮判定 §4.4 / 能力边界 §5.2 |
| D06 M0.725 medium 两个 BLAS 档各真收敛而落点分家（cl 3.7e-4）—— 近简并敏感腿 | 能力边界 §5.3 |
| D05 M0.778 medium 是 limit_cycle（400 步封顶仍是环，0 钳制） | 能力边界 §5.5 |
| tet medium 在 r_far 20/30 的重生成变体上不收敛（实现噪声测不出来） | W2.5/W2.6 判定 §4.2 |

⇒ 除承接的三条常设要求（G-TEETH / G-DOMAIN / G-CADENCE）外，本阶段加第四条，
从第一轮起生效：

- ★★★ **G-ATTRACTOR：凡在敏感腿邻域的测量，先固定出处态再下结论** ——
  BLAS=1（库运行时钉死，读库不读 env）、暖缓存态（重编译/清 `__pycache__` 后先白跑）、
  初值/种子/线程数进证据出处列；结论必须写明它落在哪个吸引子上。对「换了吸引子」的
  任何主张，判据是**固定一切只动一个旋钮**（第 34 轮的做法），单次对比不算数。
