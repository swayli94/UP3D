## 1. Part 1 — **复现 P-B**(必须最先,且**不动库**)

`_SIGMA_REFRESH_MAX` 是**模块常量**,在驱动循环里**运行时读取**(`newton.py:1265`)。
⇒ 诊断脚本**在进程内 monkeypatch 它**(`newton._SIGMA_REFRESH_MAX = 10**9`),
**不编辑库文件** —— 这是本轮 Part 1 唯一的"改动",而且它只活在 bench 进程里。

**腿**:注释记录 P-B 的那个工况 **coarse M0.7875 / α1.25** 逐字复现,

每步都刷新,记录 `n_shock`、`sigma_min`、`max|Δσ|`、残差、以及**哪些单元在集合里进出**。

**事前判据**

| | 条件 | 判定 |
|---|---|---|
| **L1** | 存在一条腿,其 `n_shock` 在尾部(最后 10 次刷新)**取值 ≤ 3 个且反复出现**,且 `max|Δσ|` **不趋零**,且残差**不再下降** | ⇒ **P-B 复现**,机理分析有主语 → Part 2/3 按它定向 |
| **L2** | 没有任何腿出现 L1(σ 与残差都继续收敛到底) | ⇒ ★ **P-B 在这些工况上不存在** ⇒ 那么 `_SIGMA_REFRESH_MAX` 的**立项理由本身需要重新测量**,而"为什么有极限环"这个问题**在本处无对象** —— 如实上报,**不去别处找一个来证明它** |

## 2. Part 2 — **报警机制**(使用者的最低要求,**本轮必交**)

驱动器**已经**收集了需要的数据:`sigma_history` 每次刷新存
`(sigma_min, n_shock, m1_max, sigma_delta, converged)`。所以检测**不需要新的测量**,只需要判读。

**两个签名分开报,不合成一个数**(否则又是把两种病混成一个指标):

| 标志 | 触发 | 含义 |
|---|---|---|
| `sigma_frozen_in_transient` | **最后一次**刷新的 `sigma_delta` > 阈值 τ_t | σ 在**还在动**的时候被冻住了(P-A) |
| `sigma_selection_churn` | 尾部若干次刷新里 `n_shock` 取值集合 ≤ 3 且反复,且 `sigma_delta` 不趋零(P-B) | 集合在翻动 |

**必交的形式**:两个布尔 + 支撑数字进**返回字典**,并在触发时打印**警告**。

★★ **"报错"的严格程度是一个被测量的决定,不是本轮就拍的**:
把它升级成**拒绝**(像 `sigma_transport_not_converged` 那样让 `converged=False`)是一次**契约变更**,
它可能让**已提交的能力锚点集体变红**。⇒ 本轮**先测**:在已提交的 M1 门 12 点 + 快层的 5 组上
**有多少会触发**;数出来之后,升级与否写进判定,交使用者裁决。
**先测再升级**,而不是"先严起来再看谁红" —— 后者会把一次契约变更伪装成一次 bug 修复。

★ **阈值 τ_t 必须事前定,且必须承认它是标定**:取 **τ_t = 1e-3**,理由是注释记录的 P-B 把
`max|Δσ|` 钉在 **2.9e-2**、而收敛尾部的 Δσ 应当趋零,1e-3 在两者之间约一个数量级。
★★ 项目已记的规矩:**任何固定阈值都是标定不是保证**(EW forcing / taper r_c / descent10 都栽过)
⇒ 判定里必须报**触发率对 τ_t 的敏感性**(τ_t ∈ {1e-2, 1e-3, 1e-4}),而不是只报一个数。

**守卫 G-P2**:报警是**纯读判**,不得移动任何数字 ⇒ M1 门默认路径与已提交 8 线程记录
**12 行 × 14 字段逐位相同**。不过就停。

## 3. Part 3 — **治法 A/B**(方向由 Part 1 决定,**默认关闭**)

候选(全部默认 OFF、legacy 逐位):

1. ★★ **只冻集合、不冻幅度**(使用者已同意的那条,靶子来自代码自己的理由:
   注释论证的是**离散集合**不可被 Newton 解决,而实现把**集合和幅度一起冻**了);
2. **松弛**:`sigma ← (1−ω)·sigma_old + ω·sigma_fresh`,ω < 1;
3. **平均**:σ 取最近 k 次刷新的均值(或**最小值** —— 后者更保守,不会低估熵增)。

**事前判据(binding = 路径依赖,因为那才是这条线要治的病)**

| | 要求 |
|---|---|
| **F1** | 跨种子 {0, 5, 12} 的 **cl_p 散布**(★ **只在收敛腿之间**算,少于 2 条收敛则 **UNDEFINED**)从基线的 **32.11 %** 降到 **≤ 5 %** |
| **F2** | 不得把 P-B 放回来:开启后**不出现 L1 签名**,且残差仍收敛到与基线同量级 |
| **F3** | legacy 路径**逐位相同**(flag 默认 OFF) |
| **F4** | 收敛代价 RECORDED:Newton 步数与墙钟(不设判据,如实记) |

★ **F1 与 F2 是一对不能只满足一个的要求** —— 只满足 F1 等于用"永不冻结"换来一致性,
而那正是 `_SIGMA_REFRESH_MAX` 当初要解决的问题;只满足 F2 等于没治病。

## 4. ★★ KILL CRITERION

1. **G-P2 不过**(报警机制移动了数字)⇒ 立刻回退,停;
2. **Part 1 得 L2**(P-B 复现不出来)⇒ **Part 3 的候选 1 失去靶子**
   (它的立项理由就是"集合会极限环"),此时 **Part 3 只做候选 2/3**,并把
   "`_SIGMA_REFRESH_MAX` 的立项理由需重新测量"作为结论上报;
3. **F1 与 F2 无法同时满足**,且两轮内改不出来 ⇒ 这条路判死,把
   "σ 冻结的路径依赖是当前离散化的固有代价"写进能力边界;
4. **单腿 > 10 min** ⇒ 停(预算 ≤ 40 min,Part 1 的无上限刷新腿可能变慢,单独计时)。

**明确不算 kill**:
- **L2/L3**(极限环不是我以为的形态)—— 有用的负结果;
- **Part 3 只有一个候选成功** —— 一个够了;
- **M1 仍不达标**(沿用前四轮的豁免)。
