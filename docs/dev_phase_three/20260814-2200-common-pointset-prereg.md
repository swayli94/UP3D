## 4. 事前判据(binding = **LE 上表面**,公共点集)

`R = d_self(S2→S4) / e(S4)`,两者都在公共点集上。

| | 条件 | 判定与后续 |
|---|---|---|
| **N-MODEL** | **R ≤ 1/3** 且 `d_self(S0→S2) > d_self(S2→S4)` | ⇒ ★★★ **我的预测被推翻**:解已基本收敛而不朝实验 ⇒ 残余是**模型误差** ⇒ **M3 的 LE 靶需要一条模型误差带**(照 Track V 的 A4),LE 线以测量结论收口;★ 并且上一轮那 0.214/0.250 被判为**前缘夹紧伪影** |
| **N-DISC** | **R ≥ 1**,或 `d_self` **不缩小** | ⇒ ★★ **预测被证实**:解**没收敛** ⇒ 根因在**离散侧**,这**推翻**"换网格解决不了 M3" |
| **N-MIX** | 1/3 < R < 1 且 d_self 缩小 | ⇒ **RECORDED,不宣称**;报 Richardson 极限到实验的距离 |

**必须一并报(非判据)**

- ★★★ **P2 判别式**:上一轮 √2 的 d_self 里,**被丢掉的那些点贡献了多少**?
  即把 `d_self(S3→S4)` 拆成"公共点部分"与"被丢点部分" ——
  **这是"上一轮的读数是不是伪影"的直接测量**,而它零成本;
  ★ 但它只能作 **RECORDED**(那两个数我已看过);
- **观测阶** `p = log2(d(S0→S2)/d(S2→S4))`(因子 2 ⇒ 直接以 2 为底),**报出、不作判据**;
- **Richardson 极限**到实验的距离(仅当 d_self 缩小时);
- 逐带逐面(LE/MID/TE × 上/下)的 e 与 d_self;
- **公共点集的点数与被丢点的 x 位置**。

**守卫**

- **G-R(保管链)**:S4 在**全点集**上的 e(LE 上) 必须 **= 0.242221 逐位** ⇒ 证明读的是同一批曲线;
- ★★ **G-I(恒等式)**:`e_full² · n_full = e_common² · n_common + Σ(被丢点残差²)` **必须成立到 rtol 1e-12**
  ⇒ 若不成立,我的点集算术错了,**任何 R 都无意义**(与"偏置 vs 散布"那轮同一种守卫);
- **G-N(点数)**:报出 n_full / n_common / n_dropped;
- ★ **G-Z(零求解)**:脚本**不得**调用任何求解器 —— 断言它只读 npz 与 CSV。
