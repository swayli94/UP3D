## 1. 路线 (A) 是什么,以及为什么先做它

造结构化/半结构化的**六面体贴体块**(O 型或 C 型:正交近壁层 + 可**独立控制**的分级),
**剖成四面体**喂给现有求解器。**一个内核、一条锁、一个已测结论都不动。**

支撑"转"的三条依据(能力边界 §7)全部是关于**网格可控性**的,没有一条是关于单元类型的:
① 这个范式里做不出单变量网格实验(四个旋钮全越界,`r_far` 近体 +67% 而它根本不属于尺寸场);
② LE 亏空由**体网格分级**主导而分级不可独立控制;③ 正交壁面层是 P1 场唯一没试过的杠杆。
★ 而 roadmap 的**禁止项**明写"不得再新增第二条并行技术路线" —— (B) 恰是那个;
依据 ⑤(六面体 DOF 更省)是**标注过的推断、未测**,拿未测推断去启动第二个求解器,顺序反了。

## 2. ★★ 两条事前必须写下的风险(否则会拿到看起来正面、实际不成立的答案)

**风险 1 —— 剖分会不会把供体确定性抵消掉。**
供体规则是 `upstream_elements`:沿 `V_e` 走**质心位移最负**的面邻居,多跳直到累计位移达到该单元
自身的流向尺度(`max_hops = 4`;无上游邻居时 `u(e) = e`)。结构化块里流动大致沿网格线 ⇒ 最优邻居
分离得开;**但一个 hex 剖成 5–6 个 tet 会引入对角面**,那些邻居的质心偏移可能近乎垂直。
⇒ **(A) 的供体收益可能死在剖分上**。这是 Q1 能否被 (A) 回答的关键,所以它是**被测量的对象**,不是假设。
★ 若测出收益确实被剖分吃掉,那本身就是 (B)(或"hex-aware 供体规则")的立项依据 —— 见 §5 kill criterion。

**风险 2 —— 用六面体并不会消掉刻面法向误差。**
O 型网格的壁面**仍是平面刻面**,`O(h)` 法向误差照旧(P11 已测:mapped-P1 曲面单元把球面
11.56% → 11.33%,没救回来 ⇒ 那条路已排除)。真正会变的是**刻面尺寸均匀**与**近壁层正交**
⇒ 切向梯度重构的模板更好。所以 Q2 的量**不是**法向误差,是**壁面 Cp 误差与其收敛阶**。

## 4. 事前判据(数字与口径在此固定)

### Q1 —— 熵修正的上游单元是否更容易确定(使用者关切 ①)

在**同一流场状态**上对比 `cases/meshes/naca0012_2.5d`(非结构)与 L2(hex→tet),
量四个供体图指标(纯诊断,不改求解器):

| 量 | 定义 | 判据 |
|---|---|---|
| **D1 歧义边距** | 每个单元"最优 vs 次优"面邻居的投影位移差,除以最优值;取中位数 | hex 侧中位边距 **≥ 2×** 非结构侧 ⇒ PASS |
| **D2 自指率** | `u(e) = e` 的单元占比(该处修正没有链) | hex 侧 **≤ 1/2** 非结构侧 ⇒ PASS |
| **D3 供体环** | 环的个数,以及无害(全 s = 1)/ 含激波 的拆分 | hex 侧环数 **= 0** ⇒ PASS(非结构侧实测 2 / 68624) |
| **D4 走跳深度** | 用满 `max_hops = 4` 的单元占比 | RECORDED,无判据 |

★ **D1/D2 在 α = 0 的无升力状态上也测一遍**,因为那时流向与网格线最对齐 —— 若连那里都不改善,
风险 1 就是实锤。

### Q2 —— 壁面曲面的解析是否更好(使用者关切 ②)

| 量 | 判据 |
|---|---|

## 5. ★★ KILL CRITERION(使用者的话,落成可判的条件)

> "如果不能解决的话,就再做 (B)。"

**(A) 判死的条件 —— 三者任一成立**:

1. **Q1 与 Q2 都不 PASS**:即 D1/D2/D3 全部未达判据 **且** W1/W2 都未达判据
   ⇒ 剖分把两项收益都吃掉了 ⇒ **(A) 对使用者的两个关切无效**,转 (B)。
2. **G0 不过**:新生成器**仍然做不出单变量实验**(某个旋钮越界)⇒ (A) 连它最主要的理由都没兑现
   ⇒ 先修生成器;若两轮之内修不出单变量性,转 (B)。
3. **Q1 PASS 但 Q2 死于风险 2**(壁面精度不改善)**且** M1 的 (b)(c) 差距**未收窄**
   ⇒ 供体变干净了却买不到任何指标 ⇒ 记为"供体确定性不是瓶颈",转 (B) 或转回 §3 亏空清单。

**(A) 判活(继续投入)的条件**:Q1 或 Q2 至少一组 PASS,**且** G0 过。
⇒ 那时才把 M1 的三条判据搬上来,并按结果决定要不要 3-D(M6)。

★ **明确不算 kill 的情形**:M1 仍不达标。M1 的剩余差距是**亚单元激波定位**
(GS1.1 实测:误差 ≈ 0.35·C 个单元、在 h 上近似常数;要 ±0.0055 c 需 h_shock ≲ 0.005–0.01 c),
它与网格范式是**两件事**;把 M1 不达标算成 (A) 的死因,等于用一个已知的独立瓶颈去否掉一条
本来只承诺"网格可控性 + 壁面模板"的路线。
