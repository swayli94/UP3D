## 4. 机理侧看到的东西(RECORDED)

逐种子看,**θ 增大时种子逐个分叉到不同的支上,而分叉的是哪个种子取决于网格族**:

| | seed 0 | seed 5 | seed 12 |
|---|---|---|---|
| 混合 θ=0 → 1 | 0.3595 → 0.3477 → **0.2727** → 死 → 0.2614 | 0.3596 → 0.3518 → 0.3468 → 0.3278 → 0.2582 | 0.3595 → 0.3525 → 0.3455 → 0.3508 → **0.3515** |
| 非结构 θ=0 → 1 | 0.4590 → 0.4407 → 0.3870 → 0.4203 → 0.4080 | 0.4590 → 0.4403 → 0.4127 → 0.4091 → 0.4071 | 0.4590 → **0.3752** → **0.3386** → **死(−0.3604)** → **死(0.5092)** |

- 混合族 θ=1 的 32 % 是 **seed 12 站在与 0/5 不同的支上**;
- 非结构族的病态种子是 **seed 12**,它随 θ 增大直接走向非收敛 ——
  所以那一族 θ=1 的散布"小"(0.21 %),是因为**离群者已经死了、不进统计**。

★★ ⇒ **一个统一的、可检验的说法**:σ 变强并不是把大家推到"更散的解",
而是**让不同起点的迭代走向不同的支,并让其中一些直接失去收敛**。
"散布"这个指标同时被这两件事影响,而它们方向相反 —— 这正是原始曲线非单调的根源。
**下一轮要量的应当是"分叉 + 失收敛"两件事,而不是一个把它们混在一起的散布数。**

## 7. 本轮我的错

1. ★★ **判据的第二个缺陷**:跨 θ 比散布**却不要求收敛种子集相同**,于是"非单调"这个 T2 触发条件
   被**集合大小**污染(混合族上已确认是假象)。上一轮是**单边带**,这一轮是**未平衡面板** ——
   同一个毛病的两个面:**我写的判据没覆盖到自己要比较的那个量的定义域**;
2. ★ **注册里写"散布随 θ 单调"时,我默认了每个 θ 的样本集相同**,而这件事在一个
   "收敛性本身也随 θ 变化"的实验里**恰恰不成立** —— 而"收敛性随 θ 变差"正是本轮想测的现象之一。
   ⇒ 教训:**当自变量同时影响样本的存在性时,任何跨自变量的统计都必须先固定样本集。**
