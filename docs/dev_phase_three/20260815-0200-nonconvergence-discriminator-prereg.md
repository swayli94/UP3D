## 1. ★★ 判别原理:`d_self` 是**逐点**量 —— 问它**住在哪**

`d_self` 到目前为止只被当成一个 RMS。但它是每个实验点上的一个差值 ⇒
**它的平方质量在弦向、在展向的分布,就是四条候选的指纹**:

| 候选 | 指纹 |
|---|---|
| (a) 前缘峰 | d² 质量集中在**最前端**(x/c < 0.05),且**不**与声速线重合 |
| (b) 亚单元激波 | d² 质量与**该站的声速线穿越位置**重合 |
| (d) 尖端 | d² 质量集中在**外侧站**(η ≥ 0.80),而内侧站正常收敛 |
| (c) σ 相位 | ★ **指纹与 (b) 重叠**(σ 只在 m1 > 1 的单元起作用)⇒ **不能用足迹分辨** ⇒ 需要一条 **A/B**(见 §2 臂 2) |

## 2. 两条臂

**臂 1(零求解)—— d² 质量的解剖。** 用已落盘的 S0/S2/S4 曲线与上一轮的**公共点集**:
① 逐点算 `d = Cp_S2 − Cp_S4`(binding 的那一对);
② 分区:**弦向** x/c < 0.05 / [0.05, 0.15);**展向** η ≤ 0.65 / η ≥ 0.80;
   **声速线**:每站按 `Cp = Cp*`(M∞ 0.8395 的临界压力系数,解析式)定位穿越点,取其 **±0.02 c** 邻域;
③ 每个区报 **集中度 = (该区 d² 质量占比) / (该区点数占比)**。
★★ **集中度的零假设是 1.0**(质量按点数均匀分布)—— 这是与"偏置 vs 散布"那轮的 **1/n 比较**同一手法:
**判据比的是"与均匀分布相比",不是一个手拍的阈值。**

**臂 2(便宜求解)—— σ 的 A/B。** 同三级、同配方,只把 `entropy_correction` 翻成 **False**,
重算 `d_self(S2→S4)`。★ 这是唯一能把 (c) 与 (b) 分开的东西,而它只要 ~165 s 的求解。
★ 若某级在 σ OFF 下不收敛 ⇒ 该级退出,如实记(**σ OFF 掉的级本身是一条读数**,不是失败)。

## 4. 事前判据(binding = **LE 上表面、S2→S4 这一对**)

| | 条件 | 判定与后续 |
|---|---|---|
| **C-A** 前缘峰 | `x/c < 0.05` 区集中度 **≥ 2.0** 且**最高**,且它**不**与声速线区重合 | ⇒ 前缘离散(峰的分辨)是靶子 |
| **C-B** 亚单元激波 | **声速线 ±0.02c** 区集中度 **≥ 2.0** 且**最高** | ⇒ ★★ 与能力边界 §3 的**首位亏空合流**,两条线并作一条 |
| **C-C** σ 相位 | 臂 2:σ OFF 下 `d_self(S2→S4)` **降到 ≤ 1/2** 的 σ ON 值(且各级收敛) | ⇒ σ 冻结是主因;修法在 σ 侧(本会话已有三条被测过的候选) |

- **逐站** d_self(5 站)与**逐站声速线位置**,以及它**是否落在 LE 带内** ——

  **这条限定必须写进判定**,不许悄悄当成"(b) 被否";
