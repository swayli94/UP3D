## 0. 入口检查(零求解)

已确立的:LE 亏空是**量级/水平误差**,不是形状或位置误差
(上一轮:η0.90 在曲线**最平**处却最差 ⇒ 位置在那里原则上解释不了;
弦向平移扫描 H2:最优 δ = 0)。而候选只剩 **G1.6 家族**。

**但"量级误差"还能再分成两种完全不同的病**:

| | 症状 | 指向 |
|---|---|---|
| **常数偏置** | 计算 Cp 在整个带上系统性地偏高/偏低 | **局部载荷 / 环量**(该站的升力量不对) |
| **散布** | 均值对得上,但点与点之间乱 | **壁面恢复 / 刻面几何**(G1.6 家族) |

⇒ 这一分解**直接决定下一步该往哪投**,而它是**一次求解 + 零成本分析**。

★ 现成数据不够:前两轮的脚本都算了曲线但**没有落盘残差** ⇒ 需要**一次求解**(实测 ~184 s)。

## 1. 量:一个恒等式,不是一个拟合

对某站某带的 N 个点,记 d_i = Cp_计算(x_i) − Cp_实验(x_i):

    bias = mean(d)          var = mean((d − bias)^2)          RMS^2 = bias^2 + var

**偏置占比** `f_bias = bias² / RMS²` ∈ **[0, 1]**。

★★ **它无量纲、有界、自归一** ⇒ 判据不需要任何物理尺度的手拍阈值,
这正好避开我前几轮栽过的"绝对阈值"缺陷。
★ 而 **bias 的符号**必须一并报:`bias < 0` 表示计算的 Cp **更负 = 吸力更强**
⇒ 那是"外翼前缘过度加速";`bias > 0` 是反向。**符号是诊断的一半。**

**守卫**

- **G-I(恒等式)**:每站每带必须满足 `bias² + var == RMS²`,**rtol 1e-12**。
  ★ 不过就停 —— 那说明我的分解写错了,而**任何 f_bias 都无意义**;
- **G-R(同溯源活参照)**:本次求解的**池化 LE 上 RMS 必须 = 0.242221**(上一轮逐位值)
  ⇒ 证明是同一条腿。不过就停下对齐;
- **G-S(符号一致性,RECORDED)**:报各站 bias 的**符号**是否一致 ——
  ★ 若符号在站间**翻转**,那就**不是**一个全局水平误差,这一条比 f_bias 更有信息。
