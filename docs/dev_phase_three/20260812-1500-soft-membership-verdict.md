**就在等熵答案旁边**。

★★★ **所以"散布从 32 % 掉到 4 %"这件事,数据上分不清是**
**(a) 跳变消失了,还是 (b) 剩下的修正太弱、已经没什么可敏感的了。**
这与 θ 那一轮的混淆**同源**(θ 缩放乘积,分不出"一次强收费"和"多次弱收费")。
⇒ **要分开,必须专门设计一条"去掉跳变但保持幅度"的腿**:
在带内做**重整化**,使被收的总熵与硬开关下相同(例如把 `w_soft` 归一化到带内积分守恒),
而不是让带内单元少收费。**这一条本轮没做,如实登记为未完成。**

## 4. F5(模型侧的代价)—— **混合族 FAIL**

M1 判据 (a) 的口径是 x_shock **0.61 ± 0.02 = [0.59, 0.63]**。

## 5. ★★ eps 的敏感性:剧烈且**非单调** ⇒ eps = 0.05 是**甜点**,不是稳健设置

非结构族的 cl 散布随 eps:**0.21 %(基线)→ 10.27 %(0.02)→ 1.84 %(0.05)→ 41.08 %(0.10)**。

⇒ 通过判据的那一格是一个**窄的、非单调的甜点**。
项目已被这个形状咬过四次(EW forcing / taper r_c / descent10 / 本轮的 τ),
所以**这一格的 PASS 不能当作"这个设置可以采纳"**。

## 6. ★ 我自己判据的**第三个缺陷**

**F1 是一个绝对阈值(≤ 5 %),而两族的基线差 150 倍**(32.11 % vs 0.21 %)。
于是在非结构族上,eps=0.05 把散布从 **0.21 % 变成 1.84 %(实际变差 8.8 倍)**,却被判 **PASS**。

⇒ **F1 分不出"改善"与"在阈值内的退化"。** 正确的形式应当是**相对基线**的判据
(例如"散布 ≤ 基线的 1/3 且 ≤ 5 %")。
★ 这是连续三轮的第三个判据缺陷:**单边带 → 未平衡面板 → 绝对阈值**。
三次都是同一个毛病:**我写的判据没有覆盖被比较量的定义域**。
**按规矩不事后改判** —— 本文按 F1 的字面记 PASS,并把这个缺陷登记为必须在下一轮修掉的东西。
