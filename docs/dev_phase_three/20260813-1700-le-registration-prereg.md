## 1. 本轮要问的、从未被检查过的那件事

LE 带是 **x/c ∈ [0, 0.15] 的上表面**,而那里实验 Cp **极陡**(前缘吸力峰)。
⇒ **一点点弦向错位,就会把 RMS 放大得极大** —— 而这**从未被检查**:
所有已做的工作都在问"振幅为什么不对",没人问过"**有多少只是位置不对**"。

**判别器(一个参数,零额外求解)**:允许一个**全局弦向平移** δ,把计算曲线在 x+δ 处取值,
再对同一批实验点算 LE 带 RMS,并对 δ 取最小。

★★ **它便宜到不做没有理由**:分析本身零成本;只需 **1 次求解**(生产腿 medium,实测 **162 s**)
把全精度的 section 曲线拿出来。

## 2. ★★★ 一条必须事先写死的解读禁令

**"平移能解释误差"绝不等于"误差不存在或不重要"。**
一个位置偏了的吸力峰**仍然是求解器的误差**。判别器做的是**重新归因**:
把它从"**振幅 / 壁面恢复**"类改判为"**位置**"类 —— 而这两类指向**完全不同的后续工作**
(前者指向 G1.6/P11 的刻面几何与 P1 恢复;后者指向前缘附近的**几何离散或来流方向/环量**)。

★ 这条现在写下,是因为本会话已经因为"把一个诱人的解释当成结论"付过代价。

## 4. 设计

**一次求解**:生产腿 `(entropy=True, kutta="pressure")`、medium、带 taper、16 线程
(**线程由脚本打印**)。**seed 0**(与已产出的那一行同溯源)。
**平移扫描** δ ∈ **[−0.02, +0.02] c**,步长 **0.001 c**(41 个点),**事前声明**。
**5 个未遮蔽站点**逐字沿用(η 0.20/0.44/0.65/0.80/0.90),遮蔽的 0.96/0.99 只作 RECORDED。

## 5. 事前判据

**主量**:LE 上表面带 RMS(对 5 站汇总),作为 δ 的函数;**基线 = δ = 0**。

| | 条件 | 判定与后续 |
|---|---|---|
| **H1 位置主导** | 存在 \|δ\| **≤ 0.01 c** 使 LE 上 RMS **≤ 0.08**(S2 自己的靶) | ⇒ ★ **LE 那 70 % 里位置成分占主导** ⇒ 归因改判为"位置类",后续转向**前缘几何离散 / 来流方向 / 环量**,**不再**投入振幅类(刻面几何、P1 恢复)|
| **H2 位置不能解释** | 全部 \|δ\| ≤ 0.02 c 上 LE 上 RMS 都 **> 0.15** | ⇒ **位置不是主因** ⇒ 亏空是**真实振幅误差** ⇒ 下一个嫌疑是 **G1.6 类**(刻面几何 + P1 壁面恢复),而 P11 已把曲面元这条路测负 ⇒ 这将是一条**很硬**的结论 |
| **H3** | 介于两者之间,或最小值出现在 \|δ\| > 0.01 c | ⇒ **RECORDED,不宣称方向**;★ 若最小值落在扫描边界上,**必须如实报"边界受限"**,不得当成结果 |

**必须一并报(非判据)**

- **每站**的最优 δ(★ 若各站最优 δ **方向不一致**,那就**不是**一个全局错位,而是别的东西 —— 这一条比总 RMS 更有信息);
- 实验侧 LE 带的 **|dCp/dx| 中位数**,以及"多少 δ 等价于一个 RMS 单位"的换算;
- MID / TE 带在最优 δ 下的变化 —— ★ **若平移把 LE 修好却把 MID 弄坏,那它就不是一个可接受的解释**。

## 6. ★★ KILL CRITERION

1. **求解不收敛** ⇒ 无曲线可分析,停(实测该配置 3 种子全收敛,风险低);
2. **有效 δ 少于 21 个**(半个扫描)⇒ 插值范围不足,扫描无意义,停;
3. ★ **最小值落在 δ 扫描边界上** ⇒ **不得外推**;记 H3 并如实报边界受限;
4. 单腿 > 900 s ⇒ 停(实测 162 s)。
