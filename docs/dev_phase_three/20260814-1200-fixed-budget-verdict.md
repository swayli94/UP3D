## 8. 诚实的限定(一条都不省)

1. ★ **参照"曲线"只有两点** ⇒ 是**斜率**;所有"曲线上/下"读数都受此限;
2. ★★ **A3 不是全面变好**:MID 上 **0.122512 → 0.132587(+8.2 %,更差)**,而 LE 下
   **0.210982 → 0.111728(−47.0 %)** ⇒ 它**把 MID 换成了 LE**。只报 LE 会掩盖这一点;
3. ★ **逐站不均匀**:η0.65 **−34.8 %** 最好,而 **η0.90 只 −4.7 %**、η0.44 −5.3 %
   ⇒ **η0.90 在 LE 加密下同样最顽固**,与前三轮"η0.90 特殊"一致;
4. ★★ **解在动**(G-S,RECORDED):A3 的 **M_max 1.6958 而峰值在内侧**(`m_max == m_max_inboard`),
   其余腿峰值在外侧;cl_p A1 0.2757 / A2 0.2462 / A3 0.2642 vs 控制 0.2659 ⇒ **不能**把 RMS 的变化
   全归给"同一个解被解析得更准";
5. ★ **σ 冻结报警在每条腿上都报 `frozen_in_transient`** —— 与本会话早先测到的触发率一致
   (τ=1e-3 上 100 %),**RECORDED,非本轮判据**;
6. ★ **A2 的读数不可用**(AR 3.4× 控制)⇒ "壁面重"这个方向**实际上没测成**,
   只有 A1(外场重)和 A3(近体重)两侧。
