## 0. 为什么这是下一轮,而不是"再试一个分级旋钮"

上一轮测到:**按比例的全尺度加密**是唯一被测到能降低对实验误差的杠杆
(四级单调,LE 上 RMS **−54.9 %**),但它要 **25.2× 单元 / 549× 墙钟** ⇒ 对 **2 CPU·min 不是产品答案**。
而 **单旋钮**腿在 M6 上已被测过、**不降误差**(−1.4 %…+3.4 %)。
⇒ 剩下的问题只有一个,而它决定后面所有投入:

> **那 −54.9 % 是"尺度之间的比例"买来的,还是"单元总数"买来的?**

★★ **两个答案的后续完全相反**:若是**比例** ⇒ 分级/自适应能在产品成本内拿到精度;
若是**纯单元数** ⇒ 分配无解,**那才是"提高阶数(等参 P2)"第一次拿到被测量支撑的立项理由**
(上一轮把 P2 记为"已评估-未开"时,写下的立项条件正是这一条)。

## 2. ★★★ 主量:不是"两个数比大小",而是"**落在曲线上还是曲线下**"

★ 直接写"固定单元数"会犯我这一季第 4 号判据缺陷(**把输出当输入**):
**单元数是网格生成的输出**,我只能**搜**,不能**设**。所以判据不建立在"数完全相等"上:

> 在 HEAD 上重测一条**误差 vs 单元数**的参照曲线(同代码、同配方),
> 然后看**重分配后的网格是落在这条曲线上,还是落在它下面**。

★★ 这样做同时解决三件事:① 残余的单元数不匹配**自动被吸收**(在腿自己的单元数处比曲线);
② 判据是**相对**的(比自己的曲线,不是比一个手拍的绝对值);
③ 它问的正是产品问题("**同样的单元数能不能买到更好的精度**")。

**参照曲线(HEAD 重测,2 点)**:`h_wall 0.030 / h_edge 0.015 / h_te 0.015`(≈ 旧 coarse)与
`h_wall 0.015 / 0.0075 / 0.0075`(≈ 旧 T0 = committed medium 的 h_wall)⇒ 给出本轮自己的
**增益 G = RMS(coarse) − RMS(medium)** 与两点的单元数。
★ **不接 2026-08-01 的 0.3899/0.2358**(第 5 问,跨时间);上一轮已写死这一条。

**固定预算腿(预算 = 本轮 HEAD coarse 腿自己的单元数,±10 %)**:

| 腿 | 干预 | 补偿 |
|---|---|---|
| **A0 控制** | 生产默认(`h_far` 默认 = 2.5) | — |
| **A1 体网格重** | `h_far` **1.25**(≈2× 细) | 抬 `h_wall`(+`h_edge` 同比)直到落回预算带 |

它在这里的作用是**剂量响应的另一侧**,让"比例有效"这件事必须**双向**成立才算。

## 5. 事前判据(binding = **LE 上表面 RMS**,与前三轮同一个量)

设 G = RMS(coarse) − RMS(medium)(HEAD 重测,**若 G ≤ 0 ⇒ kill 条 1**),
r = [RMS(A0) − RMS(best A)] / G = **重分配在固定预算下恢复的增益比例**。

| | 条件 | 判定与后续 |
|---|---|---|
| **B1 分配是杠杆** | **r ≥ 1/3**,且方向**双向一致**(A1 与 A2 分居 A0 两侧) | ⇒ ★ **同样的单元数能买到明显更好的精度** ⇒ 下一步投**分级/自适应配方**;★ 并**推迟**任何提高阶数的投入 |
| **B2 是纯单元数** | 全部固定预算腿都落在 **A0 的 ±10 %** 以内(即 \|r\| < ~0.1 量级),且质量守卫通过 | ⇒ ★★ **分配无解** ⇒ **等参 P2 的立项条件(上一轮 §6)首次被满足**,把它写进能力边界作为**有测量支撑的**候选;★ 但仍**不等于**立即开工(穿透 4/4 与禁止项不变,仍需使用者裁决) |
| **B3** | 介于两者之间;或**方向不一致**(A1/A2 同侧);或收敛+合格腿 < 2 | ⇒ **RECORDED,不宣称方向**;★ **方向不一致必须如实报** —— 它会说明"体网格细/粗"不是那条轴 |

**守卫**

- **G-B(预算)**:每条腿的**实际单元数**必须落在控制腿的 **±10 %**;★ 落不进就**记为未达预算**并
  **在曲线上比**(§2),**不许**当作固定预算腿;
- **G-Q(网格质量,相对)**:`max_aspect ≤ 2×` 控制腿自身、`min_dihedral ≥ 1/2×` 控制腿自身
  ⇒ 不合格腿**排除并记录**。★ 这条来自本阶段的 hex v1 事故(AR **1305** 而守卫只查了定向:
  "没有翻转单元"≠"网格可用");
- **G-M(守卫要覆盖结论所claim的东西)**:每条腿必须报 **LE 带切向/法向间距** *和*
  **r = 1–2 MAC 处的中位单元尺寸** —— ★ phase two 的教训:只看皮肤会把"体网格动了 24 %"读成"干净";
- **G-S(解在动,RECORDED)**:每条腿报 `M_max / m1_max / sigma_min / cl_p`。
  ★ 上一轮实测全尺度加密使 M_max **+43.2 %**、cl_p **+12.1 %** ⇒ **"解变了"是读数的一部分,不是噪声**。

## 6. ★★ KILL CRITERION

1. **G ≤ 0**(HEAD 上 coarse 不比 medium 差)⇒ 参照曲线不存在,**停** —— ★ 那本身会是对上一轮
   四级阶梯的**反驳**,必须如实报而不是换个量再试;
2. **控制腿 A0 不收敛** ⇒ 停(整轮无基线);
3. **某条腿 4 次生成仍进不了预算带** ⇒ 该腿记为**未达预算**并只在曲线上读,**不再加生成次数**;
4. **总墙钟 > 3 600 s** 或**单腿 > 900 s** ⇒ 停并如实报已完成的部分;
5. ★ **所有腿的 LE RMS 逐位相同** ⇒ **不是 B2,是可疑**(旋钮没进到求解)⇒ 先查仪器
   —— 与分诊 ① 的 G-D、尖端轮 kill 条 4 同一教训。

**明确不算 kill**:**B2** —— 它是**有价值的**结果,它把 P2 从"没被证明必要"变成"**有测量支撑的候选**";
**M3 仍不达标**(沿用前十二轮的豁免)。
