## 1. ★★★ 量:两个**同单位**的量,判据是它们的**比**

在**同一批实验横坐标**上取值(所以两个量都是"Cp 的 RMS",可以直接比):

    e(h)      = RMS[ Cp_h(x_exp) − Cp_exp ]                  ← 对实验的误差(以往一直在量的)
    d_self(h) = RMS[ Cp_h(x_exp) − Cp_{h/√2}(x_exp) ]        ← 相邻两级之差(自收敛 / Cauchy)

**判据 = `d_self / e`,无量纲、不需要任何物理尺度的手拍阈值。** 逻辑:

| | 含义 |
|---|---|
| `d_self` **随加密变小**,且 **≪ e** | 解**已经基本收敛**到某个东西,而那个东西**不是实验** ⇒ 残余是**模型误差** ⇒ **任何无粘 FP 解都到不了靶子**,靶子本身要带模型误差带(Track V 的门早就有 A4 带,**M3 从来没有**) |
| `d_self` **不随加密变小**,或与 `e` 同量级 | 解**还没收敛** ⇒ 残余是**离散/求解器**问题 ⇒ phase two 说的"游走"成立,而根因在离散侧 |

★ **这不需要任何新参照数据**,也不需要 XFOIL/Euler ——
`cases/reference_data/` 里 M6 只有实验、**没有无粘参照**(已查),所以外部路线本来就走不通;
**自收敛读数绕开了这件事**,而它回答的正是同一个问题。

## 4. 事前判据(binding = **LE 上表面**;MID/TE 一并报)

设最细那一对为 (S3, S4):`R = d_self(S3→S4) / e(S4)`。

| | 条件 | 判定与后续 |
|---|---|---|
| **N-MODEL** | **R ≤ 1/3** 且 `d_self` 在 4 对上**单调变小** | ⇒ ★★★ 解已基本收敛而**不朝实验**;残余 ≥ 2/3 是**模型误差** ⇒ **M3 的 LE 靶子需要一条模型误差带**(照 Track V 的 A4 做法),**LE 这条线以"测量结论"收口** |
| **N-DISC** | **R ≥ 1** 或 `d_self` **不变小** | ⇒ ★★ 解**没收敛** ⇒ "游走"成立且根因在**离散侧**;下一步是"**为什么不收敛**"(与分配/阶数都不同的第三类问题) |
| **N-MIX** | 1/3 < R < 1(且 d_self 单调) | ⇒ **RECORDED,不宣称**;并报**外推的收敛极限**与它到实验的距离 |

**必须一并报(非判据)**

- 4 对的 `d_self` 与 5 级的 `e`,**逐带逐面**(LE/MID/TE × 上/下);
- ★ **观测阶** `p` 由 d_self 的相邻比给出(√2 射线 ⇒ `p = log2(d_i/d_{i+1})/0.5`),**报出但不作判据**

- ★★ **Richardson 外推的极限** `Cp_∞` 及 `RMS[Cp_∞ − Cp_exp]`:**若它显著大于 0.08,那就是"靶子不可达"的直接数字**;

- **S2 vs 上一轮 C_coarse 的差** = `h_far` clamp 缺陷对 LE 带的效应(RECORDED,首次量化);
