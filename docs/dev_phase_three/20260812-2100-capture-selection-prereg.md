# 20260812-2100 预注册 — **改"捕获"而不改"幅度"**:在已算出的 σ 场里**挑**一个,而不是混合

**在任何代码之前提交**(roadmap 原则 8)。上游 = [20260812-1900 判定](20260812-1900-magnitude-preserving-verdict.md) §5。

## 0. ★★ 入口检查(零求解)—— 它直接判掉了两个候选

使用者最初列的三个候选里,**松弛**与**平均**在这里**都会把上一轮刚排除的混淆带回来**:

| 候选 | 幅度中性? |
|---|---|
| **平均**(σ 取窗口内若干次刷新的均值) | ✗ **不中性** —— 0.743 与 0.987 的均值是 0.865,**比 0.743 弱**;这正是"削弱"那条混淆 |
| **松弛**(σ ← (1−ω)σ_old + ω σ_new) | ✗ **不中性** —— 它就是指数加权平均,同上 |
| ★★ **选择**(在已经算出来的那几个 σ 场里**挑**一个) | ✓ **构造性中性** —— 不做任何混合,采纳的就是某一次刷新**原样**算出的场 |

⇒ **本轮做"选择",而不是"平滑"。** 这不是偏好:上一轮的全部教训就是"幅度与捕获同向移动时无法归因",
而**选择规则是唯一一个能只动捕获的手段**。

**规则(事前定死)**:在刷新阶段结束时,采纳 **|Δσ| 最小的那一次刷新**的 σ 场
(Δσ = 该次与上一次的 max|逐元素差|)。**第一次刷新没有 Δσ,不参与候选**(除非只有一次)。

★★ **它不引入任何新旋钮**:候选集合 = "所有有 Δσ 定义的刷新",没有窗口宽度、没有阈值、没有指数。
⇒ 本轮**没有可被指责为调参的自由度**,这是它相对"平滑"路线的第二个优势。

★ 为什么它对症:实测 seed 0 的 m1_max 轨迹是 1.26/1.23/1.58/1.33/1.36/1.49/1.33/**1.95** ——
**最后一次是最差的一次**(尖峰),而现行实现恰恰采纳最后一次。选最"安静"的那次就避开尖峰。

| | 条件 | 判定 |

| **K1** | m1_max 散布**下降**,**且** cl 散布满足 **F1′** | ⇒ ★ **只改捕获就够** ⇒ 机理确认(P-A),且**不需要动幅度** ⇒ 进入采纳评估(F5) |

**同时必须报**

- **G-M(幅度中性,输入侧守卫)**:采纳的 `sigma_frozen` 必须与**某一次候选刷新的 σ 场逐位相同**
  ⇒ 证明"没有发生混合"。**不过就停**(那说明我实现成了平滑而不是选择);

  本轮若 K1 成立,**F5 必须同时改善才谈采纳** —— 只改善散布不算。

## 附录 #1(**冒烟测试之后、正式执行之前登记**)—— 我的选择规则有**系统性偏置**

实现完成后的一次冒烟(混合族 seed 0)暴露了一个规则层面的缺陷:

| | 采纳的刷新 | σ_min | m1_max | 结果 |
|---|---|---|---|---|
| off(对照) | 第 8 次(最后) | 0.74317 | 1.9522 | cl 0.261367 / x_shock 0.7141 |
| **on(|Δσ| 最小)** | **第 2 次** | **0.98975** | **1.2286** | cl 0.357488 / **x_shock 0.5601** |

★★ **"|Δσ| 最小"会被"σ 几乎没在做事"的刷新最小化** —— 也就是**激波还没长出来**的早期刷新。
所以它系统性地挑弱修正:采纳的 σ_min 是 0.98975(几乎不修正),
而得到的 x_shock **0.5601 ≈ σ 全关时的 0.5605**。

⇒ **规则不混合(G-M 仍成立),但在效果上仍偏向弱修正** ——
**上一轮刚排除的"削弱"混淆会从侧门回来**,一个 K1 结果仍然是被混淆的。

### 修正(现在定,不看结果)

**主规则改为"相对 Δσ 最小"**:

    rel_delta = |dsigma| / max(1 - sigma_min_of_that_refresh, 1e-12)

- σ 几乎不作用的刷新,`1 − σ_min ≈ 0` ⇒ **相对 Δσ 很大,不再被选中** ⇒ 偏置消除;
- **仍然没有新旋钮**(1e-12 只是除零保护,不是标定);
- **仍然是"选择"而非"平滑"** ⇒ **G-M 不变**。

**绝对 |Δσ| 规则保留为 RECORDED 的对照臂**(它已经跑过冒烟,数字在上表),
这样"偏置是真的"这件事在判定里有据可查,而不是我口头说一句。

★ 判据 K1–K4、F1′、平衡面板、G-M、F3、F2、F5 **一字不改**;改的只是**主规则的统计量**,
且这个修改是**在看到任何 K 判据读数之前**做的 —— 冒烟只看了"机制是否开火"与 G-M。
