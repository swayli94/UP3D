## 0. 这笔债是什么(读原文,不凭印象)

M6 分诊那一轮(`20260813-0300` 预注册)把问题拆成两臂:

> arm A(**爬坡**,生产配方,三种子)→ **Q-A**:committed M6 锚点可复现吗?
> arm B(**在 M0.8395 直接求解,无爬坡**)→ **Q-B**:**系统本身**有没有多解?
> ★ 若 A 稳而 B 散,结论是"**爬坡钉住了解选择**",**不是**"M6 没有多解"。

**Q-A 已答**(分诊重做,2026-08-13):三种子在**爬坡**路径上 **cl_p 散布 0.0011 %**、
**LE 上 RMS 散布 0.0025 %**,全部机器精度收敛 ⇒ **T1**。
★ 而 arm B 当时因成本被**推迟**(addendum #2),成为登记在案的挂账。

★★ **为什么 Q-B 重要**:项目自己的记录是"**ramp 与 seed 是同一个函数的两种实现**"
⇒ 若爬坡是**钉住解**的那个东西,那么 **Q-A 的"可复现"就不是"系统唯一"**,
而 **M1 的 (b)(c) 不可测量**这条结论(来自 2.5-D 的多解)在 3-D 上就还没有对照。

## 1. ★★★ 入口检查:**不能照 triage 脚本的 arm B 原样跑**

`bench/run_task3_m6_triage.py::production_solve` 的 arm B 写得很清楚(已读原文),但它
**没有加生产 tip_taper** —— 它的已提交 CSV 正是那个已知会死的配置:
`task3_m6_triage_{8t,16t}.csv` 里 **cl_p 0.2493、三腿 converged=False**
(与 M3 重测那一轮测到的"圆角帽 + 无 taper ⇒ medium 爬坡整体失败"完全一致)。

⇒ 照它原样跑,直解臂会因为**缺 taper**而不收敛,而**不是**因为**缺爬坡**
⇒ **那会答错问题**(把两个原因混在一个 conv=False 里,正是 CLAUDE.md 记过的"别报裸的 conv=False")。

★★ **因此本轮的直解臂建在 `run_m3_budget.solve()` 的生产腿上**(它**有** taper),
**只去掉爬坡这一步**:探针 M0.70 → 然后 `solve_newton_lifting` **直接在 M0.8395**,而不是
`solve_newton_transonic`。
★ **这是对 triage arm-B 定义的一处 deliberate deviation,理由如上,并在此登记。**
★ 守卫 **G-S(源码复制)**:脚本必须**断言**它复制的正是 `run_m3_budget.solve` 的 pressure 分支
(用 `inspect.getsource` 比对关键行),否则两臂就不可比 —— 这是 `run_m3_budget` 自己对
`test_p8_newton::_m6_case` 用过的同一手法。

## 4. 事前判据(binding = **cl_p 的跨种子散布**;LE 上 RMS 一并报)

**参照(同溯源)**:Q-A 的爬坡臂散布 **cl_p 0.0011 %**、**LE 上 RMS 0.0025 %**,
出处 `bench/gate_results/m3_budget_head_medium{,_seed5,_seed12}.csv`(每种子一个文件)。

| | 条件 | 判定与后续 |
|---|---|---|
| **QB-RAMP-PINS** | ≥2 腿收敛,且 cl_p 散布 **≥ 10×** 参照(即 **≥ 0.011 %**) | ⇒ ★★ **爬坡在钉住解选择** ⇒ **Q-A 的"可复现"不等于"系统唯一"**;3-D 上**存在**被爬坡掩蔽的多解 ⇒ 与 2.5-D 的多解结论连成一条 |
| **QB-UNIQUE** | ≥2 腿收敛,且散布 **≤ 2×** 参照(**≤ 0.0022 %**) | ⇒ **在种子所能探到的范围内,该工况的系统本身唯一**(不需要爬坡来钉)⇒ M1 的 (b)(c) 不可测量这条**不向 3-D 推广** |
| **QB-MIX** | 介于 2× 与 10× 之间 | ⇒ RECORDED,不宣称 |
| **QB-UNDEF** | **收敛腿 < 2** | ⇒ ★★★ **UNDEFINED**,并**逐腿分型**;★★ **禁止句(逐字沿用分诊的登记)**:**不收敛不是唯一性的证据** —— 不得写成"直解不出来 ⇒ 没有多解" |

**必须一并报**
- 逐腿:`converged / |R| / n_newton / n_limited / n_floored / accept_reason / 分型 / 墙钟`;
- 逐腿:`cl_p / cl_KJ / M_max / m1_max / sigma_min` 与 **LE 上 RMS**;
- ★ **探针腿自己的 cl**(`probe_cl`)—— 它是"种子有没有改变初始状态"的直接读数;
- ★ 与 **Q-A 的爬坡腿逐项并排**,并标明**唯一差别是爬坡**。

**守卫**
- ★★ **G-S(源码复制)**:断言直解臂复制的是 `run_m3_budget.solve` 的 pressure 分支(`inspect.getsource` 比对);
- **G-D(种子确实进入求解)**:三腿的 `probe_cl` 必须**不全相同**;
  ★ 分诊重做已记 **seed 12 与 seed 0 在 CSV 精度上相同** ⇒ 若再现,**如实记为"该种子可能未进入求解"**,
  **不**把它算作一个独立样本;
- **G-P(同溯源参照)**:打印 Q-A 三个 CSV 的路径与读到的 cl_p;
- **G-C(不覆盖证据)**:本轮写**自己的**文件 `task3_qb_direct.csv`,Q-A 的三个文件**一字节不动**;

## 5. ★★ KILL CRITERION

1. **G-S 不过**(复制与 `run_m3_budget.solve` 不一致)⇒ **停**,两臂不可比;
2. **G-D 不过**(三腿 `probe_cl` 全相同)⇒ **停**:种子没进求解,散布读数无意义;
3. **单腿 > 1 200 s** ⇒ 该腿记为**超时**并停止该腿(★ 不延长,爬坡存在的理由就是直解慢);
4. **总墙钟 > 3 600 s** ⇒ 停并报已完成部分;
5. ★ **参照 CSV 找不到** ⇒ 停(不许用别的轮次的数顶替)。

**明确不算 kill**:四支判定中的**任何**一条 —— ★ 尤其 **QB-UNDEF**,它是**最可能**的结果,
而它的价值在于**逐腿分型**(把"直解为什么不行"分成钳制 / 限制环 / 病态 / 线搜索 / σ 输运);
**M3a 仍不达标**(沿用前二十四轮的豁免)。
