★★★ **所以本轮必须把两个不同的问题分开,不许混成一个:**

1. **Q-A(实用问题)**:**已提交的 M6 锚点是不是一次任意抽样?**
   ⇒ 用**生产配方(爬坡)**跑三个种子。这是决定那些数可信度的那一问。
2. **Q-B(机理问题)**:**M6 这个离散系统本身在该工况上是否多解?**
   ⇒ 需要**绕开爬坡**(直解),因为爬坡会掩盖它。

★ **若 Q-A 稳定而 Q-B 散** ⇒ 结论是"**爬坡把选择钉住了**",**不是**"M6 没有多解"。
这两句话不同,而**只有前者是数据支持的**。本轮**明确禁止**把 Q-A 的稳定报成后者。

## 2. 设计

**条件**:M6 / **M0.8395 / α3.06**(TEST 2308 逐字)、**coarse**、**8 线程**。
**配方**:`run_m3_budget.py::solve` 的 **`(entropy=True, kutta="pressure")` 生产腿逐字**
—— 它就是产出 P14 锚点与 M3 预算的那一条。
**种子集合事前声明**:`{0, 5, 12}`(与 2.5-D 各轮同一集合,便于对照)。

| 臂 | 做什么 | 回答 |
|---|---|---|
| **A(爬坡,生产)** | 三个种子各跑一次生产爬坡 | **Q-A** |
| **B(直解,机理)** | 三个种子各在 M0.8395 上**直接** `solve_newton_lifting`(无爬坡),其余逐字相同 | **Q-B** |

⇒ **6 次求解**。★ 臂 B 很可能不收敛(GS3.3a 实测:无爬坡 222.8 s 不收敛 vs 爬坡 70.8 s 收敛)——
**那是一个被允许的结果**,按前提 P1 记为 UNDEFINED,**不得**当成"臂 B 没有多解"。

**每条腿记**:cl_p、cl_KJ、x_shock(各 η)、**LE / MID / TE 三个带的 RMS**、m_final、
clamps、σ_min、m1_max、`sigma_freeze_report`、墙钟。

## 3. 事前判据

**主量**:臂 A 平衡面板上的 **cl_p 与 cl_KJ 相对散布**,以及 **LE 带 RMS 的相对散布**。

| | 条件 | 判定与后续 |
|---|---|---|
| **T1** | 臂 A:cl 散布 **≤ 0.5 %** **且** LE 带 RMS 散布 **≤ 2.5 %** | ⇒ ★ **已提交的 M6 coarse 锚点在生产配方下是可复现的**,不是任意抽样 ⇒ **LE 那 70 % 站得住**,分诊 ② 可以照常推进 |
| **T2** | 臂 A:cl 散布超 0.5 % **但** LE 带 RMS 散布 ≤ 2.5 % | ⇒ ★★ **协议 §3 那个假设被证实**:**升力是多解的载体,LE 亏空与它可分离** ⇒ LE 工作可推进,而**每一个 3-D 升力数都要改报集合** |
| **T3** | 臂 A:**LE 带 RMS 散布也超 2.5 %** | ⇒ **LE 那 70 % 需要重新定基**,"LE 占 70 %"在该工况上无意义 ⇒ LE 项必须改到 α=0 / 冻结 Γ 上做 |
| **T4** | 臂 A 平衡面板 < 2 条 | ⇒ **UNDEFINED**,RECORDED,不宣称方向 |

**臂 B 一律 RECORDED**(它回答 Q-B,而 Q-B 不决定锚点可信度):
若 B 散而 A 稳 ⇒ 记为"**爬坡钉住了选择**";若 B 不收敛 ⇒ 记为"**Q-B 在本配方下不可测**"。

**守卫 G-R(仪器)**:臂 A 的 **seed 0** 腿必须复现已提交的 P14 coarse 锚点
(cl_p **0.262778** / cl_KJ **0.268813**)到 **0.5 %** 之内。★ 不过就停 —— 那说明我没在复现生产路径,
下面所有散布都无从解释。
