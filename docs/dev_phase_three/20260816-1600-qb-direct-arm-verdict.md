## 3. ★★ 本轮真正的产出:分型一致指向「钳制」

CLAUDE.md 的失败分型表把五种模式与**完全不同的修法**对应起来:

| 模式 | 签名 | 修法 |
|---|---|---|
| ★ **clamping** | `n_limited`(m_cap)或 `n_floored`(rho_floor)> 0 —— **以及那些单元在哪** | **物理/几何** |
| limit cycle | 残差振荡、descent10 ≈ 1、数值重访 | 冻结选择 churn |
| ill-conditioning | `n_gmres_stalled` > 0 | 预条件 |
| line-search collapse | λ → 0 | 全局化 |
| σ-transport | `accept_reason = sigma_transport_not_converged` | 熵修正 |

**三腿全部落在第一行**(22–83 lim / 26–48 flr,而 `accept_reason` 为 None、无 GMRES 停滞)
⇒ ★★ **直解失败是"钳制"这一族**,所以它**不是**求解器全局化或预条件不够,
而是**在没有爬坡的情况下,解路径会走进 m_cap / rho_floor 被激活的状态**。
★ 与本阶段早先的一致读数:M6 在 α3.06 下**加密会把峰值推进 m_cap**(已记),而爬坡的作用正是
**逐级把状态带过那个区**。

★ **失败程度的种子依赖**(如实报,不做解释):seed 0 明显更差(83/48 clamps、只走 30 步就停、|R| 2.1e-3),
而 seed 5/12 走满 60 步并压到 |R| 2.4e-5 / 4.0e-5、clamps 少 3–4 倍。
★★ **这不能读成多解** —— 三腿**都没有解**,可比的东西不存在(禁止句)。

★ **F_final 很小**(3.7e-07 … 3.7e-04)而 |R| 停在 1e-5 量级 ⇒ **Kutta 侧基本满足、流场侧被钳制卡住**,
与"钳制是限速环节"一致。
