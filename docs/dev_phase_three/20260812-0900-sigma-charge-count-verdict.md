## 2. ★★★ 我要撤回的一句话(这是本轮最该记的过程错)

上一轮末尾我写过:**"'被收多次'不是假设,是算式逼出来的 N ≥ 7–12。"**
推理是"每个因子 s = σ_RH(M₁),而 M₁ ≤ 流场峰值马赫 ⇒ σ ≥ σ_RH(m_max)^N"。

**实测把它否掉了**:

| 腿 | 我用的参考 `sqrt(mach2_max)` | 实际的 `m1_max` | 实测 N |
|---|---|---|---|
| 混合 seed 0 | 1.3987 | **1.9522** | **1** |
| 混合 seed 5 | 1.3329 | **1.8581** | **2** |
| 混合 seed 12 | 1.3817 | 1.2473 | 1 |

**一次收费就够了** —— 因为膝点走步找到的 M₁ 是 1.95,远高于我当作上界的那个 1.40。

**错在哪**:`mach2_max` 是**最终收敛场**的峰值(`newton.py:1332`,解完之后算),
而 `m1_max` 是**最后一次 σ 刷新那一刻**的走步结果。两者**测在迭代的不同时刻**,
我拿它们做了**跨量比较**,还据此把一个假设**升级成了定理**。

★ 这与项目已记的"**引用你的流水线真正跑过的那一个**"(P14 的 TE gap 两种口径)、

**教训**:把假设升级成定理之前,先确认不等式两边**是同一时刻、同一场、同一函数**测的。
(N2 那条断言之所以"通过",正是因为它用了**正确的** `m1_max`;是我在散文里用了错的参考。)

## 4. ★★★ 机理:σ 被冻在振荡的一个瞬态相位上(**读出来的,不是推断**)

`newton.py:1265` + 那段 measured 注释:**`_SIGMA_REFRESH_MAX = 8`** —— σ 只在前 8 步刷新,
之后**冻住**。注释给的理由是实测的、而且是对的:**后激波"集合"是离散选择、会极限环**
(coarse M0.7875 上一个单元在集合里进出交替、残差停在 ~5e-6),冻住它才能让尾部变成
固定的光滑系统、让 Newton 二次收尾。

**本轮读出的是它的副作用。** m1_max 在 9 次记录(1 次初始 + 8 次循环内)上的轨迹:

| 腿 | 刷新 / 总步 | m1_max 轨迹(**最后一个 = 被永久冻住的值**) |
|---|---|---|
| 混合 seed 0 | **8 / 48** | 0;1.26;1.23;1.58;1.33;1.36;1.49;1.33;**1.9522** |
| 混合 seed 5 | **8 / 31** | 1.32;1.63;1.32;1.34;1.42;1.53;1.32;1.28;**1.8581** |
| 混合 seed 12 | **8 / 37** | 2.71;2.57;2.34;2.01;1.96;1.70;1.64;1.28;**1.2473** |
| 非结构 seed 0 | **8 / 28** | 0;1.34;1.62;1.25;1.54;1.29;1.37;1.39;**1.3900** |
| 非结构 seed 5 | **8 / 21** | 1.38;1.34;1.27;1.29;1.30;1.31;1.31;1.30;**1.3385** |

三件事同时成立:

1. **每条腿都把 8 次预算用光**,之后 σ 冻住 **13–40 步**(seed 0 是 40 of 48);
2. **轨迹在大幅变化**(1.26 → 1.23 → 1.58 → 1.33 → 1.36 → 1.49 → 1.33 → 1.95);
   ★★★ **勘误(2026-08-12,下一轮的入口检查发现)**:本文原写"与注释自己说的『集合会极限环』一致"
   —— **那个归因是错的**。注释记录的极限环是 `n_shock 73↔74`、σ_min 在**第 7 位**上交替、
   发生在**尾部**;而这里 σ_min 的摆幅是 **0.02–0.99**,差六个数量级,形状也不是二周期
   (seed 12 是 0.4201→0.2539→**0.0000**→0.6245→…→0.9874,**单调恢复的瞬态**)。
   ⇒ **这 8 次刷新量到的是 Newton 瞬态,不是那个已记录的极限环。**
   两者**方向相反**:打掉尾部极限环要**停止刷新**,避免冻在瞬态上要**继续刷新**
   —— 固定的 8 次两边都不保证,**这才是路径依赖的真正来源**;
3. ★★ **seed 0/5 的最后一次刷新正好落在尖峰上(1.95 / 1.86)** 并被永久冻住;
   **seed 12 落在已经安定下来的 1.25 上**(它的轨迹是单调下降 2.71 → 1.25)。

⇒ **冻的是瞬态的哪个时刻,由种子决定**(原文写"振荡的哪个相位",按上面的勘误更正)。 而冻住的幅度差了 1.95 vs 1.25 ——
σ 0.743 vs 0.987,于是尾部要收敛的**固定系统本身不同**,收敛到的解自然不同(cl 0.26 vs 0.35)。

★★★ **最尖的一条(读代码自己的理由得到的)**:那段注释的论证覆盖的是**离散集合**
——"a discontinuous selection is not something Newton can resolve"——
但**实现冻住的是整个 σ 数组,集合 和 幅度 一起冻**。
**幅度是连续量,它本来不需要被冻**;把它冻在一个任意相位上,正是路径依赖被注入的地方。
⇒ 这给出一个**有明确靶子的候选修法**:只冻**选择集合**,幅度继续随状态更新。
(候选,不是提案;要开须另行预注册。)
