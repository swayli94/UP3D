   `run_capability_matrix.py` 的 `MACH_NOT_ATTAINED` 判据**永远不可能开火**，而它自己的

   **未知**。任何把 M3a 当"不可达"引用的句子都是错的。
5. ★★ **最硬的一条开放亏空不是"误差大"，而是"解不收敛"**：M6 的 **LE 上表面** `d_self`
   随加密**增大 21.2 %**（R = 1.2245）。近奇异内区只解释约一半（41.7 % 的点占 74.9 % 的
   d² 质量），**外区仍不收敛且没有任何机理候选** —— σ / 尖端 / 激波足迹 / 局部弦长 /

6. ★★ **离散多解是这个求解器目前最危险的性质，而它不报任何错**：M0.80/α1.25 上只换
   `n_picard_seed`，三个解各自 `|R| ≤ 3e-11、0/0 clamps`，x_shock 撑开 0.1683 c = 判据带的
   **8.4×**，cl 撑开 32.11 % = 判据的 **10.7×**。七轮治法全部测过，结论是**取舍不是缺陷**。
7. ★ **【推断，附廉价证伪法】线程依赖很可能不是独立缺陷，而是第 6 条的症状。**
   我逐条检查了全部 `prange` 循环【实测】：唯一的跨迭代归约是一个**整数**计数器

   的线程依赖只能从 BLAS / pyamg / SuperLU 进来，而它**只有在解不唯一时才会表现成不同的解**。
   与已测事实一致：M6 M0.8395 爬坡 8t/16t **逐位相同**、M0.72 唯一，而线程翻转恰好只发生
   在 M0.80/α1.25。⇒ 别把它们当两笔债修。
8. ★★ **产品层的能力是零，而项目的目标句是产品句**【实测】：没有 CLI、没有

9. ★ **文档量已经超过代码量**【实测】：跟踪的 `.md` **54 267 行** vs 库 **20 230 行**（2.7×），

   GS4.1 那份"唯一入口"文件的存在本身就是这件事的症状 —— 而它自己在 §0 里写下的维护约定

### 5.3 ★★【是取舍不是缺陷】—— 这条最容易被读错

**唯一性 vs 熵修正强度**。七轮系统测量的结论【转述】：

> 现有每一种手段（强度刻度 θ、软化宽度 eps、指数 q、捕获选择规则）在压低种子散布的同时
> **都在削弱修正**；而唯一一种构造性**不**削弱修正的手段（在已算出的 σ 场里"选择"而非
> "混合"，输入侧逐位守卫 12/12 PASS）**没有**压低散布 —— 反而把 binding 族的散布从
> 1.21 % 推到 7.47 % 并丢掉一个种子（K3，路线判死）。

⇒ **就当前离散化而言这是一对取舍**，边界清楚：**包线内（M0.72）完全唯一**；
出问题只在**强激波 + 升力耦合同时在场**时。
★ 并且顺带否掉了一个诱人的中间结论：捕获到的 `m1_max` 散布与 cl 散布**单调对应**
（相关成立），但去动它**推不动** cl 散布 ⇒ **相关不是杠杆**。

### 5.4 ★★★ 一条必须撤回的"不可达"

**M3a 的"无粘不可达"**（四点全尺度外推给出 MID/TE 地板 0.0516–0.0707）

54 267 行 md / 20 230 行库。phase 3 的 68 份轮次文件里，**勘误传播**本身是反复出现的成本项

### 9.2b ★★ 附录（2026-08-17，零机时）：那两个候选**具体是什么**，以及一处对我自己建议的削弱

★ 起因：§9.2 的表列了两个候选却没有定义它们，而**一个没有可引参照的建议就是一句话** ——
这正是本报告 §7.6 批评的那种形状。以下逐条给出**出处**，并**修正**表里"未估"那一格。

#### (A) 翼身粘性 case 入口 = 一个不存在的 `build_wingbody_case`

粘性求解需要一个 `CouplingCase`：把壁面网格翻译成 IBL 要的东西 —— 表面网格 + 入流带的
Dirichlet 层流种子 + 出流边 + 对称面 + 掩蔽带 + 转捩位置 + u_e 恢复区 + transpiration 掩蔽。
**HEAD 上有三个 builder，缺第四个**【实测 `pyfp3d/viscous/coupling.py`】：

| 有 | 行 | 没有 |
|---|---|---|
| `build_airfoil_case`（2.5-D 翼型） | 386 | |
| `build_closed_body_case`（闭合体 / 机身 BOR） | 467 | |
| `build_wing_case`（三维升力机翼，GV5.0/GV5.3） | 531 | ★ **`build_wingbody_case`** |

⇒ **M4 现在报不出 FAIL，只能报"没有入口"**（D7 原文：「HEAD 上还没有这个入口，
是独立的实现任务」）。缺的不是"把两个拼起来"，而是几处**语义上没有答案**的地方：
`build_wing_case` 的 docstring 明写 **z = 0 是对称面自然边界**，翼身上那里是**机身**；
`x_le` / `chord_at` 两个 planform callable 在机身段无定义；结合处（waterline）角区要一个
处置，而按 GS4.1 的 R2 先例**必须测不能假设**。

★★ **风险，事前写下**：GV3.3 实测机身**尾锥不收敛**（σ/μ 0.5533、横流 0.2631）、
GV5.0 实测机翼**根部上表面分离斑块 runaway**（ṁ_max ×12.4）。翼身把这两个已知病灶放进
**同一个 case** ⇒ **这项工作的产物很可能不是「M4 达标」而是「M4 第一次可测」**，
而那必须**事前登记成目标**，否则会变成又一次"跑不出来"。

#### (B) 体内梯度重构 = 换掉"每单元一个常梯度"这个恢复算子

**现状**【实测 `pyfp3d/kernels/gradient.py:32-52`】：每个四面体一个常梯度
`grad(φ)_e = Σᵢ φᵢ·B_e[i,:]` ⇒ 每单元一个 `q²` ⇒ 当地马赫 ⇒ 人工密度开关
`nu_e = C·max(0, 1 − mc²/max(m², mc²))` ⇒ 上风供体选择 ⇒ σ 的激波集合判定。
**整条跨声速机制都站在这一个常梯度上。**

**为什么它是登记项 1 的修法**（`phases/p2/docs/dev_phase_two/20260731-0000-s1b-chainfree-sigma.md`
§9.4，五族判别子全部失败**并给出机制**）：

> ★★ **阻塞性结论**：**一个畸形四面体在马赫场里产生的局部 signature，与一个激波的
> signature 是同一个东西**（单格大落差）。任何局部或半局部统计量都分不开它们 ——
> **因为没有东西可分**。

★ 且**不是分辨率问题**：max 从 **0.219 只降到 0.111，远慢于 O(h)** ⇒ 薄片/畸形单元。
真实的马赫场不是"均匀噪声"，是"**主体干净 + 约 1 % 重尾离群**"。
同文 §9.5 的三条出路里 **(b) 修梯度** = patch 最小二乘 / 二次重构代替逐单元常梯度
⇒ **坏单元不再产出坏马赫**；§9.5 同时点明它与 G1.6 **同根**。

**一个修法接三条开放亏空**：M1 的 (b)(c)（亚单元激波位置误差 × `dcl/dx_shock ≈ 2/弦长`
的放大）、G1.6 的壁面精度（同根）、以及 §6.1 把 LE 非收敛定的靶子
「前几个百分点弦长内、声速界面的亚单元表示」。
★ 壁面侧的对应物 `post/surface.py::wall_tangential_gradient_quadratic` **已经存在且默认在用**
（roadmap S2 第 1 条：GS2.2 因"前提已是现状"作废）；**体内侧没有**。

#### ★★ 两处修正

**① 它不撞裁决 D2 —— 这一条是放宽，不是收紧。**
D2 否的是**等参 P2**（几何与场**同时**二次）。体内梯度重构**自由度不变** ——
