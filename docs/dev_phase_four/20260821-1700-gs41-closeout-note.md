★★★ **由此立下的、可机器执行的规矩**（不是格言）：

1. **G-ASREGISTERED** —— 判据函数**打印自己注册时的原文**；逐站判据**必须返回 `(inside, total, worst)`**；
2. **A-WHOLE / G-WHOLE2** —— 转录源码时**逐块分类每个赋值**，未分类即 FAIL
   （★ 因为 **G-USED 这类"遍历我写下的常数"的守卫,永远看不见我没写下的项**）；
3. **G-ONECHANGE** —— 每条诊断腿**只改一件事并打印改了什么**；
4. **G-NOREWRITE** —— 改判定码时证明**数值列逐位不变**；
5. **G-SAMEAXIS / G-COLSEM** —— 共同横轴与列语义**先验证再使用**；
