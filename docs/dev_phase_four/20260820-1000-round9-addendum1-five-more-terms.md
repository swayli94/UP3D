## 1. 干跑发现了什么

第九轮要转录滞后方程,而滞后方程的源项是 `√CτEQ − √Cτ`,`Cτ` 经 `c_D` 驱动 `dH/dξ`。
**所以动手前必须先确认 `c_D` 与 XFOIL 同式。**逐块读 `xblsys.f` 的湍流段(不是只读常数所在的行),
发现**五处**我们与 XFOIL 不同 —— **全部是"整项缺失",不是"常数写错"**：

| # | XFOIL | 我们现在 | 出处 |
|---|---|---|---|
| 1 | 湍流站 `c_f = max(CFT, CFL)` —— 同时算层流式并取大者 | 只有 `CFT` | `xblsys.f:913-921` |
| 2 | 壁面耗散乘 `DFAC = 0.5+0.5·tanh((H_k−1)/(H_min−1))`,`H_min = 1+2.1/ln Re_θ` | 无 | `xblsys.f:965-985` |
| 3 | 外层项 `Cτ·(0.995 − U_s)` | `Cτ·(1 − U_s)` | `xblsys.f:1014` |
| 4 | 外层**层流应力**项 `0.15(0.995−U_s)²/Re_θ` | **整项没有** | `xblsys.f:1029` |
| 5 | `U_s > 0.95` 时钳到 **0.98**（`ITYP ≤ 2`） | 无 | `xblsys.f:836-838` |

★ 注意 #1 与 #2 的**不对称**要照抄:动量方程用 `max(CFT, CFL)`,而**耗散的壁面项用纯 `CFT`**
(`xblsys.f:959` 用 `CF2T`)。这不是笔误,是源码如此。

## 2. ★★★ 这暴露了 G-USED 的盲区（第八轮的守卫**看不见**这一类）

第八轮的教训是"G-SOURCE 查了常数的**值**,没查它**被用**",于是本轮注册了 **G-USED**
(每个新常数置零必须改变结果)。

★★ **但这五处里没有一处是 G-USED 能发现的** —— 它们**没有常数**可查:
`0.995` 我从来没写过,`DFAC` 整个函数不存在,`max(CFT,CFL)` 是个控制流。
**一个遍历"我写下的常数"的守卫,永远看不见"我没写下的项"。**

⇒ 新守卫 **G-WHOLE**：**逐块**转录(整个 `IF(ITYP.EQ.2)` 分支),
并在输出里**逐行列出源码块的每一个赋值语句与我们的对应项**,缺一个就报。
★ 找到这五处的不是任何守卫,是**把源码块整段读完**而不是读常数所在的行。
