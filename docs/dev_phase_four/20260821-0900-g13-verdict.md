## 3. P-SEED 在 side_b 上失败 —— **一个候选，不是一个结论**

side_b 首站 `Cτ` 低 **3.8 %**（band 2 %）。★ **两种读法，本轮分不开**：

1. **`CTRCON`/`CTRCEX` 的种子公式在这个 `H_k` 上不准**（side_b 转捩站 `H = 2.267`，side_a `H = 2.303`）；
2. ★★ **它是[第十轮](20260821-0000-transition-attribution-verdict.md)那件事的残留** ——
   XFOIL 的转捩站状态由 **`TRDIF` 的区间分段**给出，我们在**整站**上算种子
   ⇒ 种子被喂了一个略微不同的 `(H, Re_θ)`。

★ **不得**用 (2) 把 (1) 解释掉 —— **我没有测**。登记为 **G18**。
★★ 而 side_a **通过**（1.0070）这一事实**支持 (2) 而非 (1)**：
若种子公式本身不准，两侧没有理由一侧过一侧不过 —— **但这仍是推理不是测量。**

## 4. ★★★ 最该被引用的一条：**平板那条红，追回到参照**

E-CF 自第五轮起红了九轮。本轮把它放到**有可信参照的那一侧**旁边看：

| | 参照 | 出带 |
|---|---|---|
| 平板 | Coles–Fernholz + 1/4 幂律（**适用性未验证**） | 27/70，`Re_θ 576–2997` |
| 翼型 | **XFOIL 自己**（同族 ⇒ 隔离实现与相关式选择） | **5/214**，`Re_θ 236–452` |

★★ 平板的 `Re_θ 576–2997` 那一大段，**在翼型上完全没有对应** ——
而翼型侧用的是**同族**参照。⇒ **那一段最可能是"我们与那两条相关式不同"，不是"我们错"**。
★ 这与[第九轮 A 腿](20260820-1400-five-terms-verdict.md) §4 的读数**独立同向**：
把闭包改得**更忠实**，与那两条的一致**变差**。

★★★ **禁止句**：**不得**因此说"平板侧没问题" ——
**正确的说法是：平板侧的红不能归给闭包，因为它的参照不合格；它现在是一个未决的参照问题，不是一个缺陷。**
