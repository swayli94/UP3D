## 1. 交付物

**新文件 `pyfp3d/viscous/strip2d.py`** —— 沿流向行进的**二维**积分边界层：

- **Drela 二方程 + lag**：`dθ/dξ` 与 `dH*/dξ`（或等价的 `δ*`/`H` 形式），加剪应力 lag；
- **行进求解**：从驻点/前缘沿 ξ 单向推进，**不组装全局系统**（这正是它比
  `ibl3.py` 的隐式三维系统便宜的机理）；
- ★ **闭包复用 `pyfp3d/viscous/closures.py`**（已有 17 条测试锁），**不重写** ——
  一次只加一件东西；**若某条闭包不适用，必须在判定里点名，不得静默换掉**。

★ **`ibl3.py` 一行不改**（roadmap：冻结不删）。**本轮不碰求解器、不碰耦合。**

## 2. 判据（**先过入口文书 §5 的七问 + 本季新增两条**）

### 2.1 主判据：**平板 / Blasius**（有解析解，门的原文）

| 判定码 | 条件 | |
|---|---|---|
| **V-BLASIUS** | 层流平板上，`c_f·√Re_x` 与 `H` 同时落在 Blasius 值的 **±5 %** 内，**且**在**至少 3 个** `Re_x` 十倍程上成立 | 通过 |
| **V-ORDER** | 网格加密下误差**单调下降**，且拟合阶 **≥ 0.8** | 与 V-BLASIUS **同时**要求 |
| **V-FAIL** | 任一条不成立 | ★ **如实报 FAIL，不改判据、不换算例** |
| **V-UNDEF** | 可用的 `Re_x` 十倍程 < 3 | 不报方向 |

★ **±5 % 与 0.8 的出处必须写在判定里**（第 6 问：定带的参考数也要过第 5 问）。
**它们是我现在选的，不是从别处搬的** —— 因此**事前声明**：这两个数是**本轮自己的标定**，
若下一轮要引用，必须连"它们是 GS4.1 第一轮挑的"一起引。

### 2.2 次判据：**自相似解**（Falkner–Skan）

**F-SIMILAR**：在 `m ∈ {0（Blasius）, 0.0435（β=1/12）, 1（驻点）}` 三个楔角上，
`H` 落在 Falkner–Skan 表值 **±8 %** 内。
★ **带比平板宽**，理由事前写下：闭包是**积分**闭包，对压力梯度的拟合本就比零梯度松；
**不是因为窄带过不了**。

### 2.3 ★★ 湍流侧：**本轮只作 RECORDED，不设门**

门的原文只要求"平板/Blasius/自相似解"——**都是层流**。
湍流条带（lag 方程）**本轮跑但不判**，报 `c_f` 与 `H` 对 1/7 幂律与 XFOIL 参考的偏差。
★ **理由**：给一个我没有解析真值的东西设门，就是拿标定当保证（本季四次绝对阈值缺陷）。

## 3. 守卫

| ID | |
|---|---|
| ★ **G-FROZEN** | `ibl3.py` 与 `closures.py` **逐位未改**（`git diff --exit-code`）—— 冻结是 roadmap 明令 |
| ★ **G-REUSE** | 新核**调用** `closures.py` 的函数，不复制它们的公式（源码断言：新文件中不出现闭包常数字面量） |
| **G-NOSOLVE** | 本轮**不调用任何 FP 求解器**（沿用 GS4.0k 强化过的写法：**把求解入口替换成抛异常的桩**，求解不是"会被发现"而是"不可能发生"） |
| ★ **G-ANALYTIC** | Blasius / Falkner–Skan 的参照值**在脚本里独立算出并打印**（不从我记忆里写常数）；`c_f√Re_x = 0.664`、`H = 2.59` 作为**打印出来的自检**而非硬编码判据 |
| **G-WALL** | 每个算例的墙钟都报（R1 的外推数据） |

## 4. 第八问（极端样本）

| 情形 | 处置（事前） |
|---|---|
| 行进在某个 ξ 上**分离**（`H` 发散） | **不是失败** —— 层流平板不该分离；若发生，**报为核的缺陷并停**（kill 条 2） |
| 某个 `Re_x` 十倍程上**点数 < 5** | 该十倍程**不计入**，打印点数 |
| 网格加密后误差**不变**（阶 ≈ 0） | ★ 可能是**触到闭包的模型地板**而非离散误差 ⇒ **报 V-FAIL 但在判定里分开这两种解释**，不合并 |
| 三个楔角里有一个**不收敛** | **只报两个并说明**；若 < 2 个收敛 ⇒ **F-UNDEF** |
| ★ 误差**全部 < 1 %** | 打印"全部优于 1 %"，判据照报 —— 但**不得**把 ±5 % 的通过说成"精度 5 %" |

## 5. Kill criterion（**写在开工之前**）

1. ★ **V-FAIL 且原因定位到闭包本身** ⇒ **停**，报"闭包家族不适用于条带核"，
   **不换闭包**（换闭包 = 一次改两件事）；开新的一轮决定换不换。
2. ★ **层流平板上出现分离** ⇒ **停**（核有缺陷，读数不可读）。
3. ★ **G-FROZEN / G-REUSE / G-NOSOLVE 任一失败 ⇒ 停。**
4. ★ **总机时 > 20 min ⇒ 停**（二维条带应是**秒级**；超了说明我做成了别的东西）。
5. ★ **需要改 `pyfp3d/viscous/ibl3.py` 或 `closures.py` ⇒ 停并记 RECORDED。**
