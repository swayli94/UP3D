## 4. RECORDED —— 三条必须一起读的限定

### 4.1 `C` 本身**不随 h 单调**

`C(P1)` = **0.467 / 0.479 / 0.428**（xcoarse / coarse / medium），`C(P0)` = 0.168 / 0.221 / 0.191。
⇒ **峰的位置稳（永远 k=1），峰的高度不稳。** 峰/端比也非单调（1.87 / 1.64 / 2.00），
而其中一部分来自**分母**（控制臂自己在抖）。
★ 所以可以说的是「**k\* 稳**」，**不能**说「**效应量稳**」。

### 4.2 D-USABLE **依赖分辨率**

`k*` 臂上 ≥50 面的分量：**1（xcoarse）/ 6（coarse）/ 8（medium）**。
⇒ 上一轮"把不可测的判据变得可测"这条**在 xcoarse 上只勉强成立**（1 个分量）。
★ 引用它时必须带级别。

### 4.3 四条禁止句仍然全部有效

必要非充分 · 零求解对"放进求解器"零发言权 · **相干 ≠ 正确** ·
★ **`k*=1` 跨三级 ≠ 跨工况** —— 三级全在 **M0.88 / α3.06**，**工况维度仍未测**。

## 5. 结论

**已建立**（在 M0.88/α3.06、翼身 conforming 族、三级跨 20× 单元数上）：

1. 恢复算子的 patch 尺度有**内点最优**，且**最优永远是 k = 1（单元 + 面邻居）**；
2. 该最优的**物理半径严格随 h 缩**（半径/h = **0.723 / 0.723 / 0.724**）
   ⇒ 它是**拓扑规则不是待标定的长度**；
3. 在同一 patch 上，**重拟合的相干性是求平均的 1.6–1.8×**，且该比值**随加密增大**。

**未建立**：位置的正确性；工况维度；求解器内的行为；以及**效应的量**（§4.1）。

★ **仍然不撤销**：「共同修法 = 体内梯度重构」的退役（那句话退役是因为**从没被检验过**）。
本轮加固的是**上一轮开出来的那条新候选**：**k=1 小 patch 线性重拟合**。

## 6. 一句话

**换了三个级别、跨 20 倍单元数，最优 patch 一次都没动，而它的物理半径在三位数字上
正比于 h —— 这是很久以来第一个测出来"不是标定"的量；位置对不对、别的工况成不成立，
仍然没有任何东西证明。**
