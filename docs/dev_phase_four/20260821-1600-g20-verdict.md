## 3. 由此结清的三件事

1. ★★★ **种子链正确** —— `h_star_turb → slip_velocity → ctau_eq → s_tau_at_transition`
   在**两个不同状态**（`H` 2.566 / 2.398，`Re_θ` 315 / 207）上对 XFOIL **0.12 % / 0.15 %**；
2. ★★ **第十六轮那剩余 ~10 % 不是种子链** ⇒ 它归给 **`H` 混淆**，即
   **我们在 `XT` 的 `H` 由我们的层流闭包给出，而那是与 XFOIL 不同族的**
   —— ★ 一条**已登记、刻意为之**的差异，且**第四轮测出我们那一族对 Falkner–Skan 更准**；
3. ★ **整条转捩区差距的分解定了**：**XFOIL 自身一步离散 ≈ 41 %** + **层流闭包族差 ≈ 59 %**，
   **两者都被理解、都是刻意的** ⇒ **不是缺陷。**

★ **禁止句照写（预注册 §5 逐字）**：**不得**说"转捩处理已验证" ——
本轮验证的是**种子公式**，在 `XT` 落在站上这一特例下；
**一般情形 `XT` 在区间内部，喂给种子的状态仍是我们自己层流行进的**。
