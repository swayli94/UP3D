## 2. ★★★ 判据缺陷：A-USED 只想到了"动了"和"没动"

「禁用必须改变结果」是**单边**的（第 1 问）：
它把**「转录正确但不可达」**和**「根本没接进去」**映到**同一个 FAIL**。
而这两件事的处置完全相反 —— 一个是**保真**（源码有,我们照抄了),一个是**缺陷**。

★ 这同时也踩了第 2 问：**自变量改变了样本是否存在** ——
在我们的 `H` 值域内,那个样本**不存在**。

**这是本季第五次同族缺陷,也是本轮第二次判据自查发现的**（第一次是附录 #1 里 G-USED 看不见缺项）。

## 3. 修法：A-USED 出三类,只有第三类 FAIL

| 类 | 条件 | 判定 |
|---|---|---|
| **WIRED+REACHABLE** | 在 `packet_turb` 可达状态下禁用 ⇒ `c_D` 改变 | 通过 |
| ★ **WIRED+UNREACHABLE** | `packet_turb` 值域内不可达,但**在被调函数层可证接线** ⇒ **RECORDED**,并**必须打印其上确界与触发值** | 通过（记录） |
| **NOT-WIRED** | 两者都不成立 | **A-FAIL → kill 2** |

★★ **反向结果落在哪**：若 #5 连函数层都证不出接线,就是 NOT-WIRED ⇒ FAIL。
★ 而 WIRED+UNREACHABLE **不是免票**：它把一句话写进记录 ——
**「`U_s` 钳位在本模块从不生效；它第一次可能生效的地方是 B 腿的压力梯度检查,
或任何把 `H_TURB_LO` 降到 1.05 以下的改动」** —— 那是一条给后续的具体交待,不是一句"通过"。
