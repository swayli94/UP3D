## 2. ★★ 这个 FAIL 的归属：闭包家族，**不是**离散化 —— 三条独立证据

预注册 §4 第三行**明令**「阶 ≈ 0 可能是触到闭包的模型地板而非离散误差 ⇒ 报 V-FAIL 但把两种解释**分开**」。
分开的结果**不是措辞，是 11 个数量级**：

| n_substep | 对 Blasius 的误差（`H`） | **自收敛**误差（`H`） |
|---|---|---|
| 250 | 4.51496435e-02 | 5.978e-10 |
| 500 | 4.51496434e-02 | 3.521e-11 |
| 1000 | 4.51496434e-02 | 2.169e-12 |
| 2000 | 4.51496434e-02 | **1.339e-13** |

1. **离散误差在 n=2000 上是 1.3e-13**，比那 4.5 % 的差距低 **11 个数量级**，
   且自收敛阶 **4.039 / 3.859 = RK4 的设计阶** ⇒ 行进是对的。
2. **代数不动点根本不含离散化**（`similarity_fixed_point`：自相似假设代入两条积分方程，消去 `dδ/dξ`，
   剩一条纯代数条件），而行进**落在它上面**：m=1 差 **1.06e-15**、m=1/23 差 5.49e-5、m=0 差 3.58e-4。
3. 该代数值 `H = 2.708292` 与 GV1.1 用**三种独立构造**建立的 **2.7083** 吻合到 **5 位**
   ⇒ 这是**第四种**独立构造。

★ **一处必须说清、不许当成"部分通过"的**：V-ORDER 的 `H` 腿报了 `mono=True`，那是
**第 9 位以后**的 RK4 残差骑在一个常数地板上的抖动（`4.51496435e-02 → 4.51496434e-02`），
**没有任何意义**；`c_f` 腿同样的数据报了 `mono=False`。两腿都是阶 ≈ 0，判定同为 V-FAIL。

★★ **重定位，按附录 #1 要求的分寸写**：本轮把 GV1.1 (a) 的那条 FAIL 从「三维 IBL 的属性」
移到「**闭包家族的属性**」—— 但**这一半 GV1.1 自己已经做了**（其 VERDICT 原文：FE 解与闭包自己的
二维行进在 `H` 上吻合 2.2e-4 / 1.1e-4，即"求解器忠实地积分了给它的家族"）。
**本轮新增的是**：(i) 把它推到**不含任何离散化**的代数层（上面第 2 条），
(ii) **`c_f` 那一侧**（§1），(iii) 与三维系统**不共享离散化**的第二个实现给出同一答案。

★★ 而**因本轮结果新产生的、必须由用户裁决的岔路**（本轮**不擅自开**，kill 条 1 的原话是"开新的一轮决定换不换"）：

★★ **先说清一件事：为什么"改闭包"不可能是一次重标定** —— 在这套闭包里
`θ`、`θ*`、`δ*`、`c_f`、`c_D` **全部是同一条型线 `u(η; A)` 的泛函**（同一套 Gauss–Legendre 求积；
`c_f` 就是 `2A/re_d`，`A` 本身是壁面斜率；`c_D` 是同一条型线的耗散积分），
而不动点条件 `c_f(A)/c_D(A) = 4 t(A)/s(A)` **两边每一项都出自同一个形状**
⇒ **二维层流下这个族只有一个形状参数，却要同时命中 `H` 与 `c_f` 两个目标**。
族**能**表示 `H = 2.59`（`blasius_A`，`A = 7.883`），但方程不把它**留**在那儿（漂到 `A = 8.03`）。
★ **实测无旋钮**：`C_L_DEFAULT` 减半、`A1_BRADSHAW` 加倍、改 `KAPPA`/`B_SPALDING`/`CTAU_LAM`
五个常数，`H` **逐位不动**（2.708292）⇒ 层流侧完全由型线族 `_lam_UW` 决定。
