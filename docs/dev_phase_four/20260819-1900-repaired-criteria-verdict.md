**读法**：
- **最大超出 0.844 pp、中位偏差 3.84 %** ⇒ 闭包**处处在两条已建立相关式的 ~4 % 之内**；
  所谓"失败"是它在 `Re_θ ≈ 4900–6200` 那一小段里**刚好**踩出收窄到 3.0–4.8 % 的带；
- ★★ **这一簇与第五轮（5071–6231）是同一处** —— 两轮用**不同的窗口**独立测到同一个位置，
  ⇒ **它是闭包的真性质**，不是窗口artefact；本轮分辨率更细（8 站 vs 4 站）。

★★★ **归因现在是干净的**（第五轮做不到这一点）：
① `E-ATTRACT` 在 `Re_θ = 578` 就达成 ⇒ 那一簇（`Re_θ ≈ 5000`）**远离转捩、且与初值无关**；
② 两轮不同窗口测到同一位置；
⇒ **不是转捩、不是种子、不是窗口 —— 是相关式闭包自己。**

★ **偏差随 `Re_θ` 呈 V 形**（10.1 % @578 → 1.06 % @2962 → 8.05 % @9206）
⇒ 闭包的 `c_f(Re_θ)` 与两条参照**斜率不同**、在 `Re_θ ≈ 3000` 附近交叉，
**不是一个常数偏置**。★ 但 `dev` 是**对两条参照取 max**，而两条参照自己在 `Re_θ≈5000` 也交叉
⇒ **V 形有一部分来自度量的构造，不得全部读成闭包的斜率误差。**

## 4. ★★ G2 的修法有效，但它**只修掉它声称要修的那一样**

窗口起点由 `E-ATTRACT` **测出来**（`Re_θ = 578`，排除 2/120 站），不是我挑的。

★ 而这暴露了一件事前没想到、值得记的事：
**"忘掉初始条件"（`Re_θ = 578` 就达成）远早于"贴上已建立的 `c_f` 曲线"** ——
窗口首站的 `c_f` 仍偏 10.1 %。**这是两个不同的瞬变。**
⇒ G2 修掉的是**初值污染**，它**没有**、也**不声称**修掉闭包自身向渐近行为的趋近。
★ 所以窗口首站那 0.844 pp 现在**归给闭包**，而不是归给种子 —— 这正是修好归因的价值。
