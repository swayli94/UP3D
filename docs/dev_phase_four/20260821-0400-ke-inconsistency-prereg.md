## 1. ★★★ 主仪器：**把我们的解代进 XFOIL 的残差，看它按几阶消失**

两套格式都是二阶 ⇒ 把**精确解**代进任一格式的残差，残差应当是 **O(h³)**。

> 取我们 RK4 在 `[X, X+h]` 上**收敛到机器精度**的 `y2`，代入 `REZT / REZH / REZC`，
> 扫 `h`，看**各自**的阶。

| 结果 | 读法 |
|---|---|
| 三条都 **O(h³)** | 两套方程**相同** ⇒ 第十一轮的差另有来源（**回到 §3**） |
| 某条是 **O(h²)** | ★★ **那一条与我们的 ODE 不一致** —— 一阶相容而非二阶 |
| 某条是 **O(h)** 或 O(1) | 那一条**根本不相容** |

★ **这个仪器没有前一轮那个缺陷**：不再人为扰动 `u`，`y2` 由积分给出，
`HLOG/TLOG/SLOG` 都取真值。

## 2. 定位到项：**逐项置换**

一旦确认是 `REZH`，把它拆成四项，**逐项**用我们 ODE 的对应量替换，看哪一项把阶从 2 拉回 3：

| 项 | `REZH` | 我们的对应 |
|---|---|---|
| a | `HLOG = ln(HS2/HS1)` | `θ dH*/dξ` 的链式重构（`dH*/dH·H′ + dH*/dRe·Re′`，**中心差分**） |
| b | `BTMP·ULOG`，`BTMP = 2HCA/HSA + 1 − HA − HWA` | `H*(H−1)·θ u′/u`（`M=0` ⇒ `HCA=0`） |
| c | `XLOG·0.5·CFX`，`CFX` **上风加权** | `0.5·H*·c_f` |
| d | `XLOG·DIX`，`DIX` **上风加权** | `2c_D` |

★ **反向结果落在哪**：若**没有**单项能把阶拉回，则不一致是**多项耦合**或在 §3 的别处，**照实记**。

## 3. 若 §1 说两套方程相同，去哪里查（**使用者授权的"必要时查别处"**）

| 嫌疑 | 为什么 | 怎么查 |
|---|---|---|
| ★ **`h_star_turb` 的可微性** | 它有分支（`hk < ho`、`rtz = max(Re_θ,200)`、`ho` 在 `Re_θ=400` 换式）⇒ **中心差分跨过分支就无意义** | 在实测状态附近扫 `H*` 的一阶/二阶差商，找不光滑处 |
| ★★ **`rhs_turb` 的链式重构** | 我们解的是 `dH/dξ`，`dH*/dξ` 是**推出来的**；两个偏导都是 FD | 用**解析**偏导（或复步/更小步）替换，看差是否消失 |
| **`march_correlation` 的步长分配** | 按 `log(x)` 份额分配，非均匀站点上可能极不均 | 打印每段实际 `nsub` |
| **`bl_thickness` / `packet_turb` 的一致性** | 两条行进器都调它们，应当**逐位**相同 | 同一状态双向调用，比逐位 |
