## 0. 设计原则：**一次只动一件事**

**几何、网格级别、配方全固定**（翼身 conforming **coarse**，`r_c=0.05`，le14 配方逐字），
**只动工况**。

★ 用**十字设计**而不是网格，因为项目偏好单变量清晰度：

| 轴 | 腿 | 备注 |

| **M 轴**（α = 3.06 固定） | M = **0.78 / 0.82 / 0.86 / 0.88** | M0.88 已在盘上（`gs40d_levels/coarse.npz`）⇒ **它是锚点，只跑 3 条新腿** |

★ **腿在看到谁收敛之前就定死**。不收敛的腿**按 CLAUDE.md 的分型表分型后如实报**，
**不得**静默丢掉，也**不得**换成"能收敛的工况"（roadmap 明令禁止项）。

### 0.1 ★★★ 第八问先问：**这个判据会不会被"没有激波"白送**

**会**，而且这是本轮最大的构造性陷阱：**亚临界工况没有声速集 ⇒ `C` 无定义**。
若把它算成"没有反例"，判据就被**空洞满足**了。⇒ **事前定死**：

> **既不算支持也不算反对**。
> ★ 若计入的腿 **< 2 条**，整轮 **UNDEFINED**（常设：收敛腿 < 2 不报方向）。

★ 这一条来自本季已犯过的同族缺陷：`f_bias ≡ 1` 当 n=1、`CONC_max` 按构造不可达、

## 1. 判据

量、臂、阈值**全部逐字沿用**前两轮（第 6 问：定带的参考数必须同源）：
`C` = ≥10 面分量里的跨声速面份额；臂 `P0..P3` + `S1`；
内点极大需 **≥1.30×** 两端；`max/min < 1.15` 判平；`k*` 并列**取最小的 k**。

| 判定码 | 条件（**binding = 所有计入的腿**） | 含义 |
|---|---|---|
| **W-FIXED** | **每一条计入的腿都 `k*=1`**，且都满足内点极大 | ★ 最优在**工况上也是拓扑的** ⇒ 上一轮的可迁移性**扩到工况维度** |
| **W-DRIFT** | 每条腿都有内点极大，但 `k*` **不全是 1** | ★ `k*` 依赖工况 ⇒ 一并报**它跟谁走**（§2 的激波强度） |
| **W-VANISH** | **任一**计入的腿**没有内点极大** | ★★ **k=1 的最优是工况特有的** ⇒ **候选被削弱到"只在 M0.88/α3.06 附近"**（kill 条 1） |
| **W-MIX** | 混合 | 不宣称方向 |

★ **反向结果落在哪（第 1 问）**：**W-VANISH 与 W-DRIFT 都是本轮完全可能拿到的**，
而 **W-VANISH 直接把候选的适用范围砍回一个点**。

## 2. RECORDED（本轮的机理产出）

1. ★ **`k*` 与激波强度的关系** —— 每条腿在**控制臂**上量两个数：
   **超声速单元占比** 与 **M_max**。若判 W-DRIFT，`k*` 与它们的关系就是机理答案；
   若判 W-FIXED，这张表证明**强度确实变过**（否则 W-FIXED 是白送的）。
   ★★ **这一条是 W-FIXED 的前提检查**：**必须看到激波强度在腿之间显著变化**，
   否则"跨工况不变"只是"工况没怎么变"。**事前定死**：若最强腿与最弱腿的
   超声速占比**差不到 2×**，W-FIXED 降级为 **RECORDED，不宣称跨工况**。
2. **半径/h 逐腿** —— 同一张网格 ⇒ 它**应当恒为 0.723**。若不是，说明我算错了（仪器检查）。
3. **`|C_P1 − C_S1|/C_S1` 逐腿** —— 上一轮测到它随加密增大（1.59→1.66→1.82）；
   本轮看它随**工况**怎么动。
4. **不收敛腿的分型**（`clamping` / `limit_cycle` / `ill-conditioning` / 线搜索 / σ-transport）。

## 4. Kill criterion

1. ★ **W-VANISH ⇒ 候选的适用范围砍回 M0.88/α3.06 附近**，本轮结束，退役推到判定 + 审计。
2. ★ **G-ANCHOR 对不上 ⇒ 停**（仪器）。
3. ★ **计入的腿 < 2 ⇒ UNDEFINED，停**，**不加工况**（看到结果后加腿 = 范围蔓延）。
4. ★ **§2.1 的强度前提不成立（最强/最弱 < 2×）⇒ W-FIXED 降级为 RECORDED**，不宣称跨工况。
5. ★ **总机时 > 25 min ⇒ 停**（预计：求解 ~70 s + 阶梯 6 腿 × ~30 s ≈ 5 min）。
6. ★ **任何一步需要改 `pyfp3d/` ⇒ 停并记 RECORDED。**

## 5. 事前预测（**不假装盲测**）

1. ★ **预测 W-FIXED** —— `k*=1` 在所有计入的腿上。**推翻方式**：任一腿的 argmax 不是 1，
   或任一腿没有内点极大。
2. ★ **预测 M0.78 可能被 EXCLUDED-SUBCRITICAL**（激波太弱）。★ 若如此，M 轴只剩 3 点，
   **我不会补一个更低的 M 来凑** —— 那是范围蔓延。
3. ★ **预测 α=4.59 / M0.88 可能不收敛**（超出已记录的翼身跨声速上限）。**如实分型报。**
4. ★ **预测强度前提成立**（M0.78→0.88 的超声速占比应差 ≥2×）。
   ★ **若不成立，本轮就问不出跨工况的问题** —— 那本身是个要记下来的结果。
5. 总机时 < 10 min。

★ 预测落空**照实记、不改预测**（本季已落空四次）。
