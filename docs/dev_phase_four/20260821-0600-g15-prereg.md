## 0. G15 不是"一个没解释的现象"，是**两条互斥的实测**

| A（第十二轮 §1） | B（第十一/十二轮） |
|---|---|
| 把我们的精确解代进 XFOIL 三条残差 ⇒ **`O(h³)`** ⇒ XFOIL 格式**与我们的 ODE 二阶相容** | 固定区间上两点行进**随 `k` 收敛**，收敛到一个**离我们的解 2.36e-3 的答案** |

★★★ **二阶相容 ⇒ 解必须随 `h→0` 收敛到我们的解。** 所以 **A 与 B 不能同时为真**。
本轮的任务不是解释 B，是**找出 A、B 里错的那一条**。

★ 顺带把量级算清楚，免得把"大"当"神秘"：局部 `O(h²)`、`N = L/h` 步、
`H` 的 ODE 在该状态附近**放大**（实测 256 步放大 ~1.9e4，即 `λ ≈ 1.8e3 /单位ξ`，`e^{λL} = 1.6e4`）
⇒ 全局 `≈ h·L·e^{λL}`，在 `k=256` 上给 **1.9e-3**，与实测 2.36e-3 同量级。
★★ **所以 `k=256` 的数值不神秘；神秘的是它随 `k` 不按 `1/k` 下降。**

## 1. ★★★ 主假设：**Newton 在每步选了另一个根**

`TP.step` 用 `guess = y1` 解一个 3×3 非线性系统。若该系统在 `y1` 附近**有第二个根**，
则每步都可能落到"另一支"上：**局部残差极小（实测 `|F| ≤ 1.1e-15`）、
全局却走在另一条轨迹上** —— 这**同时**满足 A 与 B，是唯一能同时满足两者的机制。

**判别子（一次只改一件事，G-ONECHANGE）**：
> **把每步 Newton 的初值从 `y1` 换成 RK4 在该步的答案。** 其余一切不动。
> - 若 march 从此落到 RK4 的答案上 ⇒ **多根，`y1` 选错支** ⇒ **B 错**，A 成立；
> - 若仍落到原处（差仍 2.36e-3）⇒ **单根** ⇒ **A 错**，回到 §2。

## 2. 若不是多根，A 错在哪（备选，逐条一次只改一件事）

| 嫌疑 | 怎么查 |
|---|---|
| ★ K-ORDER 的 `y2` 不是精确解 | 用**两种独立方式**求 `y2`（`march_correlation` 的 RK4 / `scipy.solve_ivp` 高阶自适应），比对；残差重测 |
| ★ K-ORDER 只在**一个** `h`-窗口上读了阶 | 把 `h` 扫宽（`1e-3..1e-6`），逐条残差**各自**报阶，不取最大 |
| `H` 与 `H*` 的换算 | K-ORDER 比的是残差，与 `H` 的提取无关 ⇒ 只在 §1 失败后才查 |
