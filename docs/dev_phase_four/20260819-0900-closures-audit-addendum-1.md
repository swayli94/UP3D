## 2. 逐条定位：**六条全是我的度量缺陷**

| 条 | 报出的 worst_rel | 真实原因 |
|---|---|---|
| **A1** | 6.203e-08 | ★ `f2, f3` 含 `(1−η)²` 因子 ⇒ **η→1 时取零**。我的 `_rel` 分母是 `max(|paper|, 1e-300)` ⇒ 在最后一个高斯点上，1e-16 的绝对差被除成 1e-8 的"相对差" |
| **A2/A3/A4** | 2.170e-09 | 同上：`W = B f2 + Ψ f3` 在 η→1 取零 |
| **A11** | 7.575e-05（`tc2`） | ★★ 我声称"库的 8 点规则对这些积分**精确**，因为被积函数是次数 ≤13 的多项式"——**这句话只对非-Ψ 的那一半成立**。Ψ 加权的四条（`dq_c, tc1, tc2, dc1, dc2`）的被积函数含 **`Δψ = arctan(W/U)`（eq 40）= 超越函数**，8 点规则**不精确** ⇒ 我拿 8 点的截断误差去比 40 点的截断误差。**非-Ψ 的那些全部读到 1e-14/1e-15**（见第一次执行输出） |
| **A12** | 1.387（`CDx`） | ★ 层流态上 `C_D^× = ∫(S dW/dη − T dU/dη)dη`，而层流的 `S ∝ dU/dη`、`T ∝ dW/dη` ⇒ **被积函数恒等于零**。两侧实测 `4.4e-20` 与 `−1.1e-19`，**都是数值零**，我却做了相对比较 |

★ 而 `A12` 的其余三项本来就通过：`Cf1` rel **0**、`Cf2` rel **0**、`CD` rel **1.2e-14**。

## 4. 改了什么（**度量**，不是**阈值**）

| | 修法 | 依据 |
|---|---|---|
| **尺度感知的相对差** | 分母改为 `max(\|paper\|, s)`，`s` = **该量在样本上的自身尺度**（`max\|paper\|`），由调用方显式给出 | 一个在样本内取零的量，其误差只能相对**它自己的量程**衡量 |
| **A11 拆成两半** | (i) **非-Ψ**（多项式，8 点精确）⇒ 独立 40 点比对，`1e-12`；(ii) **Ψ 加权**（超越）⇒ **在同一个 8 点规则上**比对，隔离"被积函数定义"这件事，`1e-12` | 拿同一规则比，才是在测 eq (60) 的**定义**而不是测积分分辨率 |
| **A11 新增 RECORDED** | 8 点 vs 200 点的截断差**单独报**，不进判据 | ★ 它顺便检验库注释那句"24 点可解析 δ⁺ 到 O(1e5)"的同类主张 |
| **A12 `CDx`** | 层流态上按**恒等式**检查（`\|CDx\| ≤ 1e-12 × 各项自身尺度`）；★ **另加一个湍流态**，那里 `CDx` 真的非零，检查才有内容 | 在恒为零的量上做相对比较没有信息 |
