## 2. ★★★ 零机时读数：**事前预测 2 在执行之前就被推翻了**（方向相反）

闭包家族的**零压力梯度自相似不动点**可以**纯代数**求出，不需要任何行进、任何离散化：
自相似要求 `θ = δ·t(A)`、`θ* = δ·s(A)` 且 `A` 常数，代入两条积分方程
（`dθ/dξ = c_f/2`、`dθ*/dξ = 2c_D`）消去 `dδ/dξ` 得

> **`c_f(A) / c_D(A) = 4 t(A) / s(A)`**，且在该 `A*` 上 **`c_f·√Re_x = √(2 A* t(A*))`**。

在 `closures.py` 的层流分支上解得（`brentq`，物理支 `A ∈ [7.9, 8.5]`）：

| 量 | 家族不动点 | Blasius | 偏差 | 对 ±5 % 带 |
|---|---|---|---|---|
| `A*` | 8.02881134 | — | — | — |
| **`H`** | **2.708292** | 2.59109 | **+4.52 %** | ★ **带内** |
| **`c_f·√Re_x`** | **0.710235** | 0.664115 | **+6.94 %** | ★ **带外** |

★ **交叉校验**：`H = 2.708292` 与 GV1.1 VERDICT 独立建立的 **2.7083**（「three independent
constructions」）**吻合到 5 位** ⇒ 本推导可信，且它是**第四条**独立构造。

★★★ **后果 —— 照实记，不改预测、不改带**：预注册 §6 预测 2 写的是
「**`c_f` 过而 `H` 不过**」，理由是 `2.7083 vs 2.59 = +4.6 %`。
**但 +4.6 % 落在它自己引用的 ±5 % 带之内**，而**同一个不动点上 `c_f` 偏 +6.9 %、落在带外**。
⇒ 若行进如期收敛到该不动点，本轮的实际结果应是**镜像的**：**`H` 过而 `c_f` 不过**。

★ 这正是本季记过的判据缺陷家族的又一例（**「定带用的参考数也过第 5 问了吗」= 入口文书 §5 第 6 问**）：
**被引来支持"会失败"的那个数，从来没有拿去和它所支持的那条带比过**。
★ 而 `c_f` 这一侧是**新信息**：GV1.1 的 (b) 门量的是 `|c_f_FE − c_f_march|/c_f_march`，
**两臂共用同一个闭包 ⇒ 共模比较**，从未对过解析真值。

**判定不因此改变**：V-BLASIUS 要求 `c_f√Re_x` 与 `H` **同时**在带内 ⇒ 仍应落 **V-FAIL**，
且原因仍定位到闭包 ⇒ **kill 条 1 照常开火**。变的只是**哪一个量在失败**，以及**为什么**。

## 4. 干跑校验的其余读数（**返回数与参数类型**，不只是签名）

- `closure_scalar(state, q, rho, mu, mach, turbulent, c_l)` → **3 个返回值** `(out (30,), dout (30,6), dout_e (30,2))`，均 `ndarray`；
- `blasius_A(target_H=2.5906, ...)` → **标量** `float64`（`2.5906` 上得 `A = 7.883031`）；
- `blasius_seed(x, ...)` → **`(6,)` ndarray**（整个 state，不是标量）；
- ★ **层流**的 `θ`、`θ*` 对 `re_d`（即对 `q`）**恰好无依赖**（FD `∂θ/∂q = 0`，`dout_e[TH11,0] = 0`）
  ⇒ 隐式 ODE `M y' = F` 在**有压力梯度时对层流依然精确**；
- ★ **湍流**的 `θ`、`θ*` **依赖** `re_d` ⇒ 一般形式必须补显式项 `(∂θ/∂re_d)(ρδ/μ)·du_e/dξ`；
  FD 校验通过：`dout_e[TH11,0]·ρδ/μ = 1.577e-5 × 2000 = 3.154e-2` vs FD `3.153e-2` ✓；
- `dout[:, 0]`（对 `δ` 的导数）是**全导数**（含 `re_d(δ)` 的链式），FD 相对差 `4.9e-9`（层流）/ `1.6e-6`（湍流）；
- ★ **`H(A)` 不单调**：`A` 从 7.883 降下去，`H` 先降到 ≈2.07（`A ≈ 6`）再升 ⇒ **同一个 `H` 有两个 `A`**；
  物理支 = 与 Blasius 连续相连的那支（`A ∈ [6, 8.03]`）。给 Falkner–Skan 播种时必须留在该支上。
- 求解器入口（G-NOSOLVE 要替换成抛异常桩）**六个都在**：`solve_newton_lifting`、
  `solve_newton_transonic`、`solve_subsonic`、`solve_subsonic_lifting`、`solve_laplace`、`solve_laplace_lifting`。
