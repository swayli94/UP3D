## 6. 这条线现在的**唯一**去处

**A1–A7 已经把机理刻画到"有形状、有尺度规则、有强度依赖、与几何无关"。
剩下的两个问题都不是零求解能碰的**，而它们**决定这条线值不值得继续**：

| | 问题 | 能不能做 | 代价 |
|---|---|---|---|
| **N1** | **位置正确性** | ★ **能** —— `post/shock.py` 走**壁面三角切向梯度**，与体单元梯度**零共享**；且 M6 机翼在 **M0.8395/α3.06** 有**实验 Cp 七站**（`reference_data/`，唯一外部裁判） | 1 条新解（秒级）+ 零求解分析 |
| **N2** | **求解器内行为** | ★★ **完整答案不能**（要改 Jacobian 的 CSR 图 + 精确 FD 验证 = 审计 §9.2b 定价的那件事）；★ 但**能先量"爆炸半径"**：在收敛态上，换成重构的 `q²` 会**改变多少单元的人工耗散状态与上风供体** | 零求解 |

⇒ **下一轮建议**：**两件一起做，各自独立**（Part A = N1，Part B = N2 的爆炸半径）。
★ **Part B 明确不是"求解器内行为"的答案**，是**它的定价** —— 说清楚这一点是本小结的最后一句。
