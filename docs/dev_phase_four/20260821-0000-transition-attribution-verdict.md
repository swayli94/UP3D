## 2. ★★★ 先说**没有自由度**的那个读数，它比"最好点"弱

T-C1' 注册的是"**能否**进带"（在推导出的扫描范围内），所以它是一个**存在性**问题；
**取最好点是判据允许的,但那是有自由度的读数**。**无自由度的读数**是把 `x_tr` 放在
**我们自己设的强制转捩点 `x/c = 0.05`**（网格最近点 0.05007）：

| | `θ` | `H` | 出界总数 |
|---|---|---|---|
| side_a | 1.10 % | ★ **2.39 %** —— **略微超出 2 % 带** | 9 |
| side_b | 0.69 % | **0.45 %** | 8 |

⇒ **在完全没有自由度的位置上，side_b 通过、side_a 差一点点。**
★ 而最优点落在 `x/c 0.0505`（side_a）/ `0.0496–0.0501`（side_b）——
**离我们设的 0.05 都在一个站距（~0.0045）之内** ⇒ **预测 8 命中**，
最优点**没有跑到别处去**，所以不存在"别的东西在补偿"的迹象。

★★ **本节是本轮最该被引用的一节**：**头条应当读"无自由度时 side_b 进带、side_a 2.39 %"，
而不是"最好点 0.45 %"。**

## 3. `TRDIF` 的处置：**关闭为"非缺项"**

第九轮 §3/§8 把 `TRDIF`（`xblsys.f:1197`）列为"我们缺的模型"。**那个分类是错的**：

- `TRDIF` 把间隔劈成"层流段 + 湍流段"，是 XFOIL **因为用两点隐式格式**才需要的**离散装置**；
- 我们的 `_turbulent_at(xx)` 比较的是 **RK4 的连续坐标**，**本来就在间隔内任意点切换**；
- 实测：干净种子 + 内点 `x_tr` ⇒ 那一站 `H` 到 **0.45 %**（`H` 从层流 2.568 到湍流 1.823 之间的 2.303，
  **正是"走了一部分层流、一部分湍流"该有的值**）。

⇒ **G10 的 `TRDIF` 分支关闭（负面：不是缺项）。** ★ 而 kill 条 4 事前禁止的"消去法归因"
**没有被用到** —— 这一条是**直接测出来的**，不是消去出来的。

## 4. T-C3：一个**诚实的"没测出来"**

逐量上界 **0.212–0.416**，**没有** ≤ 0.1 ⇒ **不能排除**。
★★ 但**也不能说它是主因**：我们的粗 RK4（约每间隔一步）**不是** XFOIL 的两点隐式格式，
后者正是为那个分辨率设计的 ⇒ **用一个更差的离散去量"离散值多少"，只能给上界。**
**要真答这条,得把 XFOIL 的两点隐式格式实现出来 —— 本轮明确不做，登记为 G12。**

## 7. ★★★ 本轮真正的教训：**两轮的叙事被两处仪器缺陷撑着**

第九轮 B 腿产出了一条听起来很实在的结论 ——
"转捩后 `x/c 0.049–0.089` 与 XFOIL 差 101 %/270 %，候选是 `TRDIF`"。
**其中：**

| 那条结论的成分 | 实际是什么 |
|---|---|
| `Cτ` **270 %** | ★ 拿我们的 `√Cτ` 比 XFOIL 的**放大因子**（附录 #1） |
| `c_f` **101 %** | ★ 同上，早两站 |
| 出界跨到 `0.0888` | ★ 从**部分湍流站**当种子起步（附录 #2） |
| **候选 `TRDIF`** | ★★ **分类错误** —— 它是离散装置，我们的连续行进已包含 |

**修完之后剩下的是**：`x_tr` 放在我们自己设的转捩点上，**side_b 进带、side_a `H` 2.39 %**，
残余出界 3–8 处集中在转捩后弛豫段。

★★★ **一句话:一个"求解器与参照不符"的发现,拆到最后主要是我的量法。**
而它能被拆开，靠的是**每一步都有出处、每一次改判据都在执行前登记、旧数一个都不改写** ——
**没有这些，第九轮那张表会作为"能力边界"被引用下去。**
