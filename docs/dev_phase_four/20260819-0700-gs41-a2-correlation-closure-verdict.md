## 4. ★★★ D-ORDER 又 FAIL 了 —— 而这一次暴露的是**判据本身的缺陷**

| `n_substep` | 对 Blasius 的误差（`H`） | **自收敛**误差（`H`） |
|---|---|---|
| 250 | 2.5754e-04 | 3.513e-14 |
| 500 | 2.5754e-04 | 3.496e-14 |
| 1000 | 2.5754e-04 | 3.445e-14 |
| 2000 | 2.5754e-04 | **3.342e-14** |

**读法**：
1. 对 Blasius 的误差**不动**（阶 0.000）⇒ 按判据字面 **D-FAIL**，如实报；
2. 但那条"地板"是 **2.58e-4 = 0.026 %**，即**相关式拟合自身的残差** —— 第一轮那条是 **4.5 %**；
3. **离散误差是 3.3e-14 = 机器精度**，在 `n_substep = 250` 上**就已经完全收敛**。

★★★ **判据缺陷（本季第 9 个，登记给下一轮，本轮不改）**：
**D-ORDER（= 第一轮 V-ORDER 逐字）量的是"对真值的误差随加密下降"，
而加密只能动离散误差。只要模型有任何偏置，它就按构造失败。**
⇒ 它对第一轮的 **4.5 % 偏置**和本轮的 **0.026 % 偏置**给出**完全相同的判定码**（D-FAIL，阶 0.000）——
**一个 175 倍的改善对它完全不可见**。
**一个不能区分这两者的判据，量的不是它名字所说的东西。**
★ **本轮不重 specify 它**（事后放宽是被禁止的）；**下一轮若要再用，必须先修它**，
修法方向已明确：把"对真值的误差"与"离散误差"拆成**两条判据**，而不是让一条同时承担。

★★ **附带一条同族的小缺陷**：`H` 的自收敛"阶 0.024"是**在机器精度的数上拟合出来的**
（3.5e-14 → 3.3e-14）⇒ **在舍入噪声上拟合出来的阶不是阶**。
第一轮 §4 事前考虑了"撞上模型地板"，**没有考虑"已经收敛到机器精度"** —— 这是第八问的一个新面孔。
（`c_f` 侧的自收敛阶 **3.908** 仍在 RK4 的设计阶上，因为它的自误差还没到舍入。）

## 5. D-TURB：复现了，而**报"未复现"的是我的守卫**

D-TURB 的读数 **−7.71 %..+11.36 %** 与第一轮**逐位相同**，但脚本打印 `bit-reproduced: False`。
逐站核对：最大相对差 **1.277e-09**。

★★ **那正是 CSV 的写入精度**：第一轮以 `%.8e`（**9 位有效数字**）落盘 ⇒ 存储的相对精度约 **1.5e-9**，
而我把阈值挑成 **1e-9** —— **比数据自己的存储精度还紧，这条检查在原理上不可能通过**。
⇒ **不是回归，是守卫缺陷**：拿一个满精度浮点去对它自己的**9 位转录**比较。

★ 归类：与本项目记过的**「容差必须从条件数推出来，不能挑一个整数」**（缺陷 #10）同族，
新面孔是**从"存储精度"推**。★ 与附录 #1 那条（量纲错配）合起来，**本轮我自己犯了两次同族缺陷**。

## 9. 结论与下一步

**GS4.1 的门文字，两条都达到了** —— 但按 §2，其中"验证通过"那条是**近乎循环的转录检查**，
**不是**独立验证。诚实的一句话总结：

> **(a2) 让条带核在生产级 0.504 s 内跑完一次整表面 BL（1815× 三维 IBL），
> 并按构造坐在 Blasius 上（不动点偏 0.026 %，对型线族的 4.52 % 是 175.6×）。
> 而"它是否比型线族更接近真实边界层"，本轮没有测，也不能从本轮推出。**

★ **建议的下一轮（使用者裁决）**，按我的优先级：
1. ★★ **修 D-ORDER 判据**（§4）——它现在对模型偏置和离散误差不可分，**在被再次使用之前必须修**；
2. ★★ **独立验证**：拿相关式闭包对**不是它训练数据**的东西比 —— 最现成的是
   `cases/reference_data/naca0012_viscous_xfoil/`（committed 外部裁判）；这才是非循环的精度读数；
3. ★ **湍流相关式 + `C_τ` 滞后**（消掉 §8 那道接缝）；
4. 第二轮登记的便宜跟进项：在 13 764 站上验一次自收敛阶。

★ **GS4.2（Veldman 准同时/交互律）的前提现在有了具体形状**：直接法在 `H → 4` 奇异（`dH*/dH → 0`），
