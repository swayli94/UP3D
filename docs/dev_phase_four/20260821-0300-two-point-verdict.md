## 3. 这意味着什么，以及**不**意味着什么

- ★★ **可能是我们的库有问题**：`rhs_turb` 的动能方程与 XFOIL 的 `REZH` 不是同一条。

  而这里连消去都还没做完。**必须指名是哪一项。**
