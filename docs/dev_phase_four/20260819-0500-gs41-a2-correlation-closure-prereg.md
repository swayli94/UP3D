## 1. ★★ 干跑校验：转录已经核过了，所以 D-BLASIUS **在注册之前就是已知通过**

用**第一轮那个独立的 Falkner–Skan ODE 预言机**（`bench/studies/gs41_strip_core/run.py::falkner_skan`，
积 ODE 得解，不含任何相关式）核对我要敲的三条相关式，**零机时**：

| m | H(ODE) | `H*` 偏差 | `Re_θ·c_f/2` 偏差 | `Re_θ·2c_D/H*` 偏差 |

⇒ **转录正确**；在 Blasius 上三条都在 **0.1 % 以内**，⇒ **D-BLASIUS 必然通过，且余量约 50×**。
★ **照第一轮附录 #1 的做法在执行前披露**，不假装盲测。
★ 拟合自身的误差在**强逆压**（m = −0.08）的 `c_f` 上到 **5.1 %** —— 这是**相关式的固有误差**，
不是实现缺陷；本轮的门只到 m = 1/23 与 1，**不覆盖**那一端（事前说明，见 §6 禁止句）。

### 1.1 ★★★ 结构上的关键事实：**Blasius 是相关式系统的不动点，按构造**

零压力梯度自相似要求源项相消。在 Blasius 上代入：
`2c_D = 0.34676/Re_θ` 而 `H*·c_f/2 = 0.34651/Re_θ` ⇒ **两者相消到 2.5e-4/Re_θ**。

⇒ **这正是第一轮那个 FAIL 的镜像**：型线族闭包**不能**把 Blasius 留在原地（漂到 `H = 2.7083`），
而相关式闭包**按构造**把它留在原地。**这就是 (a2) 的全部内容**，一句话可讲完。

### 1.2 直接法在分离处**按构造奇异**（事前登记，不是缺陷）

行进形式 `dH/dξ = [源项] / (θ · ∂H*/∂H)`，而
`∂H*/∂H = −0.076(4−H)(H+4)/H²` **在 H = 4 处为零**（实测：H=3.9 → −0.00395、H=3.99 → −0.00038）。
⇒ **给定 `u_e` 的直接二方程法在层流分离（H ≈ 4）处奇异** —— 这是该方法的已知性质，
**正是 GS4.2（Veldman 准同时/交互律）存在的理由**，不是本轮的缺陷。
本轮的算例（Blasius/FS 附着，H ≈ 2.2–2.6）**离它很远**；第八问里给了处置。
