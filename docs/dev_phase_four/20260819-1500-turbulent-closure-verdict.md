## 1. ★★★ 先说物理结论：**湍流闭包是work 的**

上一次凭记忆实现，ZPG 平板塌到 `H = 0.60`（物理不可能）。本轮**有出处地**实现之后：

- `H` 从转捩后的 1.80 单调弛豫到 **1.33–1.44**，正是 ZPG 湍流平板该有的值；
- `c_f` 在 `Re_θ ∈ [500, 10⁴]` 上与**两条独立的已建立相关式**相差多数在 **1–5 %**；
- ★ **G-DI 精确通过（0.00e+00）** —— 那条为上次失败专门写的断言，正是它守住的地方。

⇒ **`DI = 2c_D/H*` 的读法是上次唯一的实质错误**（结构与常数当时就对到 1 %）。

## 2. T-CF 失败在哪：**一站转捩 + 一簇擦边**

| `Re_θ` | `H` | 偏差 | 带 | 超出 |
|---|---|---|---|---|
| **556** | 1.5071 | **12.00 %** | 9.26 % | **2.74 pp** |
| 5071 | 1.3514 | 3.37 % | 3.00 % | 0.37 pp |
| 5434 | 1.3485 | 3.87 % | 3.37 % | 0.50 pp |
| 5820 | 1.3457 | 4.38 % | 4.12 % | 0.26 pp |
| 6231 | 1.3430 | 4.89 % | 4.88 % | **0.02 pp** |

**两类，必须分开说**：

**(a) `Re_θ = 556` 是转捩调整**，即**预注册 §3 事前登记**的那个机制
（GV3.1 实测瞬时切换 vs XFOIL 的 e^N 斜坡 ⇒ 首个转捩后站 `c_f` +44 %）。
★ 按预注册禁止句 ④，**不得**把它记为相关式的失败。
★★ **但我的量测设计有缺陷**：我把 `x_tr` 与判据窗口的起点选得**重叠**了 ——
转捩弛豫伸进了 `Re_θ ≥ 500` 的窗口里。**机制我事前想到了，它会伸进窗口我没想到。**

**(b) `Re_θ ≈ 5071–6231` 的四站是真的擦边**，超出仅 **0.02–0.50 pp**。
⇒ **排除转捩区并不能救**（`Re_θ ≥ 800` 仍是 28/32）⇒ **这不是纯粹的转捩伪影**。

★★ **而它揭示了推导带的一个性质**：带 = `max(3 %, 2s)`，`s` = 两条参照**彼此**的分歧。
两条参照在 `Re_θ ≈ 5000` 附近**交叉**（`s` 最小）⇒ **带在那里收缩到 3 % 地板**。
⇒ **推导带在参照彼此最一致的地方最难过。** 这大概是**对的**行为
（两条独立相关式都同意的地方，第三条差 3.9 % 确实在共识之外），
但它意味着"在窄带处 FAIL"与"在宽带处 FAIL"**不是同一件事**，引用时必须分开。

## 3. ★★★ T-EQUIL 的失败是**我的判据**，不是闭包

我注册的是「自洽平衡 = `H` 末半程漂移 `< 2 %/decade`」。实测 **4.80 %/decade** ⇒ 字面 FAIL。

**但 ZPG 湍流边界层的 `H` 本来就随 `Re_θ` 下降** —— 实测从 `Re_θ 2000` 的 1.3807
到 `10⁴` 的 ~1.325，约 **5 %/decade**，而这正是**物理**。
⇒ **我把「平衡」（自洽、不塌陷）与「`H` 恒定」混为一谈了**，
于是判据要求了一件**物理上错误**的事。

★★ **本轮不重 specify**（事后放宽被禁）⇒ **如实报 T-FAIL**，并**登记为下一轮使用前必修**：
「自洽」应该判**是否塌陷/是否单调收敛到湍流分支**，而**不是**判 `H` 的漂移率；
若要判漂移，参照必须是**同一条已建立相关式给出的 `H(Re_θ)` 斜率**，而不是零。

★★★ **这是本季第四轮连续出现判据缺陷**（③ D-ORDER 对模型偏置与离散误差不可分；
④ 相对度量用在会取零的量上；⑤ 附录 #1 参照的变量对错了；⑤ 本条）。
四条的共同点仍是那句：**判据没有覆盖它所比较的那个量的定义域** ——
这一次是**没覆盖"这个量本来就会随自变量变化"**。
