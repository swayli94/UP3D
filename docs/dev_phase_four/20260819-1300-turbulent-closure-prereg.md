## 2. ★★★ 一条**已知会踩**的陷阱，事前登记为守卫

我上一次凭记忆实现时，ZPG 平板**塌到 `H ≈ 0.60`（物理上不可能，`H = δ*/θ > 1`）**。
事后对着源码定位：**结构与常数都对到 1 %**（`G_B` 0.75 ✓、`C_T` 0.0148 vs 我的 0.015），
真因是我把 `DIT` 的 `DI = 2c_D/H*` 当成了 `c_D`，**多乘了一个 `H*/2`**。

⇒ **G-DI**：执行时**断言** `c_D` 的构造满足 `2·c_D/H* == DI`，并把两者一起打印。
★ 这不是"小心一点"，是**把一次已发生的失败做成机器检查**。

## 3. 转捩（本轮的处置，**与项目现有选择一致**）

- **强制转捩**：给定 `x_tr`，`x < x_tr` 走层流相关式，`x ≥ x_tr` 走湍流；
- 切换处**保持 `θ` 与 `H` 连续**，并把 `C_τ` 初始化为该处的 `C_τEQ`（局部平衡）；
- ★ **不做 e^N**（论文 D13 eq (34)(35) 的 TS 包络）—— 那是 `ibl3.py` 侧的 D-TR 已记录的分歧，
  本轮沿用同一选择，**不新增一种机制**；
- ★★ **事前登记它的已知后果**：GV3.1 实测"瞬时切换 vs XFOIL 的 e^N 斜坡 ⇒ **首个转捩后站 `c_f` +44 %**"。
  **本轮若在首站看到同量级偏差，那是转捩模型，不是相关式** —— 这句话现在写下，收口时不许当新发现。

## 4. 判据

### 4.1 主判据：ZPG 湍流平板

| 判定码 | 条件 |
|---|---|
| **T-CF** | `c_f(Re_θ)` 在 `Re_θ ∈ [500, 10⁴]` 上与**两条独立的已建立 ZPG 相关式**同时相符 |
| **T-H** | 同区间上 `H ∈ [1.25, 1.50]` |
| **T-EQUIL** | 行进到达自洽平衡：`H` 在末半程的相对漂移 `< 2 %/decade`，且全程 `1.05 < H < 4` |
| **T-FAIL** | 任一条不成立 ⇒ ★ **如实报，不调常数** |

★★★ **T-CF 的带是"推导"的，不是挑的**（本季三次同族缺陷的修法）：
取 **Coles–Fernholz** `c_f = 0.024 Re_θ^{−1/4}` 与 **Kármán–Schoenherr**（`0.242/√c_f = log₁₀(Re_θ c_f)`）
两条**互相独立**的已建立相关式，**先测它们彼此的分歧** `s(Re_θ)`，
**带 = max(3 %, 2·s)** —— 即"不比两条公认相关式彼此的差距更差"。
★ 两条带的参照数**都不是我挑的**，且**分母就是它们自己的分歧**（第四轮那条常设：阈值连同分母一起推导）。

★ **反向结果落在哪（第 1 问）**：**T-FAIL 完全可能** —— 若转录仍有误（上次就有），
或"局部平衡"这个近似在 ZPG 上就不够，都会在这里落。**T-FAIL 不触发换公式，触发的是停下来定位。**

### 4.2 次判据（**单边**，RECORDED）

**T-CROSS**：与**型线族**（`closures.py` 的湍流分支）在 ZPG 上的已提交读数比较
（第一轮实测：`c_f` 对 1/7 幂律 **−7.71 %..+11.36 %**、`H ∈ [1.350, 1.787]`）。

★★ **这是单边检查，事前说明**：两族是**不同的模型**，**没有义务一致** ⇒
**一致 = 转录正确的支持性证据；不一致 = 不确定，不构成"发现了错误"**。
★ 这不是被禁止的那种跨族比较（第三轮禁止句 ④）：那禁的是把两族当**同一模型的两种实现**互换；
这里是**各自对同一外部真值**（ZPG 相关式）报读数，即第三轮 §2 规则 3 指定的防分叉机制。

## 8. 事前预测（不假装盲测；本季已落空 18 次）

1. ★★ **T-EQUIL 通过，`H` 落在 1.35–1.45** —— 上次的 0.60 已定位为 `H*/2` 因子，G-DI 会挡住它。
   ★ **推翻方式**：仍然塌陷 ⇒ 说明我对 `DIT` 的读法还有第二处错。
2. ★ **T-CF 通过** —— 依据：我用**同一条** `CFT` 公式在四审的干跑里对 Coles–Fernholz 已量到
   **−5 %..+6 %**（`Re_θ` 500–10⁴），而带是 `max(3 %, 2s)`。
   ★ **但这条不保险**：那次是**直接给定 `H = 1.4`** 算的，本轮的 `H` 是**行进解出来的** ——
   若解出的 `H` 偏离 1.4，`c_f` 会跟着偏。
3. **T-H 通过**（1.25–1.50）。
4. ★ **两条 `H*` 臂给出的 `H` 相差 < 2 %** —— 它们在 `H≈1.4` 处只差 ~1.3 %（四审干跑测过 1.743 vs 1.765）。

   但**不会**逐点吻合（不同模型）。★ 这条**按设计只能支持、不能证伪**。
6. 转捩后首站出现 GV3.1 那类正偏差。
7. 总机时 < 10 min，零求解。
