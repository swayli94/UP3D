## 2. ★ 交叉核对臂（新增的**守卫**，不是新判据）

`strip2d.similarity_fixed_point(m)` **纯代数**解出闭包家族自己的自相似态（无行进、无离散化）。
行进必须落到它上面；落不到就是**行进的缺陷**，不是闭包的性质。
★ 这条把「离散化对不对」与「闭包对不对」在**测量层**就分开，而不是在判定的散文里分开。
附录 #1 已用它验过零压力梯度侧（`H = 2.708292` 对 GV1.1 独立建立的 **2.7083**）。

## 3. 三点实现记录（**先于执行**，因为它们改变数值）

1. ★ **子步按 `log x` 分配、且段内几何推进**。跨 3 个十倍程的站点布局下，按 `x` 的**线性**份额分配子步会让
   最上游、最刚的那一段只分到 2 个子步。GV1.1 的参照臂是**线性站点**，两种规则在那里重合 ⇒ 这不是与它的分歧。
2. ★ **`similar_seed` 的 `theta` 与 `H` 都是显式入参**。第一版在内部用 Blasius 相关式推 `theta`，
   于是把**平板厚度强加给楔流**，m=1 的行进被推离物理支并发散到 `A ~ 3e11`。
   ⇒ 调用者拥有相似解，库只负责把它映到闭包家族上。
3. ★ **`H(A)` 有折叠** ⇒ 播种用**限定在物理支上的二分**（与 Blasius 连续相连的那支），不是裸 Newton。
