## 1. 我们要造的东西（一句话）

**一个基于非结构网格的 2.5D/3D 通用跨声速全速势 + 积分边界层求解器，
能算翼型 / 机翼 / 翼身组合体，快到能进设计循环。**

参照物：BLWF（Fortran + 结构/嵌套网格）算一个翼身组合体、含生成网格、
约 2 CPU·min。这是速度标尺，不是精度标尺。

## 3. 八条工作原则（短，故意的）

1. **对外部真值验收，不对自己的历史数字锁定。** 任何 regression lock 必须写清它的
   外部锚点；没有外部锚点的锁只能标注为"防漂移，不代表正确"，且不得用于判定能力。
2. **顺序不可换**：S1 激波算子 → S2 壁面精度 → S3 速度 → S4 粘性 → S5 产品化。
   越级会重演第一阶段。
3. **便宜的判据先行。** 任何离散格式的改动，先在一维/准一维/解析算例上量出
   "误差 vs 参数 vs h"的曲线，再上机翼。三维算例只用来确认，不用来发现。
4. **一次只加一个旋钮，且必须写下它的删除条件。** 不留永久性 default-off 旋钮：
   要么成为默认，要么在验收后删掉。（第一阶段积累了约 25 个。）
5. **测试用公差（1e-12），不用 bitwise**（裁决 §7 D1）。bitwise 断言只允许用于
   "这段代码根本没执行不同的算术"这一类——即同一个数组被原样返回
   （如 ν = 0 时 `rho_tilde` 直接返回 `rho`），标记 `@pytest.mark.identity`。
   **"两个计算在数学上相等"不构成位相同的理由**：不同内核的求和顺序会差 1 ULP
   （审计实测：4051 个矩阵元里 244 个差 2.2e-16）。跨改动的位相同校验放
   `bench/bitcheck.py`，是开发时工具，不是永久测试。
6. **证据必须有提交的产物**（继承第一阶段最好的纪律）：一个数字只活在 .md 里
   就不算证据。
7. **文档预算**：本 roadmap 保持一页可读；每轮开发一个文件；`progress.md` 每轮一行。
   叙事写在轮次文件里，不往 roadmap 里堆。
8. **每个阶段必须预先写下 kill criterion**（什么结果算这条路走不通、下一步转向哪里）。
   写在开工的那个轮次文件里，不允许事后补。

### 明确的禁止项（都来自审计发现的实际教训）

- 不得把"更收敛的那个解"当成"正确的解"；两条路径不一致时，结论是**两个都还没资格
  当基准**，必须用外部真值裁决。
- 不得在根因未修时做精细化（第一阶段的 GV5.1b/1c/1d、V6 尾迹面 δ*（效应 +0.05%）
  都属于这类）。
- 不得用 `M_max` 作为能力指标，直到翼尖尾涡自由边奇点（第一阶段 P13）被处理——
  现在它读的是局部伪影。
- 不得把解不出来的工况改成解得出来的工况来通过门禁；解不出来就记为 FAIL 并写进
  kill criterion。
- 不得再新增第二条并行技术路线（第一阶段两套尾迹模型 × Picard/Newton 孪生 = 4 个
  驱动器，Track B 有 17 个阶段花在其中一条的病理上）。

### S1 — 跨声速激波算子（总闸门）★ **已收口 2026-07-29**：交付物是一条**测量出来的能力边界**（M_max ≲ 1.2）+ 锁住它的 M1a + 七条已排除路线 + 三条待裁决候选，见 [20260729-0230-s1-closeout.md](20260729-0230-s1-closeout.md)

**问题定义 v2（2026-07-28 改写，依据 GS1.1 的测量）。**

> **v1（已推翻，留档）**：审计 §4.1 曾归因于 `kernels/upwind.py` 把
> `ρ̃ = ρ − ν·Δℓ·(∂ρ/∂ℓ)` 里的 `Δℓ·∂ρ/∂ℓ` 近似成"面邻居游走走了多远"，
> 认为有效耗散与物理尺度解耦。**GS1.1 测量结果不支持这个归因**
> （[20260728-1640-s1-shock-bench.md](20260728-1640-s1-shock-bench.md) §4.3/§4.5）：
> 在有解析解的 Laval 喷管上，位置误差 O(h)、C 敏感性 O(h)（0.087→0.049→0.024）、
> 误差 ~1 个单元、对网格抖动不敏感；在**生产翼型网格 α = 0** 上同样成立
> （散布 0.041→0.018）。所以**不做"新耗散公式"这件事**。

真正的链条（GS1.1 §4.6 实测）：

1. 算子给出的激波位置误差是正常的 **~1–2 个单元**；
2. 升力对激波位置的敏感度是 **dcl/dx_shock ≈ 2 每弦长**；
3. 于是要 cl 到 ±3%（指标 M1，cl ≈ 0.36 ⇒ ±0.011），激波位置必须控到
   **±0.0055 弦长** —— 而粗网格 h_wall = 0.02c、中网格 0.01c，光 1 个单元就超了 2–4 倍。

⇒ **S1 要解决的是"激波位置的可控精度"，不是耗散公式。** 另外 GS1.1 发现了一个
独立的、已测量的病灶：`rho_floor` 钳制会制造**机器零残差的伪解**（§4.4，四个数量级 A/B）。

| GS2.2 | 壁面速度恢复：最小二乘/二次重构设为默认（`wall_tangential_gradient_quadratic` 已存在） | 球面 h=0.08：max|ΔCp| < 2%，驻点速度 < 0.02 |
| GS2.3 | 三维确认 | M6 七站 Cp RMS < 0.05（无粘，对已提交实验；= 指标 M3 的精度部分） |

kill criterion（按 §7 D2 裁决修订）：若 GS2.1+GS2.2 后球面仍 > 2%，**不转 P2**。
做法是：把便宜的杠杆推到底（更密的壁面间距、更好的恢复），把达到的水平作为
**测量结论**记录下来，带着这个已知误差水平继续 S3/S4——因为产品指标 M2/M3
（对实验的 Cp / 激波 / cd）才是最终判据，球面 2% 只是一个代理指标。
只有当"非结构路线无法达到 M2/M3"被测量证实之后，才触发 S6 讨论半结构网格。

### S3 — 速度（改配方，不重写）

**已知的白送项**（审计 §3.3 实测）：只把 `precond` 从 `"direct"` 换成 `"amg"`，
M6 medium 从 108 s → 31.7 s，答案一个数字都没变。

| 门 | 内容 | 验收 |
|---|---|---|
| GS3.1 | `precond="amg"` 成为所有生产配方的默认；`direct` 限制在 < 5k 自由度的调试 | 全部三维算例答案不变（公差 1e-8 相对），墙钟 ≥ 3× 改善 |
| GS3.2 | 真正的二维路径（三角形单元），停止用"一层棱柱切四面体"冒充二维 | 二维单点 < 1 s；AMG 迭代数从 480 降到 < 50；答案与 2.5-D 路径一致 < 0.5% |
| GS3.3 | 去掉马赫爬坡：目标马赫直接伪时间 + 非精确 Newton（EW forcing），种子改便宜的线性化解 | 种子+爬坡开销从 13.6 s（占 43%）降到 < 3 s；同解 |
| GS3.4 | 端到端 | M6 medium 无粘 < 15 s；翼身组合体 medium < 40 s |

kill criterion：无（这些是配方级改动，风险低）。若 GS3.3 造成鲁棒性下降，
保留爬坡作为**自动回退**，但不得成为默认路径。

### S4 — 粘性重启（做减法）

**问题定义**（审计 §4.4）：第一阶段直接上 Drela 2013 的三维 IBL（6 未知量/节点、
两个剪应力输运、横流），结果边界层比无粘贵 9 倍（1032 s vs 115 s），二维对 XFOIL
δ* 误差 28%、Δcl 只有 54%，三维松耦合不收敛、紧耦合卡在残差地板。而实测横流
max|B|/|A| ≤ 0.072——为横流付的复杂度没用上。

| 门 | 内容 | 验收 |
|---|---|---|
| GS4.1 | 弦向条带二维 IBL（Drela 二方程 + lag，或 Drela–Giles 三方程），沿流向行进 | 整机翼边界层 < 1 s；平板/Blasius/自相似解验证通过 |
| GS4.2 | 耦合改 **Veldman 准同时 / 交互律**，替代松循环与增广 Newton | 分离算例不跑飞（收敛或有界）；外迭代 ≤ 5 |
| GS4.3 | 二维标定 | NACA0012 M0.5 对 XFOIL：δ* < 10%、cf < 15%、Δcl 比值 ∈ [0.8, 1.25] |
| GS4.4 | 二维跨声速标定 | RAE2822 case 9/10 对实验：激波 ± 0.02c、cl ± 3%、cd ± 10 counts（= 指标 M2） |
| GS4.5 | 三维 | M6 加粘性后 Cp RMS 比无粘改善且 ≤ 0.05 |

`pyfp3d/viscous/ibl3.py` + `closures.py` **冻结不删**，标记为研究分支，
若 GS4.5 出现明确需要横流的证据再解冻。

kill criterion：若 GS4.4 在激波算子（S1）达标后仍差 > 0.03c，说明问题不在耦合而在
无粘侧的模型极限（FP 等熵激波），据此重新评估"FP 是否够用"。

### S6 — 战略后备（**已搁置**，见 §7 D2；S1 收口后其触发条件已部分满足，见 20260729-0230 §5.3）

差 5–10 倍（工程判断，非实测；可查的支撑是球面 11.6% 和 M6 Cp RMS 0.13）。

**2026-07-28 裁决：搁置。** 现行路线 = **非结构 + P1**，一直做到它被测量证明不行。

| 后备路线 | 状态 |
|---|---|
| 等参 P2（几何 + 场同时二次） | **不采用**（使用者裁决）：没有一个生产级全速势求解器走这条路，说明它不是必要条件，而复杂度极高（几乎重写核心） |
| 半结构（C-H）贴体网格，复用同一套装配 | **后备**：只在"非结构路线达不到产品指标 M2/M3"被测量证实之后才启动评估 |

触发条件（必须是测量结果，不是判断）：S1 达标后 M2（RAE2822 激波 ±0.02c）或
M3（M6 Cp RMS < 0.05）仍无法达到，且原因归到网格规整度 / 每自由度精度上。

★ 记录一个诚实的反面注记（不影响本裁决，只是别忘了）：生产级全速势求解器之所以
不需要 P2，很大程度上是因为它们**都用贴体结构网格**（即后备路线 B）——它们不是靠
高阶单元解决壁面精度，而是靠网格规整度。所以"没人用 P2"不能直接推出"P1 + 非结构
够用"。这个论点在触发条件被满足时会重新变得相关。

## 5. 工作节奏与记录格式

* **一轮 = 一个聚焦的改动 + 它的测量**。一轮一个文件：
  `docs/dev_phase_two/yyyymmdd-hhmm-<name>.md`，格式见
  [`_TEMPLATE.md`](_TEMPLATE.md)：**目的 / 改了什么 / 怎么测的 / 结果（带数字）/
  判定 / 下一步**。
* 每轮结束在 [`progress.md`](progress.md) 加**一行**（不写叙事）。
* 每轮必须报告：全套测试状态、以及对 `bench/baseline_*.csv` 的 A/B 差异。
* 判定只有三种：**PASS**（达到预先写下的门）、**FAIL**（没达到，如实记录）、
  **RECORDED**（测量值，无预设门）。**不允许事后放宽门槛**——门要改，必须在
  改之前单独写一轮"重新定义门"的记录并说明理由。
* 结论与代码同一轮提交；轮次文件里的数字必须能在 `results/` 找到对应产物。
