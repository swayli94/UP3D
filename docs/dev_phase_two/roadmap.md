## 1. 我们要造的东西（一句话）

**一个基于非结构网格的 2.5D/3D 通用跨声速全速势 + 积分边界层求解器，
能算翼型 / 机翼 / 翼身组合体，快到能进设计循环。**

参照物：BLWF（Fortran + 结构/嵌套网格）算一个翼身组合体、含生成网格、
约 2 CPU·min。这是速度标尺，不是精度标尺。

## 3. 八条工作原则（短，故意的）

1. **对外部真值验收，不对自己的历史数字锁定。** 任何 regression lock 必须写清它的
   外部锚点；没有外部锚点的锁只能标注为"防漂移，不代表正确"，且不得用于判定能力。
2. **顺序不可换**：S1 激波算子 → S2 壁面精度 → S3 速度 → S4 粘性 → S5 产品化。
   越级会重演第一阶段。
3. **便宜的判据先行。** 任何离散格式的改动，先在一维/准一维/解析算例上量出
   "误差 vs 参数 vs h"的曲线，再上机翼。三维算例只用来确认，不用来发现。
4. **一次只加一个旋钮，且必须写下它的删除条件。** 不留永久性 default-off 旋钮：
   要么成为默认，要么在验收后删掉。（第一阶段积累了约 25 个。）
5. **测试用公差（1e-12），不用 bitwise**（裁决 §7 D1）。bitwise 断言只允许用于
   "这段代码根本没执行不同的算术"这一类——即同一个数组被原样返回
   （如 ν = 0 时 `rho_tilde` 直接返回 `rho`），标记 `@pytest.mark.identity`。
   **"两个计算在数学上相等"不构成位相同的理由**：不同内核的求和顺序会差 1 ULP
   （审计实测：4051 个矩阵元里 244 个差 2.2e-16）。跨改动的位相同校验放
   `bench/bitcheck.py`，是开发时工具，不是永久测试。
6. **证据必须有提交的产物**（继承第一阶段最好的纪律）：一个数字只活在 .md 里
   就不算证据。
7. **文档预算**：本 roadmap 保持一页可读；每轮开发一个文件；`progress.md` 每轮一行。
   叙事写在轮次文件里，不往 roadmap 里堆。
8. **每个阶段必须预先写下 kill criterion**（什么结果算这条路走不通、下一步转向哪里）。
   写在开工的那个轮次文件里，不允许事后补。

### 明确的禁止项（都来自审计发现的实际教训）

- 不得把"更收敛的那个解"当成"正确的解"；两条路径不一致时，结论是**两个都还没资格
  当基准**，必须用外部真值裁决。
- 不得在根因未修时做精细化（第一阶段的 GV5.1b/1c/1d、V6 尾迹面 δ*（效应 +0.05%）
  都属于这类）。
- 不得用 `M_max` 作为能力指标，直到翼尖尾涡自由边奇点（第一阶段 P13）被处理——
  现在它读的是局部伪影。
- 不得把解不出来的工况改成解得出来的工况来通过门禁；解不出来就记为 FAIL 并写进
  kill criterion。
- 不得再新增第二条并行技术路线（第一阶段两套尾迹模型 × Picard/Newton 孪生 = 4 个
  驱动器，Track B 有 17 个阶段花在其中一条的病理上）。

### S1 — 跨声速激波算子（总闸门）★ **已收口 2026-07-29**：交付物是一条**测量出来的能力边界**（M_max ≲ 1.2）+ 锁住它的 M1a + 七条已排除路线 + 三条待裁决候选，见 [20260729-0230-s1-closeout.md](../../phases/p2/docs/dev_phase_two/20260729-0230-s1-closeout.md)

**问题定义 v2（2026-07-28 改写，依据 GS1.1 的测量）。**

> **v1（已推翻，留档）**：审计 §4.1 曾归因于 `kernels/upwind.py` 把
> `ρ̃ = ρ − ν·Δℓ·(∂ρ/∂ℓ)` 里的 `Δℓ·∂ρ/∂ℓ` 近似成"面邻居游走走了多远"，
> 认为有效耗散与物理尺度解耦。**GS1.1 测量结果不支持这个归因**
> （[20260728-1640-s1-shock-bench.md](../../phases/p2/docs/dev_phase_two/20260728-1640-s1-shock-bench.md) §4.3/§4.5）：
> 在有解析解的 Laval 喷管上，位置误差 O(h)、C 敏感性 O(h)（0.087→0.049→0.024）、
> 误差 ~1 个单元、对网格抖动不敏感；在**生产翼型网格 α = 0** 上同样成立
> （散布 0.041→0.018）。所以**不做"新耗散公式"这件事**。

真正的链条（GS1.1 §4.6 实测）：

1. 算子给出的激波位置误差是正常的 **~1–2 个单元**；
2. 升力对激波位置的敏感度是 **dcl/dx_shock ≈ 2 每弦长**；
3. 于是要 cl 到 ±3%（指标 M1，cl ≈ 0.36 ⇒ ±0.011），激波位置必须控到
   **±0.0055 弦长** —— 而粗网格 h_wall = 0.02c、中网格 0.01c，光 1 个单元就超了 2–4 倍。

⇒ **S1 要解决的是"激波位置的可控精度"，不是耗散公式。** 另外 GS1.1 发现了一个
独立的、已测量的病灶：`rho_floor` 钳制会制造**机器零残差的伪解**（§4.4，四个数量级 A/B）。
