## 1. 目的与要实现的东西

GS1b.2 的前提检验给出四条支撑（roadmap S1b 表），其中**结构性的那一条是决定性的**：
代码里现有的唯一削波机制（人工密度）∝ h，**随加密自己消失**（Q5 实测：fine 上
C=1.5 与 C=3.0 几乎重合），所以治不了一个不随 h 消失的病。熵因子只依赖**当地激波前
马赫数**，是 h 无关的。

**要实现的关系式（GS1b.2 §4.1 已用数值验证，不是推导出来就用）**：

> **ρ_s = σ · ρ_isen(q²)，σ = p₀₂/p₀₁（激波前马赫数 M₁ 的总压比）**

完全气体、总焓沿流线守恒 ⇒ `ρ₀ = p₀/(R T₀)` 且 T₀ 过激波不变 ⇒
`ρ₀₂/ρ₀₁ = p₀₂/p₀₁` **恰好**。已验证：加上它之后 FP 的质量守恒跳跃**精确复现
Rankine–Hugoniot**（0.0000%，M₁ = 1.15–1.60 全部）。
★ **不是** `σ^{1/(γ−1)}`（那会把指数用两次，我在 GS1b.2 里犯过一次并已订正）。

### 1.1 实现方案（三件事，每件都写清为什么这么选）

**(1) 激波探测 —— 复用现有的上游指派，不新建一套。**
`UpwindOperator` 在 `weighted=False` 模式下已经为每个单元算出唯一的上游供体
（`upstream_elements` → `self._upstream`）。激波 = 沿流线由超声速转亚声速，
所以判据是：单元 `e` 的供体 `u` 超声速而 `e` 亚声速 ⇒ `e` 是**激波后**单元，
`M₁ = M(u)`，局部因子 `s_e = p₀₂/p₀₁(M₁)`。**不新增几何或拓扑机器。**

**(2) 向下游输运 —— 沿供体链做乘积。**
熵沿流线守恒，所以 `σ_e = σ_{u(e)} · s_e`。供体映射是每单元唯一，构成一个森林，
所以用**固定次数的扫掠**迭代这个关系式即可（信息每扫掠传播一跳），扫掠数上限
兼作防环保护。σ = 1 表示从未过激波。

**(3) σ 冻结（lagged），不进 Jacobian —— 并且如实说明这是什么。**
σ 通过 `p₀₂/p₀₁(M₁)` **连续**依赖 φ，所以漏掉 ∂σ/∂φ 会让 Jacobian 真的不精确
（这与现有"上游指派不可导"不同 —— 那个是分片常数，几乎处处可导）。
因此：**σ 在每个 Newton 步开始时冻结，整步（残差 + Jacobian + 线搜索）共用同一个
σ，步间刷新**，与现有的 freeze/refresh 机器同一节奏。这样
**Jacobian 对"被求解的那个（冻结 σ）系统"是精确的**，FD 检验也对它做；
外层 σ 刷新是一个不动点迭代，它的收敛性是本轮**必须记录**的量。
若外层刷新不收敛 ⇒ 记 FAIL 并升级到"把 ∂σ/∂φ 也求导"（不在本轮范围）。

**(4) 插入点 —— 库改动尽可能小。**
`UpwindOperator.rho_tilde(grad, q2, rho, ...)` 把等熵密度 `rho` 当**输入**，
所以熵因子可以在**内核之外**乘上去：`rho ← σ * rho`，人工密度混合与其灵敏度
一行不用改。新旗标 `entropy_correction`（默认 **False**），
删除条件写在 §2.3。

### 2.2 ★ 预注册的定量预测（在写任何求解器代码之前算出来的）

用 `bench/s1_duct/nozzle.py` 的几何与同一组 Dirichlet 数据
（Δφ = 19.31862767，即等熵模型下激波正好在 x_s = 12.0、M₁ = 1.29998 的那一组）：

| 模型 | 激波位置 x_s | M₁ | σ |
|---|---|---|---|
| 等熵（现状） | **12.0000** | 1.30000 | — |
| **熵修正（预测）** | **11.6200** | 1.28022 | 0.982657 |

**位移 = −0.3800 长度单位 = −1.90% L ≈ −2.3 个 nx=120 单元，方向 UPSTREAM。**

判据 B 就是命中这个数：`|x_s(ON) − 11.62|` 必须随加密下降，且在最细一级
（nx = 400，h = 0.05）**小于 2 个单元**。这个数字与求解器无关（纯 quasi-1-D 反解），
所以它是一个真正的外部锚点，不是自我一致性检查。

### 2.3 效果（这才是 B 值不值得的判据）

| # | 判据 | 判定 |
|---|---|---|
| **F**（主判据） | 固定 C = 1.5，M0.7875/α1.25 的**三级 cl 跳幅收缩**：现状 coarse→medium **+40.5%**。要求跳幅**至少减半**（≤ +20%） | 收缩 < 5 个百分点 ⇒ 等熵过预测**不是**翼型发散的驱动因素，**B 关闭为负结果**，转 §6 的升级路线 |

**kill criterion（明确写下）**：A–E 全过但 **F 不过** ⇒ **B 是测量出来的负结果**：
等熵过预测可以被精确修掉（1-D 命中预测），但它**不是**翼型三级发散的驱动因素。
那时的下一步不是继续调熵修正，而是转向 GS1.7 测出的**闭合方程 0/0 结构**
（`F = T₀ + (b−1)Γ`，两者同时 ~h^0.6 趋零），或者触发 roadmap §7 D2 搁置的 S6。
