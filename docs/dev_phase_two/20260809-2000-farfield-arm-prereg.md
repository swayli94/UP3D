# 20260809-2000 预注册 — 登记项 0:用**域半径** `r_far` 造一条真正只动远场的臂

**执行前提交。** 目的是**收尾**(把一个悬置问题关掉,好让能力边界能陈述),
**不是提升能力** —— 使用者 2026-08-09 明确的口径。

## 1. 为什么需要这条臂

第三次 LE 因子的判据 P 达成,但同日的 **§0b ERRATUM** 发现 `h_far` **不是远场旋钮**:
它把 **r ∈ 1–2 MAC 处的中位单元尺度改了 +24.04%**(以及 0–0.5 +2.40% / 0.5–1 +1.90%),
LE 带法向间距 `h_n` **+1.525%** —— 而当时的守卫 **G1 只查了表面**。
⇒ 被归因的是"**体网格(含近体分级)**",而"**远场本身**是否控制 LE 带"**至今没有被干净地测过**。

## 2. 为什么用 `r_far` 而不是改生成器

| 路线 | 取舍 |
|---|---|
| 改生成器,把远场尺寸场与近体解耦 | **能力工作** —— 使用者的收尾口径明确排除 |
| **用域半径 `r_far`** | **采纳** —— 不动表面几何、不动任何尺寸场,只把外边界推远;且 **B5 给了先验** |

★ **B5 的先验(2026-07-12)**:它扫过远场**半径** R ∈ {15, 30, 60, 120}c,测得
option a(Dirichlet+vortex,**本轮所用**)**domain-robust** —— Γ 在 15→120c 内只差
**0.45% / 1.09%**,15c 处与 conforming 差 0.25%。
⇒ **事前预期是"LE 带几乎不动"**。这让本轮成为一次**有预期的检验**,不是钓鱼。
⚠ 但 B5 测的是 **Γ(积分量)**、在 **2.5-D** 上;本轮测 **LE 带的局部 Cp**、在 **M6 3-D** 上,
所以它是**先验**而非答案。

## 3. 设计

`onera_m6_wing_mesh`,round tip + 生产 taper + pressure Kutta,**M0.75 / α3.06**(与第三次因子同工况),
`h_wall = 0.020`、`h_le = 0.010`、`h_te = 0.010`、`h_wake = 0.060`、**`h_far = 2.4` 固定**。

| 腿 | `r_far` | 含义 |
|---|---|---|
| **R00** base | **15 · MAC**(现值) | 基线 |
| **R10** far-domain | **30 · MAC** | 只把外边界推远一倍 |

## 4. ★★ 守卫(这一节是上次 erratum 换来的:守卫要覆盖**结论所声称的那个东西**)

| | 守卫 | 阈值 | 不满足时 |
|---|---|---|---|
| **G1a** | **表面网格不动**:壁面三角形数、LE 带面数相同;LE 带 `h_t` **和** `h_n` 相对差 < **1%** | 1% | 该腿**不是**"只动远场" |
| **G1b** | ★ **近体体网格不动**:径向壳 r < 2 MAC 的中位单元尺度相对差 < **1%**(上次 `h_far` 在这里是 **+24%**) | 1% | 同上 |

## 5. 事前判据(数字在此固定)

参照量:`h_far` 那条臂(**不干净**)测得 **Δ_LE = 0.09811**。

| | 条件 | 结论 |
|---|---|---|
| **C(erratum 被证实)** | G1a+G1b **PASS** 且 **Δ_LE(R10) < 0.02** | **远场本身几乎不控制 LE 带** ⇒ `h_far` 那 0.098 主要是**近体分级**,§0b 的改写**被证实**;边界文档写"LE 亏空由**近体体网格分级**主导" |
| **D(erratum 不完整)** | G1a+G1b **PASS** 且 **Δ_LE(R10) ≥ 0.05** | **远场本身也控制 LE 带** ⇒ 改写**不完整**,边界文档必须写"**近体分级与远场边界二者都控制**",并记 B5 的先验在 3-D 局部量上**不成立** |
| **I** | 介于 0.02 与 0.05 之间 | **RECORDED,不下结论** |
| ★ **N(没有干净臂)** | G1a 或 G1b **FAIL** | **这个生成器里不存在干净的远场臂** ⇒ **"远场 vs 近体"这个二分在 phase two 不可测**,如实写进能力边界作为**有界负结论**,并把"改生成器解耦尺寸场"交给 phase three。**不得**为了得到一个能做的实验而改生成器 |

**附带 RECORDED(无判据)**:两腿对**实验**的 LE 误差 `E_LE` 及其变化(addendum #4 的口径),
以及 `M_max`、`x_shock`、单元数。

## 6. 成本

第三次因子在 r_far 15 上实测每腿 **52–74 s**(h_wall 0.020)。`r_far` 30 使域体积 ×8,
在 `h_far = 2.4` 下单元数**会明显增加**,量级未知。
- 单腿 > **600 s** ⇒ 停,如实上报(**不加预算**);
- 网格生成 > **300 s** ⇒ 同上(域变大后 gmsh 可能明显变慢)。

- **不试 r_far 60/120** —— 除非 R10 落在 I 区且再一档能把它推出 I 区;这一条要另行登记。
- 不动库代码。
