## 1. GS3.3 与一条**已关闭的门**冲突

roadmap GS3.3:"**去掉马赫爬坡**:目标马赫直接伪时间 + 非精确 Newton,种子改便宜的线性化解",
验收 = 种子+爬坡开销 **13.6 s(占 43%)→ < 3 s**;同解。

而 **G10.3 `no-ramp direct-solve feasibility`,CLOSED 2026-07-11,判决 KEEP the Mach ramp**
(8 次运行 + 提交的 CSV,事前登记了 (A)/(B)/(C) 三类与晋升规则):
* 远离 fold(M6):no-ramp **收敛到同一个解**(class A),分支选择**不是**那里的约束;
  但 Picard-5 经过 **clamped** 状态(medium 峰值 45 lim+flr),141.4 → 79.0 s(**快 44%**)违反
  clamp-free 条款;Picard-40 只快 6.6%,违反 ≥20% ⇒ **无路径满足规则**;
* fold 区(NACA medium):两种种子**都是 class (C)**;深种子无爬坡时**主动有害**。

⇒ 纪律 #8:**不得在无新证据时重开已关闭的负结果**。
但**确实有新证据**:G10.3 是在 `precond="direct"` + 滞后 LU 下测的,
而爬坡的主要开销正是"**每层一次 splu + 种子**",**GS3.1 刚把它换成 AMG**。
所以本轮不是"重开",是**在新成本基准上复核**。

## 3. ★ 另一半也被证伪:**生产爬坡路径的种子开销是 0.00 s**

审计的 "13.6 s 种子 = 43%" 是**单次直解**的数字 —— 本轮在无爬坡腿上测到 **15.4 s**,**吻合**。
但 `solve_newton_transonic` 各层用**上一层热启动**,聚合 `timings["seed"] = 0.00 s`。

⇒ **GS3.3 的动机所依据的那笔开销,生产路径根本不付。**
"把种子改成便宜的线性化解"**没有东西可省**。

## 4. 结论:GS3.3 **前提证伪,建议关闭**

* "去掉爬坡" = G10.3 的**已关闭负结果**,在新成本基准上复核后**更负**(3.1× 慢 + 不收敛);
* "改种子" = 生产路径**种子成本为零**,无可省;
* **GS3.1 已经交付了 GS3.3 的意图**:它要省的正是每层 splu,而 AMG 把 M6 medium 的
  爬坡从(G10.3 记录的)141.4 s 压到 **70.8 s**。

★ **建议把 GS3.3 关闭为"前提被 GS3.1 消解"**,而不是留着当一个待办 ——
留着它会让后人以为还有 13.6 s 可捡。
