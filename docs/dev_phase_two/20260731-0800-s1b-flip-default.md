### 1.1 ★ 一处我先前说得不准,先自己纠正

我在 GS1b.6 的 B1 里写过"翻默认不会破坏 M1a 这条锁",依据是 M1a 的**三级一致性**判据
(medium→fine 从 +0.91% 变 +0.67%,仍 < 1%)。**但 M1a 还锁了绝对 cl**
(`CL_RTOL = 2.0e-3`),而实测 fine 的 ON 值 0.254939 vs 锁的 0.255662 =
**−2.8e-3,超出 2e-3**。所以 **M1a 的 fine 腿会红**,必须一起重锚。
三级一致性判据本身仍然通过,而且**略好**。

## 2. 重锚的协议(不是"跑一遍粘上去")

每一个新锚都必须带三样:

| 必须写清 | 说明 |
|---|---|
| **实测值** | 在 runner 默认 16 线程下测,记录配方与网格 |
| **锚的是什么** | 有外部参照的写参照(Euler 锚点带);没有的**明确标注"防漂移锁,不代表正确"** |
| **旧值留档** | 以 erratum 形式保留,不得静默覆盖(纪律 #11) |
