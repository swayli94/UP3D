## 3. ★★ 没登记、但更重要的三件事

### ① 在 M0.8395,**每一个加密方向都把峰值马赫推向限幅器**

| 收敛的三腿 | (h_wall, h_le) | M_max |
|---|---|---|
| F1_00 | (0.030, 0.015) | **1.564** |
| F2_00 | (0.020, 0.010) | **2.205** |
| F2_01 | (0.020, 0.0075) | **2.859** |

加密 LE 让 M_max **1.56 → 2.20 → 2.86**(仍收敛,但一路奔向 3.0 的帽子);
加密 bulk 直接**撞帽**。⇒ **在这个工况上,基于加密的 LE 归因实验是不可用的** ——
这比 GS2.1 的"LE 误差不受分辨率控制"是一个**强得多、也具体得多**的陈述:
不是"误差不响应",而是**求解器跟不动那个加密方向**。
它同时解释了 GS2.1 的非单调:那条扫掠是在一个**每一步都在逼近限幅器**的序列上做的。

⚠ **仪器缺口,如实记**:我只记了 clamp 的**数量**,没记它们**在哪** ——
而 CLAUDE.md 的分类纪律明写"`n_limited`/`n_floored` > 0 **以及那些单元在哪**"。
所以"峰值在翼尖还是在 LE"本轮**答不了**,而这正是区分 P13 尖端奇点与 LE 吸力峰的关键。
下一轮必须带位置。

## 5. 重新设计(登记,**本轮不执行**)

问题没变,但**工况和度量都得换**,理由是 §3①:

1. **换到亚临界工况**(候选 M0.50/α3.06)。LE 吸力峰在亚声速就存在,而激波、
   限幅器和尖端超声速斑块都消失 ⇒ 加密方向变得可用。
2. **换度量:自收敛(R),不是对实验的误差**。亚临界没有 M6 实验可比,但本轮的问题
   ("LE 误差是本地的还是周围的")**不需要实验** —— 只要问"加密 bulk 与加密 LE
   哪一个更改变 LE 带的 Cp"。这正是使用者定的 **R 判据**,而且它**顺带绕开**了
   "对无粘求解器测有粘实验误差"那个前提问题。
3. **换旋钮**:`h_edge` 已被本轮否证。需要一个**真正只动 LE 表面分辨率**的机制,
   或者接受"LE 面数会随 bulk 变"并改用**回归/协变量**设计而不是因子设计。
4. **带上 clamp 与峰值的位置**(§3① 的仪器缺口)。
5. **round tip 上补测 LE 带的误差-加密序列**(§3②),否则 flat 上那条 0.725 无从替换。

★ 本轮**没动库代码**。
