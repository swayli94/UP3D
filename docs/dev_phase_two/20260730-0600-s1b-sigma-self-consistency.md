## 1. 目的：ON 的答案目前**没有唯一定义**

实测（committed CSV + 门控 ON 腿）：

| medium M0.7875 | 自适应延拓 | P8 配方 | 一致？ |
|---|---|---|---|
| **等熵 OFF** | x_shock **0.6738** | **0.6738** | **一致到 4 位** ✓ |
| **熵修正 ON** | x_shock **0.6029** | **0.4852** | **差 0.118 c** ✗ |

coarse M0.80 上 ON 是稳的（0.6186 vs 0.6197，差 0.001）。所以**熵修正在 medium 上引入了
配方依赖** —— 而 OFF 没有。

机制（与 GS1b.4 / GS1b.5 的诊断一致）：**σ 是冻结的**，冻结在哪个中间态取决于配方
走了几级、每级重建几次；而 σ 的状态间不稳定随加密增长（0.13 → 0.99 → 4.6 pp）。
coarse 上小到看不见，medium 上放大成 0.12 c。

⇒ **这阻断重锚**：不能把一个取决于配方 0.12 c 的值锚成 committed 数字 ——
那正是我们刚在 Picard 那里拆掉的错误。

## 2. 做法：把 σ 推到不动点

收敛态应当满足的是 **`R(φ; σ(φ)) = 0`**（σ 与状态自洽），而现在满足的是
`R(φ; σ_frozen) = 0` 且 `σ_frozen ≠ σ(φ)`。不动点**与配方无关**，因为它是方程的解。

实现（尽量少动结构）：`solve_newton_lifting` 收敛后自检 —— 用终态重建 σ，
若 `max|σ(φ) − σ_frozen|` 超过内部容差，就以终态为**热启动**再解一遍
（新解的种子 σ 恰好就是 `σ(φ_prev)`，即自洽映射的一步），最多若干个 **σ epoch**。
epoch 数与最终自洽差都进返回值。

**旋钮纪律**：容差与 epoch 上限都是**模块常数**（不是驱动器参数），理由写在常数旁边 ——
它们不是调参盘，是"何时算自洽"的定义。coarse 上已量过自洽差只有修正自身的 **4.0%**，
所以预期只需很少几轮。

## 3. 失败判据

## 4. 改了什么

`pyfp3d/solve/newton.py`：`solve_newton_lifting` 收敛后自检 σ 自洽性 ——
用终态重建 σ，若相对差（以修正自身大小 `1 − σ_min` 归一）超过
`_SIGMA_SELF_TOL_REL`，就以终态热启动**递归再解一遍**（新解的种子 σ 恰好是 `σ(φ_prev)`），
最多 `_SIGMA_POLISH_MAX` 个 epoch。两个都是**模块常数**（不是驱动器参数），
理由写在常数旁边。返回值新增 `sigma_self_consistency` /
`sigma_self_consistency_history` / `n_sigma_epochs`。

## 5. 结果：P1 PASS，**P2 FAIL** —— 不动点到不了，配方依赖被换成了 epoch 依赖

### 5.1 P1 = PASS：配方依赖从 0.118 c 降到 0.0029 c

medium M0.7875、熵修正 ON、两条配方、同一 epoch 上限（6）：

| 配方 | x_shock | cl_p | epochs | 自洽差历史 |
|---|---|---|---|---|
| A 自适应延拓（M0.60 起，dm 0.04） | **0.6137** | 0.424846 | 6（撞上限） | 0.319 → 0.929 → 1.015 → 0.770 → 0.766 → 1.031 → **1.000** |
| B P8 配方（`solve_newton_transonic`） | **0.6108** | 0.416396 | 6（撞上限） | 1.000 → 1.000 → 0.633 → 1.216 → 0.776 → 0.774 → **0.353** |

**配方差 0.0029 c**（门槛 0.012）⇒ **P1 PASS**，比 polish 之前的 **0.118 c** 小 **40 倍**。

★ 过程记一笔：第一次跑 B 时我**忘了传** `entropy_correction`（只传了
`**NEWTON_TRANSONIC_RECIPE`），于是 B 跑的是等熵，读数 0.6738 / 0.523426 正好等于
OFF 的值 —— 是"它和 OFF 一模一样"这件事暴露了我的漏传。`solve_newton_transonic` 要
经 `newton_kw` 转发。

### 5.2 P2 = **FAIL**：自洽差不下降，在 0.35–1.22 之间震荡

两条配方的历史都**不单调下降**，都撞满 6 个 epoch，终值 **1.000 / 0.353**，
而容差是 **0.02**。⇒ **σ 的不动点迭代不收敛，是极限循环。**

这与 GS1b.4 的诊断完全自洽：σ 继承供体图的 churn，所以映射 σ → φ → σ **不是压缩映射**。
polish 并没有找到不动点，它只是把两条轨迹**洗进同一个邻域**。

## 6. 判定与下一步

**GS1b.9：P1 PASS / P2 FAIL；polish 保留，但它没有达到本轮的目标（一个唯一定义的 ON 答案）。**

| 判据 | 结果 |
|---|---|
| **P1** 配方依赖 ≤ 0.012 c | **PASS**（0.0029 c，改善 40×） |
| **P2** 自洽差下降到容差内 | **FAIL**（震荡 0.35–1.22，终值 1.00 / 0.35，容差 0.02） |
| P3 正确性不退 | 19/19 常开测试过（含 0 维恒等式、FD 精确、默认关闭逐位不变） |
| P4 OFF 路径逐位不变 | 满足（polish 只在 ON 下运行） |
| P5 成本 | 每次 ON 解多 ~6 次热重解，墙钟约 ×2（medium 34–66 s） |

**保留 polish 的理由**：它把配方依赖降了 40 倍，这是净改善；去掉它就回到 0.118 c。
**但必须同时记住**：ON 的答案现在是**"跑满 epoch 上限之后的状态"这个过程**定义的，
不是 `R(φ; σ(φ)) = 0` 的解，且带 **±0.012 c** 的上限敏感性。

**⇒ medium 的 P8 锁仍然不能重锚**（在 0.012 的容差上锚一个 0.0123 散布的量 =
锚一次抛硬币）。**coarse 可以**（那里 ON 配方无关到 0.001，σ 自洽差只有 4%）。
