## 1. 目的：一个靶子，两个症状

GS1b.3 的判据 E 与 GS1b.3b §7.3 已经测出这是**同一个对象**：

| 症状 | 实测 |
|---|---|
| **E：σ 刷新不收敛** | 一个单元在"激波后"集合里反复进出（n_shock 73 ↔ 74），`max|Δσ|` 钉在 **2.9e-2** 不降，残差停 5e-6；靠把刷新封顶到 8 次才收得动 |
| **§7.3：M₁ 状态间不稳定** | fine 走 0.005 的马赫步，相邻状态 M₁ 跳 **1.26–1.49**、σ_min 跳 **0.932–0.986**（5.4 个百分点）；收敛目标态上却是干净的（1.271/1.347/1.352） |

共同根因：**σ 的构造里每一步都是硬判断**——

1. "激波后单元" = `供体超声速 AND 自己亚声速`（两个硬阈值，M = 1 处不连续）；
2. 向上游走的停止 = `上升 < knee_frac × 迄今最大上升` 就 `break`（硬比较）；
3. 走出气泡的停止 = `M² ≤ 1` 就 `break`（硬阈值）。

三处都是"状态动一点点、结果跳一跳"。所以修法不是加松弛，而是**把每一个硬判断换成
光滑过渡**，让 σ 成为马赫场的连续（且分段光滑）函数。

★ 这也直接服务于下一步：只有 σ 光滑，把 ∂σ/∂φ 纳入 Jacobian 才有意义（现在它几乎处处
为零而函数本身在跳，求导毫无用处）。

## 2. 做法（写在动代码之前）

单一光滑宽度 **`eps_m`（马赫单位）**驱动全部三处，用同一个 smoothstep：

```
ramp(t) = 0                t <= 0
        = t^2 (3 - 2t)     0 < t < 1      (C^1，两端导数为 0)
        = 1                t >= 1
```

1. **激波后的软指示**：`chi = ramp((M_u - 1)/eps_m) * ramp((1 - M_e)/eps_m)`，
   局部因子 `s_e = 1 - (1 - sigma(M1)) * chi`。硬版本是 chi ∈ {0,1}；软版本让 M = 1
   附近的单元携带部分熵，于是"73 ↔ 74 的翻转"变成一个连续变化的权重。
2. **膝点的软停止**：不再 `break`，而是给每一跳一个门
   `g_k = ramp((r_k/R - f_lo)/(f_hi - f_lo))`（`R` = 迄今最大上升），
   累计权重 `w_k = prod_{j<=k} g_j`，M₁ 取**加权平均** `sum w_k M_k / sum w_k`。
   走出结构后 g → 0，其后所有单元权重自然趋零。
3. **气泡边界的软停止**：把 `M² <= 1` 的 break 换成同一个 `ramp((M-1)/eps_m)` 乘进 `w_k`。

**旋钮**：`eps_m`（默认待定，见 §3 的敏感性要求）、`f_lo/f_hi`（膝点软带，替代
`knee_frac`）。三个都必须给出**实测敏感性**和**删除条件**，否则不算完成。

## 3. 失败判据（预先写下）

| # | 判据 | 判定 |
|---|---|---|
| **S1**（主判据） | fine 上 0.005 马赫步的延拓，相邻状态之间 `max|Δσ_min| ≤ 1 个百分点`（现状最大 **4.6 pp**，σ_min 摆动 0.932–0.986） | 降不到 1 pp ⇒ 不稳定不在"走法的离散性"里，**停下重新诊断**，不要继续加光滑 |
| **S2** | σ 刷新**收敛**：`max|Δσ|` 逐次下降，且在封顶之前就收敛（即 `entropy_refresh_max` 变成不必要） | 仍极限循环 ⇒ 判据 E 仍 FAIL，如实记 |
