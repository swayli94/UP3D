# M3 重定:**拆成 M3a(精度,归 S4)+ M3b(速度,归 S3)—— 两个数字一个都没放松**

轮次文件名:`20260802-0100-m3-respec.md`
分支:`claude/phase-two-s2`
依据:`20260802-0000-floor-verdict.md`(四点超定拟合;地板 SUPPORTED)
使用者裁决:2026-08-02 —— 采纳"改判据"这条建议

---

## 1. 先说清楚这**不是**移动靶子

改产品指标是最容易变成自欺的动作,所以把约束写在前面:

* **两个数字都保持原样**:精度仍是 **RMS < 0.05**,速度仍是 **< 60 s**;
* **改的只有归属**,而且**理由是测量**,不是"我们做不到";
* **原始表述完整保留**在本文件与 roadmap 的脚注里,可回溯。

## 2. 测量到的事实(全部已提交)

M3 的参照是 `cases/reference_data/onera_m6_experiment/experiment-Cp.dat`
—— **Re 11.72e6 的有粘风洞实验**。而 pyFP3D 在这条路径上是**无粘**全速势。

四点全尺度加密序列(h = 0.030 / 0.020 / 0.015 / 0.010,taper + pressure,**四腿全部严格收敛**、
0 limited / 0 floored)测出:

| 量 | 行为 | 归属 |
|---|---|---|
| **LE 带 Cp** | **收敛到零**(0.3899 → 0.2704 → 0.2358 → 0.1758,纯幂律阶 **0.709**) | **离散** |
| **激波位置** | 位移 **收敛到零**(0.0624 → 0.0408 → 0.0239,阶 **0.845**,偏移模型退化) | **离散** |
| **MID/TE 的 Cp 电平** | **加密消不掉**(MID 上 A = **0.0740**,超定残差比 **0.039**;A 在 3→4 点稳定) | **模型** |
| 重建的全点地板 | **0.0516(LE 归零)– 0.0707(LE 取面值)** | ≥ 0.05 |

⇒ **0.05 这个门槛落在无粘模型地板之下**:一个无粘求解器**在任何网格上都拿不到它**。
把它继续挂在无粘阶段的名下,等于给这条路线记一笔**它无法偿还的债**。

## 3. 重定后的两条

| ID | 内容 | 目标 | 归属 | 理由 |
|---|---|---|---|---|
| **M3a** | M6 七站 Cp 对**有粘实验** | **RMS < 0.05**(不变) | **S4 / Track V(有粘)** | 参照是有粘实验;差额里那块**模型地板**只有有粘能力能还 |
| **M3b** | 同算例**无粘速度** | **< 60 s**(不变) | **S3(速度)** | 与地板无关,**完全是本路线自己的债**,且目前**没达标** |

★ **M3b 现在是一条未达标的硬门**:medium 无粘 108 s(换 AMG 31.7 s),
而 T1(1.16 M tets)是 **4 011 s**。**没有任何数字被放松。**

## 4. 顺带明确 S6 不因此触发

S6 的触发条件原文是"M2 或 M3 仍无法达到,**且原因归到网格规整度 / 每自由度精度上**"。
§2 测出 M3 那一项的原因归到**模型**,不是网格 ——
且**离散侧的两个量(LE、激波位置)都已在非结构网格上收敛**。
⇒ **半结构网格不会移走这个地板**,S6 的触发条件在 M3 这一项上**不成立**。
(M2 = RAE2822,是**另一条独立的**触发路径,未受本轮影响 —— GV5.2 记录它 FAIL,
但其归因是"松耦合在跨声速下太弱",同样偏模型侧。)

## 5. 保留的不确定性(不因重定而消失)

* 地板值来自 h ∈ [0.010, 0.030] 的**外推**(四点超定一个自由度);
* LE 两带的偏移拟合**病态**,故给出 0.0516 / 0.0707 两个重建值,**都报**;
* "地板是粘性的"目前只有**符号**证据(粘性把 MID/TE 四带全部推向实验,量级仅 0.4 %),
  与 GV5.2"松耦合太弱"一致 —— **要坐实需要更强的粘性计算或一个无粘 Euler 参照**,
  使用者已预授权在必要时再取。**M3a 归到 S4 正是把这件事放到它该在的地方。**
