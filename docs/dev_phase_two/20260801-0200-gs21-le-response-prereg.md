# 预登记(GS2.1 第一步):LE 的 Cp 误差**到底受不受分辨率控制**?

轮次文件名:`20260801-0200-gs21-le-response-prereg.md`
分支:`claude/phase-two-s2`
**本文件在生成任何新网格之前提交**(roadmap 原则 8)。

---

## 1. 为什么不直接建棱柱层

GS2.1 写的是"各向异性壁面棱柱层"。上一轮已测出它的前提成立
(LE 带各向异性 h_t/h_n = 0.567,法向粗 1.8×;吸力峰只有 3–4 个单元托着)。
**但"前提成立"不等于"这条路能到"** —— 而真正的 3-D 各向异性棱柱层在 gmsh 里
不是一个开关(`BoundaryLayer` 场是二维的;三维要走 `extrudeBoundaryLayer` +
与外层非结构网格的拓扑拼接),是**一套要建的机器**。

本项目反复奏效的纪律是:**先用便宜的杠杆判定那个量到底受不受这个变量控制。**
现有生成器已经有一个**单变量 LE 加密旋钮**:`h_edge`(默认 0.5·h_wall,
作用范围 = 到 LE/TE 曲线距离 DistMin 0.02 / DistMax 0.3 的 Threshold 场)。
**先扫它。** 若 LE 的 Cp 误差对 LE 带加密**响应强**,那条昂贵的路值得投;
**若不响应,棱柱层同样不会有用**,而且 D2 的 kill criterion 进入视野。

★ 同时按 P11 的教训带一条对照:**单变量加密可能撞"体网格污染地板"**
(P11 实测:固定 h_min 只加密远场,壁面 φ 误差降 3.17×;单变量 h_min 扫描则撞地板)。
所以必须有一条**同时加密 h_wall** 的腿,否则"LE 不响应"这个结论可能只是地板效应。

## 2. 协议(执行前固定)

网格:`onera_m6_wing_mesh` 直接调用,**只动列出的量**,其余按 `_level_params` 的
medium 值(h_wall = 0.015、h_wake = 3 h_wall、h_far = 120 h_wall、r_far = 15 MAC、
`tip_cap="flat"`、`embed_wake=True`)。

| 腿 | h_wall | h_edge | 含义 |
|---|---|---|---|
| **L0** | 0.015 | 0.0075(= 0.5 h_wall) | 基线 = 已提交 medium |
| **L1** | 0.015 | **0.00375**(0.25 h_wall) | LE 带 ×2 |
| **L2** | 0.015 | **0.001875**(0.125 h_wall) | LE 带 ×4 |
| **L3** | **0.010** | 0.00375 | ★ 全尺度对照(壁面 ×1.5 + LE ×2)—— P11 的教训 |

求解:P14 跨声速配方逐字、`kutta_estimator="probe"`(**理由**:上一轮实测 probe 与
pressure 的 LE 上 RMS 只差 **0.0006**,而 probe 便宜一半;基线取 probe 的 **0.2361**)。
熵修正 = 默认 ON。提取器 = GV5.3 的那一个。线程 16。

## 3. 事前登记的判据

以 **LE 上表面 RMS**(基线 0.2361,S2 的中间靶 < 0.08)为量:

| 条件 | 结论 |
|---|---|
| L2 或 L3 使 LE 上 RMS **≤ 0.15**(即走完到 0.08 的 ≥ 35%)且单调下降 | **LE 误差受分辨率控制** ⇒ 建各向异性棱柱层这条路值得投 |
| 全部腿的变化 **< 10%**(≥ 0.212) | **LE 误差不受 LE 分辨率控制** ⇒ 棱柱层也无用;**这是一个重大负结果**,S2 转向"P1 场固有能力 / 几何"两个嫌疑,并触发 D2 的 kill criterion 讨论 |
| 介于两者之间 | **RECORDED**,并用 L3 与 L1/L2 的对比判断是否为**污染地板**(若 L3 明显优于 L2,则是地板,结论 = 需要全尺度加密而非只加密壁面) |

**同时必须记录(不作判据)**:每腿的单元数、生成时间、求解墙钟、AMG/直接解迭代数、
以及 `n_limited/n_floored` 与收敛性 —— 因为**产品目标含速度**,
一个把 LE 修好但把网格放大 5 倍的方案是要如实标注代价的。

**失败即结论**:若某腿网格生成失败或求解不收敛,如实记录该腿为缺失,
**不得**用相邻腿顶替(GV5.3 的 R4 同一条)。
