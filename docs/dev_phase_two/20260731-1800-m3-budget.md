## 2. ★ R2 闸门起作用了 —— 3-D 熵缺陷是**随分辨率出现**的

| | σ_min | m1_max | n_floored | \|R\| | 收敛 | R2 |
|---|---|---|---|---|---|---|
| M6 **coarse** ON | **0.9713** | 1.3376 | **0** | 6.86e-12 | ✓ | **PASS** |
| M6 **medium** ON | **0.0** | **2.99999…** | **57** | 2.49e-06 | ✗ | **FAIL** |

medium 的病征与 **G8.2 那条 strict xfail 逐位吻合**(57 floored、\|R\| 2.49e-06)。
新信息有两条,都比"G8.2 在 3-D 上 xfail"这句话精确得多:

1. **它不是"3-D 的问题",而是"medium 及更细"的问题** —— 同样的代码、同样的配方、
   同样的条件,在 M6 coarse 上完全健康(σ_min 0.971、0 floored、严格收敛)。
2. **机制被数字点出来了**:`m1_max = 2.9999999999999996` = **m_cap 本身**。
   膝点行走(knee walk)走到了**限幅马赫**,于是 σ = σ_RH(3.0) ≈ 0 → 密度塌陷 → 57 个 floored 单元。
   也就是说:**行走返回的不是一个物理的激波前马赫数,而是一次行走失败**
   (donor 环,或穿过了多道激波)。

⇒ **修法方向明确且便宜**:膝点行走必须**拒绝**一个到达/超过 m_cap 的 M1
(它按构造不可能是物理前激波值),而不是拿它去算 σ。这条现在是**登记项**。
⚠ 依 R2,medium ON 腿的 RMS 0.1919 与 cl_p 0.2110(比锚点低 20%)**不是熵效应读数**,
是这个缺陷在复现 —— **不得**引作"熵修正在 3-D 无用"的证据。

## 4. ★★ 本轮的主产物:误差预算(medium,OFF = R1 有效腿)

按**平方和份额**分解(5 个未遮罩站、181 个实验点;各带之和按构造重建站 RMS,已断言):

| 带 | RMS | 点数 | 平方和份额 |
|---|---|---|---|
| **LE 上表面**(x/c < 0.15) | **0.2361** | 38 | **69.6 %** |
| **MID 上表面**(0.15–0.85,激波所在) | **0.0955** | 69 | **20.7 %** |
| LE 下表面 | 0.0901 | 18 | 4.8 % |

| MID 下表面 | 0.0233 | 36 | 0.6 % |
| TE 下表面 | 0.0419 | 5 | 0.3 % |

**⇒ 前缘吸力区(上表面)一项占 70%。** 这正是 GV5.3 记录的"浅 LE 吸力",
也**正是 S2 的靶子** —— **S2 的前提成立**。

**但接下来的算术是本轮最重要的一句话:**

| 假设完全消除 | 全点池化 RMS |
|---|---|
| 现状 | 0.1296 |
| LE 上表面 | **0.0715** ← 仍 > 0.05 |
| LE 上 + LE 下 | 0.0656 |
| **LE 上 + MID 上** | **0.0404** ✓ |
| LE 上 + LE 下 + MID 上 | 0.0287 |

**⇒ 棱柱层(壁面/前缘)一项做到完美也拿不到 M3 < 0.05(最好到 ~0.0715)。**
要到 0.05 需要把平方和压掉 **85.1%**,而 LE 上 + MID 上合起来才 **90.3%** ——
**两项都必须做**,而第二项(激波带)正卡在 §2 那个 3-D 熵缺陷上。

加密的效果(coarse → medium):LE 上 0.372 → 0.236(**−37%**),
MID 上 0.123 → 0.096(−22%)—— 两者都随加密改善,LE 更快。

## 5. 结论与顺序影响

1. **S2 的前提确认成立**(它攻的是最大的单项,70%),按 §3 的 R3 继续 → **GS2.1 棱柱层**。
2. **但 M3 < 0.05 是一个两项目标**,S2 单独交付不了。roadmap 里 M3 挂在 S2 名下这件事
   **需要改**:S2 的验收应改为"把 LE 上表面这一项压到 ~0"(可测:LE 上 RMS < 0.08 ⇒ 全点 ~0.07),
   M3 本身则是 S2 + 3-D 熵修复的**联合**目标。
3. **新登记项(3)**:膝点行走的 m_cap 逃逸 —— 在 M6 medium 复现,病征与 G8.2 一致,
   修法已定位(拒绝 M1 ≥ m_cap 的行走结果)。它是 M3 第二项的**前置条件**。
4. ⚠ **不能分辨的部分要说清**:LE 的 70% 是"壁面法向精度"、"前缘弦向分辨率"、
   还是"P1 场在吸力峰处的固有能力"(P11 测到 h=0.08 处 ~11%),本轮**分不开** ——
   棱柱层买的是前两者,第三者若占大头则 D2 的 kill criterion 会触发。
