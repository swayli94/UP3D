## 5. S1 整体结论（八轮测量的汇总）

### 5.1 已确立（都是测量，不是推断）

| # | 结论 | 证据 |
|---|---|---|
| 1 | **通量算子是一致的**：喷管解析解上位置误差 O(h)、C 敏感性 O(h)、~1 单元、对网格抖动不敏感；生产翼型网格 α=0 上同样成立 | GS1.1 §4.3/§4.5 |
| 2 | **强等熵激波本身没问题**：喷管在 M₁ 直到 **1.60** 仍 O(h) 收敛（比值 0.46–0.53） | GS1.6 判据 0 |
| 3 | **固定 Γ 时场求解健康**：M0.72 冻结环量后 cl 最后一步只变 **0.04%**（自由 Γ 是 0.91%）；场映射三级散布 0.008–0.012c 且在收敛 | GS1.6 §4.2、GS1.7 §4.3 |
| 4 | **闭合实现无关**：两种 Kutta 代数给出的根一致到 0.13–0.17%、加密跳幅一致到 0.1%，尽管条件数一个 O(1)、一个 ∝ h^(−0.56) | GS1.3、GS1.3b、GS1.7 §4.4 |
| 5 | **闭合方程渐近退化**：`F = T₀ + (b−1)Γ`，`T₀ → 0` 且 `(1−b) → 0`（都 ~h^0.6），根是两者之比；弱激波下同步消失（收敛），强激波下抵消失效（发散） | GS1.7 §4.5 |
| 6 | **升力的 h-收敛包线 = M_max ≲ 1.2**：收敛比 0.08/0.21/0.36/0.90 对 M_max 0.85/1.17/1.27/1.60；**包线内准确**（M0.72 外推 cl 0.2563） | GS1.3b §4.3 |
| 7 | **钳制会制造机器零残差伪解**，现已契约化拒绝 | GS1.1 §4.4、GS1.4 |
| 8 | **马赫爬坡可以删掉**：目标马赫直接解同解、快 2.8×、且在爬坡到不了的细网格上到得了 | GS1.2b §4.3 |
| 9 | **松耦合粘性回路不可 run-to-run 复现**（同 commit 两遍差 max rel 1.024） | GS1.4 §4.1 |

### 5.2 已排除的路线（每条都有测量，不要再重开）

| 路线 | 为什么排除 |
|---|---|
| 重写人工耗散公式（几何 Δℓ + 最小二乘 ∂ρ/∂s） | 算子本来就一致（结论 1） |
| 对偶网格保守 FV + 熵满足通量（S1-alt） | 同上：修的是不存在的一致性问题 |
| 换 Kutta 估计器（probe ↔ pressure） | 两者同解同漂移（结论 4） |
| 新做一个 h-无关的闭合行 | `pressure` 本来就是（A 1.2–2.2），且无效（结论 4） |
| 伪时间推进（PTC/SER）做全局化 | 一律比纯 Newton 差；已删除（GS1.2b） |
| **只靠加密** | 包线外发散；包线内也要 ~350× 才能把 40% 压到 3%（GS1.2/GS1.3） |
| 把 M1 换成能通过的工况 | roadmap 禁止项；D3 已裁定保留 M1 为 FAIL |

### 5.3 仍然开着的（需要你裁决，我不自行展开）

**核心矛盾**：包线是 **M_max ≲ 1.2**，而 M1/M2/M3 的工况全部需要 **≳ 1.3**。

| 候选 | 内容 | 现状 |
|---|---|---|
| **A. 显式处理 fold** | 把耦合系统当成带极限点的问题解：弧长延拓 / bordered 系统 / deflation。这修的是**数值那一半**——让求解器能沿着分支走过 fold，而不是掉下去 | 未测量。GS1.7 §4.6 的 fold 解释目前是**解释**不是已证事实，开工前应先用矩阵量证实（Γ 方向刚度是否真的过零） |
| **B. 移动 fold（非等熵 FP）** | 在激波处引入熵跳，降低强激波下的过预测，从而把 fold 推到更高马赫 | ★ **注意措辞**：GS1.6 判据 0 只推翻了"等熵过预测导致**无升力**算例失去 h 收敛"这一条，**没有**排除"熵修正能移动**耦合**系统的 fold"。这条路可以带着新的理由回来，但必须重新写前提检验 |
| **C. 接受包线** | 把产品重新定位为弱激波跨声速工具（M_max ≲ 1.2） | 与你给的 M 0.3–0.87 翼身组合体目标不符 |

**另外两件已测量、待你点头的收尾动作**（都会动第一阶段的门禁数字，所以没有自作主张）：

1. **`pressure` 成为默认 Kutta 估计器**：条件数 1.2–2.2 vs probe 的 15–33
   （虽然不改变发散，但没有理由默认用病态的那个）；
2. **马赫爬坡降级为回退**：目标马赫直接解同解、快 2.8×、覆盖更广（结论 8）。

## 6. 判定

**GS1.5 = FAIL（如实记录），S1 = 收口。**

S1 的问题陈述在八轮里被改写了三次，每次都是被下一次测量推翻的：
通量算子 → 闭合行条件数 → 强激波等熵过预测 → **最终落在"升力–激波耦合系统在
强激波下随加密趋近极限点"**。三条被推翻的归因都留了档，没有一条是靠争论翻掉的。

S1 的可交付成果：**一条测量出来的能力边界（M_max ≲ 1.2）+ 一个锁住它的回归
（M1a）+ 一份七条已排除路线的清单 + 三条待裁决的候选**。这比"S1 通过"诚实，
也比第一阶段那种"把失败工况挪走"的做法有用。
