## 0. 一句话

**`tip_taper` 当初是为了在等熵求解器上买高马赫 robustness 而引入的简化模型,代价 ≈−1.5% cl。
S1b 把熵修正设为默认之后,那份 robustness 已经由一个物理上更正确的模型提供 ——
实测:无 taper + 熵修正 **干净收敛**,无 taper − 熵修正 **不收敛**。
⇒ taper 现在是纯系统误差。**

## 1. 用户提供的关键背景(本轮的起点)

> taper 是为了避免翼尖环量减小导致翼尖涡没办法正确表达、导致发散而做的**简化模型**,
> 引入了系统误差。如果有更好的解决办法,你可以尝试。

这决定了**验收判据是它被引入的那件事(防发散),不是偏差变小** —— 一个偏差更小但丢掉高马赫
收敛的配置是**倒退**,不管 cl 看起来多好。该规则写进 runner docstring,执行前固定。

## 2. LE-2 / LE-3:两个假设死了,一个真杠杆浮出

**LE-2 展向定位**(x/c × η 双向分带,LE-0 的积分仪器):赤字在**翼尖**,不在根部 ——
我的"根部-对称面终止"假设**方向完全反了**。四个三维组合一致:根部 p ≈ 1.4–1.7(健康),
翼尖 m6wing **无正阶**、wingbody p ≈ 0.15。这同时解释了 LE-1 的反常(翼身内侧强收敛且
三角形更多,把池化值稀释成健康)。

**LE-3 三腿隔离**(taper 必须配 `pressure` 才走 B31 的 Gamma-pin 行混合,所以不能两腿):

| η 分箱 | L1 probe | L2 pressure | L3 press+taper |
|---|---|---|---|
| [0.4,0.6) | **1.663** | **1.261** | 1.254 |
| [0.8,1.0) 翼尖 | **1.983** | **1.270** | 1.264 |

★ **taper 对收敛几乎为零**(每箱 0.005–0.008,且五箱幅度一致 = 微小全局扰动)。
★★ **真杠杆是 Kutta 估计器**:probe → pressure 把翼尖从 1.983(无正阶)拉到 1.270。
与 P14 吻合(probe 的 O(h) 读数偏差被 Kutta 映射放大 ≈14× 进 Γ,而 Γ(z) 误差就该出现在
翼尖载荷上)。⇒ **`NEWTON_M6_RECIPE` 仍在用 P14 已取代的 probe 估计器**,这是一个承重的
配方缺口(单独机翼路径)。

## 3. LE-4:偏差两个杠杆,以及 docstring 的一处 erratum

`tip_taper_factors` 自己推导过:γ_eff ~ u^(s−1/2),**边缘正则化 ⟺ s > 1/2**;偏差
∝ O((r_c/b)^{3/2})。它称 `vanish_linear`(s=1)是"the minimal-bias form that should
regularize",而生产用的是 `vanish_smooth`(s=2)——"unloads the tip MORE"。

**实测(翼身 conforming,M0.50 偏差 / M0.84 robustness):**

| 配置 | coarse 偏差 | **medium 偏差** | M0.84 medium |
|---|---|---|---|
| `none` | 0.000% | **0.000%** | **✓ 0/0, \|R\| 2.07e-14** |
| `vanish_smooth` 0.05(生产) | −1.180% | **−1.514%** | ✓ 0/0 |
| `vanish_linear` 0.05 | −1.347% | **−1.679%** | ✓ 0/0 |
| `vanish_smooth` 0.025 | −0.337% | **−0.515%** | ✓ 0/0 |
| `vanish_linear` 0.025 | −0.362% | −0.575% | ✓ 0/0 |

★★ **ERRATUM(库文档,非实现):`vanish_linear` 的偏差比 `vanish_smooth` 更大**
(−1.679% vs −1.514%)。机理:smoothstep 在翼尖侧卸载更多(那里 Γ~√u 本来就小、损失的升力
少),在带内侧卸载更少(那里 Γ 大);**积分**下来 smoothstep 拿掉的升力更少。docstring 那句
讲的是**渐近指数 s**,不是**积分偏差**。

★ **r_c 是主导杠杆**:0.05 → 0.025 把偏差砍 **2.9–3.5 倍**(标度律预测 2.83×)。

## 4. 决定性判别子:熵修正接管了 robustness

`none` 在 **coarse 和 medium 都到 M0.84**,与 B32 把"medium 天花板 M0.79 → M0.84"归因于
taper 的前提冲突。B32 是在**等熵**求解器上测的,而 S1b 已把熵修正设为默认。单旋钮 A/B:

```
无 taper, entropy_correction=True    conv=True   0/0  |R| = 2.070e-14   (511 s)
无 taper, entropy_correction=False   conv=False  0/0  |R| = 7.273e-06   (1389 s)
```

⇒ **确证**:熵修正削弱激波(1−σ 达 3–4%),正好削掉了当初导致翼尖失速的那个峰值。
**taper 的防发散职责已被一个物理上更正确的模型接管。**

★ 复现性自检:该 True 腿的 |R| 2.070e-14 与 LE-4 `none` 腿的 2.07e-14 一致。
