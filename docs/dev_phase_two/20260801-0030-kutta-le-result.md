## 3. ★★ 但假设**被否证** —— 按事前规则,不是按事后解释

事前规则:LE 上 RMS 下降 **≥ 0.05** ⇒ Kutta 是 LE 的主因;**< 0.02** ⇒ 不是。
**实测下降 0.0006。** ⇒ **不是。S2 按计划推进。**

**这里有一个本身就值得记录的事实:拿回 4.9% 的升力,那 5 站的 Cp 几乎不动**
(LE 上 −0.0006、LE 下 **+0.0022 变差**、MID 上 **+0.0009 变差**、TE 上 −0.0237 变好)。
**升力量级与 Cp 形状误差在这里是解耦的。**
⇒ **新登记项 (5)**:那 4.9% 的升力**加到哪儿去了**未测 —— 合理猜测是**被遮罩的尖端区**
(η > 0.9,pressure 估计子主要改 Γ 分布最陡的地方,即 P14 记录的 probe 逐站抖动最大处),
但**这是推断,不是测量**。

## 5. ★★★ GS2.1 的前提:第一次被测出**支撑** —— 并**订正我自己前一小时的读数**

★ **订正**:我先前报"LE 带内 82 个表面节点、弦向中位间距 0.0009 c ⇒ 不是弦向分辨率问题"。
**那个读数错了约 10 倍**:它把一条 ±0.02·b 展向**带**内的节点投影到 x 上取差分,
同一 x 附近堆了不同 z 的节点。用**窄板**(±0.002·b)重测,诚实的数字是:

| M6 medium,LE 带 x/c < 0.15 | 值 |
|---|---|
| 弦向节点数(单板,含上下表面) | **~11**(coarse ~6) |
| 弦向间距 dx/c | **≈ 0.010**(coarse ≈ 0.020)—— 与面内尺度 h_t/c ≈ 0.0085 自洽 |
| 首层**法向**高 h_n/c | **≈ 0.019** |
| **各向异性 h_t/h_n** | **0.567** ⇒ **首层单元比它宽 1.8 倍高** |

而**实验的吸力峰在 x/c ≈ 0.034** —— 也就是**离前缘只有 3–4 个单元**。
一个只有 3–4 个单元托着的峰,测出来比实验浅 16%(−0.948 vs −1.127),
**正是欠分辨的样子**。

⇒ **GS2.1 的前提成立,而且方向明确**:法向是**较粗**的方向(1.8×),
棱柱层正是攻它;但**弦向也粗**(峰只有 3–4 个单元),所以 GS2.1 应当是
**各向异性壁面层 + 前缘弦向聚集**,而不只是法向加层 —— 这与 P11 那条
"全尺度加密才恢复阶数、单变量扫描撞地板"的对照一致。
