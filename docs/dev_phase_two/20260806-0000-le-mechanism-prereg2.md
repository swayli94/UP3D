## 1b. ★★ ADDENDUM #1(使用者 2026-08-06,**执行前**):M0.50 是**降级了问题**,不只是换工况

使用者指出:LE 亏空是**跨声速**求解器的问题,**必须有激波在场**;换到 M0.50 不合理,
0.6/0.7 也比 0.5 合理。**这条批评成立,而且比"不够跨声速"更严重。**

**为什么**:项目自己有一条锁,`tests/test_s1b_entropy.py::
test_scope_boundary_no_shock_means_bit_identical` —— **全场无超声速单元时,熵修正 ON/OFF
逐位相同**。M0.50 的 M6 机翼正是这种状态,于是在那个工况上:

| 机制 | 在 M0.50 的状态 |
|---|---|
| 人工密度上风 / `upwind_c` | **惰性**(ν ∝ 超临界程度,亚声速处为 0) |
| 熵修正 σ | **恰好 1**,ON/OFF 逐位相同(上面那条锁) |
| `m_cap` 限幅器 | **永不触发** |

⇒ 在 M0.50 上测到的会是**纯 P1 场的壁面精度误差**,即 **G1.6 / P11 那一类** ——
而 **P11 已经答过**(球面 11.6% = h=0.08 处 P1 场的固有能力,不是壁面变分犯规)。
**那不是产生 M3 那 69.6% 的机制。换掉工况就等于换掉了问题。**

★ 我的原始动机(绕开 `m_cap` 让加密方向可用)是**仪器动机**,而我让它**覆盖了物理要求** ——
这与本阶段反复栽的那类错误同形:为了让实验做得成而移动了被测对象。

**修正后的做法:工况不靠假设选,先测出窗口。** 不能直接采用 0.7 ——
`NEWTON_M6_RECIPE` 的注释说 M6 在 **m_start 0.70 是亚临界的**("the ramp's FIRST level is
subcritical"),若如此则 0.70 同样没有激波。所以插入一步:

### 步骤 0(新增,先做):测"**有激波 且 加密可用**"的窗口

对 M∞ ∈ {0.60, 0.70, 0.75, 0.78, 0.80, 0.8395}(α 3.06,h_wall 0.020 的探针网格),
每个马赫跑**两腿** —— 基线与 `h_far` 减半 —— 记录:

| 记录量 | 用途 |
|---|---|
| `M_max`、`n_shock_cells` | **有没有激波**(超声速区是否存在) |
| 截面 Cp 的 `x_shock`(η 0.44/0.65/0.90) | 激波是否**可定位** |
| `n_limited` / `n_floored` **及其位置** | **加密方向是否可用** |
| `seed_fallback.fired` | 是否靠回退才活 |

**窗口的定义(事前固定)**:一个马赫**在窗口内**当且仅当
**(i)** 基线与加密腿**都收敛且 0 limited / 0 floored**,**且**
**(ii)** 两腿**都有超声速区**(`n_shock_cells` > 0 或 M_max > 1),**且**
**(iii)** 至少一个展向站能定出 `x_shock`。

**主实验放在窗口内的最高马赫上** —— 越接近 M3 的 0.8395 越好,因为那才是被问的工况。

**若窗口为空**(只要有激波、加密就撞帽),那**本身就是结论**,而且比因子实验的任何结果都重要:
**在这个求解器上,"有激波"与"可加密"两个条件不可同时满足** ⇒ LE 亏空**不能用加密归因**,
必须先解决 `m_cap`/翼尖那一侧。届时按此如实上报,**不得**退回亚声速去凑一个能做的实验。

## 3. 度量:**位移**,不是误差

对每一腿,在 `run_m3_budget` 的**同一 7 站、同一插值**上取 LE 带(x/c ∈ [0, 0.15))的
Cp,与 **G00** 逐点相减,报

```
Δ_LE(leg) = RMS over the LE band of ( Cp_leg − Cp_G00 )
```

不需要实验、不需要第三层。★ 同时报 MID/TE 带的位移作为**对照**:若远场加密把
**每个带**都同等移动,那测到的是全局位移而不是 LE 特有的污染 —— 这一条**必须报**,
否则 LE 的读数无法归因。
