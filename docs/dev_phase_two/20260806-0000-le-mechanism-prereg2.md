## 1. 第一版为什么做不成(三个障碍,逐条对应换法)

| 障碍(实测) | 换法 |
|---|---|
| **M0.8395 上每个加密方向都把峰值马赫推向 `m_cap`**(三腿 M_max **恰好 3.0**,clamp 到 883/202)⇒ 加密臂**没有读数** | **换到亚临界 M0.50** —— 没有激波、没有限幅器、翼尖超声速斑块消失 |
| **`h_edge` 不是干净的单变量 LE 旋钮**:按住它、只动 `h_wall`,LE 三角形仍 **+41.7%** | ★ **体网格臂改用 `h_far`** —— 它**完全不碰表面网格**,而且这正是 P11 在球面上用的那条臂 |
| 对**有粘实验**测**无粘**求解器的误差,本身是个前提问题(M3 拆分的理由) | **改测位移,不测误差** —— 自比较,不需要实验 |

★ **`h_far` 这一步是本设计的关键,而它来自项目自己已接受的机制**:P11 实测
"在固定 h_min = 0.03 下**只加密远场**,壁面 φ 误差掉 **3.17×**,argmax 从 r = 1.53 移回壁面,
阶数恢复到 **1.89**" —— 那正是"固定体网格污染地板"的证明方式。
第一版错在用 `h_wall` 当体网格旋钮,而 `h_wall` 同时细化了整个表面(包括 LE)。

## 2. 设计

`onera_m6_wing_mesh(h_wall, h_edge, h_te, h_wake, h_far, r_far, tip_cap="round", ...)`,
生产 taper + pressure Kutta,**M∞ 0.50 / α 3.06**(M6 的既有亚声速工况)。

| 腿 | h_wall | h_le | **h_far** | 含义 |
|---|---|---|---|---|
| **G00** | 0.020 | 0.010 | **2.4** | 基线 |
| **G10 far-only** | 0.020 | 0.010 | **1.2** | **只加密远场;表面网格一个节点都不动** |
| **G01 le-only** | 0.020 | **0.0075** | 2.4 | 只加密 LE |
| **G11 both** | 0.020 | **0.0075** | **1.2** | 两者 |

`h_te = 0.5·h_wall`、`h_wake = 3·h_wall`、`r_far = 15·MAC` 四腿全同。
**`h_wall` 四腿全同 = 0.020** ⇒ 表面的"体侧"分辨率不变,变的只有**远场**与**LE**。

## 3. 度量:**位移**,不是误差

对每一腿,在 `run_m3_budget` 的**同一 7 站、同一插值**上取 LE 带(x/c ∈ [0, 0.15))的
Cp,与 **G00** 逐点相减,报

```
Δ_LE(leg) = RMS over the LE band of ( Cp_leg − Cp_G00 )
```

不需要实验、不需要第三层。★ 同时报 MID/TE 带的位移作为**对照**:若远场加密把
**每个带**都同等移动,那测到的是全局位移而不是 LE 特有的污染 —— 这一条**必须报**,
否则 LE 的读数无法归因。

## 4. 事前判据(数字在此固定)

| | 条件 | 结论 |
|---|---|---|
| **P(污染)** | **Δ_LE(G10) ≥ 0.60 × Δ_LE(G11)**,**且** Δ_LE(G10) > Δ_LE(G01) | LE 亏空**主要由远场/体网格控制**,不是 LE 局部 ⇒ **S2 的靶子从"LE 处的棱柱层"改为体网格与远场**,并与 P11 的球面机制**合并为同一条** |
| **N(否证)** | **Δ_LE(G10) < 0.10 × Δ_LE(G11)** | 远场污染**被否证**;LE 亏空既非 LE 局部(第一版已测 −1.55%)、亦非远场污染 ⇒ 需要第三个候选(登记:尾迹 `h_wake`、`r_far` 本身、翼尖 taper) |
| **I** | 介于两者之间 | **RECORDED,不下结论** |
| **对照条款** | 若 Δ_MID(G10) 与 Δ_TE(G10) 都 ≥ 0.8 × Δ_LE(G10) | 远场加密是**全局位移**,上面的 P/N **一律不得读** —— 只能记为"远场影响全场",另设计 |

## 6. 成本(这一次从**实测**估,不从旧数猜)

第一版的实测:h_wall 0.020 的**跨声速**腿(含 M0.70 probe seed + 完整马赫爬坡)= **59 s** 求解
+ 18 s 生成。本轮是**亚临界单点**,无爬坡、无 probe seed ⇒ 应**显著低于** 59 s,
但 `h_far` 减半会**增加体单元数**(远场更密),量级未知。

- 单腿 > **400 s** ⇒ 停止,如实上报;
- 四腿总计 > **1200 s** ⇒ 只报已完成的腿。

★ 第一版把成本估错了一个数量级(写 7 s/61 s,实测 187 s/1043 s),原因是引用了**别的配方**的
旧数字。本轮的估计**只引用本轮同族的实测 59 s**,并且仍然设闸门。
