
# 20260805-0200 — 追 σ 输运:根因是一个 2 单元的无害环,以及一个错的收敛判据

承接 [20260805-0030](20260805-0030-le15-le16-classifier-fix.md) §4 点名的唯一活线索。

## 0. 一句话

`sigma_transport_not_converged` 的根因**不是**熵修正本身、**不是**翼尖、**不是**供体环塌缩,
而是:**供体图里一个长度 2 的无害环(环上无激波)让 pointer-doubling 的 24 轮全部空转**,
于是收敛判据「每个祖先都是真根」永远不成立,把一个 |R| = 8.8e-15 的完美解判成失败。
修法是把判据换成「**累积乘积不再变化**」—— 它同时保留对真塌缩的检测。

## 1. 先读代码,不从名字推(今天第八次的教训)

`newton.py:1282-1288` 写得很明确:

```python
if converged and not ws.sigma_converged:
    # a donor cycle defeated the entropy transport, so sigma is garbage on part
    # of the mesh  →  拒绝上报收敛(GS1.4 clamp-not-silent 契约)
    converged = False;  accept_reason = "sigma_transport_not_converged"
```

⇒ 它**不是**"σ 还没迭代收敛",而是"**供体环击败了熵输运,部分网格上 σ 是垃圾**",于是按契约
**拒绝谎报收敛**。而 `entropy.py` 的判据是 `converged = (n_rounds < n_round)`,
`transport_sigma` 的终止条件是「**每个祖先都是真正的根**」(`upstream[A[e]] == A[e]`)——
docstring 特意说明**不能**用"指针不再移动",因为长度 2 的环会让每个单元变成自己的祖先、
**看起来像根**。

## 2. 术语(用户指出我造词与混用,逐个定清)

| 词 | 含义(实现层/图论,**不是**流体力学) |
|---|---|
| **图** | **供体图**:每个单元 e 有唯一上游供体 `upstream[e]`;每节点恰一条出边的有向图 |
| **链** | 顺箭头走的路径 e → upstream[e] → … |
| **根** | 自己是自己的供体(`upstream[r]==r`),即"上游走查走不动了" |
| **环** | **图论环**:A→B→…→A,永远到不了根。**与"极限环"、与环量 Γ 无关** |
| **自指** | 长度 2 的环经一轮 doubling 后每个单元成为自己的祖先,**看起来像根而其实不是** |
| **s** | 单元的**激波因子** = 该单元跨激波的总压比 p₀₂/p₀₁;无激波则 s = 1 |
| **σ** | **累积**熵因子 = 沿链一路乘到根的所有 s 之积;密度取 ρ_s = σ·ρ_等熵 |
| **σ 塌缩** | 环上有 s<1 时 doubling 每轮把乘积**平方**,P^(2^k) → **恰好 0**(密度为零 = 垃圾) |
| **settle** | doubling 到达不动点(所有祖先是真根),再迭代不变 |

⚠ **我在分类器里用"极限环"指残差振荡**,与这里的"图的环"是**两件无关的事**,同一个"环"字。

## 3. ★ 撤回我一句方向反了的推理

我说过「90099 个单元只有 29 个根 ⇒ **最长链远超 2²⁴**」。**错,而且反了。** Doubling 每轮把祖先
推进 2^k 步,24 轮覆盖 2²⁴ ≈ 1670 万步;整个网格只有 9 万个单元,**任何链都不可能那么长**。

正确的推理:**24 轮对 9 万单元的图绰绰有余,而轮数上限仍被用满 —— 这本身就证明图里有环**
(环无论多少轮都不 settle)。结论碰巧对,理由是胡说。同理我对 p13 那例说的"链太长"也错。

## 4. 实测

| 例 | 单元 | 根 | 激波单元 | **环上单元** | **环上有 s≠1** | σ_min | \|R\| |
|---|---|---|---|---|---|---|---|
| p13 round-tip coarse M0.5 | 68624 | 20 | **0** | **2** | **0** | **1.000000** | 8.85e-15 |
| conf_wb_coarse M0.78 α2.0 | 90099 | 29 | 187 | **2** | **0** | 0.993485 | 9.34e-11 |

**两例都只有一个长度 2 的环,而且环上没有激波** —— 正是 docstring 自己那个例子
(u(0)=1, u(1)=0):**两个单元互相把对方当供体**。

后果链条(conf_wb 例):

```
2 个互指单元 → doubling 24 轮空转 → 62503 个下游单元走不到根
             → 其中 1408 个链上还有未乘入的 s≠1  ⇒ 这些单元的 σ 确实不完整
             → converged=False  ⇒ 整个解被判失败
```

**链长与激波深度**(conf_wb 例,单跳实测):

```
链长(到根跳数):     中位 35   p90 82   最长 145      99.36% 能到根,573 落入环
链上最上游激波深度:  中位 15   p99 53   最深 61
⇒ 走到「最深激波」只需 61 跳,走到「根」要 145 跳
```

## 5. 供体图的图论要求**只**来自熵修正

| 消费者 | 用法 | 需要无环? |
|---|---|---|
| 人工密度上风 `rho_tilde`、Newton Jacobian Term 3(`jacobian.py`,`u = upstream[e]`) | **只走一跳** | **不需要** —— A 取 B、B 取 A 有界且良定义 |
| 熵输运 `transport_sigma` | 需**整条链到根**(σ 是路径积) | **需要** |

`grep` 确认"根/链/环/pointer-doubling"只出现在 `entropy.py`(其它文件里的 "root" 全是**翼根** z=0)。
⇒ **那个 2 环在 S1b 加入熵修正之前完全无害**,是熵修正把它**变成**了问题。

## 6. 为什么要沿路径积分、要不要走到远场、能不能设上限

- **为什么积分**:熵修正建模流体**自己携带**的总压损失,到达 e 的流体穿过了上游每一道激波,
  p₀(e) = p₀∞·∏(p₀₂/p₀₁)。只看本地会漏掉上游所有激波。
- **要走到远场吗**:原理上是(那里 σ=1),**实现上不必** —— 一旦走过路径上**最上游的那道激波**,
  后面全是 s=1,**乘积不再变化**。
- **能设上限吗**:**能**,而且实测支持:σ 在第 61 跳后就恒定,而"到根"要 145 跳。

## 7. 修法 (E),以及为什么前四个都不对

| | 做法 | 为什么不采 |
|---|---|---|
| (A) 判据改「剩余链上 s 全为 1」 | **不够** —— conf_wb 例有 1408 个单元的 σ **真的没算完** |
| (B) 提高 `n_round` | **无效** —— 环无论多少轮都不 settle |
| (C) 无激波时判收敛 | 只治 p13,不治 conf_wb |
| (D) 在供体图里打断环 | ⚠ **会改上风密度与 Jacobian Term 3** ⇒ 移动所有已提交跨声速数 |
| (D′) 在熵内部用副本打断环 | 可行,但仍是**结构性改动**,且要判定"哪个环可断" |
| **(E) 判据改为「累积乘积在一轮内不再变化」** | **采纳** |

**(E) 为什么对三种情形都正确:**

| 情形 | (E) 的行为 |
|---|---|
| 无害环(环上 s=1) | 乘积早已稳定 ⇒ **判收敛** ✓(现在误判失败) |
| σ 未算完的单元 | 乘积仍在变 ⇒ 继续;**只需走到第 61 跳**而非 145 ⇒ 更早收敛 ✓ |
| **带削波激波的环(真塌缩)** | 乘积**每轮平方、持续变化** ⇒ **永不稳定 ⇒ 仍然拒绝** ✓ 契约保住 |

且 **不碰供体图** ⇒ 上风与 Jacobian Term 3 **逐位不变**。
