# GS1.7：扫 Γ，把"场映射"和"闭合根"分开

轮次文件名：`20260729-0010-s1-gamma-sweep.md`

分支：`claude/phase-two-s0-s1`

> §1 与 §1.1 在执行任何计算之前写下（roadmap 原则 8）。§4 起执行后填。

## 1. 目的

GS1.6 的固定 Γ 判别测到：M0.72 冻结环量后场的 h 依赖只剩 **0.04%**（自由 Γ 是
0.91%）⇒ 剩余误差几乎全在 **Γ 的确定过程**上。但那个实验在 M0.7875 上不成立
（施加了不相容的环量）。这一轮用**每级各自自洽求解的 Γ 扫描**取代它。

### 1.0 已有数据能推出的机制（本轮要验证或推翻）

probe 闭合是不动点映射 `T(Γ) = Γ`（T = 后缘位势跳跃）。GS1.3b 测得
`|S_code| = |1 − b|` = 0.0670 / 0.0454 / 0.0309（coarse/medium/fine）
⇒ `b = dT/dΓ` = 0.933 / 0.955 / 0.969。局部线性化 `T = T₀ + bΓ` 给
**Γ\* = T₀/(1 − b)**。用实测 Γ\*（0.189159 / 0.264262 / 0.3575）反推：

| 级别 | 1 − b | 实测 Γ\* | 反推 T₀ |
|---|---|---|---|
| coarse | 0.0670 | 0.189159 | **0.01268** |
| medium | 0.0454 | 0.264262 | **0.01200** |
| fine | 0.0309 | 0.3575 | **0.01105** |

**分子 T₀ 近乎收敛（−5%、−8%），分母 (1 − b) 缩了 32%、32%。**
即：Γ\* 发散不是因为"闭合读数漂移"，而是因为**不动点映射的斜率 b → 1**。

但这与 GS1.3b 的另一条实测有张力：`pressure` 闭合行的条件数是 O(1) 且不随 h 退化，
两种闭合行的**根却完全一致**（cl 差 ≤ 0.3%）。若根只由 (1−b) 决定，pressure 的根
应该不一样。所以本轮要测的是：**根的漂移到底是"闭合代数"的性质，还是"后缘流动状态
随 h 漂移"的性质**（后者会被两种闭合行以各自的灵敏度同样读到，从而给出相同的根）。

### 1.1 做法

每一级网格、每一个 Γ（在该级可行窗口内）**自洽求解场**（Kutta 行完全去掉），记录：

* **场映射**：`Γ → x_shock`、`Γ → cl_p`、`Γ → M_max`；
* **两个闭合残差**：`F_probe(Γ) = T(φ) − Γ` 与 `F_press(Γ) = |q_u|² − |q_l|²`（原始值）；
* clamp 计数（有 clamp 的点标记为不可用 —— GS1.6 §4.3 的教训）。

工况：**M0.72**（收敛的对照）与 **M0.7875**（发散的）。

### 1.2 失败判据（预先写下；含"测不出来"与"动作前提"）

| # | 判据 | 判定 / 含义 |
|---|---|---|
| **0（动作前提）** | 各级必须有**重叠的可行 Γ 窗口**（无 clamp、场收敛），否则跨级比较无意义 | 无重叠 = 本轮改为"只报告每级自身的曲线"，并明确说明不能跨级比较 |
| 1 | **场映射是否重合**：在重叠窗口内，三级的 `Γ → x_shock` 曲线差 < 0.02c | 重合 ⇒ 场健康，根因在闭合侧；不重合 ⇒ 回到场侧，且必须解释喷管为何不漂移 |
| 2 | **闭合残差怎么变**：在共同 Γ 上，`F_probe` 与 `F_press` 随 h 的漂移量，以及各自的斜率 | 若两者的 `δF/(dF/dΓ)` 相等 ⇒ 根漂移是**后缘流动状态**的性质（rendering-independent），机制确定 |
| 3 | **b → 1 的直接确认**：`dT/dΓ` 由扫描斜率直接拟合，与 GS1.3b 的矩阵值（0.933/0.955/0.969）对比 | 差 > 10% = 我的线性化不成立，§1.0 的推断作废 |
| 4 | **测不出来** | 若 M0.7875 上多数 Γ 点都 clamp（重复 GS1.6 §4.3 的失败），只报 M0.72 并说明 |

**约束**：库代码零改动（纯测量）；不引入新旋钮；不为了让点收敛而改配方
（clamp 的点如实标记丢弃）。

```bash

```

## 4. 结果

### 4.1 判据 0：M0.7875 上**没有重叠的可行窗口**，且窗口本身随加密塌缩

| 级别 | 可用点 / 总点 | 说明 |
|---|---|---|
| coarse | **6 / 6** | Γ ∈ [0.19, 0.34] 全部干净（无 clamp） |
| medium | **1 / 6** | 只有 Γ=0.28（平衡值 0.2643 附近）可用，其余全部 M_max = 3.0 |
| fine | **0 / 3** | 全部撞限速器 |

按预注册的判据 0，**M0.7875 不能做跨级比较**，只报告每级自身的曲线。
但这个"塌缩"本身是一条测量结论：**固定场的可用 Γ 窗口从 ±0.15（coarse）塌到
±0.02（medium）再到 0（fine）**。M0.72 上则一直很宽（5/5、3/5、2/3）。

### 4.2 判据 3：`b = dT/dΓ → 1`，与矩阵测量一致

M0.72，扫描斜率拟合：

| 级别 | b | **1 − b** | 相邻比值 |
|---|---|---|---|
| coarse | 0.9477 | 0.0523 | — |
| medium | 0.9657 | 0.0343 | 0.656 |
| fine | 0.9771 | 0.0229 | 0.668 |

⇒ **(1 − b) ∝ h^0.60**，与 GS1.3b 矩阵路线的 h^0.56 一致（判据 3 PASS）。
M0.7875 coarse 拟合 b = 0.9742（矩阵值 0.933，差 4.4%，在 10% 内）。

### 4.3 判据 1：**场映射收敛**（根因不在场侧）

M0.72，共同 Γ 上的 x_shock（coarse / medium / fine）：

| Γ | x_shock | 散布 |
|---|---|---|
| 0.1267 | 0.2987 / 0.2915 / 0.2871 | **0.0117c**（差值 −0.0072 → −0.0044，比值 0.61） |
| 0.1350 | 0.3012 / 0.2942 / 0.2928 | **0.0084c** |

散布 < 0.02c 且在收敛 ⇒ **判据 1 PASS：固定 Γ 时场是健康的、收敛的。**

### 4.4 判据 2：**根的漂移与闭合实现无关**（第三次确认）

两种闭合行的根（M0.72）：

| 级别 | root(probe) | root(pressure) | 差 |
|---|---|---|---|
| coarse | 0.12186 | 0.12170 | 0.13% |
| medium | 0.12678 | 0.12657 | 0.17% |
| fine | 0.12789 | 0.12774 | 0.12% |

而两者的**条件数走向相反**：`dF_press/dΓ` = 4.25 → 5.37 → 6.89（**变好**），
`|1−b|` = 0.052 → 0.034 → 0.023（**变坏**）。**条件数一个变好一个变坏，根却一起漂移
同样的量**（+4.1%、+0.9%）⇒ 根的漂移是**离散解本身的 h 收敛**，不是闭合代数的产物。

### 4.5 ★ 机制：闭合方程是**两个同时趋零的量之比**

probe 闭合 `F = T(Γ) − Γ = T₀ + (b−1)Γ`，根 `Γ* = T₀/(1−b)`。用扫描值反算 T₀：

| 工况 | 级别 | T₀ | 1 − b | Γ* = T₀/(1−b) | 实测 Γ* |
|---|---|---|---|---|---|
| **M0.72** | coarse | 0.006371 | 0.0523 | 0.1218 | 0.121833 |
| | medium | 0.004349 | 0.0343 | 0.1268 | 0.126786 |
| | fine | 0.002928 | 0.0229 | 0.1279 | 0.127890 |
| **M0.7875**（由 GS1.3b 矩阵值反推） | coarse | 0.01268 | 0.0670 | 0.189 | 0.189159 |
| | medium | 0.01200 | 0.0454 | 0.264 | 0.264262 |
| | fine | 0.01105 | 0.0309 | 0.358 | 0.3575 |

* **M0.72**：T₀ 缩 −32%、−33%，(1−b) 缩 −34%、−33% ⇒ **同步趋零、比值几乎不变**
  ⇒ Γ\* 只动 +4.1%、+0.9%（收敛）。
* **M0.7875**：T₀ 只缩 −5%、−8%，而 (1−b) 缩 −32%、−32% ⇒ **抵消失效**
  ⇒ Γ\* 按 1/(1−b) 发散。

也就是说：`T` 按定义趋于 Γ，所以 `F = T − Γ` 在 h→0 时退化成 **"0 = 0"**，
它的根是两个消失量之比。弱激波下这两个量同步消失，比值稳定；强激波下激波的
h 依赖扰动了那个很小的 T₀，比值就跑飞。

### 4.6 解释（**标注为解释，不是已证事实**）：耦合系统在 h→0 时趋近一个极限点（fold）

把所有证据放一起，最简洁的统一解释是**离散耦合系统在强激波下随加密趋近一个 fold**：

| 证据 | 与 fold 的关系 |
|---|---|
| Γ 方向刚度 \|S_code\| 在 M0.7875 上 0.0312 → 0.0117（每级 ×0.375），而 M0.5 上 ×0.68 | 强激波下刚度**塌得快一倍**，外推在有限 h 处过零 |
| 固定场的可用 Γ 窗口 ±0.15 → ±0.02 → 0（§4.1） | fold 附近解流形变薄 |
| 同一边界数据存在多个机器零残差解（GS1.1 §4.4） | fold 附近典型 |
| cl 对 C 的 26–47% 敏感、对 h 的 +40%/+37% 漂移 | fold 附近任何扰动都被放大 |

## 5. 判定

**GS1.7 = PASS（测量完成，四条判据全部有结论）。**

| 判据 | 结果 |
|---|---|
| 0 可行窗口 | M0.72 有重叠；**M0.7875 没有**（按预注册只报每级曲线）；窗口塌缩本身是结论 |
| 1 场映射 | **PASS** —— 散布 0.0084–0.0117c 且在收敛 ⇒ 场健康 |
| 2 闭合漂移 | 两种实现的根一致到 0.13–0.17%，而条件数走向相反 ⇒ 根漂移与实现无关 |
| 3 b → 1 | **PASS** —— (1−b) ∝ h^0.60 vs 矩阵 h^0.56 |
| 4 测不出来 | 部分触发（M0.7875 跨级比较做不了），已如实报告 |

一句话：**Kutta 闭合方程在 h→0 时退化为"两个同时趋零的量之比"；弱激波下两者同步
消失所以收敛，强激波下抵消失效所以发散。场本身是健康的，闭合实现也是无辜的
（第三次确认）。最简洁的统一解释是耦合系统在强激波下随加密趋近一个极限点。**

库代码零改动。
