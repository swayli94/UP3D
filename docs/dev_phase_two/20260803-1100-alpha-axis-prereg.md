## 2. 被检验的机理主张(不是我的新猜测,是 B23 的既有测量)

B23 测过:翼身结合处的伪超声速 pocket 是**升力/尾迹耦合**的 —— α = 0 时两个网格层
都干净,并随 α **超线性增长**。B25 的 `inboard_clip` 把 α = 3.06 的 pocket 从
corrM 14.66 治到 0.63。

M∞ = 0.50 是**亚声速来流**,局部 1.50 不可能是物理激波,所以对 `ls_wb_medium`
该动的杠杆是 **α,不是 M∞**。这一轮就是去测这个杠杆。

## 3. 预注册的判据(可被否证)

**P1 — 区分两类 CLEAN_OVER_MMAX。** 定义灵敏度 S = −ΔM_max / Δα(每度)。

- **预测**:翼身格(wb)的 S **显著大于** 2.5-D NACA 格(`ls_naca_coarse`)。
- 理由:wb 的越线量来自升力耦合的几何奇点;`ls_naca_coarse` 在 M0.80 的 1.4077 是
  **真实跨声速 pocket**,它主要由 M∞ 定,降 α 只能小幅削弱。
- **若 S_wb ≈ S_naca**,则「wb 越线 = 奇点、naca 越线 = 物理激波」这个区分不成立,
  两类状态必须合并叙述 —— 记为否证。

**P2 — B23 的直接预测。** `ls_wb_medium` 在 M∞ = 0.50、**α = 0** 应当明显干净
(预注册阈值 M_max < 1.0)。若 α = 0 仍 ≥ 1.4,则 B23 的归因**不能**外推到
medium 层 level-set 翼身的全局 M_max —— 那是一条新发现,必须记录,不得沿用旧归因。
(这一条正是「不要把上一阶段的归因当结果带进新测量」的 P14 教训。)

**P3 — α 松弛后的包线。** 每格沿 α 下降,**第一个** CLEAN(收敛 + M_max < 1.4)即为
该格的「α-松弛包线点」,记录 (M∞, α)。这是交付物,不是通过/失败判据。

## 4. 协议

- **M∞ 固定**在该格**首个越线级**(即矩阵里第一个 CLEAN_OVER_MMAX 的马赫数);
  `ls_wb_medium` 固定在阶梯底 M0.50。这样测的是「α 能否买回这一级」。
- α 阶梯(降序,命中即停):
  - M6 系(惯例 3.06°):**2.00, 1.00, 0.50, 0.00**
  - NACA 系(惯例 1.25°):**0.80, 0.50, 0.25, 0.00**
- α = 0 是**机理检查**(P2),不是交付工况:该处升力 ≈ 0,`cl` 无意义,读的是 M_max。
- 求解配方、网格、判据函数 `classify()`、M_max 判据 1.4 **全部沿用矩阵 runner**
  (直接 import `bench/run_capability_matrix.py`,不复制)。**没有任何指标被放松** ——
  M_max < 1.4 的条件原样保留,变的只是 α 这一个自由度。
- 5 格全测,不只 `ls_wb_medium`:P1 需要 naca 格作对照,否则无法区分两类越线。
