## 2. G1 按字面:**FAIL** —— 如实判,不改判据

事前判据:`M_max < 1.6` **或** 尖端带 ≤2/8。实测 **1.6719** 与 **8/8** ⇒ **两条都不满足,FAIL。**
按预登记的处置:**本轮不得把 T1 的 RMS 当作 P11 杠杆的答案。** 照办。

## 3. ★ 但那个闸门是我设计错的 —— 这本身是本轮的发现

**错在哪**:我用"峰值在 η>0.95 的尖端带内"当作"**尖端后缘自由边奇点**"的代理。
但 T0 的峰值**搬家了**:从 L0p 的 **x/c 1.041(尖端后缘)** 变到 **x/c 0.0391(尖端前缘)** ——
**那是另一个东西**(外翼前缘吸力峰),而我的判据把它一并算作"尖端带",于是读出 FAIL。
`M_max < 1.6` 那个阈值也是拍的:实测从 2.1005 掉到 1.6719 = **−20 %**,只是差一点没过一条任意的线。

**⇒ 判据 FAIL 是真的,判据本身也是错的。** 这两句必须同时说。
我**不会**用"闸门设计得不好"去把 FAIL 读成 PASS —— 事前登记的全部意义就是防这一手。

## 4. ★★ taper 真正做到的事(测量,不是解释)

本轮的目的是让 **P11 那条杠杆变得可读**。就这件事而言:

| | L3p(**无** taper) | **T1(有 taper)** |
|---|---|---|
| 收敛 | **✗** \|R\| 1.03e-05 | **✓ \|R\| 7.11e-15** |
| M_max | **3.1330**(越过 m_cap 邻域) | 1.9557 |
| n_limited / n_floored | 0 / 0(但未收敛) | **0 / 0,收敛** |
| LE 上 RMS | 0.3172(**非读数**) | 0.1758 |

**同一张 1.16 M tets 的网格:无 taper 不收敛,有 taper 收敛到机器精度。**
⇒ **taper 达成了本轮的实际目的(让全尺度网格可解)**,尽管我的 M_max/尖端带闸门判它 FAIL。

★ 交叉校验:T0 的 cl_p **0.273472** vs 无 taper 的 pressure 腿 **0.277257** ⇒ taper 代价 **−1.37 %**,
与 B32 在翼身组合体上实测的 **≈ −1.3 %** 吻合 —— taper 的接线是对的。

## 6. 成本:精度与速度正面冲突(上报,不掩饰)

但依预登记 §5,**本轮不替使用者裁决**。

## 7. 下一步(需要一条新的预登记,不是本轮的延伸)

1. **修正后的闸门**必须区分**尖端后缘自由边奇点**(B31/B32 治的那个)与**尖端前缘吸力峰**
   —— 例如判据改为"峰值不在 x/c > 0.9 的尖端后缘角",或直接以**同一网格上 taper 的
   开/关是否把不收敛变成收敛**为闸门(这一条本轮已经满足)。
2. 因为修正判据是在看过数字之后写的,**必须配样本外腿**。最便宜的样本外预测:
   **coarse + taper**(55 k tets,约 20 s)—— 若"全尺度加密"是真杠杆,
   则 coarse → T0 → T1 的 LE 上 RMS 必须**单调下降**,且 coarse 明显差于 0.2358。
   这是一条**可被证伪的事前预测**,而且几乎免费。
3. T2(h_wall 0.0075,约 2.7 M tets)按 T1 的 4 011 s 外推是**数小时**级 ——
   在成本闸门下**不应**盲跑;它的价值要等 §7.2 的便宜样本外腿先说话。
