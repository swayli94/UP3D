## 2. 判据(事前定死,尤其这两个词)

**"收敛"** ≡ 驱动报 `converged=True` **且** `n_limited == 0` **且** `n_floored == 0`。
理由:项目自己的 clamp-not-silent 契约(GS1.4 / B15)—— **一个带 clamp 的"收敛"不是解**。
带 clamp 但残差达标者记为 **CLAMPED**,单列,**不计作收敛**。

**"合理"** ≡ 依使用者本轮的放松条件,**头条包线是 `M_max < 1.4`**。
另有两项**记录但不作门**:
* 有已提交锚点处的 `cl_p` 偏差(锚点是旧代码状态测的,只作交叉核对);
* `cl_p` 与 `cl_KJ` 的一致性(两个独立估计量分歧大 = 结果可疑)。

## 3. 矩阵(10 格)

| | conforming | level-set |
|---|---|---|
| NACA 2.5-D medium | ● | ● |
| M6 wing coarse / medium | ● | ● |
| M6 wing-body coarse / medium | ● | ● |

**每格两问:**
* **(Q1 亚声速锚)** M∞ 0.5 能否干净收敛 —— **这一格若失败,该路径是坏的**,后续不用测;
* **(Q2 包线)** 沿马赫阶梯上爬,报告**最后一个同时满足"干净收敛"与 `M_max < 1.4`** 的点。
  阶梯:M 0.50 → 0.60 → 0.65 → 0.70 → 0.75 → 0.78 → 0.80 → 0.82 → 0.84(α 用各算例的约定)。
  终止:首次**不收敛**或 **M_max ≥ 1.4** 即停,并如实记录停在哪一档、因为哪一条。

★ **报告的是"包线"而不是"某个点过没过"** —— 因为 M6 在 M0.84 上 `M_max` 已到 2.1
(尖端奇点),那本来就在任何全速势模型的有效性之外。
**"M_local < 1.4 内是否处处收敛"才是使用者问的那个问题。**
