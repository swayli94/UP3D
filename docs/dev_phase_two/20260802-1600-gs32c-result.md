## 2. 判读:**不实施**(照事前判据执行)

预登记 §4 的那一格:**1.5×–3× ⇒ RECORDED,不实施** ——
理由也是**事前**写好的:"**间隔太窄的阈值等于把两个算例硬编码进库里**",
而样本只有 **4 个矩阵**。

**2.60× 不说成"够接近"。** 3× 这个门槛正是为防这一手而设,
且它的理由(4 个样本)一点没变。
**同理,不再去试更多统计量直到某个凑够 3×** —— 那正是这个门槛要防的过拟合。

⇒ **先验探测器路线否决;(B) 自适应回退登记为下一轮。**

## 3. ★ 但 S3 有物理意义,值得留给将来

`theta = 0.25` 下**强连接占比**:2.5-D 是 **17–22 %**,3-D 是 **56–57 %**。
这不是数字巧合,是两类网格的**真实区别** —— 拉伸网格上大多数连接是弱的
(z 向与面内量级差得远),各向同性网格上多数是强的。
**它同时解释了默认 theta = 0 为什么在 2.5-D 上灾难性**:
把 78–83 % 的弱连接当成强连接来聚合。

⇒ **若将来有更多网格族(RAE2822、圆柱、翼身、更多层级),S3 是该重访的统计量** ——
届时阈值能放在有真实余量的位置。**登记为条件性重开项。**

## 4. 下一轮:(B) 自适应回退(需使用者裁决是否现在做)

内容:先用默认建 AMG;若该矩阵的 CG/GMRES 迭代超阈值,则用 `evolution` 重建并**缓存该选择**。
代价:动 `newton.py` 的重建逻辑、每矩阵多付**一次**慢求解、并引入状态
(而 `build_amg_preconditioner` 的 docstring 保证逐位可复现 —— 缓存必须**不破坏**它,
否则 G3.3 的"M∞→0 逐位等于 Laplace"门会受影响。**这是那一轮的主要设计约束。**)

## 5. 现状小结(GS3.2 三轮合计)

* **(前提)** 归因成立但审计的理由错:306:1 是**面内**梯度,二维一样有;病因是 z 层与它相乘;
* **(b)** 根因是 **pyamg 默认 theta = 0.0,对各向异性全盲**;2.5-D 上 **278 → 6 次、总时间 4.20×**
  (真矩阵已验证,且与纯 Laplace 数字几乎相同 ⇒ **起作用的各向异性是几何的**);
  **但 3-D 上默认已最优,换了慢 2.1×** ⇒ 无全局赢家;
* **(c)** 先验探测器**不可分到 3×** ⇒ 不实施,(B) 待裁决;
* **(a)** 真二维路径:**推迟不取消**,价值已收窄为 DOF 减半 + 单元 3× 少。
