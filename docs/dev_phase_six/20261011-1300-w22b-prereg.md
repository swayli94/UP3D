## 1. 目的

让两条精确跨声速算例(C05 准一维喷管 = 唯一带激波的精确解;C08 Ringleb =
唯一 2-D 跨声速精确解)各增加一条**生产配置腿**(`solve_newton_nonlifting`,
熵修正 ON、m_cap 在位、钳制记账在位),与既有 DuctSystem 腿**并列** —
— DuctSystem 腿保留为对照,**不退役**(它是「出厂 kernel + 重写驱动器」
那条路的记录)。

**预先写下的失败标准**:
- 生产腿若**取代**了 DuctSystem 腿(而不是并列)⇒ FAIL(对照没了,归因就没了);
- 若生产腿的判据带比既有腿**宽**而未写明 ⇒ FAIL(不许用生产腿的名义放宽);
- 若 `solve_newton_nonlifting` 的既有行为(A55 的七条)因此改变 ⇒ FAIL。

## 2. 改动内容(事前登记)

1. `pyfp3d/solve/newton.py`:非升力入口加**处方 Dirichlet 模式** ——
   参数如 `dirichlet_nodes` / `dirichlet_values`(或等效形状),给出时
   **取代** farfield 默认;与 wc=None 以外的 lifting 形状互斥(显式报错)。
   只允许加分支,lifting 与远场非升力路径的既有运算零改动(位相同守卫沿用)。
2. C05/C08 各加**一条生产腿**:`solve_newton_nonlifting(mesh, m_inf=…,
   dirichlet=(inlet∪outlet 节点, 精确解 φ 值))`,熵修正 ON、m_cap/m_crit 默认、
   `precond` 用生产默认(amg);物理判据与既有腿**同带** ——
   新带需要标定时按实测**事前登记**再设(见 §3-C2),不借既有带的名义放宽。
3. 证据:C05/C08 的 `summary.csv` **各增生产腿行**(既有行逐位不动,
   证据锁自证);INDEX.md 与门 docstring 同步写明「精确解从本轮起也经过
   生产驱动器」。
4. A55 扩一条机制腿:处方 Dirichlet 模式下的 sphere(或小块) sanity —
   指定值真的被压在指定节点上(读残差/边界值断言),且与 farfield 默认互斥报错。

## 4. kill criterion

- 若生产配置下精确解的读数**变差**到出带(例如熵修正/钳制介入了喷管激波)
  ⇒ **停**:这是 m_cap/熵修正在精确解上的代价,**如实记录为生产配置的已知
  代价**(进 docstring 与能力边界文书草稿),不许把带放宽到能过;
- 若处方 Dirichlet 与远场默认在同一算例上给出不同答案(本该等价的情形)
  ⇒ 停,实现错了。
