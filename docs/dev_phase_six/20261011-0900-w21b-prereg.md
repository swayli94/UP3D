## 1. 目的

ASME V&V 20 的 `u_val² = u_num² + u_D²` 里,本项目此前只量了 `u_D`。
W2.1a 把 `u_num` 量出来了(RECORDED)。本轮把它**接进判据**:
D05/D06 的每条设门腿,判据从「`|S − D|` ≤ 标定带」改写为
「`|S − D|` ≤ **min(标定带, u_val)**」,并让每条腿**报告自己的不确定度与判定体制**。

**预先写下的失败标准**:
- 改写让任何一条腿的**实际带变宽**而未逐条列明 ⇒ FAIL(覆盖回退不许静默);
- 把模型形式误差(跨声速 FP vs Euler 的熵产生,熵修正正是为它存在)算成
  离散缺陷而让一个**已归因**的腿变红 ⇒ FAIL(kill criterion,见 §4);
- 参照侧与我侧不用同一把尺(误差棒口径不同)⇒ FAIL。

## 2. 设计(事前写死)

1. **同一把尺**:`u_num = |S_coarse − S_medium|`(我侧最细一档差),
   `u_D` = 参照侧各档极差(现有仪器)—— 两侧都是「最细区间差」口径,
   与参照侧 `error_bar` 的定义逐字一致。**不用 Richardson 外推**
   (阶在多半腿上读不出来;外推会把不可判写成可判)。
2. **体制三分**(每腿):
   - `u_num` UNDEFINED(W2.1a 判定 `no/unstable/undefined/not_converged`)→
     **带 = 现行标定带**,腿标 `no-bar`(没有误差棒的锁,散文里写明);
   - `u_num` 有定义且 `u_val ≤ 标定带` → **带收紧到 u_val**,腿标 `tightened`;
   - `u_num` 有定义且 `u_val > 标定带` → **带保持标定带**,腿标 `floor`
     (组合不确定度比标定还宽 ⇒ 标定带仍然管事,但要把这件事说出来)。
   ⇒ **任何腿的实际带永不因本轮变宽**(min 语义),覆盖只增不减。
3. **每腿在 `grid_convergence_ours.csv` 里新增列**:`u_num`、`u_D`、`u_val`、
   `regime`(`in-uncertainty` | `resolved-model-error {n}×` | `no-bar` | `floor`)。
   其中 `resolved-model-error` = |S−D| > u_val 且 u_val 有定义 —— 那是**判定**,
   不是红:跨声速腿预期落这里(模型误差被分辨出来 = V&V 的正经产出)。
4. **G-TEETH(行为验证,零求解)**:
   (a) 扰动 committed medium 值 ⇒ 锁红(既有,回归);
   (b) 把 committed **coarse** 值喂成扰动副本 ⇒ `u_num` 动 ⇒ 带动 ⇒
       要求带**跟着动**(F06 式「改来源、值跟着动」;不是恒真);
   (c) 抽掉 coarse 行 ⇒ 该腿退回 `no-bar` 且带 = 标定带(机制验证)。
5. **判据实现位置**:判定函数进 `tests/D/_grid_convergence.py`(与仪器同处),
   门文件只断言。`D05` 开始读参照的 `grid_convergence.csv`(u_D),D06 已有。

## 4. kill criterion

若收紧后**已归因的跨声速腿**变红(模型形式误差被当成离散缺陷)⇒ **停**,
那条腿的判据形状改为 RECORDED(分辨倍数),不硬收;登记,下一轮再定。
若 D05 读参照 `grid_convergence.csv` 发现参照的 u_D 口径与我侧不一致
(例如参照的 error_bar 是 Richardson 外推而我侧是最细差)⇒ 停,先统一口径,
不许混着比。
