## 0. ★★★ 先更正一处：**快层「100% 自锚定」这个数，我用错了地方**

使用者的反问：**「快层不算 A 类吗？」** —— 这个反问是对的，而它抓到的正是本项目记过五次的那族错误。

我量的是**一件事**：五个快层文件里，**有没有代码真的加载 `reference_data`**（答案：0）。
我随后让它代表了**另一件事**：**这五个文件不属于 A 类**。
★★★ **那是两个不同的量。** 「没有外部参照」≠「不是功能模块验证」——
A 类的定义是「**非物理正确性方面的数值正确性**」，而**一条不需要真值的机制/收敛/健壮性断言，正是 A 类**。

逐个看，结论是**快层每个文件都是混合体**：

| 快层文件 | 它断言的东西 | 类 |
|---|---|---|
| `test_seed_fallback` (70.2 s) | 冷启动回退在**三条件同时成立**时触发一次并恢复 —— 一条**控制流合约** | ★ **A** |
| `test_s1_m1a_envelope` (11.9 s) | 三级 cl **单调 + 收缩比 < 0.7 + 末步 < 5 %** —— **无需真值的网格收敛性质** | ★ **A** |
| `test_p8_newton` (134.8 s) | ① Newton 路径收敛/不钳制 → **A**；② M6 的 cl / M_max / 激波位置**对已提交数值** → **X** | **A + X** |
| `test_b9_wingbody_conforming` (15.1 s) | ① B8 失升检测器**会响** → **A**；② 交接区载荷**数值** → **X** | **A + X** |
| `test_b32_...transonic` (508.1 s) | ① M0.84**达到**、**0 钳制** → 健壮性 **E/A**；② `cl_p 0.2738` → **X** | **A/E + X** |

⇒ ★★★ **真正的结论比我原来那句强，而且更有用**：
**门的类别是「断言」的属性，不是「文件」的属性。**
现在一个文件里混着 A 与 X 两类断言，所以**任何按文件归类的做法都必然出错** —— 我就错了一次。

★★ **这条直接是给重建的设计原则**：
**一个文件 = 一类门。** 拆开之后，A 类的那半可以进快层（便宜、无需真值、天天跑），
X 类的那半等 D 类原料到位后升格为 D（见 §4）。
现在它们绑在一起，所以**便宜的机制检查被 508 s 的算例拖着跑**。

## 4.6 ★★★ 两条裁决已入账，以及**实验攻角带来的偏置（方向已知，先写下来）**

### 裁决一（已采纳）：判据形状

**(a) 激波位置 · (b) 激波前 Cp · (c) cl 设门；(d) 激波后 Cp 只 RECORDED 不设门。**
理由（使用者确认）：等熵 + 无旋在**激波处**产生**真实的模型差**，熵修正就是为此存在 ——
写成「七站 Cp 逐点之差」会**把已知的模型差当缺陷**。

### 裁决二（已采纳）：**对实验一律用实验攻角，不修正**

★★★ **而这条裁决把一个偏置引进了「对实验」那一侧，方向是已知的，必须事前写下来** ——
否则第一次读到它的人会把它当缺陷（这正是裁决一要防的同一件事，只是换了个位置）。

**机制**：实验是**有粘**的，粘性位移使翼型有效弯度下降（decambering），
并把激波**推向上游**。无粘解在**同一个 α** 上因此
**升力偏高**、**激波偏下游**。

**本项目自己的数已经能给它定量**（都是已提交的测量，不是估计）：

| 量 | 实测 | 出处 |
|---|---|---|
| cl：粘性耦合打开后的变化 | **−2.20 %**（`cl_KJ`）/ −2.40 %（`cl_p`），M6 medium | GV5.3 |
| ⇒ 无粘在同一 α 上**高**约 | **~2 %**（M6 medium 量级） | 同上 |
| 激波位置：**松**粘性耦合仍落在实验下游 | **0.06–0.10 c**，且随 M/α **变差** | GV5.2（RAE2822 P1/P2） |
| ⇒ **无粘**的下游偏置**不小于**这个数 | ≥ 0.06 c（方向确定，量级下界） | 由上一行推得，**未直接测** |
| 七站 Cp RMS：无粘模型地板 | **0.0516–0.0707** | M3a（四点全尺度加密序列） |

★★ **所以两侧的门要分开写，这是两条裁决合起来的直接推论**：

| 对比对象 | α 的歧义 | 建议 |
|---|---|---|
| **CFL3D Euler**（对我们的**无粘**） | ★ **无歧义** —— 双方都是无粘、同一个 α | **设门**，可以收紧 |
| **CFL3D RANS**（对我们的**有粘耦合**） | 无 α 歧义，但**继承湍流模型的不确定度** | **设门**，容差**不得小于两个湍流模型之间的分歧**（§4.7） |
| **实验**（对我们的**有粘耦合**） | ★★ 带下表那个**已知方向**的粘性偏置 + 风洞效应 | **记录偏置**（裁决三）；若要设门，带宽必须**容纳**偏置，且**门是单侧的** |

★ **裁决三（§4.7）把这张表补全了**：上面这三行就是它的形状 ——
**无粘 → Euler 设门 · 有粘耦合 → RANS 设门 · 有粘耦合 → 实验记录偏置**。

★★★ **而按本季的判据缺陷第 1 条，单侧门必须写出「相反的结果会落在哪里」**：
如果无粘 cl **低于**实验、或激波**偏上游**，那**不是**"更好"，
而是**与已知机制相反**⇒ 应当判**异常并停下来查**，而不是当成通过。
（本项目已有先例：GV5.3 的方向对了但幅度在 A4 输入带以下，如实记为 input-limited 而不是 PASS。）

★★ **这条选项已由裁决三决定**（2026-08-24）：**同时用实验、Euler 与 RANS**，形状见 §4.7。
⇒ α 的歧义**完全不进门，只进记录**。

## 4.7 ★★★ 裁决三（2026-08-24）：**三层参照，按模型层级对齐**

使用者原话：**「对无粘用 Euler 设门，对有粘耦合用 RANS 设门，对有粘耦合用实验记录偏置」**。

★★ **这个设计比我提的更完整，而它对的地方是「模型层级对齐」**：
我们有两个能力模式，各自拿到一个**同层级**的参照，而不是都去比同一个东西。

| 我们的模式 | 参照 | 模型差是什么 | 门 |
|---|---|---|---|
| **全速势（无粘）** | **Euler** | 等熵 + 无旋 vs 允许熵增/涡量 —— **一个机制，在激波处** | ★ **设门** |
| **全速势 + IBL（有粘耦合）** | **RANS** | 积分 BL vs 解析 BL、**湍流模型**、转捩处理、分离建模 —— **多个机制** | ★ **设门**（但见下） |
| **全速势 + IBL** | **实验** | 上面全部 **＋ 风洞效应**（壁面干扰、α 歧义、Re、转捩位置、模型变形） | **记录偏置** |

### ★★★ 一处**不对称**，必须事前量清 —— 否则第二道门继承一个没有边界的不确定度

两个模型差**不是同一种东西**：

- **FP ↔ Euler** 差在**一个已知机制**（激波处的熵/涡量），位置与方向都清楚，
  而本项目的熵修正**正是为它而存在**（S1b 实测它把 M0.80 的激波**移进** Euler 锚点带）。
- ★★ **FP+IBL ↔ RANS** 差在**好几个机制**，其中最要紧的一个是：
  **湍流模型是一个自由选择，而不同湍流模型之间的分歧，可能大于我们想门住的那个量。**

⇒ **本项目已经吃过这个教训，而且是记录在案的**：GS4.1 第 15 轮把 E-CF **从门降为 RECORDED**，
理由逐字是「**那两条相关式自身的适用范围在本仓库没有可引用出处** ⇒
平板的红**不能归因**于闭合」。**一个参照的不确定度没有边界，它就不能用来归因。**

### ⇒ 因此 RANS 的请求要加一条：**同一工况给两个湍流模型**

**至少两个**（如 SA 与 SST）。两者之间的**分歧就是这道门的分辨底噪** ——
低于那个差值的判据**在原理上无法判别**，只能报 UNDEFINED。
★ 这与本项目已在用的 **A4 输入带 2.5 %** 是同一个逻辑：**先定底噪，再定容差**。
★ NASA 的 CFL3D 验证算例本来就常同时给 SA 与 SST，所以这不是额外负担。

### ★★ 三层参照合起来的真正收益：**误差可以分解**

这是本项目**一直做不到**的事：

| 差 | 归谁 |
|---|---|
| **FP − Euler** | 我们的无粘离散 + FP 模型误差 |
| **(FP+IBL) − RANS** | **我们的粘性耦合误差** + 积分 BL 的模型误差 |
| **RANS − 实验** | RANS 自身模型误差 + 风洞效应（**不归我们**） |
| （FP+IBL） − 实验 | 以上之和 —— **这就是现在唯一能看到的量** |

★★★ **具体价值**：`M3a` 的「无粘模型地板 **0.0516–0.0707**」当初是靠**四点全尺度加密序列**
反推出来的 —— **正因为没有一个处在正确模型层级的参照**。有了 Euler 与 RANS，那个数变成**直接可归因**。
同理 GV5.2 / GV5.3 的 honest FAIL（「松位移反馈太弱」）也才能分清：
**是我们的 IBL，还是 FP 的无粘内核**。

### ★★ RANS 数据的额外要求（在 §4.4 六项之外）

1. ★★★ **湍流模型明确写出，且同一工况至少两个模型**（分歧 = 分辨底噪）。
2. ★★ **转捩处理必须与我们对齐或明确说明**：Track V 是**显式指定 x_tr**
   （RAE2822 用 x_tr/c = 0.03，M6 用 0.05；`naca0012_viscous_xfoil` 有 **xtr005 / xtr030** 两套）。
   RANS 若是**全湍流**，那是**另一个物理问题** —— 可以用，但必须写明，且它的偏置要单列。
3. **边界层必须解析**（给出壁面 y+ 与法向首层间距）。★ 一个没解析 BL 的 RANS 结果**不是参照**。
4. **Re 必须对齐实验**：NACA0012 = **3e6 / 6e6 / 6.5e6**（随工况）、
   RAE2822 = **6.5e6**、M6 = **11.72e6**（都从已提交文件读出，非转述）。
5. **cd 分解**：给出压差阻力与摩擦阻力 —— ★ **阻力目前完全没有任何参照**，
   而 FP+IBL 是能给出它的，这是一条新的能力轴。

## ★★★ 勘误 2026-08-25：**「B 类缺锯齿度量」这条建议是错的 —— 它早就存在**

我在 §上文写过：

> 「而**锯齿**本身没有度量。现有 P6 测的是恢复算子的**性质**，不是「锯齿减少了多少」
> ⇒ 建议补一条 B 类的振荡度量门」

**实测为假。** `pyfp3d/post/section_cut.py:304` 有 **`cp_oscillation_metric`**（G6.1 表面 Cp 光滑度度量），
`tests/B/test_B03_cp_metric.py` 用 **7 条**锁着它。而且它**比我打算写的更细**：

- 它**专门把 2 格锯齿与激波的真实陡升分开** —— 只在**斜率反号**的内点上取二阶差分；
  ★ 我打算写的「二阶差分范数」正是它 docstring 里点名否掉的做法：
  *"a plain second-difference RMS **counts the shock foot too** and is confounded when the
  operator moves the shock"*；
- 归一化用**整段长度**而非反号点数，免得单个激波扭结被放大；
- 根因也早已定：**逐三角形梯度恢复的产物，不是人工密度通量** —— 节点平均让该度量**降 ~330×**
  （2026-07-08）。

★★★ **我为什么会说错**：我在归类时只看了 P6 那两个测试的**名字**
（`test_p6_recovery` / `test_p6_cp_metric`），**没读实现**。
⇒ 这是本季反复记的「**提到 ≠ 使用**」的一个变体：**「名字 ≠ 内容」**。
**推荐补一个已存在的东西，比漏掉它更糟** —— 它会让人花时间造重复品。

### 那么 B05 真正缺的是什么（实测）

`cp_oscillation_metric` **只被合成曲线锁着**（B03 自己写 *"no solve required"*）；
在**真实求解**上用它的只有 `cases/demo/p4_transonic/run_demo.py` —— 一个 **demo，不在任何测试收集里**。

⇒ 空缺不是「没有度量」，而是：
**没有任何门保证「生产的恢复方法在真实非结构网格上把锯齿压住了」。**
度量有、算子有、根因清楚、330× 的改善也测过 —— **但那个改善没有锁**。
恢复方法哪天退回未平滑，**B03 照样全绿**（它测的是合成曲线上的度量本身）。

⇒ **B05 重新定义**（使用者 2026-08-25 同意）：在**真实网格的真实解**上，用**已有的**
`cp_oscillation_metric`，比较 `smooth_passes=0`（未平滑）与生产值，断言生产把度量压到某个带以下。
★ 带**由本轮实测定**，**不引用那个 330×** —— 它是 2026-07-08 在**另一个算例**上的读数，
而「同一个量在不同算例上的值」正是本项目记过五次的那族错误。

## ★★★ 平滑的适用面 —— 使用者裁决 2026-08-25，**按「被积分的是什么」划界**

我原先把「平滑」当成一个全局开关来讨论，那是错的。使用者划出的界是**按量划的**：

| 量 | 平滑 | 理由 |
|---|---|---|
| **翼型/机翼表面的总升力** | ★ **不平滑** | 那是**对整个曲面的积分**，±锯齿的抵消**天然成立**；平滑只会引入额外误差。这与 G6.3 的实测一致（开平滑把 `CL_p` 从 2.40 % 劣化到 3.35 %，因为它抹掉前缘吸力峰） |
| **截面压力分布的提取** | ★★ **需要平滑** | 截面切割是一条 **1-D 切线，没有配对**；非结构网格展向既不均匀也不对称时会**系统性偏采某一号** ⇒ **抵消不成立** |
| **截面升力系数** | ★★ **需要平滑** | ★ 它**由截面压力分布积分而来** ⇒ 与截面 Cp **同侧**。我上一版只想到 Cp 曲线，漏了这一条 |

### 实测支持这个机理（2026-08-25）

未平滑的锯齿度量：**NACA0012 2.5-D（拉伸网格，展向均匀）0.064** vs
**M6 coarse（真三维，展向不均匀）中位 ~0.17** ⇒ **约 2.7×**。
⇒ 「展向不均匀 ⇒ 截面偏采一号」**在数上成立**。
★ 而平滑在真三维上远没有 2.5-D 有效（**1.7–4.2×** vs **427×**），且 **2 遍常比 1 遍差**（非单调）。

### ★★ 而它**不是当前的瓶颈**，这一条也是实测的，且使用者确认

对实验的合并 RMS：**0.40561 → 0.40373（sp=1）→ 0.40557（sp=2）** ⇒ 改善 **0.46 %**，
且 **7 站里 3 站变差**。⇒ **锯齿是真的、可测的、真三维上更严重的 —— 但不是 Cp 对比误差的主导项。**

★★★ **登记项（使用者 2026-08-25）**：
> 「在我们解决其他本质问题的时候，也应该把光滑的影响考虑进来，
> 或者说，**至少在解决其他本质问题之后得把平滑引入回来**。」

⇒ 这条**不是「以后再说」，是一个有触发条件的登记项**：任何一次**降低了 Cp 对比主导误差**的工作
（Euler/RANS 参照到位、LE 带那 70 %、模型形式误差被分离出去）之后，
**必须重新评估平滑的影响** —— 因为它现在被淹没，不代表它以后仍被淹没。

★ 而**现在就要做的一件**：`section_cp_curve` 的 12 处活调用**没有一处开平滑**，
包括 D 类喂给对比图的那些、以及**截面 cl 的计算路径** ⇒ 按上表，那两类**都该开**。
这是一处**与裁决不符的现状**，不是待办的优化。
