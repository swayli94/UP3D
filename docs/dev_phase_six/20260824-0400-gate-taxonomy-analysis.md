## 0. ★★★ 先更正一处：**快层「100% 自锚定」这个数，我用错了地方**

使用者的反问：**「快层不算 A 类吗？」** —— 这个反问是对的，而它抓到的正是本项目记过五次的那族错误。

我量的是**一件事**：五个快层文件里，**有没有代码真的加载 `reference_data`**（答案：0）。
我随后让它代表了**另一件事**：**这五个文件不属于 A 类**。
★★★ **那是两个不同的量。** 「没有外部参照」≠「不是功能模块验证」——
A 类的定义是「**非物理正确性方面的数值正确性**」，而**一条不需要真值的机制/收敛/健壮性断言，正是 A 类**。

逐个看，结论是**快层每个文件都是混合体**：

| 快层文件 | 它断言的东西 | 类 |
|---|---|---|
| `test_seed_fallback` (70.2 s) | 冷启动回退在**三条件同时成立**时触发一次并恢复 —— 一条**控制流合约** | ★ **A** |
| `test_s1_m1a_envelope` (11.9 s) | 三级 cl **单调 + 收缩比 < 0.7 + 末步 < 5 %** —— **无需真值的网格收敛性质** | ★ **A** |
| `test_p8_newton` (134.8 s) | ① Newton 路径收敛/不钳制 → **A**；② M6 的 cl / M_max / 激波位置**对已提交数值** → **X** | **A + X** |
| `test_b9_wingbody_conforming` (15.1 s) | ① B8 失升检测器**会响** → **A**；② 交接区载荷**数值** → **X** | **A + X** |
| `test_b32_...transonic` (508.1 s) | ① M0.84**达到**、**0 钳制** → 健壮性 **E/A**；② `cl_p 0.2738` → **X** | **A/E + X** |

⇒ ★★★ **真正的结论比我原来那句强，而且更有用**：
**门的类别是「断言」的属性，不是「文件」的属性。**
现在一个文件里混着 A 与 X 两类断言，所以**任何按文件归类的做法都必然出错** —— 我就错了一次。

★★ **这条直接是给重建的设计原则**：
**一个文件 = 一类门。** 拆开之后，A 类的那半可以进快层（便宜、无需真值、天天跑），
X 类的那半等 D 类原料到位后升格为 D（见 §4）。
现在它们绑在一起，所以**便宜的机制检查被 508 s 的算例拖着跑**。

### ★★★ 为什么 CFL3D Euler 这一条能把「不可判」变成「可判」

## 4.6 ★★★ 两条裁决已入账，以及**实验攻角带来的偏置（方向已知，先写下来）**

### 裁决一（已采纳）：判据形状

**(a) 激波位置 · (b) 激波前 Cp · (c) cl 设门；(d) 激波后 Cp 只 RECORDED 不设门。**
理由（使用者确认）：等熵 + 无旋在**激波处**产生**真实的模型差**，熵修正就是为此存在 ——
写成「七站 Cp 逐点之差」会**把已知的模型差当缺陷**。

### 裁决二（已采纳）：**对实验一律用实验攻角，不修正**

★★★ **而这条裁决把一个偏置引进了「对实验」那一侧，方向是已知的，必须事前写下来** ——
否则第一次读到它的人会把它当缺陷（这正是裁决一要防的同一件事，只是换了个位置）。

**机制**：实验是**有粘**的，粘性位移使翼型有效弯度下降（decambering），
并把激波**推向上游**。无粘解在**同一个 α** 上因此
**升力偏高**、**激波偏下游**。

**本项目自己的数已经能给它定量**（都是已提交的测量，不是估计）：

| 量 | 实测 | 出处 |
|---|---|---|
| cl：粘性耦合打开后的变化 | **−2.20 %**（`cl_KJ`）/ −2.40 %（`cl_p`），M6 medium | GV5.3 |
| ⇒ 无粘在同一 α 上**高**约 | **~2 %**（M6 medium 量级） | 同上 |
| 激波位置：**松**粘性耦合仍落在实验下游 | **0.06–0.10 c**，且随 M/α **变差** | GV5.2（RAE2822 P1/P2） |
| ⇒ **无粘**的下游偏置**不小于**这个数 | ≥ 0.06 c（方向确定，量级下界） | 由上一行推得，**未直接测** |
| 七站 Cp RMS：无粘模型地板 | **0.0516–0.0707** | M3a（四点全尺度加密序列） |

★★ **所以两侧的门要分开写，这是两条裁决合起来的直接推论**：

| 对比对象 | α 的歧义 | 建议 |
|---|---|---|
| **CFL3D Euler** | ★ **无歧义** —— 双方都是无粘、同一个 α | **设门**，可以收紧 |
| **实验** | ★★ 带上表那个**已知方向**的粘性偏置 | **RECORDED 为主**；若要设门，带宽必须**容纳**上表的偏置，并且**门是单侧的**（cl 偏高、激波偏下游） |

★★★ **而按本季的判据缺陷第 1 条，单侧门必须写出「相反的结果会落在哪里」**：
如果无粘 cl **低于**实验、或激波**偏上游**，那**不是**"更好"，
而是**与已知机制相反**⇒ 应当判**异常并停下来查**，而不是当成通过。
（本项目已有先例：GV5.3 的方向对了但幅度在 A4 输入带以下，如实记为 input-limited 而不是 PASS。）

★ 一条留给设计的选项，不做决定：若将来要**同时**用实验与 Euler，
最干净的形状是 **「对 Euler 设门，对实验记录偏置」** ——
那样 α 的歧义就**完全不进门**，只进记录。
