# 勘误 2026-09-06(实施当天)

★ 按纪律,**预注册被实施推翻的地方要留痕**,不能事后悄悄改成对的。

## E1 ★★★ A4 曾经是一条**按构造恒真**的判据

原文:「A4 — 层 3 后,`tests/D` 在 **BLAS=1 / 8 / 16 三档都全绿**」。

写它的时候层 2 还是 `setdefault`,外部值会被保留 ⇒ 三档确实是三个不同的东西。
**层 2 后来改成强制覆盖,A4 的前提就被抽掉了,而我没回去看它** ——
现在外部设 1/8/16 都会被库压成 1,**三档跑的是同一个东西**,
所以「三档全绿」按构造恒真,**它不再检验任何东西**。

⇒ 这正是本次审计从头批评到尾的那个形状(F06 的「值等于它自己的来源」),
而它出现在**我自己两小时前写的预注册**里。**改一处设计而不回头重读依赖它的判据**,
是这个错误的产生机制。

**更正后的拆分**(覆盖没有损失,但归属必须写对):

| | 判据 | 谁承担 |
|---|---|---|
| **A4a** | `tests/D` 在**库强制生效下**全绿 | `tests/D` 自己,单档,真判据 |
| **A4b** | **跨档**位相同 | ★ `tests/F/test_F09` —— 它用逃生舱建立**真**对照(实测开逃生舱 2 failed / 关掉 2 passed) |

★ 不写清归属的后果很具体:下一个人会以为「D 类跑了三档、跨线程验证过了」,
而实际上那三档是同一个东西。

## E2 A3 的载体在实施中被换掉,原因是它**没有牙**

原 A3 只说「外部设 8 与 16 跑同一算例必须逐位相同」,**没有规定载体**。
实施时第一版用 coarse M0.50,**G-TEETH 当场失败**(停用固定照样绿);
再测 coarse M0.80/α1.25 与 coarse M0.75/α0,**也都逐位相同**。
⇒ **OPENBLAS 敏感性不是普遍性质**,只出现在那几条病态腿上。
载体改为 **medium M0.80/α1.25 @ `n_newton_max = 80`**(判位相同,与收敛无关)。
⇒ **预注册里「判据」写了而「载体」没写,就等于没规定它有没有牙。**
下次写 A 类/F 类判据时,载体与判据要一起预注册。

## E3 归因在实施中被**补做了单变量分离**

§1 的 F1 原本依据的脚本把 `OMP` / `OPENBLAS` / `MKL` **三个一起改**。
分离后:`OMP` 1→8 结果**逐位不变**,`OPENBLAS` 1→8 结果**变**
⇒ **自变量只有 `OPENBLAS_NUM_THREADS`**。F1 的结论不变,
但**在此之前它是未经分离验证的**。
