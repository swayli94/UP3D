## 0. 合并后的四句话

1. ★★ **体系是健康的，而且在三个方面强于常见实践**：三层参照按模型层级对齐、
   "先定参照物的分辨底噪再定容差"、证据锁的四层防静默。两份审计**独立得出同一结论**。
2. ★★★ **最该先修的不是缺口，是仪器**：`tests/D` 有两处在**干净 clone 上硬
   `FileNotFoundError`**（不是 skip）。一个在干净 clone 上会崩的门不是门，
   它让此后所有覆盖讨论都站在流沙上。
3. ★★★ **两份审计独立查到同一个结构缺陷 ⇒ 它排第一位**：**我方的腿没有数值不确定度。**
   参照侧（CFL3D）四档 + observed order + 三分渐近判定；**我方 `tests/D` 全部两档、
   无观察阶、无 GCI**。ASME V&V 20 的 `u_val² = u_num² + u_input² + u_D²` 里，
   **现在只有 `u_D` 被量了**。而工具（F08 的 `implied_order`、参照侧的 `yes/no/unstable`）
   **已经造好了，只是装反了方向**。
4. ★★★ **一个方程层面的失效模式，`design.md` §12 早已登记、落在声明包线内、
   缓解措施未强制、无门检查、而且实测就在**：α = 0 / M∞ 0.86 上**只改初值**得到
   四个各自收敛到 |R| ≈ 3e-13、零钳制的**不同解**。D05 的判据形状**已经是对的**，
   只是工况点停在 M 0.75 —— 延伸到 M 0.82，**medium 今天就是红的**。

## 2. 三处仲裁

### 2.1 `cases/gates/` 是 18 还是 20 —— **18，且这个分歧本身是一条纪律实例**

实测：顶层目录 **18** 个（+ `INDEX.md`），另有 **9** 个嵌套的历史门号子目录
（`C02/G1.3`、`D01/G2.1..G2.5`、`C09/G3.1`、`D02/G3.2`、`D03/G4.1`）。
18 与 20 都不等于 18 + 9 = 27。⇒ **"20" 没有可复算的定义**，本计划一律用 **18（顶层）**，
并在需要时写"18 顶层 + 9 历史子目录"。

★ 这是本项目记过五次的"**两个数不是同一件东西**"的第七个成员（前六：跨 pipeline /
跨档 / 跨线程 / 跨时间 / 跨网格代 / 跨配置）—— **新成员：跨计数定义**。

### 2.2 C 组是 56 还是 66 测试 —— **两个都对，因为它们是两个量**

| 定义 | 值 |
|---|---|
| 源码里 `def test_` 的个数（AST） | **66** |
| `pytest tests/C` 报告的 **passed** | **56**（+ 8 skipped + 2 xfailed = 66） |

⇒ **不是分歧，是缺一个定语。** 本计划一律写成 "**N passed / M defined**"。

### 2.3 `ibl_vs_xfoil_recon.csv` —— 比 K 审说的更糟一档

K 审写"无生产者，证据链断"。复核结果：**无生产者，也无读者**。
全仓唯一引用是 `tests/D/test_D13_ibl_vs_xfoil.py:17` 的一行 **docstring**
（"实测基线（`bench/gate_results/ibl_vs_xfoil_recon.csv`…）"）。
⇒ 它是"**提到 ≠ 使用**"那一族的又一个实例（本季已记：`tip_cap` 在 docstring 里、
F07 把自己的举例当真引用、16 个只写不读的门证据 CSV）。**处置也因此不同**：
不是"补一个生产者"，而是先判"**这个基线还需要吗**" —— 需要就同时补生产者与读者，
不需要就删文件并改 docstring。

## 3. 合并后的体系判断：强在哪里（两份审计的交集）

两份独立审计**都**点名的强项，可以当作已确立的结论：

1. **三层参照按模型层级对齐**（无粘→Euler 设门 · 有粘耦合→RANS 设门 · 对实验只记偏置）——
   AIAA G-077 的"在正确模型层级上比较"，而且**多走一步**：每道门的容差不小于参照自身的
   分辨底噪（RANS 带 = |SST−SA|；激波可分辨性 = 参考自身各档散布；实验采样间距使 5/7 站位
   不可分辨）。
2. **证据锁优于"代码对期望值"式基线比对**：`_gate_evidence.py` 额外防四类静默通过。
3. **能力边界门锁"失败的形状"**（D09/D10），并在断言消息里写"红了意味着好消息"。
4. **诚实性机制是体系级资产**：`classify_failure` 五模式、收敛旗标的线程依赖显式化
   （CSV 带 `n_threads` 列）、三条 strict xfail 全是记录在案的能力限制。
5. ★ A 审单独点名、应当**固化成模板向其他门推广**的一条：
   `test_gate_actually_reads_the_reference` 的**扰动副本行为验证** ——
   喂一份被改过的参考副本，要求读数跟着走。**这是本仓库最好的一条判据模式**，
   它杀死的是 F06 那族"字面量对字面量"与"值等于它自己的来源"的假判据。

⇒ **计划的第一原则：不动这些。** 下面每一条修改都必须保持上述五条不变。
