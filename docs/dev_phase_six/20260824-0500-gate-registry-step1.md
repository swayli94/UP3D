## 3. ★★★ 四个**在 A–F 里没有干净归属**的边界，需要裁决

这一节不是清单，是**四条会影响重编号的裁决点**。我**不擅自决定**，因为文件名会把结论固化。

### ① 整机的「网格收敛性质」，但**没有解析解**

`test_s1_m1a_envelope::test_m1a_three_level_convergence` —— 断言三级 cl **单调 + 收缩比 < 0.7 + 末步 < 5 %**。
**无解析解、无参照、无已提交值** ⇒ 它是**纯粹的收敛性质**。

- **A** 排除「整体求解器在某个具体算例上」；
- **C** 要求**有解析解**（你的 C 定义把「网格收敛性」放在 C 里，但前提是解析解）；
- **E** 是「答案不许变」，而这条不比任何值。

⇒ **三个选项**：(a) 归 **C** 并放宽「C 必须有解析解」；(b) 归 **F**（它确实是产品指标 M1a）；
(c) 新设 **A′「整机数值性质，无真值」**。★ 我倾向 **(a)** —— 收敛阶本来就是 C 的形状（裁决 ③），
只是这条**没有真值可比绝对误差**，那就**只判阶次那一半**。

### ② **模块级**解析解算 A 还是 C

`test_v2_transpiration`（圆柱 Fourier 吹气 vs 解析，4 条）、`test_gs41_closures_2d`
（`CD_ODE_BLASIUS = 0.22052` vs **Blasius**）、`test_v1_ibl3`（自相似解，2 条）——
**有解析真值，但检验的是模块，不是整机**。
⇒ 你的 A 是「功能模块」，C 是「整个求解器 + 解析解」。**它们同时满足 A 的主语和 C 的证据。**
★ 我倾向归 **A**（主语优先：A 的定义是按**被测对象**划的，C 是按**证据**划的；
被测对象是模块 ⇒ A），并在登记表里标注「A（解析证据）」。

### ③ **跨路径一致性**算 A 还是 E

`test_p8_newton::test_newton_subsonic_matches_p3`（Newton vs Picard，γ 到 1e-6、cl 到 0.5 %）、

### 4.1 ★★ 用**目录**承载类别，这样裁决 ⑤ 的分层变成一次路径选择

```
tests/A/  test_A01_kernels_assembly.py ...      未门控套件
tests/B/  test_B01_surface_recovery.py ...      未门控套件
```

★★ **为什么用目录而不是 marker**：分层就成了

**不需要任何 marker 机制，也不会出现「marker 忘了打」这一类失效**。
★ 而且它让「一个文件 = 一类门」**在文件系统层面强制**（裁决 ① 之后我提的那条设计原则）。
